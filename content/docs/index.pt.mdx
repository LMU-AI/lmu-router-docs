faq:
  - q: O que é a LMU AI?
    a: A LMU AI (Large Model Unified) é um relay estável e confiável para as APIs Claude / GPT / Gemini. Uma única chave de API permite usar modelos da Anthropic / OpenAI / Google — além dos principais modelos chineses — dentro do Claude Code, Codex CLI, Cursor, VS Code, OpenCode, Cherry Studio e outras ferramentas de codificação com IA.
  - q: Quais ferramentas a LMU AI oferece suporte?
    a: Claude Code (CLI / desktop / extensão do VS Code), Codex CLI (Mac / Windows / servidor) e Codex desktop, Cursor, Cherry Studio, OpenCode, Hermes Agent, IntelliJ IDEA Kilo Code, CC Switch e mais.
  - q: Preciso de uma chave por ferramenta?
    a: Não. Uma única chave LMU AI funciona em todas as ferramentas suportadas e em ambos os protocolos, Anthropic e OpenAI.
