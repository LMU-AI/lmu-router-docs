faq:
  - q: Qu'est-ce que LMU AI ?
    a: LMU AI (Large Model Unified) est un relais stable et fiable pour les API Claude / GPT / Gemini. Une seule clé API vous permet d'utiliser les modèles Anthropic / OpenAI / Google — ainsi que les principaux modèles chinois — dans Claude Code, Codex CLI, Cursor, VS Code, OpenCode, Cherry Studio et d'autres outils de codage IA.
  - q: Quels outils LMU AI prend-il en charge ?
    a: Claude Code (CLI / bureau / extension VS Code), Codex CLI (Mac / Windows / serveur) et Codex bureau, Cursor, Cherry Studio, OpenCode, Hermes Agent, IntelliJ IDEA Kilo Code, CC Switch et plus encore.
  - q: Ai-je besoin d'une clé par outil ?
    a: Non. Une seule clé LMU AI fonctionne dans tous les outils pris en charge ainsi qu'avec les protocoles Anthropic et OpenAI.
