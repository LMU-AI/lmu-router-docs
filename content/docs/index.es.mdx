faq:
  - q: ¿Qué es LMU AI?
    a: LMU AI (Large Model Unified) es un relay estable y confiable para las API de Claude / GPT / Gemini. Una sola clave de API te permite usar los modelos de Anthropic / OpenAI / Google — además de los principales modelos chinos — dentro de Claude Code, Codex CLI, Cursor, VS Code, OpenCode, Cherry Studio y otras herramientas de IA para programar.
  - q: ¿Qué herramientas admite LMU AI?
    a: Claude Code (CLI / escritorio / extensión de VS Code), Codex CLI (Mac / Windows / servidor) y Codex de escritorio, Cursor, Cherry Studio, OpenCode, Hermes Agent, IntelliJ IDEA Kilo Code, CC Switch y más.
  - q: ¿Necesito una clave por cada herramienta?
    a: No. Una sola clave de LMU AI funciona en todas las herramientas admitidas y en ambos protocolos, el de Anthropic y el de OpenAI.
