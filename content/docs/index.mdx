## 开放 API

| API | 用途 |
|------|------|
| [Gemini 生图 API](/docs/api/gemini-image) | Gemini 原生文生图、图生图，支持 1K / 2K / 4K |
| [GPT 生图 API](/docs/api/gpt-image) | `gpt-image-2` 文生图和图片编辑，通常返回 Base64 |
| [Grok 生图 API](/docs/api/grok-image) | Grok 文生图和图片编辑，通常返回临时图片 URL |
| [Gemini 批量生图 API](/docs/api/gemini-image-batch) | 当前仅 Gemini；异步提交多条提示词，查询明细，下载单图或 ZIP |
| [导出 Usage 使用明细](/docs/api/usage-export) | 自动化导出请求、token 和费用明细 |
