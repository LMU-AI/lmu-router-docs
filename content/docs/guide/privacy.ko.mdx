이 페이지는 LMU AI가 사용자 데이터를 처리할 때 따르는 원칙을 설명합니다. 우리는 "최소 저장, 격리, 투명성"을 데이터 처리의 세 가지 기본 원칙으로 삼습니다.

## 우리가 처리하는 데이터

우리는 데이터를 **계정 데이터**와 **요청 데이터**의 두 가지 범주로 나눕니다. 두 가지는 완전히 다른 방식으로 처리되고 저장됩니다.

### 계정 데이터

| 유형 | 내용 | 목적 |
|------|------|------|
| 신원 정보 | 이메일, 전화번호 | 로그인, 비밀번호 복구, 알림 |
| 결제 정보 | 요금제, 할당량, 주문 기록 | 청구 및 인보이스 |
| 자격 증명 정보 | API 키(암호화 저장), 로그인 세션 | 인증 |
| 사용 메타데이터 | 호출 시간, 모델, 토큰 사용량, 소요 시간 | 청구, 통계, 리포트 |

### 요청 데이터

| 유형 | 내용 | 목적 |
|------|------|------|
| 요청 본문 | 사용자가 보내는 프롬프트, 메시지, 매개변수 | 상위 모델로 전달되어 응답 생성 |
| 응답 본문 | 모델이 반환하는 콘텐츠 | 사용자에게 반환 |

**핵심 구분**: 계정 데이터는 플랫폼 자체를 운영하는 데 사용되며, 요청 데이터는 현재의 단일 API 호출을 완료하는 데만 사용됩니다.

## 데이터 저장 위치

우리 인프라는 두 개의 계층으로 구성됩니다:

**액세스 계층(중국 내)**
- 메인 서버, 사용자 데이터베이스, 결제 시스템
- **모든 계정 데이터가 여기에 저장됩니다**
- 사용자의 이메일, 전화번호, 주문, API 키는 절대 중국을 벗어나지 않습니다

**상위 채널 계층(여러 지역, 해외 포함)**
- OpenAI / Anthropic / 등과 같은 모델 제공업체의 공식 인터페이스에 접근하는 데 사용됩니다
- 이 채널들은 **모델 트래픽의 중계 역할만** 하며 사용자 신원 정보를 저장하지 않습니다
- 채널 노드는 사용자 계정을 저장하지 않으며 요청이 어느 사용자로부터 왔는지 알지 못합니다(익명화된 요청 페이로드만 봅니다)

## 로그 보관 정책

| 데이터 유형 | 보관 기간 | 저장 위치 |
|---------|---------|---------|
| 요청 / 응답 본문 콘텐츠 | **저장 안 함** | — |
| 호출 메타데이터(시간, 모델, 토큰, 소요 시간, 상태 코드) | 90일 | 중국 내 |
| 오류 로그(잘린 요청 조각을 포함할 수 있음) | 90일 | 중국 내 |
| 계정 및 주문 데이터 | 계정 수명 기간 동안; 해지 후 30일 이내 삭제 | 중국 내 |

**요청 콘텐츠에 관하여**

- 우리는 **사용자의 프롬프트나 응답 콘텐츠를 저장하지 않습니다** — 요청이 전달되면 메모리에서 해제되며 어떤 데이터베이스나 파일에도 기록되지 않습니다
- 상위 채널이 오류를 반환하면 오류 로그에 **잘린 요청 조각**(문제 재현에 사용)이 포함될 수 있으며, 이 데이터는 90일 후 삭제됩니다
- 오류 로그는 어떤 모델도 학습하는 데 사용되지 않으며 사람이 능동적으로 검토하지 않습니다; 문제 해결 지원이 필요한 티켓을 제출하는 경우에만 관련 엔지니어가 접근합니다

<Callout type="info" title="엔터프라이즈 등급용 선택형 감사 로그">

엔터프라이즈 고객은 감사 로그 기능을 선택적으로 사용하고 회사의 컴플라이언스 요구 사항에 따라 요청 / 응답 데이터를 보관할 수 있습니다. 활성화되면 로그는 암호화되어 저장되며, 접근 권한은 회사 관리자가 제어할 수 있습니다. 자세한 내용은 [엔터프라이즈 요금제](/ko/docs/enterprise)를 참조하세요.

</Callout>

## 국경 간 데이터 전송

상위 모델(Claude, GPT 등)의 서버가 해외에 위치하기 때문에, **API 호출의 요청 및 응답 본문은 전달 과정에서 해외 채널을 거칩니다**. 이는 해외 대규모 모델 API에 접근하는 모든 중계 서비스에 필요한 기술적 경로입니다.

이 단계에서의 우리의 약속:

- **해외 노드에 어떤 데이터도 저장하지 않습니다**: 채널은 전달만 하며, 전달이 완료되는 즉시 메모리가 해제됩니다
- **사용자 신원을 담지 않습니다**: 상위 채널이 보는 요청에는 이메일, 전화번호, 주문 연관 정보와 같은 계정 필드가 이미 제거되어 있습니다
- **암호화 전송**: 사용자 ↔ 액세스 계층, 액세스 계층 ↔ 상위 채널, 상위 채널 ↔ 모델 제공업체 모두 종단 간 TLS 1.2+입니다
- **제3자와 공유하지 않습니다**: 현재 호출을 완료하는 데 필요한 상위 모델 제공업체를 제외하고, 사용자의 요청 콘텐츠를 어떤 제3자에게도 전달하지 않습니다

<Callout type="warn" title="민감한 데이터에 관한 권고">

요청 콘텐츠는 모델 제공업체에 도달하기 위해 해외 채널을 거쳐야 하므로, **국가 기밀, 영업 비밀, 개인 신분증 번호와 같은 고도로 민감한 데이터가 포함된 요청을 API를 통해 보내지 마세요**. 이러한 컴플라이언스 요구 사항이 있는 경우 영업팀에 연락하여 온프레미스 배포 또는 컴플라이언스 채널에 대해 상의하세요.

</Callout>

## 우리가 하지 않는 것

- 사람의 분석, 상업적 분석 또는 모델 학습을 위해 사용자의 프롬프트나 응답 콘텐츠를 **읽지 않습니다**
- 사용자의 어떤 데이터도 제3자에게 **판매하지 않습니다**
- 사용자에게 알리지 않고 요청 및 응답 콘텐츠를 **보관하지 않습니다**
- 계정 데이터를 국경 간 이전하지 않습니다(계정 데이터는 중국 내에서만 저장됩니다)

## 보안 관행

- API 키는 데이터베이스에 암호화되어 저장되며, 앞뒤 몇 글자만 표시됩니다
- 데이터베이스에 접근하는 모든 내부 작업은 감사 로그로 기록됩니다
- 주요 변경 사항(요금제, API 키 재설정, 출금 등)은 이메일 / SMS 알림을 트리거합니다
- 프로덕션 데이터에 접근하는 팀원은 승인 절차와 최소 권한 원칙을 거쳐야 합니다
