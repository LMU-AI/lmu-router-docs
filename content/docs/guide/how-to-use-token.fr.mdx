## Types de tokens

| Type | Description |
|------|------|
| Token personnel | Lié à votre compte, utilise votre quota |
| Token de canal | Attribué par un administrateur, avec une gestion de quota indépendante |

## Consulter l'utilisation

Rendez-vous dans **console → Statistiques d'utilisation** pour consulter :

- Le nombre d'appels par jour / mois
- La consommation de tokens
- La répartition des coûts
- La part d'utilisation par modèle

## Limites de quota

Lors de la création d'un token, vous pouvez définir les limites suivantes :

- **Quota total** : le quota maximal que ce token peut consommer (laisser vide pour aucune limite)
- **Requêtes par minute** : protection par limitation du débit
- **Liste blanche de modèles** : restreindre ce token à l'appel des seuls modèles spécifiés

## Réinitialiser et révoquer

- **Réinitialiser le quota** : vous pouvez réinitialiser manuellement le quota utilisé sur la page de gestion des tokens
- **Révoquer un token** : la suppression d'un token prend effet immédiatement ; les requêtes déjà envoyées ne sont pas affectées
