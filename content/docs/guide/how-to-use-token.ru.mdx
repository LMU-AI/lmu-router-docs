## Типы токенов

| Тип | Описание |
|------|------|
| Личный токен | Привязан к вашей учётной записи, использует вашу квоту |
| Токен канала | Назначается администратором, с независимым управлением квотой |

## Просмотр использования

Перейдите в **консоль → Статистика использования**, чтобы просмотреть:

- Количество вызовов по дням / месяцам
- Потребление токенов
- Разбивку по расходам
- Долю использования по моделям

## Лимиты квоты

При создании токена вы можете установить следующие лимиты:

- **Общая квота**: максимальная квота, которую может потребить этот токен (оставьте пустым, чтобы без ограничений)
- **Запросов в минуту**: защита с помощью ограничения частоты
- **Белый список моделей**: ограничить этот токен вызовом только указанных моделей

## Сброс и отзыв

- **Сброс квоты**: вы можете вручную сбросить использованную квоту на странице управления токенами
- **Отзыв токена**: удаление токена вступает в силу немедленно; уже отправленные запросы не затрагиваются
