## Token-Typen

| Typ | Beschreibung |
|------|------|
| Persönliches Token | An dein Konto gebunden, verwendet dein Kontingent |
| Kanal-Token | Von einem Administrator zugewiesen, mit unabhängiger Kontingentverwaltung |

## Nutzung ansehen

Gehe zu **Konsole → Nutzungsstatistik**, um Folgendes anzusehen:

- Aufrufzahlen nach Tag / Monat
- Token-Verbrauch
- Kostenaufschlüsselung
- Anteil der Nutzung nach Modell

## Kontingentgrenzen

Beim Erstellen eines Tokens kannst du die folgenden Grenzen festlegen:

- **Gesamtkontingent**: das maximale Kontingent, das dieses Token verbrauchen kann (leer lassen für kein Limit)
- **Anfragen pro Minute**: Schutz durch Ratenbegrenzung
- **Modell-Whitelist**: dieses Token darauf beschränken, nur die angegebenen Modelle aufzurufen

## Zurücksetzen und Widerruf

- **Kontingent zurücksetzen**: Du kannst das verbrauchte Kontingent auf der Token-Verwaltungsseite manuell zurücksetzen
- **Token widerrufen**: Das Löschen eines Tokens wird sofort wirksam; bereits gesendete Anfragen bleiben davon unberührt
