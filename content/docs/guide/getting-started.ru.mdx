## Шаг 1 — Создайте аккаунт

Перейдите на страницу регистрации: [https://api.lmuai.com/register?ref=vJaWWr4T](https://api.lmuai.com/register?ref=vJaWWr4T)

Введите свой email и пароль, чтобы завершить регистрацию.

## Шаг 2 — Оформите подписку или пополните баланс

После входа нажмите «**Пополнить / Подписаться**» в меню слева:

- **Подписка**: выберите тариф и получите фиксированную месячную квоту
- **Пополнение**: добавляйте баланс по мере необходимости и гибко используйте любую модель

Вы готовы к работе, как только завершится оплата.

## Шаг 3 — Создайте API-ключ [#create-key]

1. Нажмите «**API Keys**» в меню слева
2. Нажмите «Создать ключ» и дайте ему любое имя
3. После создания **сохраните свой API-ключ** (значение, начинающееся с `sk-`)

## Шаг 4 — Настройте свой инструмент

**Базовый URL API:**

Выберите базовый URL, соответствующий протоколу вашего инструмента:

**Протокол Anthropic** (Claude Code, Cherry Studio, Trae, Kilo Code с Claude / китайскими моделями и т. д.):

```
https://api.lmuai.com
```

**Протокол OpenAI** (Codex CLI, Codex App, VS Code / Cursor с GPT, Kilo Code с моделями OpenAI и т. д.):

```
https://api.lmuai.com/v1
```

<Callout type="warn" title="Разница (самая частая ошибка)">

- Протокол **Anthropic** **не** имеет суффикса `/v1`
- Протокол **OpenAI** **обязательно** должен включать суффикс `/v1`

Использование неверного протокола вызывает ошибки 401 / 404. Полные сведения о протоколах, примеры SDK / curl и ограничения групп Claude Max см. в **[Протоколы API →](/ru/docs/guide/api-protocols)**.

</Callout>

Держите под рукой эти три вещи — они нужны для настройки любого инструмента ниже:
- **API-ключ**: ключ `sk-`, созданный вами в консоли (общий для обоих протоколов)
- **Базовый URL Anthropic**: `https://api.lmuai.com`
- **Базовый URL OpenAI**: `https://api.lmuai.com/v1`
