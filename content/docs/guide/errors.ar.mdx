تجمع هذه الصفحة رموز الأخطاء المتناثرة عبر مستندات API الفردية في ورقة مرجعية واحدة. **حدّد أولاً الفئة العامة عبر رمز حالة HTTP، ثم ابحث عن الحل المحدد عبر نص الخطأ الخام.**

<Callout type="info" title="سجّل معرّف الطلب قبل استكشاف الأخطاء">

معرّف الطلب في ترويسات الاستجابة هو أكثر معلومة مفيدة على الإطلاق لتشخيص المشكلة. عند التواصل مع الدعم، أدرِج معرّف الطلب ونص الخطأ الكامل — **لا ترسل مفتاح API الكامل الخاص بك**.

</Callout>

## رموز حالة HTTP

| الحالة | السبب النموذجي | ما العمل |
|---:|---|---|
| `400` | جسم طلب غير صالح، أو مُعامِل، أو معرّف نموذج، أو مسار نموذج؛ تنسيق أو ترميز صورة سيئ | أصلِح الطلب — **لا تكتفِ بإعادة المحاولة**؛ تبديل الحسابات أو إعادة المحاولة لن ينجح |
| `401` | مفتاح API مفقود أو غير صالح أو معطّل؛ Base URL لا يتطابق مع البروتوكول؛ لم يُعَد تشغيل الـ IDE فلا يزال التكوين القديم ساري المفعول | تحقق من المفتاح ومن Base URL (انظر [بروتوكولات API](/ar/docs/guide/api-protocols))، وأعد تشغيل الـ IDE؛ التفاصيل في [المشكلة 3](/ar/docs/guide/faq#issue-3) |
| `402` | رصيد غير كافٍ | اشحن الرصيد أو قلّل حجم العمل |
| `403` | احتمالان، كلاهما ممكن: ① **مجموعة** مفتاح API لا تملك تفعيل توليد الصور؛ ② **رصيد أو اشتراك أو أهلية فوترة أو صلاحية غير كافية** | تأكد أولاً من رصيد الحساب وحالة الاشتراك، ثم تأكد من أن المجموعة تملك القدرة؛ إذا كان كلاهما سليماً واستمر الخطأ، تواصل مع الدعم |
| `404` | عنوان بروتوكول OpenAI يفتقد إلى `/v1`، أو عنوان Anthropic يتضمن `/v1` عن طريق الخطأ، أو Gemini لا يستخدم `/v1beta/models/...`؛ أو أن نقطة النهاية غير مدعومة من المجموعة الحالية | أعد التحقق من Base URL ونقطة النهاية الكاملة مقابل [بروتوكولات API](/ar/docs/guide/api-protocols) |
| `413` | جسم طلب تحويل صورة إلى صورة كبير جداً | اضغط الصورة المُدخَلة |
| `429` | ① نفاد الحصة اليومية؛ ② تقييد التزامن أو RPM أو حصة المصدر الأعلى | لنفاد الحصة انظر [المشكلة 2](/ar/docs/guide/faq#issue-2)؛ ولتقييد المعدل، تراجَع أُسّياً وخفّض التزامن وRPM |
| `500` | خطأ داخلي أو سعة | سجّل رمز الخطأ ومعرّف الطلب، وأعد المحاولة عدداً محدوداً من المرات |
| `502` | فشل مصادقة أو صلاحية أو خدمة المصدر الأعلى مؤقتاً | تراجَع وأعد المحاولة؛ تواصل مع الدعم عند الحاجة |
| `503` | لا يوجد حساب مصدر أعلى متاح أو أن المصدر الأعلى محمّل بشكل زائد؛ قد يكون أيضاً **متغير بيئة يتجاوز المفتاح** | تحقق أولاً من متغيرات البيئة (انظر [المشكلة 6](/ar/docs/guide/faq#issue-6))، ثم أعد المحاولة مع تأخير وحركة مرور أقل |
| `504` | انتهاء مهلة البوابة أو المصدر الأعلى | أعد إصدار الطلب كطلب جديد مستقل |

<Callout type="warn" title="ما الذي يُعاد المحاولة عليه، وما الذي يجب إصلاحه بدلاً من ذلك">

- **لا تُعِد المحاولة**: `400` و`401` وأي خطأ صريح متعلق بالرصيد أو الصلاحية أو المُعامِل أو سياسة المحتوى — فالطلب نفسه غير صالح، وأي حساب مصدر أعلى سيعيد النتيجة ذاتها. يجب أن تصلِح الطلب أولاً.
- **آمن لإعادة المحاولة**: `429` و`502` و`503` و`504`، وانقطاعات الشبكة، وإعادة ضبط الاتصال، ومهلات القراءة — كلها أعطال مؤقتة. استخدم التراجع الأُسّي لعدد **محدود** من المحاولات (يُوصى بـ 2–3) لتجنّب الدفع مقابل استدعاءات متكررة؛ وعند `429` خفّض أيضاً التزامن وRPM.

هذا التصنيف مأخوذ من إرشادات إعادة المحاولة في واجهات API الخاصة بالصور — انظر [Gemini Image · إرشادات إعادة المحاولة](/ar/docs/api/gemini-image#retry-recommendations).

</Callout>

الأوصاف الكاملة للأخطاء لكل واجهة API: [Gemini Image](/ar/docs/api/gemini-image)، [GPT Image](/ar/docs/api/gpt-image)، [Grok Image](/ar/docs/api/grok-image)، [Gemini Batch Image](/ar/docs/api/gemini-image-batch).

## أكواد أخطاء الأعمال (الصور المجمّعة)

إلى جانب رموز حالة HTTP، تُعيد [واجهة Gemini Batch Image API](/ar/docs/api/gemini-image-batch) أيضاً أكواد أخطاء أعمال، تظهر في وحدة التحكم على شكل `error code: BATCH_IMAGE_XXX` مع معرّف طلب.

| رمز الخطأ | HTTP | المعنى | ما العمل |
|---|---:|---|---|
| `BATCH_IMAGE_DISABLED` | 404 | توليد الصور المجمّع معطّل بشكل عام | أرسل رمز الخطأ ومعرّف الطلب إلى المسؤول |
| `BATCH_IMAGE_GROUP_DISABLED` | 403 | مجموعة المفتاح الحالي لا تسمح بالصور المجمّعة أو ليست مجموعة Gemini | غيّر المفتاح أو اطلب من المسؤول تفعيل صلاحية المجموعة |
| `BATCH_IMAGE_NO_ACCOUNT_AVAILABLE` | 502 | لا يوجد مورد تنفيذ مجمّع متاح حالياً | احفظ معرّف الطلب وتواصل مع المسؤول |
| `BATCH_IMAGE_SETTLEMENT_PRICING_MISSING` | 400 | نموذج الدفعة ليس له سعر فوترة | اطلب من المسؤول تكوين سعر النموذج |
| `BATCH_IMAGE_INVALID_MODEL` | 400 | لم يُقدَّم نموذج | استخدم نموذجاً من قائمة نماذج الدفعات |
| `BATCH_IMAGE_INVALID_ITEMS` | 400 | عناصر أو دقة أو حقول طلب غير صالحة | تحقق من جسم الطلب؛ لا يُدعم حالياً سوى 1K |
| `BATCH_IMAGE_DUPLICATE_CUSTOM_ID` | 400 | `custom_id` مكرر | تأكد من أنه فريد ضمن الدفعة |
| `BATCH_IMAGE_PROMPT_TOO_LONG` | 400 | المطالبة طويلة جداً | اختصر المطالبة |
| `BATCH_IMAGE_TOO_MANY_OUTPUT_IMAGES` | 400 | عدد الصور بعد التوسّع يتجاوز الحد | قلّل العناصر أو output_count |
| `BATCH_IMAGE_INVALID_REFERENCE_IMAGE` | 400 | تنسيق أو حجم أو URI صورة مرجعية غير صالح | تحقق من MIME وBase64 وfile_uri |
| `BATCH_IMAGE_INSUFFICIENT_BALANCE` | 402 | الرصيد منخفض جداً لحجز الرسوم | اشحن الرصيد أو قلّل حجم العمل |
| `BATCH_IMAGE_IDEMPOTENCY_CONFLICT` | 409 | نفس مفتاح idempotency يشير إلى جسم طلب مختلف | استخدم Idempotency-Key جديداً |
| `BATCH_IMAGE_PROVIDER_SUBMIT_FAILED` | 502 | فشل إنشاء مهمة الدفعة في المصدر الأعلى | احفظ معرّف الطلب، وأعد المحاولة عدداً محدوداً من المرات، أو تواصل مع المسؤول |
| `BATCH_IMAGE_QUEUE_FAILED` | 502 | خدمة المهام غير المتزامنة غير متاحة مؤقتاً | احفظ معرّف الطلب وتواصل مع المسؤول |
| `BATCH_IMAGE_NOT_READY` | 409 | محاولة التنزيل قبل اكتمال المهمة | انتظر حتى تصبح الحالة completed |
| `BATCH_IMAGE_OUTPUT_DELETED` | 410 | تم تنظيف الناتج بالفعل | لم يعد بالإمكان تنزيله؛ أنشئ المهمة من جديد |
| `BATCH_IMAGE_ITEM_FAILED` | 409 | عنصر المهمة المحدد ليس له صورة ناجحة | تحقق من item.error |
| `BATCH_IMAGE_DOWNLOAD_LIMITED` | 429 | تنزيلات متزامنة كثيرة جداً | أعد المحاولة لاحقاً |

## البحث عبر نص الخطأ الخام

طابِق نص الخطأ الذي تراه فعلياً مع الجدول أدناه وانتقل مباشرة إلى الحل التفصيلي.

| نص الخطأ الخام | المعنى | الحل التفصيلي |
|---|---|---|
| `stream disconnected before completion` | انقطاع البث، عادةً بسبب VPN / بروكسي / بروكسي النظام يبدّل عنوان IP للخروج | [المشكلة 1](/ar/docs/guide/faq#issue-1) |
| `exceeded retry limit, last status: 429 Too Many Requests` | نفاد الحصة اليومية | [المشكلة 2](/ar/docs/guide/faq#issue-2) |
| `401 Unauthorized: Incorrect API key provided` | ما يزال الطلب يذهب إلى نقطة النهاية الرسمية، لا إلى مُرحِّل LMU AI | [المشكلة 3](/ar/docs/guide/faq#issue-3) |
| `running scripts is disabled on this system` (Windows) | قيد سياسة تنفيذ PowerShell | [المشكلة 4](/ar/docs/guide/faq#issue-4) |
| `CODEX is not recognized as a cmdlet` (Windows) | Node.js غير مثبّت أو أن PATH معطوب | [المشكلة 5](/ar/docs/guide/faq#issue-5) |
| `503 No available accounts` | متغير بيئة في الصدفة يتجاوز المفتاح المُكوَّن في الـ IDE | [المشكلة 6](/ar/docs/guide/faq#issue-6) |
| `400 Invalid signature in thinking block` | تبديل النماذج عبر المجموعات في محادثة واحدة؛ تعذّر التحقق من توقيع التفكير | [المشكلة 7](/ar/docs/guide/faq#issue-7) |
| `400 Unknown parameter: 'tools[0].n'` | تم إرسال مُعامِل `tools` عن طريق الخطأ إلى نقطة نهاية صور | [المشكلة 8](/ar/docs/guide/faq#issue-8) |
| `No available accounts` / النموذج غير متاح | استُدعي نموذج خارج النطاق المتاح للمجموعة الحالية | [بروتوكولات API ← استكشاف الأخطاء](/ar/docs/guide/api-protocols#troubleshooting) |

## أخطاء واجهة API لتصدير الاستخدام

تستخدم [واجهة API لتصدير الاستخدام](/ar/docs/api/usage-export) مصادقة JWT، لذا تختلف دلالات أخطائها عن قناة مفتاح API أعلاه:

| الحالة | السبب | ما العمل |
|---:|---|---|
| `401` | انتهت صلاحية JWT | جدّد باستخدام `refresh_token`، أو سجّل الدخول مجدداً |
| `403` | وصول غير مصرّح به (مثلاً الاستعلام عن `api_key_id` ليس ملكك) | تحقق مما إذا كان المفتاح يعود للحساب الحالي |
| `400` | مُعامِل سيئ (مثلاً تنسيق `start_date` خاطئ) | تحقق من تنسيق `YYYY-MM-DD` ومن أن `timezone` صالح |

## ما زلت عالقاً؟

- الحالات المشروحة خطوة بخطوة موجودة في [الأسئلة الشائعة](/ar/docs/guide/faq)
- قواعد Base URL / نقطة النهاية موجودة في [بروتوكولات API](/ar/docs/guide/api-protocols)
- الحماية من سرقة المفتاح موجودة في [أمان المفتاح](/ar/docs/guide/key-security)
- عند التواصل مع الدعم، أدرِج **معرّف الطلب** ونص الخطأ الكامل
