## Tipos de token

| Tipo | Descrição |
|------|------|
| Token pessoal | Vinculado à sua conta, usa a sua cota |
| Token de canal | Atribuído por um administrador, com gerenciamento de cota independente |

## Visualizar uso

Vá até **console → Estatísticas de uso** para visualizar:

- Contagem de chamadas por dia / mês
- Consumo de tokens
- Detalhamento de custos
- Participação de uso por modelo

## Limites de cota

Ao criar um token, você pode definir os seguintes limites:

- **Cota total**: a cota máxima que este token pode consumir (deixe em branco para sem limite)
- **Requisições por minuto**: proteção por limitação de taxa
- **Lista de permissões de modelos**: restringe este token a chamar apenas os modelos especificados

## Redefinir e revogar

- **Redefinir cota**: você pode redefinir manualmente a cota usada na página de gerenciamento de tokens
- **Revogar token**: excluir um token tem efeito imediato; requisições já enviadas não são afetadas
