## Tipos de token

| Tipo | Descripción |
|------|------|
| Token personal | Vinculado a tu cuenta, usa tu cuota |
| Token de canal | Asignado por un administrador, con gestión de cuota independiente |

## Ver el uso

Ve a **consola → Estadísticas de uso** para ver:

- Cantidad de llamadas por día / mes
- Consumo de tokens
- Desglose de costos
- Proporción de uso por modelo

## Límites de cuota

Cuando creas un token, puedes establecer los siguientes límites:

- **Cuota total**: la cuota máxima que este token puede consumir (deja el campo vacío para no tener límite)
- **Solicitudes por minuto**: protección de límite de velocidad
- **Lista blanca de modelos**: restringe este token para que solo llame a los modelos especificados

## Restablecer y revocar

- **Restablecer cuota**: puedes restablecer manualmente la cuota usada en la página de gestión de tokens
- **Revocar token**: eliminar un token surte efecto de inmediato; las solicitudes ya enviadas no se ven afectadas
