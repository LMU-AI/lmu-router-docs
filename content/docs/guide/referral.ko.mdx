친구를 LMU AI에 가입하도록 초대하세요. 친구가 충전하거나 구독할 때마다 계속 커미션을 얻습니다 — 평생 바인딩과 장기적인 수익.

---

## 규칙

- 신규 사용자가 당신의 초대 링크를 통해 가입하면 **평생 당신에게 바인딩**됩니다
- 그들이 충전하거나 구독할 때마다 **10% 장부 커미션**을 얻습니다
- 커미션은 피초대자가 실제로 소비함에 따라 점진적으로 지급됩니다(충전은 잔액 소비 진행도를 추적하고, 구독은 경과 일수를 추적합니다)
- 사용 가능한 커미션은 API 지출을 위해 **계정 잔액으로 직접 이체**하거나, WeChat / Alipay / 은행 카드로 출금할 수 있습니다
- 신규 사용자는 첫 결제 시 추가로 **¥2.00** 보너스를 받습니다

---

## 참여 방법

콘솔에 로그인한 후 왼쪽 메뉴에서 "**추천 보상**"을 클릭하면 전용 초대 링크와 초대 코드를 확인할 수 있습니다.

### 옵션 1: 초대 링크 공유

전용 링크를 복사하여 친구에게 보내세요. 친구가 링크를 클릭하고 가입하면 바인딩이 완료됩니다. 형식은 다음과 같습니다:

```
https://api.lmuai.com/register?ref=YOUR_INVITE_CODE
```

### 옵션 2: 초대 코드 공유

친구에게 초대 코드를 알려주면, 친구가 가입할 때 이를 직접 입력하여 바인딩을 완료합니다.

## 커미션 세부 사항

| 항목 | 설명 |
|------|------|
| 커미션 비율 | **10%** (피초대자의 각 충전 / 구독에 대해) |
| 신규 사용자 보너스 | 첫 결제 시 **¥2.00** |
| 바인딩 방법 | 링크를 통해 가입하면 평생 바인딩이 생성됨 |
| 커미션 지급 | 피초대자가 실제로 소비함에 따라 점진적으로 지급됨 |
| 커미션 사용 | 잔액으로 이체(즉시 사용 가능) 또는 출금 |

## 조회 및 출금

콘솔에 로그인한 후 왼쪽 메뉴에서 "**추천 보상**"을 클릭하면 다음을 확인할 수 있습니다:

- 누적 커미션, 사용 가능한 커미션, 지급된 금액
- 초대한 인원수 및 각 커미션의 내역
- 사용 가능한 커미션을 원클릭으로 잔액에 이체하거나 출금 요청

초대 링크는 홍보 흔적을 숨기므로 공유가 더 자연스럽게 느껴집니다. 콘솔의 "추천 보상" 페이지에서 전용 QR 코드를 다운로드할 수 있어 커뮤니티, 모먼트 등에서 손쉽게 공유할 수 있습니다.
