Ниже перечислены все названия моделей, которые в настоящее время поддерживает LMU AI API. **Нажмите на любую карточку, чтобы скопировать её ID модели**, затем вставьте его прямо в `settings.json`, `config.toml` или в селектор модели инструмента.

<Callout type="info" title="Как использовать название модели">

Вставьте скопированный ID модели в конфигурацию своего инструмента:

- **Claude Code** → поле `"model"` в `settings.json`
- **Codex CLI** → `model = "..."` в `~/.codex/config.toml`
- **Cherry Studio / расширение VS Code** → вставьте в выпадающий список моделей

</Callout>

## Выбор модели по сценарию использования

Не уверены, какую модель использовать? Найдите её в таблице ниже, затем скопируйте ID модели из соответствующего раздела.

| Сценарий использования | Рекомендуемые модели | Почему |
|---|---|---|
| Сложные рефакторинги, крупные изменения по многим файлам | `claude-opus-5` | Флагманский уровень Claude, отлично справляется с кодом и длинными текстами, используется по умолчанию в Claude Code |
| Повседневное кодирование, исправление багов | `claude-sonnet-5` · `claude-sonnet-4-6` | Сбалансированный уровень, компромисс между возможностями и скоростью, идеален для частого повседневного использования |
| Частые лёгкие задачи (автодополнение, форматирование, массовые мелкие правки) | `claude-haiku-4-5` · `deepseek-v4-flash` · `qwen3.6-flash` | Высокоскоростной уровень для простых одиночных задач, вызываемых много раз |
| Инструментальная цепочка Codex CLI / Codex App | `gpt-5.6-sol` · `gpt-5.4` | Новейший флагман со стороны OpenAI и модель по умолчанию в шаблоне конфигурации Codex CLI |
| Письмо на китайском, документация, диалог | `qwen3.8-max-preview` · `glm-5.2` · `kimi-k3` | Китайские LLM с отличным пониманием китайского по более низкой цене |
| Кодирование в китайском контексте | `qwen3.6-plus` · `deepseek-v4-pro` | Ориентированные на код китайские модели, вызываются напрямую с баланса аккаунта |
| Мультимодальные (смешанный ввод изображение + текст) | `mimo-v2-omni` | Единственная диалоговая модель, отмеченная здесь как мультимодальная; для чистой генерации изображений см. API изображений ниже |

<Callout type="warn" title="Прежде чем выбирать, подтвердите две вещи">

- **Доступность модели зависит от группы**: какие модели вы фактически можете вызвать — это то, что показывает страница **Доступные модели** в консоли. Например, для серии GPT требуется подписка GPT либо выбор группы GPT при оплате по факту использования. **Это не зависит от того, каким протоколом вы вызываете.**
- **Base URL должен соответствовать протоколу**: протокол определяется вашим клиентом и SDK — Base URL протокола Anthropic указывается **без** `/v1`, протокол OpenAI **обязан включать** `/v1`, а нативный Gemini использует `/v1beta/models/...`. Ошибка приведёт к прямому 404; см. [Протоколы API](/ru/docs/guide/api-protocols).

</Callout>
