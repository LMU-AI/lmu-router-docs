## 1단계 — 계정 생성

가입 페이지로 이동하세요: [https://api.lmuai.com/register?ref=vJaWWr4T](https://api.lmuai.com/register?ref=vJaWWr4T)

이메일과 비밀번호를 입력하여 등록을 완료하세요.

## 2단계 — 구독 또는 충전

로그인한 후 왼쪽 메뉴에서 "**충전 / 구독**"을 클릭하세요:

- **구독**: 요금제를 선택하고 매월 고정 할당량을 받습니다
- **충전**: 필요에 따라 잔액을 추가하고 어떤 모델이든 유연하게 사용합니다

결제가 완료되는 즉시 사용할 수 있습니다.

## 3단계 — API 키 생성 [#create-key]

1. 왼쪽 메뉴에서 "**API Keys**"를 클릭하세요
2. "키 생성"을 클릭하고 원하는 이름을 지정하세요
3. 생성이 완료되면 **API 키를 저장하세요**(`sk-`로 시작하는 값)

## 4단계 — 도구 구성

**API 기본 URL:**

도구의 프로토콜에 맞는 기본 URL을 선택하세요:

**Anthropic 프로토콜**(Claude Code, Cherry Studio, Trae, Claude / 중국어 모델을 사용하는 Kilo Code 등):

```
https://api.lmuai.com
```

**OpenAI 프로토콜**(Codex CLI, Codex App, GPT를 사용하는 VS Code / Cursor, OpenAI 모델을 사용하는 Kilo Code 등):

```
https://api.lmuai.com/v1
```

<Callout type="warn" title="차이점 (가장 흔한 실수)">

- **Anthropic 프로토콜**에는 `/v1` 접미사가 **없습니다**
- **OpenAI 프로토콜**에는 반드시 `/v1` 접미사가 **포함되어야 합니다**

잘못된 프로토콜을 사용하면 401 / 404 오류가 발생합니다. 전체 프로토콜 세부 정보, SDK / curl 예제 및 Claude Max 그룹 제한은 **[API 프로토콜 →](/ko/docs/guide/api-protocols)**을 참조하세요.

</Callout>

아래의 모든 도구 설정에 필요하므로 다음 세 가지를 준비해 두세요:
- **API 키**: 콘솔에서 생성한 `sk-` 키(두 프로토콜 공유)
- **Anthropic 기본 URL**: `https://api.lmuai.com`
- **OpenAI 기본 URL**: `https://api.lmuai.com/v1`
