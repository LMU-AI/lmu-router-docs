Эта страница собирает коды ошибок, разбросанные по отдельным документам API, в единую шпаргалку. **Сначала определите широкий класс по HTTP-коду статуса, затем найдите конкретное исправление по исходному тексту ошибки.**

<Callout type="info" title="Запишите request ID перед устранением неполадок">

Request ID в заголовках ответа — это единственная самая полезная информация для диагностики проблемы. Обращаясь в поддержку, укажите request ID и полный текст ошибки — **не отправляйте полный API-ключ**.

</Callout>

## HTTP-коды статусов

| Статус | Типичная причина | Что делать |
|---:|---|---|
| `400` | Некорректное тело запроса, параметр, ID модели или путь модели; неверный формат / кодировка изображения | Исправьте запрос — **не просто повторяйте**; смена аккаунтов или повтор не помогут |
| `401` | API-ключ отсутствует, недействителен или отключён; Base URL не соответствует протоколу; IDE не была перезапущена, поэтому по-прежнему действует старая конфигурация | Проверьте ключ и Base URL (см. [Протоколы API](/ru/docs/guide/api-protocols)), перезапустите IDE; подробности в [Проблеме 3](/ru/docs/guide/faq#issue-3) |
| `402` | Недостаточный баланс | Пополните счёт или уменьшите нагрузку |
| `403` | Два возможных варианта, оба вероятны: ① для **группы API-ключа не включена генерация изображений**; ② **недостаточный баланс, подписка, право на биллинг или разрешение** | Сначала проверьте баланс аккаунта и статус подписки, затем убедитесь, что у группы есть нужная возможность; если и то и другое в порядке, а ошибка сохраняется, обратитесь в поддержку |
| `404` | URL протокола OpenAI без `/v1`, URL Anthropic с ошибочно включённым `/v1`, Gemini без использования `/v1beta/models/...`; либо эндпоинт не поддерживается текущей группой | Перепроверьте Base URL и полный эндпоинт по [Протоколам API](/ru/docs/guide/api-protocols) |
| `413` | Тело запроса image-to-image слишком велико | Сожмите входное изображение |
| `429` | ① Дневная квота исчерпана; ② ограничение параллелизма, RPM или квоты вышестоящего сервиса | При исчерпанной квоте см. [Проблему 2](/ru/docs/guide/faq#issue-2); при ограничении частоты используйте экспоненциальную задержку и снизьте параллелизм и RPM |
| `500` | Внутренняя ошибка или ошибка ёмкости | Запишите код ошибки и request ID, повторите ограниченное число раз |
| `502` | Временный сбой авторизации, разрешений или сервиса на стороне вышестоящего сервиса | Сделайте задержку и повторите; при необходимости обратитесь в поддержку |
| `503` | Нет доступного вышестоящего аккаунта или вышестоящий сервис перегружен; также возможно **переопределение ключа переменной окружения** | Сначала проверьте переменные окружения (см. [Проблему 6](/ru/docs/guide/faq#issue-6)), затем повторите с задержкой и меньшим трафиком |
| `504` | Тайм-аут шлюза или вышестоящего сервиса | Отправьте новый, независимый запрос |

<Callout type="warn" title="Что повторять, а что нужно исправлять">

- **Не повторяйте**: `400`, `401` и любые явные ошибки баланса, разрешений, параметров или политики контента — сам запрос недействителен, и любой вышестоящий аккаунт вернёт тот же результат. Сначала нужно исправить запрос.
- **Можно повторять**: `429`, `502`, `503`, `504`, а также обрывы сети, сбросы соединения и тайм-ауты чтения — все это временные сбои. Используйте экспоненциальную задержку для **ограниченного** числа повторов (рекомендуется 2–3), чтобы не платить за повторные вызовы; при `429` также снизьте параллелизм и RPM.

Эта классификация взята из рекомендаций по повторам в API изображений — см. [Gemini Image · Рекомендации по повторам](/ru/docs/api/gemini-image#retry-recommendations).

</Callout>

Полные описания ошибок для каждого API: [Gemini Image](/ru/docs/api/gemini-image), [GPT Image](/ru/docs/api/gpt-image), [Grok Image](/ru/docs/api/grok-image), [Gemini Batch Image](/ru/docs/api/gemini-image-batch).

## Бизнес-коды ошибок (пакетная обработка изображений)

Помимо HTTP-кодов статусов, [Gemini Batch Image API](/ru/docs/api/gemini-image-batch) также возвращает бизнес-коды ошибок, отображаемые в консоли как `error code: BATCH_IMAGE_XXX` вместе с request ID.

| Код ошибки | HTTP | Значение | Что делать |
|---|---:|---|---|
| `BATCH_IMAGE_DISABLED` | 404 | Пакетная генерация изображений отключена глобально | Отправьте код ошибки и request ID администратору |
| `BATCH_IMAGE_GROUP_DISABLED` | 403 | Группа текущего ключа не разрешает пакетную обработку изображений или не является группой Gemini | Смените ключ или попросите администратора включить разрешение для группы |
| `BATCH_IMAGE_NO_ACCOUNT_AVAILABLE` | 502 | В данный момент нет доступного ресурса для пакетного выполнения | Сохраните request ID и обратитесь к администратору |
| `BATCH_IMAGE_SETTLEMENT_PRICING_MISSING` | 400 | Для пакетной модели не задана цена биллинга | Попросите администратора настроить цену модели |
| `BATCH_IMAGE_INVALID_MODEL` | 400 | Модель не указана | Используйте модель из списка пакетных моделей |
| `BATCH_IMAGE_INVALID_ITEMS` | 400 | Недопустимые элементы, разрешение или поля запроса | Проверьте тело запроса; пока поддерживается только 1K |
| `BATCH_IMAGE_DUPLICATE_CUSTOM_ID` | 400 | Дублирующийся `custom_id` | Убедитесь, что он уникален в пределах пакета |
| `BATCH_IMAGE_PROMPT_TOO_LONG` | 400 | Промпт слишком длинный | Сократите промпт |
| `BATCH_IMAGE_TOO_MANY_OUTPUT_IMAGES` | 400 | Количество изображений после расширения превышает лимит | Уменьшите число элементов или output_count |
| `BATCH_IMAGE_INVALID_REFERENCE_IMAGE` | 400 | Недопустимый формат, размер или URI референсного изображения | Проверьте MIME, Base64 и file_uri |
| `BATCH_IMAGE_INSUFFICIENT_BALANCE` | 402 | Баланс слишком мал для резервирования списания | Пополните счёт или уменьшите нагрузку |
| `BATCH_IMAGE_IDEMPOTENCY_CONFLICT` | 409 | Один и тот же ключ идемпотентности сопоставлен с другим телом запроса | Используйте новый Idempotency-Key |
| `BATCH_IMAGE_PROVIDER_SUBMIT_FAILED` | 502 | Не удалось создать пакетную задачу на стороне вышестоящего сервиса | Сохраните request ID, повторите ограниченное число раз или обратитесь к администратору |
| `BATCH_IMAGE_QUEUE_FAILED` | 502 | Сервис асинхронных задач временно недоступен | Сохраните request ID и обратитесь к администратору |
| `BATCH_IMAGE_NOT_READY` | 409 | Попытка загрузки до завершения задачи | Дождитесь, пока статус станет completed |
| `BATCH_IMAGE_OUTPUT_DELETED` | 410 | Результат уже был удалён | Его больше нельзя загрузить; создайте задачу заново |
| `BATCH_IMAGE_ITEM_FAILED` | 409 | У указанного элемента задачи нет успешного изображения | Проверьте item.error |
| `BATCH_IMAGE_DOWNLOAD_LIMITED` | 429 | Слишком много одновременных загрузок | Повторите позже |

## Поиск по исходному тексту ошибки

Сопоставьте текст ошибки, который вы фактически видите, с таблицей ниже и перейдите прямо к подробному исправлению.

| Исходный текст ошибки | Значение | Подробное исправление |
|---|---|---|
| `stream disconnected before completion` | Обрыв потока, обычно из-за смены выходного IP VPN / прокси / системным прокси | [Проблема 1](/ru/docs/guide/faq#issue-1) |
| `exceeded retry limit, last status: 429 Too Many Requests` | Дневная квота исчерпана | [Проблема 2](/ru/docs/guide/faq#issue-2) |
| `401 Unauthorized: Incorrect API key provided` | Запрос всё ещё уходил на официальный эндпоинт, а не на ретранслятор LMU AI | [Проблема 3](/ru/docs/guide/faq#issue-3) |
| `running scripts is disabled on this system` (Windows) | Ограничение политики выполнения PowerShell | [Проблема 4](/ru/docs/guide/faq#issue-4) |
| `CODEX is not recognized as a cmdlet` (Windows) | Node.js не установлен или нарушен PATH | [Проблема 5](/ru/docs/guide/faq#issue-5) |
| `503 No available accounts` | Переменная окружения оболочки переопределяет ключ, настроенный в IDE | [Проблема 6](/ru/docs/guide/faq#issue-6) |
| `400 Invalid signature in thinking block` | Переключение моделей между группами в одном разговоре; подпись thinking не может быть проверена | [Проблема 7](/ru/docs/guide/faq#issue-7) |
| `400 Unknown parameter: 'tools[0].n'` | Параметр `tools` был ошибочно отправлен на эндпоинт изображений | [Проблема 8](/ru/docs/guide/faq#issue-8) |
| `No available accounts` / модель недоступна | Вызвана модель за пределами доступного диапазона текущей группы | [Протоколы API → Устранение неполадок](/ru/docs/guide/api-protocols#troubleshooting) |

## Ошибки в API экспорта использования

[API экспорта использования](/ru/docs/api/usage-export) использует аутентификацию JWT, поэтому семантика его ошибок отличается от канала API-ключа выше:

| Статус | Причина | Что делать |
|---:|---|---|
| `401` | JWT истёк | Обновите с помощью `refresh_token` или войдите снова |
| `403` | Несанкционированный доступ (например, запрос `api_key_id`, который вам не принадлежит) | Проверьте, принадлежит ли ключ текущему аккаунту |
| `400` | Неверный параметр (например, неправильный формат `start_date`) | Проверьте формат `YYYY-MM-DD` и корректность `timezone` |
