Invitez vos amis à s'inscrire à LMU AI. Chaque fois qu'ils rechargent ou s'abonnent, vous continuez à gagner des commissions — un lien à vie et un revenu à long terme.

---

## Règles

- Lorsqu'un nouvel utilisateur s'inscrit via votre lien d'invitation, il est **lié à vous à vie**
- Chaque fois qu'il recharge ou s'abonne, vous gagnez une **commission comptable de 10 %**
- La commission est débloquée progressivement à mesure que l'invité dépense réellement (les recharges suivent la progression de la consommation du solde ; les abonnements suivent les jours écoulés)
- La commission disponible peut être **transférée directement sur le solde de votre compte** pour les dépenses d'API, ou retirée vers WeChat / Alipay / carte bancaire
- Les nouveaux utilisateurs reçoivent un bonus supplémentaire de **¥2.00** sur leur premier paiement

---

## Comment participer

Connectez-vous à la console et cliquez sur « **Récompenses de parrainage** » dans le menu de gauche pour voir votre lien d'invitation et votre code d'invitation dédiés.

### Option 1 : Partagez votre lien d'invitation

Copiez votre lien dédié et envoyez-le à un ami ; une fois qu'il clique dessus et s'inscrit, le lien est établi. Le format est :

```
https://api.lmuai.com/register?ref=YOUR_INVITE_CODE
```

### Option 2 : Partagez votre code d'invitation

Communiquez votre code d'invitation à votre ami, et il le saisit manuellement lors de l'inscription pour établir le lien.

---

## Détails de la commission

| Élément | Description |
|------|------|
| Taux de commission | **10 %** (sur chaque recharge / abonnement d'un invité) |
| Bonus nouvel utilisateur | **¥2.00** sur le premier paiement |
| Méthode de liaison | S'inscrire via le lien crée un lien à vie |
| Déblocage de la commission | Débloquée progressivement à mesure que l'invité dépense réellement |
| Utilisation de la commission | Transfert vers le solde (disponible immédiatement) ou retrait |

---

## Consultation et retrait

Après vous être connecté à la console, cliquez sur « **Récompenses de parrainage** » dans le menu de gauche pour voir :

- La commission cumulée, la commission disponible et le montant débloqué
- Le nombre de personnes invitées et le détail de chaque commission
- Le transfert en un clic de la commission disponible vers votre solde, ou une demande de retrait

<Callout type="info" title="Astuce">

Les liens d'invitation masquent les traces promotionnelles, ce qui rend le partage plus naturel. Sur la page « Récompenses de parrainage » de la console, vous pouvez télécharger votre QR code dédié, ce qui facilite le partage dans les communautés, les Moments et autres lieux similaires.

</Callout>
