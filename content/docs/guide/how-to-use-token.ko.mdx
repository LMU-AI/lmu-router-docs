## 토큰 유형

| 유형 | 설명 |
|------|------|
| 개인 토큰 | 계정에 연동되며, 본인의 할당량을 사용합니다 |
| 채널 토큰 | 관리자가 배정하며, 독립적인 할당량 관리가 적용됩니다 |

## 사용량 확인

**콘솔 → 사용량 통계**로 이동하여 다음을 확인할 수 있습니다:

- 일/월별 호출 횟수
- 토큰 소비량
- 비용 내역
- 모델별 사용 비중

## 할당량 제한

토큰을 생성할 때 다음 제한을 설정할 수 있습니다:

- **총 할당량**: 이 토큰이 소비할 수 있는 최대 할당량 (비워 두면 제한 없음)
- **분당 요청 수**: 속도 제한 보호
- **모델 화이트리스트**: 이 토큰이 지정된 모델만 호출하도록 제한

## 초기화 및 폐기

- **할당량 초기화**: 토큰 관리 페이지에서 사용된 할당량을 수동으로 초기화할 수 있습니다
- **토큰 폐기**: 토큰을 삭제하면 즉시 적용되며, 이미 전송된 요청은 영향을 받지 않습니다
