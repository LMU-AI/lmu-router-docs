## Paso 1 — Crea una cuenta

Ve a la página de registro: [https://api.lmuai.com/register?ref=vJaWWr4T](https://api.lmuai.com/register?ref=vJaWWr4T)

Ingresa tu correo electrónico y una contraseña para finalizar el registro.

## Paso 2 — Suscríbete o recarga saldo

Después de iniciar sesión, haz clic en "**Recargar / Suscribirse**" en el menú de la izquierda:

- **Suscribirse**: elige un plan y obtén una cuota mensual fija
- **Recargar saldo**: agrega saldo según lo necesites y usa cualquier modelo con flexibilidad

Estarás listo para comenzar en cuanto se complete el pago.

## Paso 3 — Crea una clave API [#create-key]

1. Haz clic en "**API Keys**" en el menú de la izquierda
2. Haz clic en "Crear clave" y dale cualquier nombre
3. Una vez creada, **guarda tu clave API** (el valor que comienza con `sk-`)

## Paso 4 — Configura tu herramienta

**URL base de la API:**

Elige la URL base que coincida con el protocolo de tu herramienta:

**Protocolo Anthropic** (Claude Code, Cherry Studio, Trae, Kilo Code con Claude / modelos chinos, etc.):

```
https://api.lmuai.com
```

**Protocolo OpenAI** (Codex CLI, Codex App, VS Code / Cursor con GPT, Kilo Code con modelos de OpenAI, etc.):

```
https://api.lmuai.com/v1
```

<Callout type="warn" title="La diferencia (el error más común)">

- El **protocolo Anthropic** **no** tiene el sufijo `/v1`
- El **protocolo OpenAI** **debe** incluir el sufijo `/v1`

Usar el protocolo incorrecto causa errores 401 / 404. Para conocer todos los detalles de los protocolos, ejemplos de SDK / curl y los límites del grupo Claude Max, consulta **[Protocolos de API →](/es/docs/guide/api-protocols)**.

</Callout>

Ten a mano estas tres cosas — cada configuración de herramienta a continuación las necesita:
- **Clave API**: la clave `sk-` que creaste en la consola (compartida por ambos protocolos)
- **URL base de Anthropic**: `https://api.lmuai.com`
- **URL base de OpenAI**: `https://api.lmuai.com/v1`
