아래는 LMU AI API가 현재 지원하는 모든 모델 이름입니다. **아무 카드나 클릭하면 해당 모델 ID가 복사되며**, 이를 곧바로 `settings.json`, `config.toml`, 또는 도구의 모델 선택기에 붙여넣으세요.

<Callout type="info" title="모델 이름 사용 방법">

복사한 모델 ID를 도구 설정에 붙여넣으세요:

- **Claude Code** → `settings.json`의 `"model"` 필드
- **Codex CLI** → `~/.codex/config.toml`의 `model = "..."`
- **Cherry Studio / VS Code 확장** → 모델 드롭다운에 붙여넣기

</Callout>

## 사용 사례별 모델 선택

어떤 모델을 사용해야 할지 모르겠다면, 아래 표에서 찾은 뒤 해당 섹션에서 모델 ID를 복사하세요.

| 사용 사례 | 추천 모델 | 이유 |
|---|---|---|
| 복잡한 리팩터링, 대규모 크로스 파일 변경 | `claude-opus-5` | Claude의 플래그십 등급으로, 코드와 긴 텍스트에 탁월하며 Claude Code의 기본값 |
| 일상적인 코딩, 버그 수정 | `claude-sonnet-5` · `claude-sonnet-4-6` | 밸런스형 등급으로, 성능과 속도 사이의 균형을 이루어 매일 자주 쓰기에 이상적 |
| 빈번한 경량 작업(자동완성, 포매팅, 대량의 소소한 편집) | `claude-haiku-4-5` · `deepseek-v4-flash` · `qwen3.6-flash` | 고속 등급으로, 여러 번 호출되는 단순한 단일 작업에 적합 |
| Codex CLI / Codex App 툴체인 | `gpt-5.6-sol` · `gpt-5.4` | OpenAI 쪽 최신 플래그십이며 Codex CLI 설정 템플릿의 기본값 |
| 중국어 글쓰기, 문서 작성, 대화 | `qwen3.8-max-preview` · `glm-5.2` · `kimi-k3` | 뛰어난 중국어 이해력을 더 저렴한 가격에 제공하는 중국 LLM |
| 중국어 맥락에서의 코딩 | `qwen3.6-plus` · `deepseek-v4-pro` | 코드 지향 중국어 모델로, 계정 잔액으로 바로 호출 가능 |
| 멀티모달(이미지 + 텍스트 혼합 입력) | `mimo-v2-omni` | 여기서 멀티모달로 표시된 유일한 대화형 모델. 순수 이미지 생성은 아래 이미지 API를 참고하세요 |

<Callout type="warn" title="선택 전에 두 가지를 확인하세요">

- **모델 사용 가능 여부는 그룹에 따라 다릅니다**: 실제로 호출할 수 있는 모델은 콘솔의 **사용 가능한 모델** 페이지에 표시되는 것을 따릅니다. 예를 들어 GPT 시리즈는 GPT 구독이 필요하거나, 종량제 결제에서 GPT 그룹을 선택해야 합니다. **이는 어떤 프로토콜로 호출하는지와는 무관합니다.**
- **Base URL은 프로토콜과 일치해야 합니다**: 프로토콜은 클라이언트와 SDK에 의해 결정됩니다 — Anthropic 프로토콜 Base URL은 `/v1`을 **포함하지 않으며**, OpenAI 프로토콜은 **반드시** `/v1`을 포함해야 하고, Gemini 네이티브는 `/v1beta/models/...`를 사용합니다. 잘못하면 곧바로 404가 발생합니다. [API 프로토콜](/ko/docs/guide/api-protocols)을 참고하세요.

</Callout>

## 중국 모델
