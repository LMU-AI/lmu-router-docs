## Passo 1 — Crie uma conta

Acesse a página de cadastro: [https://api.lmuai.com/register?ref=vJaWWr4T](https://api.lmuai.com/register?ref=vJaWWr4T)

Informe seu e-mail e uma senha para concluir o cadastro.

## Passo 2 — Assine ou adicione saldo

Após fazer login, clique em "**Adicionar saldo / Assinar**" no menu à esquerda:

- **Assinar**: escolha um plano e obtenha uma cota mensal fixa
- **Adicionar saldo**: adicione saldo conforme a necessidade e use qualquer modelo com flexibilidade

Você estará pronto para começar assim que o pagamento for concluído.

## Passo 3 — Crie uma chave de API [#create-key]

1. Clique em "**API Keys**" no menu à esquerda
2. Clique em "Criar chave" e dê qualquer nome a ela
3. Uma vez criada, **salve sua chave de API** (o valor que começa com `sk-`)

## Passo 4 — Configure sua ferramenta

**URL base da API:**

Escolha a URL base que corresponde ao protocolo da sua ferramenta:

**Protocolo Anthropic** (Claude Code, Cherry Studio, Trae, Kilo Code com Claude / modelos chineses, etc.):

```
https://api.lmuai.com
```

**Protocolo OpenAI** (Codex CLI, Codex App, VS Code / Cursor com GPT, Kilo Code com modelos OpenAI, etc.):

```
https://api.lmuai.com/v1
```

<Callout type="warn" title="A diferença (o erro mais comum)">

- O **protocolo Anthropic** **não** tem o sufixo `/v1`
- O **protocolo OpenAI** **deve** incluir o sufixo `/v1`

Usar o protocolo errado causa erros 401 / 404. Para detalhes completos do protocolo, exemplos de SDK / curl e limites de grupo do Claude Max, consulte **[Protocolos de API →](/pt/docs/guide/api-protocols)**.

</Callout>

Mantenha estas três coisas à mão — toda configuração de ferramenta abaixo precisa delas:
- **Chave de API**: a chave `sk-` que você criou no console (compartilhada por ambos os protocolos)
- **URL base Anthropic**: `https://api.lmuai.com`
- **URL base OpenAI**: `https://api.lmuai.com/v1`
