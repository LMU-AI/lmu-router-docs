このページでは、LMU AI がユーザーデータを取り扱う際に従う原則を説明します。当社は「最小限の保存、隔離、透明性」をデータ取り扱いの 3 つの基本方針としています。

## 当社が取り扱うデータ

データは**アカウントデータ**と**リクエストデータ**の 2 種類に分類します。この 2 つはまったく異なる方法で取り扱い、保存します。

### アカウントデータ

| 種類 | 内容 | 目的 |
|------|------|------|
| 本人確認情報 | メールアドレス、電話番号 | ログイン、パスワード復旧、通知 |
| 請求情報 | プラン、クォータ、注文記録 | 請求と請求書発行 |
| 認証情報 | API キー（暗号化して保存）、ログインセッション | 認証 |
| 使用メタデータ | 呼び出し時刻、モデル、トークン使用量、所要時間 | 請求、統計、レポート |

### リクエストデータ

| 種類 | 内容 | 目的 |
|------|------|------|
| リクエストボディ | 送信するプロンプト、メッセージ、パラメータ | 上流モデルに転送してレスポンスを生成 |
| レスポンスボディ | モデルが返す内容 | あなたに返却 |

**重要な区別**：アカウントデータはプラットフォーム自体を運用するために使用され、リクエストデータは現在の単一の API 呼び出しを完了するためだけに使用されます。

## データの保存場所

当社のインフラストラクチャは 2 層構造です：

**アクセス層（中国国内）**
- メインサーバー、ユーザーデータベース、請求システム
- **すべてのアカウントデータはここに保存されます**
- あなたのメールアドレス、電話番号、注文、API キーが中国から出ることはありません

**上流チャネル層（マルチリージョン、海外を含む）**
- OpenAI / Anthropic / 等のモデルプロバイダーの公式インターフェースにアクセスするために使用されます
- これらのチャネルは**モデルトラフィックの中継としてのみ機能し**、ユーザーの本人確認情報を一切保持しません
- チャネルノードはユーザーアカウントを保存せず、リクエストがどのユーザーから来たものかを認識しません（匿名化されたリクエストペイロードのみを参照します）

## ログ保持ポリシー

| データ種類 | 保持期間 | 保存場所 |
|---------|---------|---------|
| リクエスト / レスポンスボディの内容 | **非保持** | — |
| 呼び出しメタデータ（時刻、モデル、トークン、所要時間、ステータスコード） | 90 日間 | 中国国内 |
| エラーログ（切り詰められたリクエスト断片を含む場合あり） | 90 日間 | 中国国内 |
| アカウントおよび注文データ | アカウントの存続期間中。解約後 30 日以内に消去 | 中国国内 |

**リクエスト内容について**

- 当社は**あなたのプロンプトやレスポンスの内容を保存しません** — リクエストが転送されると、メモリから解放され、いかなるデータベースやファイルにも書き込まれることはありません
- 上流チャネルがエラーを返した場合、エラーログには**切り詰められたリクエスト断片**（問題の再現に使用）が含まれる場合があります。このデータは 90 日後に消去されます
- エラーログはいかなるモデルのトレーニングにも使用されず、人間による能動的なレビューも行われません。問題の解決支援が必要なチケットを提出された場合にのみ、関連するエンジニアがアクセスします

<Callout type="info" title="エンタープライズ層向けのオプションの監査ログ">

エンタープライズのお客様は、監査ログ機能をオプトインして、貴社のコンプライアンス要件に応じてリクエスト / レスポンスデータを保持できます。有効化すると、ログは暗号化して保存され、アクセスは貴社の管理者によって制御できます。詳細は[エンタープライズプラン](/ja/docs/enterprise)をご覧ください。

</Callout>

## クロスボーダーデータ転送

上流モデル（Claude、GPT など）のサーバーは海外に所在するため、**API 呼び出しのリクエストおよびレスポンスボディは、転送中に海外チャネルを経由します**。これは、海外の大規模モデル API にアクセスするあらゆる中継サービスにとって必要な技術的経路です。

この段階での当社のコミットメント：

- **海外ノードにいかなるデータも保持しません**：チャネルは転送するのみで、転送が完了すると同時にメモリは解放されます
- **ユーザーの本人確認情報を運びません**：上流チャネルが参照するリクエストは、メールアドレス、電話番号、注文の関連付けなどのアカウントフィールドがすでに除去されています
- **暗号化通信**：ユーザー ↔ アクセス層、アクセス層 ↔ 上流チャネル、上流チャネル ↔ モデルプロバイダーのすべてが、エンドツーエンドで TLS 1.2+ です
- **第三者と共有しません**：現在の呼び出しを完了するために必要な上流モデルプロバイダーを除き、あなたのリクエスト内容をいかなる第三者にも渡しません

<Callout type="warn" title="機微なデータに関するアドバイス">

リクエスト内容はモデルプロバイダーに到達するために海外チャネルを経由する必要があるため、**国家機密、営業秘密、個人 ID 番号などの高度に機微なデータを含むリクエストを API 経由で送信しないでください**。そのようなコンプライアンス要件がある場合は、オンプレミス展開またはコンプライアンス対応チャネルについて営業にご相談ください。

</Callout>

## 当社が行わないこと

- 人間による分析、商業分析、またはいかなるモデルトレーニングのために、あなたのプロンプトやレスポンス内容を**読み取りません**
- あなたのデータを第三者に**販売しません**
- **お知らせなしに**リクエストおよびレスポンス内容を**保持しません**
- **アカウントデータをクロスボーダーで転送しません**（アカウントデータは中国国内にのみ保存されます）

## セキュリティ対策

- API キーはデータベースに暗号化して保存され、先頭と末尾の数文字のみが表示されます
- データベースにアクセスするすべての内部操作は監査ログに記録されます
- 主要な変更（プラン、API キーのリセット、出金など）は、メール / SMS 通知をトリガーします
- 本番データにアクセスするチームメンバーは、承認および最小権限の原則を経る必要があります

アカウントの異常が疑われる場合は、直ちに以下を行ってください：
1. コンソールで API キーをリセットする
2. 営業またはサポートに連絡する：business@lmuai.com / WeChat 18599001010
