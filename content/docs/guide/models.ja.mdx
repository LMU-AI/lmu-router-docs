以下は、LMU AI API が現在サポートしているすべてのモデル名です。**任意のカードをクリックするとモデル ID がコピーされ**、`settings.json`、`config.toml`、またはツールのモデルセレクターにそのまま貼り付けられます。

<Callout type="info" title="モデル名の使い方">

コピーしたモデル ID をツールの設定に貼り付けます。

- **Claude Code** → `settings.json` の `"model"` フィールド
- **Codex CLI** → `~/.codex/config.toml` の `model = "..."`
- **Cherry Studio / VS Code 拡張機能** → モデルのドロップダウンに貼り付け

</Callout>

## ユースケースでモデルを選ぶ

どのモデルを使えばよいか分からない場合は、下の表で探し、対応するセクションからモデル ID をコピーしてください。

| ユースケース | 推奨モデル | 理由 |
|---|---|---|
| 複雑なリファクタリング、大規模なクロスファイル変更 | `claude-opus-5` | Claude のフラッグシップ層。コードと長文に優れ、Claude Code のデフォルト |
| 日常的なコーディング、バグ修正 | `claude-sonnet-5` · `claude-sonnet-4-6` | バランス層。能力と速度のトレードオフで、頻繁な日常使用に最適 |
| 頻繁な軽量タスク（補完、フォーマット、大量の小さな編集） | `claude-haiku-4-5` · `deepseek-v4-flash` · `qwen3.6-flash` | 高速層。何度も呼び出されるシンプルな単一タスク向け |
| Codex CLI / Codex App ツールチェーン | `gpt-5.6-sol` · `gpt-5.4` | OpenAI 側の最新フラッグシップで、Codex CLI 設定テンプレートのデフォルト |
| 中国語の執筆、ドキュメント、会話 | `qwen3.8-max-preview` · `glm-5.2` · `kimi-k3` | 優れた中国語理解を低価格で提供する中国系 LLM |
| 中国語コンテキストでのコーディング | `qwen3.6-plus` · `deepseek-v4-pro` | コード指向の中国系モデルで、アカウント残高で直接呼び出せる |
| マルチモーダル（画像 + テキストの混合入力） | `mimo-v2-omni` | ここでマルチモーダルと表示されている唯一の会話モデル。純粋な画像生成については下記の画像 API を参照 |

<Callout type="warn" title="選ぶ前に 2 つのことを確認してください">

- **モデルの利用可否はグループに依存します**: 実際にどのモデルを呼び出せるかは、コンソールの**利用可能なモデル**ページに表示される内容です。たとえば、GPT シリーズには GPT サブスクリプションが必要か、従量課金で GPT グループを選択する必要があります。**これは、どのプロトコルで呼び出すかとは無関係です。**
- **Base URL はプロトコルと一致させる必要があります**: プロトコルはクライアントと SDK によって決まります。Anthropic プロトコルの Base URL は `/v1` を**含まず**、OpenAI プロトコルは `/v1` を**含める必要があり**、Gemini ネイティブは `/v1beta/models/...` を使います。間違えると即座に 404 になります。[API プロトコル](/ja/docs/guide/api-protocols) を参照してください。

</Callout>
