## トークンの種類

| 種類 | 説明 |
|------|------|
| 個人トークン | アカウントに紐づき、自分のクォータを使用します |
| チャネルトークン | 管理者が割り当て、独立したクォータ管理を行います |

## 使用状況の確認

**コンソール → 使用状況の統計** に移動して、以下を確認できます：

- 日／月ごとの呼び出し回数
- トークン消費量
- コスト内訳
- モデル別の使用割合

## クォータ制限

トークンを作成する際、以下の制限を設定できます：

- **総クォータ**：このトークンが消費できる最大クォータ（空欄にすると無制限）
- **1 分あたりのリクエスト数**：レート制限による保護
- **モデルホワイトリスト**：このトークンで指定したモデルのみを呼び出せるように制限します

## リセットと取り消し

- **クォータのリセット**：トークン管理ページで使用済みクォータを手動でリセットできます
- **トークンの取り消し**：トークンの削除は即座に有効になります。すでに送信されたリクエストには影響しません
