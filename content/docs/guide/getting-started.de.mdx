## Schritt 1 — Konto erstellen

Gehen Sie zur Registrierungsseite: [https://api.lmuai.com/register?ref=vJaWWr4T](https://api.lmuai.com/register?ref=vJaWWr4T)

Geben Sie Ihre E-Mail-Adresse und ein Passwort ein, um die Registrierung abzuschließen.

## Schritt 2 — Abonnieren oder aufladen

Klicken Sie nach dem Anmelden im linken Menü auf „**Aufladen / Abonnieren**":

- **Abonnieren**: Wählen Sie einen Plan und erhalten Sie ein festes monatliches Kontingent
- **Aufladen**: Fügen Sie bei Bedarf Guthaben hinzu und nutzen Sie jedes Modell flexibel

Sie sind startklar, sobald die Zahlung abgeschlossen ist.

## Schritt 3 — API-Schlüssel erstellen [#create-key]

1. Klicken Sie im linken Menü auf „**API-Schlüssel**"
2. Klicken Sie auf „Schlüssel erstellen" und geben Sie ihm einen beliebigen Namen
3. Nach der Erstellung **speichern Sie Ihren API-Schlüssel** (der Wert, der mit `sk-` beginnt)

## Schritt 4 — Ihr Tool konfigurieren

**API-Basis-URL:**

Wählen Sie die Basis-URL, die dem Protokoll Ihres Tools entspricht:

**Anthropic-Protokoll** (Claude Code, Cherry Studio, Trae, Kilo Code mit Claude / chinesischen Modellen usw.):

```
https://api.lmuai.com
```

**OpenAI-Protokoll** (Codex CLI, Codex App, VS Code / Cursor mit GPT, Kilo Code mit OpenAI-Modellen usw.):

```
https://api.lmuai.com/v1
```

<Callout type="warn" title="Der Unterschied (der häufigste Fehler)">

- Das **Anthropic-Protokoll** hat **kein** `/v1`-Suffix
- Das **OpenAI-Protokoll** **muss** das `/v1`-Suffix enthalten

Die Verwendung des falschen Protokolls verursacht 401 / 404-Fehler. Für vollständige Protokolldetails, SDK- / curl-Beispiele und Claude Max-Gruppenlimits siehe **[API-Protokolle →](/de/docs/guide/api-protocols)**.

</Callout>

Halten Sie diese drei Dinge bereit — jede Tool-Einrichtung unten benötigt sie:
- **API-Schlüssel**: der `sk-`-Schlüssel, den Sie in der Konsole erstellt haben (von beiden Protokollen gemeinsam genutzt)
- **Anthropic-Basis-URL**: `https://api.lmuai.com`
- **OpenAI-Basis-URL**: `https://api.lmuai.com/v1`
