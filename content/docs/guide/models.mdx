下方为灵眸 API 当前支持的所有模型名称，**点击任意卡片即可一键复制模型 ID**，可直接粘贴到 `settings.json`、`config.toml` 或工具的模型选择框中。

<Callout type="info" title="如何使用模型名">

将复制到的模型 ID 填入对应工具的配置项即可：

- **Claude Code** → `settings.json` 中的 `"model"` 字段
- **Codex CLI** → `~/.codex/config.toml` 中的 `model = "..."`
- **Cherry Studio / VS Code 插件** → 模型选择下拉框中粘贴

</Callout>

## 按场景选模型

不确定该用哪个模型时，先按下表定位，再到对应分区复制模型 ID。

| 场景 | 推荐模型 | 为什么 |
|---|---|---|
| 复杂重构、跨文件大改 | `claude-opus-5` · `gpt-6-astra` | 各家旗舰档，代码与长文本能力出众，是 Claude Code / Codex 的默认首选 |
| 日常编码、改 bug | `claude-sonnet-5` · `glm-5.3` | 平衡档，能力与响应速度之间的折中，适合高频日常使用 |
| 高频轻量任务（补全、格式化、批量小改） | `claude-haiku-4-5` · `deepseek-v4-flash` · `qwen3.8-flash` | 高速档，单次任务简单、调用次数多的场景 |
| Codex CLI / Codex App 工具链 | `gpt-5.6-sol` · `gpt-5.5` | OpenAI 协议侧的旗舰与 Codex CLI 配置模板的默认模型 |
| 中文写作、文档撰写、对话 | `qwen3.8-max` · `glm-5.3` · `kimi-k3` | 国产模型中文理解优秀、价格更低 |
| 中文场景下的编码 | `qwen3.7-plus` · `deepseek-v4-pro` | 面向代码的国产模型，可用账户「余额」直接调用 |
| 多模态（图文混合输入） | `gemini-3.1-pro-preview` · `claude-fable-5-1` · `gpt-6-astra` | 原生多模态模型，支持图文混合输入；纯生图需求见下方生图接口 |

<Callout type="warn" title="选型前先确认两件事">

- **模型可用范围看分组**：实际能调用哪些模型以后台「可用模型」页为准。例如 GPT 系列需要订阅 GPT 套餐，或在按量计费下选择 GPT 分组。**和你用哪种协议调用无关**。
- **Base URL 要跟协议对上**：协议由你的客户端和 SDK 决定——Anthropic 协议 Base URL **不带** `/v1`，OpenAI 协议**必须带** `/v1`，Gemini 原生走 `/v1beta/models/...`。填错会直接报 404，详见 [接入协议](./api-protocols)。

</Callout>

## 国产模型

中文理解优秀、价格更低，适合日常编码、文档撰写与对话场景。与 Claude、GPT 等模型一样，**国产模型均支持使用账户「余额」调用**。

> **接入协议**：默认走 **Anthropic 协议** · Base URL `https://api.lmuai.com`（**不带** `/v1`）。详见 [接入协议 →](./api-protocols)
