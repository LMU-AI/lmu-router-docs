## Étape 1 — Créer un compte

Rendez-vous sur la page d'inscription : [https://api.lmuai.com/register?ref=vJaWWr4T](https://api.lmuai.com/register?ref=vJaWWr4T)

Saisissez votre e-mail et un mot de passe pour terminer l'inscription.

## Étape 2 — S'abonner ou recharger

Après vous être connecté, cliquez sur « **Recharger / S'abonner** » dans le menu de gauche :

- **S'abonner** : choisissez un forfait et obtenez un quota mensuel fixe
- **Recharger** : ajoutez du solde à la demande et utilisez n'importe quel modèle en toute flexibilité

Vous êtes prêt dès que le paiement est effectué.

## Étape 3 — Créer une clé API [#create-key]

1. Cliquez sur « **API Keys** » dans le menu de gauche
2. Cliquez sur « Créer une clé » et donnez-lui le nom de votre choix
3. Une fois créée, **enregistrez votre clé API** (la valeur qui commence par `sk-`)

## Étape 4 — Configurer votre outil

**URL de base de l'API :**

Choisissez l'URL de base qui correspond au protocole de votre outil :

**Protocole Anthropic** (Claude Code, Cherry Studio, Trae, Kilo Code avec Claude / modèles chinois, etc.) :

```
https://api.lmuai.com
```

**Protocole OpenAI** (Codex CLI, Codex App, VS Code / Cursor avec GPT, Kilo Code avec modèles OpenAI, etc.) :

```
https://api.lmuai.com/v1
```

<Callout type="warn" title="La différence (l'erreur la plus courante)">

- Le **protocole Anthropic** n'a **pas** de suffixe `/v1`
- Le **protocole OpenAI** **doit** inclure le suffixe `/v1`

Utiliser le mauvais protocole provoque des erreurs 401 / 404. Pour tous les détails des protocoles, les exemples SDK / curl et les limites des groupes Claude Max, consultez **[Protocoles API →](/fr/docs/guide/api-protocols)**.

</Callout>

Gardez ces trois éléments sous la main — chaque configuration d'outil ci-dessous en a besoin :
- **Clé API** : la clé `sk-` que vous avez créée dans la console (partagée par les deux protocoles)
- **URL de base Anthropic** : `https://api.lmuai.com`
- **URL de base OpenAI** : `https://api.lmuai.com/v1`
