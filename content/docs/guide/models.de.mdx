Nachfolgend findest du alle Modellnamen, die die LMU AI API derzeit unterstützt. **Klicke auf eine beliebige Karte, um ihre Modell-ID zu kopieren**, und füge sie direkt in `settings.json`, `config.toml` oder den Modellwähler eines Tools ein.

<Callout type="info" title="So verwendest du einen Modellnamen">

Füge die kopierte Modell-ID in die Konfiguration deines Tools ein:

- **Claude Code** → das Feld `"model"` in `settings.json`
- **Codex CLI** → `model = "..."` in `~/.codex/config.toml`
- **Cherry Studio / VS Code-Erweiterung** → in das Modell-Dropdown einfügen

</Callout>

## Ein Modell nach Anwendungsfall auswählen

Nicht sicher, welches Modell du verwenden sollst? Suche es in der Tabelle unten und kopiere dann die Modell-ID aus dem passenden Abschnitt.

| Anwendungsfall | Empfohlene Modelle | Warum |
|---|---|---|
| Komplexe Refactorings, große dateiübergreifende Änderungen | `claude-opus-5` | Claudes Flaggschiff-Stufe, herausragend bei Code und langen Texten, die Standardwahl für Claude Code |
| Alltägliches Coding, Bugfixing | `claude-sonnet-5` · `claude-sonnet-4-6` | Ausgewogene Stufe, ein Kompromiss zwischen Leistungsfähigkeit und Geschwindigkeit, ideal für den häufigen täglichen Einsatz |
| Häufige leichtgewichtige Aufgaben (Vervollständigung, Formatierung, viele kleine Änderungen) | `claude-haiku-4-5` · `deepseek-v4-flash` · `qwen3.6-flash` | Hochgeschwindigkeitsstufe, für einfache Einzelaufgaben, die oft aufgerufen werden |
| Codex CLI / Codex App Toolchain | `gpt-5.6-sol` · `gpt-5.4` | Das neueste Flaggschiff auf der OpenAI-Seite und der Standard in der Codex-CLI-Konfigurationsvorlage |
| Chinesisches Schreiben, Dokumentation, Konversation | `qwen3.8-max-preview` · `glm-5.2` · `kimi-k3` | Chinesische LLMs mit exzellentem Chinesisch-Verständnis zu einem niedrigeren Preis |
| Coding in chinesischen Kontexten | `qwen3.6-plus` · `deepseek-v4-pro` | Code-orientierte chinesische Modelle, direkt mit dem Kontoguthaben aufrufbar |
| Multimodal (gemischte Bild- + Texteingabe) | `mimo-v2-omni` | Das einzige hier als multimodal gekennzeichnete Konversationsmodell; für reine Bildgenerierung siehe die Bild-APIs unten |

<Callout type="warn" title="Bestätige zwei Dinge vor der Auswahl">

- **Die Modellverfügbarkeit hängt von der Gruppe ab**: Welche Modelle du tatsächlich aufrufen kannst, ist das, was die Seite **Verfügbare Modelle** in der Konsole anzeigt. Zum Beispiel erfordert die GPT-Serie ein GPT-Abonnement oder die Auswahl einer GPT-Gruppe bei nutzungsbasierter Abrechnung. **Das ist unabhängig davon, mit welchem Protokoll du aufrufst.**
- **Die Base URL muss zum Protokoll passen**: Das Protokoll wird von deinem Client und SDK bestimmt — die Base URL des Anthropic-Protokolls ist **ohne** `/v1`, das OpenAI-Protokoll **muss** `/v1` enthalten, und Gemini nativ verwendet `/v1beta/models/...`. Ein Fehler dabei ergibt einen direkten 404; siehe [API-Protokolle](/de/docs/guide/api-protocols).

</Callout>
