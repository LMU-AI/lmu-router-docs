Voici tous les noms de modèles actuellement pris en charge par l'API LMU AI. **Cliquez sur n'importe quelle carte pour copier son ID de modèle**, puis collez-le directement dans `settings.json`, `config.toml`, ou le sélecteur de modèle d'un outil.

<Callout type="info" title="Comment utiliser un nom de modèle">

Collez l'ID de modèle copié dans la configuration de votre outil :

- **Claude Code** → le champ `"model"` dans `settings.json`
- **Codex CLI** → `model = "..."` dans `~/.codex/config.toml`
- **Cherry Studio / extension VS Code** → collez-le dans le menu déroulant des modèles

</Callout>

## Choisir un modèle selon le cas d'usage

Pas sûr du modèle à utiliser ? Repérez-le dans le tableau ci-dessous, puis copiez l'ID de modèle depuis la section correspondante.

| Cas d'usage | Modèles recommandés | Pourquoi |
|---|---|---|
| Refactorisations complexes, changements importants sur plusieurs fichiers | `claude-opus-5` · `gpt-6-astra` | Le palier phare de chaque fournisseur, exceptionnel pour le code et les textes longs, le choix par défaut pour Claude Code / Codex |
| Codage quotidien, correction de bugs | `claude-sonnet-5` · `glm-5.3` | Palier équilibré, un compromis entre capacité et vitesse, idéal pour un usage quotidien fréquent |
| Tâches légères fréquentes (complétion, formatage, petites éditions en masse) | `claude-haiku-4-5` · `deepseek-v4-flash` · `qwen3.8-flash` | Palier haute vitesse, pour des tâches simples et uniques appelées de nombreuses fois |
| Chaîne d'outils Codex CLI / Codex App | `gpt-5.6-sol` · `gpt-5.5` | Le modèle phare côté protocole OpenAI et le choix par défaut dans le modèle de config de Codex CLI |
| Rédaction en chinois, documentation, conversation | `qwen3.8-max` · `glm-5.3` · `kimi-k3` | LLM chinois avec une excellente compréhension du chinois à un prix plus bas |
| Codage dans des contextes en chinois | `qwen3.7-plus` · `deepseek-v4-pro` | Modèles chinois orientés code, appelables directement avec le solde du compte |
| Multimodal (entrée mixte image + texte) | `gemini-3.1-pro-preview` · `claude-fable-5-1` · `gpt-6-astra` | Modèles nativement multimodaux qui acceptent l'entrée mixte image + texte ; pour la génération d'images pure, voir les API d'image ci-dessous |

<Callout type="warn" title="Vérifiez deux choses avant de choisir">

- **La disponibilité des modèles dépend du groupe** : les modèles que vous pouvez réellement appeler correspondent à ce qu'affiche la page **Modèles disponibles** dans la console. Par exemple, la série GPT nécessite un abonnement GPT, ou de sélectionner un groupe GPT en facturation à l'usage. **Ceci est indépendant du protocole avec lequel vous appelez.**
- **La Base URL doit correspondre au protocole** : le protocole est déterminé par votre client et votre SDK — la Base URL du protocole Anthropic est **sans** `/v1`, le protocole OpenAI **doit inclure** `/v1`, et le natif Gemini utilise `/v1beta/models/...`. Une erreur donne un 404 pur et simple ; voir [Protocoles d'API](/fr/docs/guide/api-protocols).

</Callout>
