## ステップ 1 — アカウントを作成する

サインアップページにアクセスします：[https://api.lmuai.com/register?ref=vJaWWr4T](https://api.lmuai.com/register?ref=vJaWWr4T)

メールアドレスとパスワードを入力して登録を完了します。

## ステップ 2 — サブスクリプションまたはチャージ

ログイン後、左メニューの「**チャージ / サブスクリプション**」をクリックします：

- **サブスクリプション**：プランを選んで毎月固定のクォータを取得します
- **チャージ**：必要に応じて残高を追加し、任意のモデルを柔軟に利用します

支払いが完了すればすぐに使い始められます。

## ステップ 3 — API キーを作成する [#create-key]

1. 左メニューの「**API Keys**」をクリックします
2. 「キーを作成」をクリックし、任意の名前を付けます
3. 作成後、**API キーを保存してください**（`sk-` で始まる値）

## ステップ 4 — ツールを設定する

**API ベース URL：**

ツールのプロトコルに合ったベース URL を選択してください：

**Anthropic プロトコル**（Claude Code、Cherry Studio、Trae、Claude / 中国語モデルを使う Kilo Code など）：

```
https://api.lmuai.com
```

**OpenAI プロトコル**（Codex CLI、Codex App、GPT を使う VS Code / Cursor、OpenAI モデルを使う Kilo Code など）：

```
https://api.lmuai.com/v1
```

<Callout type="warn" title="違い（最もよくある間違い）">

- **Anthropic プロトコル**には `/v1` サフィックスが**ありません**
- **OpenAI プロトコル**には `/v1` サフィックスが**必須です**

間違ったプロトコルを使うと 401 / 404 エラーが発生します。プロトコルの詳細、SDK / curl の例、Claude Max グループの制限については、**[API プロトコル →](/ja/docs/guide/api-protocols)** を参照してください。

</Callout>

以下の各ツール設定で必要になるため、この3つを手元に用意しておいてください：
- **API キー**：コンソールで作成した `sk-` キー（両方のプロトコルで共通）
- **Anthropic ベース URL**：`https://api.lmuai.com`
- **OpenAI ベース URL**：`https://api.lmuai.com/v1`
