## 数据驻留与内容留存

对企业最关键的三条原则（完整说明见[数据与隐私](/docs/guide/privacy)）：

- **账户数据不出境**：邮箱、手机号、订单、API Key 等账户数据仅存储在中国境内，不做跨境传输
- **请求内容不持久化**：prompt 与模型响应转发完成后即从内存释放，不写入任何数据库或文件
- **元数据留存 90 天**：调用时间、模型、token 用量等计费与排障所需的元数据保留 90 天，存储在中国境内

<Callout type="warn" title="跨境通道的诚实披露">

上游大模型（Claude、GPT 等）的服务器位于海外，请求体与响应体在转发过程中会经过海外通道——这是访问海外大模型的必要技术路径。通道不持久化数据、不携带账户身份，全程 TLS 加密。请勿通过 API 发送国家秘密、商业秘密、身份证号等高敏感内容；如有此类合规要求，请与商务讨论私有化网关方案。

</Callout>
