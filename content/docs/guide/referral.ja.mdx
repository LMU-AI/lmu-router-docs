友達を LMU AI に招待しましょう。彼らがチャージやサブスクリプションをするたびに、あなたはコミッションを獲得し続けます — 永久バインドで長期的な収入に。

---

## ルール

- 新規ユーザーがあなたの招待リンク経由で登録すると、そのユーザーは**あなたに永久にバインド**されます
- 彼らがチャージやサブスクリプションをするたびに、あなたは**10% の記帳コミッション**を獲得します
- コミッションは被招待者が実際に消費するにつれて段階的にリリースされます（チャージは残高消費の進捗を追跡し、サブスクリプションは経過日数を追跡します）
- 利用可能なコミッションは、API 支出のために**直接アカウント残高に振り替える**ことができるほか、WeChat / Alipay / 銀行カードへ出金することもできます
- 新規ユーザーは初回支払いで追加の **¥2.00** ボーナスを獲得します

---

## 参加方法

コンソールにログインし、左メニューの「**紹介報酬**」をクリックすると、専用の招待リンクと招待コードが表示されます。

### 方法 1：招待リンクを共有する

専用リンクをコピーして友達に送ります。友達がクリックして登録すると、バインドが完了します。形式は次のとおりです：

```
https://api.lmuai.com/register?ref=YOUR_INVITE_CODE
```

### 方法 2：招待コードを共有する

友達にあなたの招待コードを伝え、登録時に手動で入力してもらうことでバインドが完了します。

---

## コミッションの詳細

| 項目 | 説明 |
|------|------|
| コミッション率 | **10%**（被招待者のチャージ / サブスクリプションごと） |
| 新規ユーザーボーナス | 初回支払いで **¥2.00** |
| バインド方法 | リンク経由で登録すると永久バインドが作成される |
| コミッションのリリース | 被招待者が実際に消費するにつれて段階的にリリース |
| コミッションの用途 | 残高への振替（即時利用可能）または出金 |

---

## 閲覧と出金

コンソールにログイン後、左メニューの「**紹介報酬**」をクリックすると、以下を確認できます：

- 累計コミッション、利用可能なコミッション、リリース済み金額
- 招待した人数と各コミッションの内訳
- 利用可能なコミッションをワンクリックで残高に振り替え、または出金申請

<Callout type="info" title="ヒント">

招待リンクはプロモーションの痕跡を隠すため、共有がより自然に感じられます。コンソールの「紹介報酬」ページでは専用の QR コードをダウンロードでき、コミュニティやモーメンツなどで簡単に共有できます。

</Callout>
