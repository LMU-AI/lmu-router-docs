## الخطوة 1 — إنشاء حساب

اذهب إلى صفحة التسجيل: [https://api.lmuai.com/register?ref=vJaWWr4T](https://api.lmuai.com/register?ref=vJaWWr4T)

أدخل بريدك الإلكتروني وكلمة مرور لإكمال التسجيل.

## الخطوة 2 — الاشتراك أو شحن الرصيد

بعد تسجيل الدخول، انقر على "**شحن الرصيد / الاشتراك**" في القائمة اليسرى:

- **الاشتراك**: اختر خطة واحصل على حصة شهرية ثابتة
- **شحن الرصيد**: أضف رصيدًا حسب الحاجة واستخدم أي نموذج بمرونة

تكون جاهزًا للانطلاق بمجرد اكتمال الدفع.

## الخطوة 3 — إنشاء مفتاح API [#create-key]

1. انقر على "**API Keys**" في القائمة اليسرى
2. انقر على "إنشاء مفتاح" وأعطه أي اسم
3. بمجرد إنشائه، **احفظ مفتاح API الخاص بك** (القيمة التي تبدأ بـ `sk-`)

## الخطوة 4 — تهيئة أداتك

**عنوان URL الأساسي لـ API:**

اختر عنوان URL الأساسي الذي يطابق بروتوكول أداتك:

**بروتوكول Anthropic** (Claude Code وCherry Studio وTrae وKilo Code مع Claude / النماذج الصينية، إلخ):

```
https://api.lmuai.com
```

**بروتوكول OpenAI** (Codex CLI وCodex App وVS Code / Cursor مع GPT وKilo Code مع نماذج OpenAI، إلخ):

```
https://api.lmuai.com/v1
```

<Callout type="warn" title="الفرق (الخطأ الأكثر شيوعًا)">

- **بروتوكول Anthropic** **بدون** لاحقة `/v1`
- **بروتوكول OpenAI** **يجب** أن يتضمن لاحقة `/v1`

استخدام البروتوكول الخاطئ يسبب أخطاء 401 / 404. للاطلاع على تفاصيل البروتوكول الكاملة وأمثلة SDK / curl وحدود مجموعة Claude Max، راجع **[بروتوكولات API →](/ar/docs/guide/api-protocols)**.

</Callout>

احتفظ بهذه الأشياء الثلاثة في متناول يدك — كل إعداد أداة أدناه يحتاجها:
- **مفتاح API**: مفتاح `sk-` الذي أنشأته في لوحة التحكم (مشترك بين البروتوكولين)
- **عنوان Anthropic الأساسي**: `https://api.lmuai.com`
- **عنوان OpenAI الأساسي**: `https://api.lmuai.com/v1`
