A continuación están todos los nombres de modelos que la API de LMU AI admite actualmente. **Haz clic en cualquier tarjeta para copiar su ID de modelo** y luego pégalo directamente en `settings.json`, `config.toml` o el selector de modelos de una herramienta.

<Callout type="info" title="Cómo usar el nombre de un modelo">

Pega el ID de modelo copiado en la configuración de tu herramienta:

- **Claude Code** → el campo `"model"` en `settings.json`
- **Codex CLI** → `model = "..."` en `~/.codex/config.toml`
- **Cherry Studio / extensión de VS Code** → pégalo en el menú desplegable de modelos

</Callout>

## Elige un modelo según el caso de uso

¿No estás seguro de qué modelo usar? Localízalo en la tabla de abajo y luego copia el ID de modelo de la sección correspondiente.

| Caso de uso | Modelos recomendados | Por qué |
|---|---|---|
| Refactorizaciones complejas, cambios grandes entre archivos | `claude-opus-5` | El nivel insignia de Claude, sobresaliente en código y texto largo, el predeterminado para Claude Code |
| Programación diaria, corrección de errores | `claude-sonnet-5` · `claude-sonnet-4-6` | Nivel equilibrado, un compromiso entre capacidad y velocidad, ideal para uso frecuente diario |
| Tareas ligeras frecuentes (autocompletado, formateo, ediciones pequeñas en bloque) | `claude-haiku-4-5` · `deepseek-v4-flash` · `qwen3.6-flash` | Nivel de alta velocidad, para tareas simples individuales invocadas muchas veces |
| Cadena de herramientas Codex CLI / Codex App | `gpt-5.6-sol` · `gpt-5.4` | El último insignia del lado de OpenAI y el predeterminado en la plantilla de configuración de Codex CLI |
| Escritura en chino, documentación, conversación | `qwen3.8-max-preview` · `glm-5.2` · `kimi-k3` | LLM chinos con excelente comprensión del chino a un precio más bajo |
| Programación en contextos en chino | `qwen3.6-plus` · `deepseek-v4-pro` | Modelos chinos orientados al código, invocables directamente con el saldo de la cuenta |
| Multimodal (entrada mixta de imagen + texto) | `mimo-v2-omni` | El único modelo conversacional marcado como multimodal aquí; para generación de imágenes pura, consulta las APIs de imagen más abajo |

<Callout type="warn" title="Confirma dos cosas antes de elegir">

- **La disponibilidad del modelo depende del grupo**: qué modelos puedes invocar realmente es lo que muestra la página **Modelos disponibles** en la consola. Por ejemplo, la serie GPT requiere una suscripción a GPT, o seleccionar un grupo GPT en la facturación por consumo. **Esto es independiente del protocolo con el que invocas.**
- **La Base URL debe coincidir con el protocolo**: el protocolo lo decide tu cliente y SDK: la Base URL del protocolo Anthropic es **sin** `/v1`, el protocolo OpenAI **debe incluir** `/v1`, y el nativo de Gemini usa `/v1beta/models/...`. Equivocarse da un 404 directo; consulta [Protocolos de API](/es/docs/guide/api-protocols).

</Callout>
