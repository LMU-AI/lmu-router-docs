灵眸提供两类**异步**视频生成接口，均使用原厂**原生协议**：把官方 SDK 或 curl 里的地址换成灵眸地址、密钥换成灵眸 API Key 即可调用，无需改写请求体。本页是总览：先按下表选好接口，再看对应的分厂商文档；鉴权、计费、并发上限和错误码这些两家通用的规则都在本页。

<Callout type="info" title="Base URL">

```text
https://api.lmuai.com
```

| 提供方 | 创建任务 | 查询任务 | 文档 |
|---|---|---|---|
| Seedance（火山方舟） | `POST /api/v3/contents/generations/tasks` | `GET /api/v3/contents/generations/tasks/{id}` | [Seedance 视频生成 API](/docs/api/seedance-video) |
| 千问万相（DashScope） | `POST /api/v1/services/aigc/video-generation/video-synthesis` | `GET /api/v1/tasks/{task_id}` | [千问万相视频生成 API](/docs/api/wan-video) |

</Callout>

<Callout type="warn" title="需要分组开通视频生成">

API Key 所属分组需开启「视频生成」才能调用，否则返回 `403`。实际可调用的模型以你的 API Key 为准，可用 `GET /v1/models` 查询。

</Callout>

## 1. 两家怎么选 [#compare]

| | Seedance（火山方舟） | 千问万相（DashScope） |
|---|---|---|
| 模型示例 | `seedance-2.5` | `wan3.0-video` |
| 计费方式 | 按输出 token | 按「实际秒数 × 分辨率档位单价」 |
| 分辨率写法 | `480p` / `720p` / `1080p`（小写） | `480P` / `720P` / `1080P`（大写），缺省 `1080P` |
| 任务状态 | `queued` → `running` → `succeeded` / `failed` / `cancelled` | `PENDING` → `RUNNING` → `SUCCEEDED` / `FAILED` / `CANCELED` |
| 视频地址字段 | `content.video_url` | `output.video_url` |
| 取消任务 | 排队中（`queued`）的任务可取消 | 没有取消接口，提交后一定会跑完 |

模型名需与分组开放的名字**逐字一致**（区分大小写）。两家的字段名很像，但大小写和路径不同，照抄示例时不要混用。

## 2. 鉴权 [#auth]

所有请求在 Header 中携带 API Key：

```http
Authorization: Bearer YOUR_API_KEY
```

不要把 API Key 放在浏览器前端、公开仓库、URL Query 或日志中。建议由自己的服务端调用。

## 3. 异步任务流程 [#flow]

1. **创建**：`POST` 只返回任务 id，不会等待出片。
2. **轮询**：每 10 秒左右 `GET` 一次任务，直到终态（成功 / 失败 / 取消）。
3. **参考图**：API 调用需传公网可访问的图片 URL（JPG / PNG / WebP）；控制台「视频生成」页支持直接上传本地图片。
4. **下载**：成功后从响应里取视频链接。上游链接 **24 小时内有效**，请及时下载；平台会为成片保留副本，可在控制台「视频任务」页播放和下载。

<Callout type="info" title="不轮询也会正常结算">

提交后即使不再查询，任务也会由平台在后台跟进并正常结算；失败、取消的任务不收费。

</Callout>

完整的「创建并轮询」示例见 [Seedance](/docs/api/seedance-video#poll-example) 与[千问万相](/docs/api/wan-video#poll-example)的文档。

## 4. 计费与水印 [#billing]

- 创建时冻结预估金额，余额不足会直接拒绝（`402`），不会生成视频。
- 成功后按实际用量结算一次，多余的冻结额自动退回；失败、取消的任务全额退回、不收费。
- Seedance 按输出 token 计费；千问万相按「实际秒数 × 分辨率档位单价」计费。
- 成片会带平台的「AI 生成」标识，客户端无法关闭。

## 5. 并发上限 [#limits]

同一用户、同一 API Key 各自最多同时有 **5 个**生成中的任务。超限返回 `429`，并带 `Retry-After`（约 60 秒），请退避后重试。

## 6. 错误码 [#errors]

| HTTP | 含义 | 处理建议 |
|---|---|---|
| `401` | API Key 无效或已停用 | 检查 API Key |
| `402` | 余额或额度不足，无法冻结本次预估金额 | 充值后重试 |
| `403` | 分组未开启视频生成，或该模型不在分组开放范围内 | 换用支持视频生成的 API Key |
| `404 model_not_found` | 模型暂未开放（名字拼写不一致也会触发） | 按 `GET /v1/models` 返回的名字逐字填写 |
| `409` | 任务已开始生成，不能取消（Seedance 取消接口） | 等待任务结束 |
| `429` | 在途任务数达到上限 | 按 `Retry-After` 退避重试 |

更多通用错误见[错误码速查](/docs/guide/errors)。
