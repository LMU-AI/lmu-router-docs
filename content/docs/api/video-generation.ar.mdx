توفّر LMU AI نوعين من واجهات API **غير المتزامنة** لتوليد الفيديو، وكلاهما يستخدم **البروتوكولات الأصلية** للمزوّدين: استبدل العنوان في الـ SDK الرسمي أو أمر curl بعنوان LMU AI، واستبدل المفتاح بمفتاح API الخاص بك من LMU AI، ويبقى جسم الطلب دون تغيير. هذه الصفحة نظرة عامة: اختر واجهة API من الجدول أدناه، ثم اقرأ صفحة المزوّد الخاصة بها. أما القواعد المشتركة بين المزوّدَين (المصادقة والفوترة وحدود التزامن ورموز الأخطاء) فموجودة في هذه الصفحة.

<Callout type="info" title="عنوان URL الأساسي">

```text
https://api.lmuai.com
```

| المزوّد | إنشاء مهمة | الاستعلام عن مهمة | التوثيق |
|---|---|---|---|
| Seedance (Volcengine Ark) | `POST /api/v3/contents/generations/tasks` | `GET /api/v3/contents/generations/tasks/{id}` | [واجهة Seedance API لتوليد الفيديو](/ar/docs/api/seedance-video) |
| Wan (Alibaba DashScope) | `POST /api/v1/services/aigc/video-generation/video-synthesis` | `GET /api/v1/tasks/{task_id}` | [واجهة Wan API لتوليد الفيديو](/ar/docs/api/wan-video) |

</Callout>

<Callout type="warn" title="يجب تفعيل توليد الفيديو لمجموعتك">

يجب أن تكون ميزة "توليد الفيديو" مفعّلة لمجموعة مفتاح API؛ وإلا فستُعيد الاستدعاءات الرمز `403`. تعتمد النماذج التي يمكنك استدعاؤها فعليًا على مفتاح API الخاص بك؛ تحقّق منها باستخدام `GET /v1/models`.

</Callout>

## 1. الاختيار بين الواجهتين [#compare]

| | Seedance (Volcengine Ark) | Wan (Alibaba DashScope) |
|---|---|---|
| مثال على النموذج | `seedance-2.5` | `wan3.0-video` |
| الفوترة | حسب رموز الإخراج (Token) | حسب "الثواني الفعلية × سعر الوحدة لفئة الدقة" |
| قيم الدقة | `480p` / `720p` / `1080p` (أحرف صغيرة) | `480P` / `720P` / `1080P` (أحرف كبيرة)، والقيمة الافتراضية `1080P` |
| حالة المهمة | `queued` ← `running` ← `succeeded` / `failed` / `cancelled` | `PENDING` ← `RUNNING` ← `SUCCEEDED` / `FAILED` / `CANCELED` |
| حقل رابط الفيديو | `content.video_url` | `output.video_url` |
| إلغاء مهمة | يمكن إلغاء المهام في قائمة الانتظار (`queued`) | لا توجد نقطة نهاية للإلغاء؛ فالمهمة المُرسَلة تستمر دائمًا حتى الاكتمال |

يجب أن يطابق اسم النموذج الاسمَ المفعّل لمجموعتك **تمامًا** (مع مراعاة حالة الأحرف). تستخدم الواجهتان أسماء حقول متشابهة لكن بحالة أحرف ومسارات مختلفة، فلا تخلط بينهما عند نسخ الأمثلة.

## 2. المصادقة [#auth]

أرسل مفتاح API الخاص بك في ترويسة كل طلب:

```http
Authorization: Bearer YOUR_API_KEY
```

لا تضع مفتاح API في كود الواجهة الأمامية للمتصفح، أو في المستودعات العامة، أو في سلاسل استعلام URL، أو في السجلات. استدعِ الـ API من خادمك الخاص.

## 3. تدفق المهام غير المتزامنة [#flow]

1. **الإنشاء**: يُعيد `POST` معرّف المهمة فقط؛ ولا ينتظر الفيديو.
2. **الاستطلاع**: نفّذ `GET` على المهمة كل 10 ثوانٍ تقريبًا حتى تصل إلى حالة نهائية (نجاح / فشل / إلغاء).
3. **الصور المرجعية**: يجب أن تمرّر استدعاءات الـ API رابط URL لصورة يمكن الوصول إليه علنًا (JPG / PNG / WebP)؛ أما صفحة توليد الفيديو في وحدة التحكم فتقبل رفع الصور المحلية.
4. **التنزيل**: عند النجاح، خذ رابط الفيديو من الاستجابة. تكون روابط المزوّد الأصلي **صالحة لمدة 24 ساعة**، لذا نزّلها بسرعة؛ وتحتفظ المنصة بنسخة من كل فيديو مكتمل، ويمكنك تشغيلها وتنزيلها من صفحة مهام الفيديو في وحدة التحكم.

<Callout type="info" title="تتم التسوية حتى لو توقفت عن الاستطلاع">

بعد الإرسال، تتابع المنصة المهمة في الخلفية وتسوّيها بشكل طبيعي حتى لو توقفت عن الاستعلام؛ ولا تُحتسب رسوم على المهام الفاشلة والملغاة.

</Callout>

للاطلاع على أمثلة كاملة للإنشاء والاستطلاع، راجع صفحتَي [Seedance](/ar/docs/api/seedance-video#poll-example) و[Wan](/ar/docs/api/wan-video#poll-example).

## 4. الفوترة والعلامات المائية [#billing]

- يُجمَّد مبلغ تقديري عند إنشاء المهمة. إذا كان رصيدك غير كافٍ، يُرفض الطلب مباشرةً (`402`) ولا يُولَّد أي فيديو.
- عند النجاح، تُسوّى المهمة مرة واحدة وفق الاستخدام الفعلي، ويُعاد أي فائض من المبلغ المجمَّد تلقائيًا؛ أما المهام الفاشلة والملغاة فتُستردّ قيمتها بالكامل ولا تُحتسب عليها رسوم.
- تُحتسب رسوم Seedance حسب رموز الإخراج (Token)؛ وتُحتسب رسوم Wan حسب "الثواني الفعلية × سعر الوحدة لفئة الدقة".
- تحمل الفيديوهات المكتملة علامة "مُولَّد بالذكاء الاصطناعي" الخاصة بالمنصة، ولا يمكن للعملاء إيقافها.

## 5. حدود التزامن [#limits]

يمكن لكل مستخدم ولكل مفتاح API أن يملك **5** مهام كحد أقصى قيد التوليد في الوقت نفسه. وعند تجاوز ذلك، تُعيد الطلبات الرمز `429` مع ترويسة `Retry-After` (نحو 60 ثانية)؛ تراجَع ثم أعد المحاولة.

## 6. رموز الأخطاء [#errors]

| HTTP | المعنى | ما يجب فعله |
|---|---|---|
| `401` | مفتاح API غير صالح أو معطّل | تحقّق من مفتاح API الخاص بك |
| `402` | الرصيد أو الحصة غير كافيين لتجميد المبلغ التقديري | اشحن رصيدك وأعد المحاولة |
| `403` | لم يُفعَّل توليد الفيديو للمجموعة، أو أن النموذج غير متاح في المجموعة | استخدم مفتاح API يدعم توليد الفيديو |
| `404 model_not_found` | النموذج غير متاح بعد (الخطأ الإملائي في الاسم يؤدي إلى ذلك أيضًا) | استخدم الاسم الدقيق الذي يُعيده `GET /v1/models` |
| `409` | بدأت المهمة في التوليد ولا يمكن إلغاؤها (نقطة نهاية الإلغاء في Seedance) | انتظر حتى تكتمل المهمة |
| `429` | بلغ عدد المهام الجارية الحد الأقصى | تراجَع وفقًا لـ `Retry-After` ثم أعد المحاولة |

للأخطاء العامة، راجع [رموز الأخطاء](/ar/docs/guide/errors).
