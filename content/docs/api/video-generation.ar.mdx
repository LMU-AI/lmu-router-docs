يوفّر LMU AI نوعين من واجهات API **غير المتزامنة** لتوليد الفيديو، ويعتمد كلاهما **البروتوكول الأصلي** لدى المزوّد. يكفي أن تستبدل في SDK الرسمي أو أمر curl العنوانَ بعنوان LMU AI، والمفتاحَ بمفتاح LMU AI API الخاص بك، ويبقى جسم الطلب كما هو دون تغيير.

<Callout type="info" title="عنوان URL الأساسي">

```text
https://api.lmuai.com
```

| المزوّد | إنشاء مهمة | الاستعلام عن مهمة |
|---|---|---|
| Seedance (Volcengine Ark) | `POST /api/v3/contents/generations/tasks` | `GET /api/v3/contents/generations/tasks/{id}` |
| Wan (Alibaba DashScope) | `POST /api/v1/services/aigc/video-generation/video-synthesis` | `GET /api/v1/tasks/{task_id}` |

</Callout>

<Callout type="warn" title="يجب تفعيل توليد الفيديو لمجموعتك">

يجب أن تكون ميزة "توليد الفيديو" مفعّلة لمجموعة مفتاح API، وإلا أعادت الاستدعاءات الرمز `403`. تتحدد النماذج المتاحة لك فعليًا بحسب مفتاح API، ويمكنك معرفتها عبر `GET /v1/models`.

</Callout>

## 1. نظرة عامة

| المزوّد | نموذج على سبيل المثال | الفوترة |
|---|---|---|
| Seedance (Volcengine Ark) | `seedance-2.5` | بحسب Token المخرجات |
| Wan (Alibaba DashScope) | `wan3.0-video` | بحسب "عدد الثواني × فئة الدقة" |

يجب أن يطابق اسم النموذج **تمامًا** الاسمَ المفعّل لمجموعتك، مع مراعاة حالة الأحرف.

## 2. المصادقة

أرسل مفتاح API في ترويسة كل طلب:

```http
Authorization: Bearer YOUR_API_KEY
```

لا تضع مفتاح API في شيفرة الواجهة الأمامية للمتصفح، ولا في المستودعات العامة، ولا في سلاسل الاستعلام ضمن عناوين URL، ولا في السجلات. استدعِ الواجهة من خادمك الخاص.

## 3. سير المهمة غير المتزامنة

1. **الإنشاء**: يعيد طلب `POST` معرّف المهمة فقط، ولا ينتظر اكتمال الفيديو.
2. **الاستعلام الدوري**: أرسل طلب `GET` عن المهمة كل 10 ثوانٍ تقريبًا حتى تبلغ حالة نهائية (نجاح / فشل / إلغاء).
3. **الصور المرجعية**: يجب أن تمرّر استدعاءات API عنوان URL لصورة متاحة للعموم (JPG / PNG / WebP). أما صفحة "توليد الفيديو" في وحدة التحكم فتقبل رفع الصور من جهازك.
4. **التنزيل**: عند النجاح، خذ رابط الفيديو من الاستجابة. تظل روابط المزوّد **صالحة لمدة 24 ساعة**، فاحرص على تنزيلها مبكرًا. تحتفظ المنصة بنسخة من كل فيديو مكتمل، ويمكنك تشغيلها وتنزيلها من صفحة "مهام الفيديو" في وحدة التحكم.

<Callout type="info" title="تُسوّى الفوترة حتى إن توقفت عن الاستعلام">

بعد إرسال المهمة، تتابعها المنصة في الخلفية وتسوّيها على النحو المعتاد حتى إن توقفت عن الاستعلام. ولا تُحتسب أي رسوم على المهام الفاشلة أو الملغاة.

</Callout>

## 4. Seedance · إنشاء مهمة

### `POST /api/v3/contents/generations/tasks`

| المعامل | النوع | إلزامي | الوصف |
|---|---|---|---|
| `model` | string | نعم | اسم النموذج، ويجب أن يطابق تمامًا الاسمَ المفعّل لمجموعتك (مع مراعاة حالة الأحرف) |
| `content` | array | نعم | محتوى الإدخال. النص: `{"type":"text","text":"…"}`؛ الصورة المرجعية: `{"type":"image_url","image_url":{"url":"…"},"role":"first_frame"}`، وتكون قيمة `role` إما `first_frame` (الإطار الأول) أو `reference_image` (صورة مرجعية) |
| `resolution` | string | لا | فئة الدقة: `480p` / `720p` / `1080p` |
| `duration` | integer | لا | مدة الفيديو بالثواني |
| `ratio` | string | لا | نسبة العرض إلى الارتفاع: `16:9` / `9:16` / `1:1` / `4:3` |
| `generate_audio` | boolean | لا | تحديد ما إذا كان الصوت يُولَّد مع الفيديو |

## 5. Seedance · الاستعلام عن مهمة

### `GET /api/v3/contents/generations/tasks/{id}`

قيم `status`: `queued` ← `running` ← `succeeded` / `failed` / `cancelled`. عند النجاح، يوجد عنوان URL للفيديو في `content.video_url`.

```bash
curl https://api.lmuai.com/api/v3/contents/generations/tasks/TASK_ID \
  -H "Authorization: Bearer YOUR_API_KEY"
```

  "content": {
    "video_url": "https://…/video.mp4"
  },
  "usage": {
    "completion_tokens": 108900,
    "total_tokens": 108900
  },
  "created_at": 1792629131,

## 6. Seedance · عرض قائمة المهام

### `GET /api/v3/contents/generations/tasks?limit=20&offset=0`

يعيد المهام التي أُنشئت بمفتاح API الحالي (تتراوح قيمة `limit` بين 1 و100، والقيمة الافتراضية 20). صيغة الاستجابة هي `{object, data[], has_more}`. ويظل الاستعلام عن سجلات المهام ممكنًا بعد انتهاء صلاحية رابط الفيديو.

## 7. Seedance · الإلغاء / الحذف

### `DELETE /api/v3/contents/generations/tasks/{id}`

- يمكن إلغاء المهام التي لا تزال في قائمة الانتظار (`queued`) دون أي رسوم.
- لا يمكن إلغاء المهام التي بدأ توليدها (`running`)، ويُعاد حينها الرمز `409`.
- يمكن حذف سجل المهام المكتملة لدى المزوّد، دون استرداد أي مبلغ.

## 8. Wan · إنشاء مهمة

### `POST /api/v1/services/aigc/video-generation/video-synthesis`

مطابق تمامًا للبروتوكول الأصلي في Alibaba Cloud Model Studio (DashScope). ترويسة التنفيذ غير المتزامن `X-DashScope-Async: enable` اختيارية، إذ تضيفها المنصة تلقائيًا.

| المعامل | النوع | إلزامي | الوصف |
|---|---|---|---|
| `model` | string | نعم | مثلًا `wan3.0-video` |
| `input.prompt` | string | نعم | الموجّه |
| `input.media` | array | لا | الوسائط المرجعية، مثل `[{"type":"first_frame","url":"…"}]`، وتكون قيمة `type` إما `first_frame` أو `reference_image` |
| `parameters.resolution` | string | لا | فئة الدقة: `480P` / `720P` / `1080P`، والقيمة الافتراضية `1080P` |
| `parameters.duration` | integer | لا | المدة بالثواني، والقيمة الافتراضية 5 |
| `parameters.watermark` | boolean | لا | تضبطه المنصة بشكل موحّد وفق سياسة المجموعة، وقد تُتجاوز القيمة التي يرسلها العميل |

## 9. Wan · الاستعلام عن مهمة

## 10. الفوترة والعلامات المائية

- يُجمَّد مبلغ تقديري عند إنشاء المهمة. إذا لم يكفِ رصيدك، يُرفض الطلب مباشرةً (`402`) ولا يُولَّد أي فيديو.
- عند النجاح، تُسوّى المهمة مرة واحدة بحسب الاستخدام الفعلي، ويُعاد تلقائيًا أي فائض من المبلغ المجمّد. أما المهام الفاشلة والملغاة فيُستردّ مبلغها بالكامل ولا تُحتسب عليها أي رسوم.
- يُحتسب Seedance بحسب Token المخرجات، ويُحتسب Wan بحسب "عدد الثواني الفعلية × سعر الوحدة لفئة الدقة".
- تحمل الفيديوهات المكتملة وسم المنصة "مُولَّد بالذكاء الاصطناعي"، ولا يمكن للعملاء تعطيله.

## 11. حدود التزامن

يمكن لكل مستخدم ولكل مفتاح API تشغيل **5** مهام توليد كحد أقصى في الوقت نفسه. وما يتجاوز ذلك يعيد الرمز `429` مع ترويسة `Retry-After` (نحو 60 ثانية)، فانتظر ثم أعد المحاولة.

## 12. رموز الأخطاء

| HTTP | المعنى | الإجراء المطلوب |
|---|---|---|
| `401` | مفتاح API غير صالح أو معطّل | تحقّق من مفتاح API |
| `402` | الرصيد أو الحصة غير كافيين لتجميد المبلغ التقديري | اشحن رصيدك ثم أعد المحاولة |
| `403` | توليد الفيديو غير مفعّل للمجموعة، أو النموذج غير متاح لها | استخدم مفتاح API يدعم توليد الفيديو |
| `404 model_not_found` | النموذج غير متاح بعد (ويظهر هذا الخطأ أيضًا عند وجود خطأ إملائي في الاسم) | استخدم الاسم كما يعيده `GET /v1/models` تمامًا |
| `409` | بدأ توليد المهمة ولا يمكن إلغاؤها | انتظر حتى تكتمل المهمة |
| `429` | بلغ عدد المهام الجارية الحد الأقصى | انتظر المدة المحددة في `Retry-After` ثم أعد المحاولة |

للاطلاع على الأخطاء العامة، راجع [رموز الأخطاء](/ar/docs/guide/errors).

## 13. مثال كامل: الإنشاء والاستعلام الدوري

<Tabs items={['Seedance', 'Wan']}>
<Tab value="Seedance">

```python
import time, requests

BASE = "https://api.lmuai.com"
HEADERS = {"Authorization": "Bearer YOUR_API_KEY"}

# 1. Create the task
resp = requests.post(f"{BASE}/api/v3/contents/generations/tasks", headers=HEADERS, json={
    "model": "seedance-2.5",
    "content": [{"type": "text", "text": "Waves gently lapping the beach at dusk, slow motion"}],
    "resolution": "720p", "duration": 5, "ratio": "16:9",
})
resp.raise_for_status()
task_id = resp.json()["id"]

# 2. Poll until a final state (every 10 seconds)
while True:
    task = requests.get(f"{BASE}/api/v3/contents/generations/tasks/{task_id}", headers=HEADERS).json()
    status = task["status"]
    if status in ("succeeded", "failed", "cancelled", "canceled", "expired"):
        break
    time.sleep(10)

# 3. Download (the link is valid for 24 hours)
if status == "succeeded":
    url = task["content"]["video_url"]
    with open(f"{task_id}.mp4", "wb") as f:
        f.write(requests.get(url).content)
else:
    print("Generation failed:", task)
```
