LMU AI provides two kinds of **asynchronous** video generation APIs, both using the vendors' **native protocols**: replace the address in the official SDK or curl command with the LMU AI address and the key with your LMU AI API key, and the request body stays unchanged.

<Callout type="info" title="Base URL">

```text
https://api.lmuai.com
```

| Provider | Create task | Query task |
|---|---|---|
| Seedance (Volcengine Ark) | `POST /api/v3/contents/generations/tasks` | `GET /api/v3/contents/generations/tasks/{id}` |
| Wan (Alibaba DashScope) | `POST /api/v1/services/aigc/video-generation/video-synthesis` | `GET /api/v1/tasks/{task_id}` |

</Callout>

<Callout type="warn" title="Video generation must be enabled for your group">

The API key's group must have "Video generation" enabled; otherwise calls return `403`. The models you can actually call depend on your API key — check them with `GET /v1/models`.

</Callout>

## 1. Overview

| Provider | Example model | Billing |
|---|---|---|
| Seedance (Volcengine Ark) | `seedance-2.5` | By output tokens |
| Wan (Alibaba DashScope) | `wan3.0-video` | By "seconds × resolution tier" |

The model name must match the name enabled for your group **exactly** (case-sensitive).

## 2. Authentication

Send your API key in the header of every request:

```http
Authorization: Bearer YOUR_API_KEY
```

Do not put your API key in browser front-end code, public repositories, URL query strings, or logs. Call the API from your own server.

## 3. Asynchronous task flow

1. **Create**: `POST` only returns a task id; it does not wait for the video.
2. **Poll**: `GET` the task about every 10 seconds until it reaches a final state (succeeded / failed / cancelled).
3. **Reference images**: API calls must pass a publicly accessible image URL (JPG / PNG / WebP); the Video Generation page in the console accepts local image uploads.
4. **Download**: on success, take the video link from the response. Upstream links are **valid for 24 hours**, so download promptly; the platform keeps a copy of each finished video, which you can play and download on the Video Tasks page in the console.

<Callout type="info" title="Billing settles even if you stop polling">

After submission, the platform follows up on the task in the background and settles it normally even if you stop querying; failed and cancelled tasks are not charged.

</Callout>

## 4. Seedance · Create a task

### `POST /api/v3/contents/generations/tasks`

| Parameter | Type | Required | Description |
|---|---|---|---|
| `model` | string | Yes | Model name; must exactly match the name enabled for your group (case-sensitive) |
| `content` | array | Yes | Input content. Text: `{"type":"text","text":"…"}`; reference image: `{"type":"image_url","image_url":{"url":"…"},"role":"first_frame"}`, where `role` can be `first_frame` (first frame) or `reference_image` (reference image) |
| `resolution` | string | No | Resolution tier: `480p` / `720p` / `1080p` |
| `duration` | integer | No | Video length in seconds |
| `ratio` | string | No | Aspect ratio: `16:9` / `9:16` / `1:1` / `4:3` |
| `generate_audio` | boolean | No | Whether to generate audio as well |

To use a first-frame reference image, append an image item to `content`:

```json
{
  "model": "seedance-2.5",
  "content": [
    {"type": "text", "text": "The camera slowly pushes in as waves gently lap the beach"},
    {"type": "image_url", "image_url": {"url": "https://example.com/first-frame.png"}, "role": "first_frame"}
  ],
  "resolution": "720p",
  "duration": 5
}
```

<Callout type="warn" title="Notes">

- In first-frame mode (`role` is `first_frame`), **do not send `ratio`**: the aspect ratio follows the first-frame image, and the upstream rejects the request with `400` if you send it.
- `callback_url` is not forwarded upstream; you will not receive a callback even if you pass it. Use polling instead.

</Callout>

## 5. Seedance · Query a task

### `GET /api/v3/contents/generations/tasks/{id}`

`status` values: `queued` → `running` → `succeeded` / `failed` / `cancelled`. On success, the video URL is in `content.video_url`.

```bash
curl https://api.lmuai.com/api/v3/contents/generations/tasks/TASK_ID \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Response (success):

```json
{
  "id": "cgt-20261022103211-ab12c",
  "model": "seedance-2.5",
  "status": "succeeded",
  "content": {
    "video_url": "https://…/video.mp4"
  },
  "usage": {
    "completion_tokens": 108900,
    "total_tokens": 108900
  },
  "created_at": 1792629131,
  "updated_at": 1792629262
}
```

## 6. Seedance · List tasks

### `GET /api/v3/contents/generations/tasks?limit=20&offset=0`

Returns the tasks created with the current API key (`limit` from 1 to 100, default 20). The response is `{object, data[], has_more}`. Task records remain queryable after the video link expires.

## 7. Seedance · Cancel / delete

### `DELETE /api/v3/contents/generations/tasks/{id}`

- Tasks still in the queue (`queued`) can be cancelled at no charge.
- Tasks that have started generating (`running`) cannot be cancelled and return `409`.
- Finished tasks can have their upstream record deleted, with no refund.

## 8. Wan · Create a task

### `POST /api/v1/services/aigc/video-generation/video-synthesis`

Identical to the native Alibaba Cloud Model Studio (DashScope) protocol. The async header `X-DashScope-Async: enable` is optional; the platform adds it automatically.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `model` | string | Yes | For example `wan3.0-video` |
| `input.prompt` | string | Yes | Prompt |
| `input.media` | array | No | Reference media, such as `[{"type":"first_frame","url":"…"}]`; `type` can be `first_frame` or `reference_image` |
| `parameters.resolution` | string | No | Resolution tier: `480P` / `720P` / `1080P`, default `1080P` |
| `parameters.duration` | integer | No | Length in seconds, default 5 |
| `parameters.watermark` | boolean | No | Set uniformly by the platform according to group policy; a client-supplied value may be overridden |

## 9. Wan · Query a task

### `GET /api/v1/tasks/{task_id}`

`output.task_status` values: `PENDING` → `RUNNING` → `SUCCEEDED` / `FAILED` / `CANCELED`. On success, the video URL is in `output.video_url`, and the billed seconds are in `usage.duration`. There is no cancel endpoint: once submitted, a task always runs to completion.

```bash
curl https://api.lmuai.com/api/v1/tasks/TASK_ID \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Response (success):

```json
{
  "request_id": "…",
  "output": {
    "task_id": "c65c77fe-323b-4140-8de6-5a7241d9ec44",
    "task_status": "SUCCEEDED",
    "video_url": "https://…/output.mp4"
  },
  "usage": {
    "duration": 2.0,
    "video_count": 1
  }
}
```

## 10. Billing and watermarks

- An estimated amount is frozen when the task is created. If your balance is insufficient, the request is rejected outright (`402`) and no video is generated.
- On success, the task is settled once by actual usage, and any excess frozen amount is returned automatically; failed and cancelled tasks are fully refunded and not charged.
- Seedance is billed by output tokens; Wan is billed by "actual seconds × resolution-tier unit price".
- Finished videos carry the platform's "AI-generated" label, which clients cannot turn off.

## 11. Concurrency limits

Each user and each API key can have at most **5** tasks generating at the same time. Beyond that, requests return `429` with a `Retry-After` header (about 60 seconds); back off and retry.

## 12. Error codes

| HTTP | Meaning | What to do |
|---|---|---|
| `401` | The API key is invalid or disabled | Check your API key |
| `402` | Insufficient balance or quota to freeze the estimated amount | Top up and retry |
| `403` | Video generation is not enabled for the group, or the model is not available in the group | Use an API key that supports video generation |
| `404 model_not_found` | The model is not available yet (a misspelled name also triggers this) | Use the exact name returned by `GET /v1/models` |
| `409` | The task has started generating and cannot be cancelled | Wait for the task to finish |
| `429` | The number of in-flight tasks has reached the limit | Back off according to `Retry-After` and retry |

For general errors, see [Error Codes](/en/docs/guide/errors).

## 13. Complete example: create and poll

<Tabs items={['Seedance', 'Wan']}>
<Tab value="Seedance">

```python
import time, requests

BASE = "https://api.lmuai.com"
HEADERS = {"Authorization": "Bearer YOUR_API_KEY"}

# 1. Create the task
resp = requests.post(f"{BASE}/api/v3/contents/generations/tasks", headers=HEADERS, json={
    "model": "seedance-2.5",
    "content": [{"type": "text", "text": "Waves gently lapping the beach at dusk, slow motion"}],
    "resolution": "720p", "duration": 5, "ratio": "16:9",
})
resp.raise_for_status()
task_id = resp.json()["id"]

# 2. Poll until a final state (every 10 seconds)
while True:
    task = requests.get(f"{BASE}/api/v3/contents/generations/tasks/{task_id}", headers=HEADERS).json()
    status = task["status"]
    if status in ("succeeded", "failed", "cancelled", "canceled", "expired"):
        break
    time.sleep(10)

# 3. Download (the link is valid for 24 hours)
if status == "succeeded":
    url = task["content"]["video_url"]
    with open(f"{task_id}.mp4", "wb") as f:
        f.write(requests.get(url).content)
else:
    print("Generation failed:", task)
```
