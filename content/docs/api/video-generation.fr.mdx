LMU AI propose deux types d'API de génération vidéo **asynchrones**, qui utilisent toutes deux les **protocoles natifs** des fournisseurs : remplacez l'adresse dans le SDK officiel ou la commande curl par l'adresse LMU AI et la clé par votre clé API LMU AI ; le corps de la requête reste inchangé. Cette page est une présentation générale : choisissez une API dans le tableau ci-dessous, puis consultez la page du fournisseur correspondant. Les règles communes aux deux fournisseurs (authentification, facturation, limites de concurrence et codes d'erreur) sont décrites sur cette page.

<Callout type="info" title="URL de base">

```text
https://api.lmuai.com
```

| Fournisseur | Créer une tâche | Interroger une tâche | Documentation |
|---|---|---|---|
| Seedance (Volcengine Ark) | `POST /api/v3/contents/generations/tasks` | `GET /api/v3/contents/generations/tasks/{id}` | [API de génération vidéo Seedance](/fr/docs/api/seedance-video) |
| Wan (Alibaba DashScope) | `POST /api/v1/services/aigc/video-generation/video-synthesis` | `GET /api/v1/tasks/{task_id}` | [API de génération vidéo Wan](/fr/docs/api/wan-video) |

</Callout>

<Callout type="warn" title="La génération vidéo doit être activée pour votre groupe">

Le groupe de la clé API doit avoir l'option « Génération vidéo » activée ; sinon, les appels renvoient `403`. Les modèles que vous pouvez réellement appeler dépendent de votre clé API ; vérifiez-les avec `GET /v1/models`.

</Callout>

## 1. Choisir entre les deux [#compare]

| | Seedance (Volcengine Ark) | Wan (Alibaba DashScope) |
|---|---|---|
| Exemple de modèle | `seedance-2.5` | `wan3.0-video` |
| Facturation | Selon les tokens de sortie | Selon « secondes réelles × prix unitaire du palier de résolution » |
| Valeurs de résolution | `480p` / `720p` / `1080p` (minuscules) | `480P` / `720P` / `1080P` (majuscules), `1080P` par défaut |
| Statut de la tâche | `queued` → `running` → `succeeded` / `failed` / `cancelled` | `PENDING` → `RUNNING` → `SUCCEEDED` / `FAILED` / `CANCELED` |
| Champ de l'URL vidéo | `content.video_url` | `output.video_url` |
| Annulation d'une tâche | Les tâches en file d'attente (`queued`) peuvent être annulées | Aucun endpoint d'annulation ; une tâche soumise s'exécute toujours jusqu'au bout |

Le nom du modèle doit correspondre **exactement** au nom activé pour votre groupe (sensible à la casse). Les deux API utilisent des noms de champs similaires mais une casse et des chemins différents ; ne les confondez pas lorsque vous copiez des exemples.

## 2. Authentification [#auth]

Envoyez votre clé API dans l'en-tête de chaque requête :

```http
Authorization: Bearer YOUR_API_KEY
```

Ne placez pas votre clé API dans du code front-end exécuté dans le navigateur, dans des dépôts publics, dans les paramètres de requête d'URL ni dans des journaux. Appelez l'API depuis votre propre serveur.

## 3. Flux des tâches asynchrones [#flow]

1. **Création** : `POST` renvoie uniquement un identifiant de tâche ; il n'attend pas la vidéo.
2. **Interrogation** : effectuez un `GET` sur la tâche environ toutes les 10 secondes jusqu'à ce qu'elle atteigne un état final (réussie / échouée / annulée).
3. **Images de référence** : les appels API doivent transmettre une URL d'image accessible publiquement (JPG / PNG / WebP) ; la page Génération vidéo de la console accepte le téléversement d'images locales.
4. **Téléchargement** : en cas de succès, récupérez le lien de la vidéo dans la réponse. Les liens en amont sont **valides pendant 24 heures**, téléchargez-les donc rapidement ; la plateforme conserve une copie de chaque vidéo terminée, que vous pouvez lire et télécharger sur la page Tâches vidéo de la console.

<Callout type="info" title="La facturation est réglée même si vous arrêtez l'interrogation">

Après la soumission, la plateforme suit la tâche en arrière-plan et la règle normalement, même si vous cessez de l'interroger ; les tâches échouées ou annulées ne sont pas facturées.

</Callout>

Pour des exemples complets de création et d'interrogation, consultez les pages [Seedance](/fr/docs/api/seedance-video#poll-example) et [Wan](/fr/docs/api/wan-video#poll-example).

## 4. Facturation et filigranes [#billing]

- Un montant estimé est gelé à la création de la tâche. Si votre solde est insuffisant, la requête est directement rejetée (`402`) et aucune vidéo n'est générée.
- En cas de succès, la tâche est réglée une seule fois selon l'utilisation réelle, et tout excédent gelé est automatiquement restitué ; les tâches échouées ou annulées sont intégralement remboursées et ne sont pas facturées.
- Seedance est facturé selon les tokens de sortie ; Wan est facturé selon « secondes réelles × prix unitaire du palier de résolution ».
- Les vidéos terminées portent le label « Généré par IA » de la plateforme, que les clients ne peuvent pas désactiver.

## 5. Limites de concurrence [#limits]

Chaque utilisateur et chaque clé API peut avoir au maximum **5** tâches en cours de génération simultanément. Au-delà, les requêtes renvoient `429` avec un en-tête `Retry-After` (environ 60 secondes) ; patientez puis réessayez.

## 6. Codes d'erreur [#errors]

| HTTP | Signification | Que faire |
|---|---|---|
| `401` | La clé API est invalide ou désactivée | Vérifiez votre clé API |
| `402` | Solde ou quota insuffisant pour geler le montant estimé | Rechargez votre compte et réessayez |
| `403` | La génération vidéo n'est pas activée pour le groupe, ou le modèle n'est pas disponible dans le groupe | Utilisez une clé API prenant en charge la génération vidéo |
| `404 model_not_found` | Le modèle n'est pas encore disponible (un nom mal orthographié déclenche aussi cette erreur) | Utilisez le nom exact renvoyé par `GET /v1/models` |
| `409` | La génération de la tâche a commencé et elle ne peut plus être annulée (endpoint d'annulation Seedance) | Attendez la fin de la tâche |
| `429` | Le nombre de tâches en cours a atteint la limite | Patientez selon `Retry-After` et réessayez |

Pour les erreurs générales, consultez [Codes d'erreur](/fr/docs/guide/errors).
