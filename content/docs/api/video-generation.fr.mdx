LMU AI propose deux types d'API de génération vidéo **asynchrones**, toutes deux utilisant les **protocoles natifs** des fournisseurs : remplacez l'adresse dans le SDK officiel ou la commande curl par l'adresse LMU AI et la clé par votre clé API LMU AI ; le corps de la requête reste inchangé.

<Callout type="info" title="URL de base">

```text
https://api.lmuai.com
```

| Fournisseur | Créer une tâche | Interroger une tâche |
|---|---|---|
| Seedance (Volcengine Ark) | `POST /api/v3/contents/generations/tasks` | `GET /api/v3/contents/generations/tasks/{id}` |
| Wan (Alibaba DashScope) | `POST /api/v1/services/aigc/video-generation/video-synthesis` | `GET /api/v1/tasks/{task_id}` |

</Callout>

<Callout type="warn" title="La génération vidéo doit être activée pour votre groupe">

« Génération vidéo » doit être activée pour le groupe de la clé API ; sinon, les appels renvoient `403`. Les modèles que vous pouvez réellement appeler dépendent de votre clé API — vérifiez-les avec `GET /v1/models`.

</Callout>

## 1. Vue d'ensemble

| Fournisseur | Exemple de modèle | Facturation |
|---|---|---|
| Seedance (Volcengine Ark) | `seedance-2.5` | Par tokens de sortie |
| Wan (Alibaba DashScope) | `wan3.0-video` | Par « secondes × palier de résolution » |

Le nom du modèle doit correspondre **exactement** au nom activé pour votre groupe (sensible à la casse).

## 2. Authentification

Envoyez votre clé API dans l'en-tête de chaque requête :

```http
Authorization: Bearer YOUR_API_KEY
```

Ne placez pas votre clé API dans du code front-end exécuté dans le navigateur, dans des dépôts publics, dans des paramètres de requête d'URL ou dans des journaux. Appelez l'API depuis votre propre serveur.

## 3. Flux des tâches asynchrones

1. **Créer** : `POST` renvoie uniquement un identifiant de tâche ; il n'attend pas la vidéo.
2. **Interroger** : appelez `GET` sur la tâche environ toutes les 10 secondes jusqu'à ce qu'elle atteigne un état final (réussie / échouée / annulée).
3. **Images de référence** : les appels API doivent transmettre une URL d'image accessible publiquement (JPG / PNG / WebP) ; la page Génération vidéo de la console accepte le téléversement d'images locales.
4. **Télécharger** : en cas de succès, récupérez le lien de la vidéo dans la réponse. Les liens fournis par l'amont sont **valides 24 heures**, téléchargez-les donc rapidement ; la plateforme conserve une copie de chaque vidéo terminée, que vous pouvez lire et télécharger sur la page Tâches vidéo de la console.

<Callout type="info" title="La facturation est réglée même si vous arrêtez d'interroger">

Après la soumission, la plateforme suit la tâche en arrière-plan et la règle normalement même si vous cessez de l'interroger ; les tâches échouées et annulées ne sont pas facturées.

</Callout>

## 4. Seedance · Créer une tâche

### `POST /api/v3/contents/generations/tasks`

| Paramètre | Type | Obligatoire | Description |
|---|---|---|---|
| `model` | string | Oui | Nom du modèle ; doit correspondre exactement au nom activé pour votre groupe (sensible à la casse) |
| `content` | array | Oui | Contenu d'entrée. Texte : `{"type":"text","text":"…"}` ; image de référence : `{"type":"image_url","image_url":{"url":"…"},"role":"first_frame"}`, où `role` peut valoir `first_frame` (première image) ou `reference_image` (image de référence) |
| `resolution` | string | Non | Palier de résolution : `480p` / `720p` / `1080p` |
| `duration` | integer | Non | Durée de la vidéo en secondes |
| `ratio` | string | Non | Format d'image : `16:9` / `9:16` / `1:1` / `4:3` |
| `generate_audio` | boolean | Non | Indique s'il faut également générer l'audio |

<Tabs items={['cURL', 'Python', 'Node.js']}>

```bash
curl https://api.lmuai.com/api/v3/contents/generations/tasks \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \

    "model": "seedance-2.5",
    "content": [
      {"type": "text", "text": "Waves gently lapping the beach at dusk, slow motion"}
    ],
    "resolution": "720p",
    "duration": 5,
    "ratio": "16:9",
    "generate_audio": true
  }'
```

Pour utiliser une image de référence comme première image, ajoutez un élément image à `content` :

```json
{
  "model": "seedance-2.5",
  "content": [
    {"type": "text", "text": "The camera slowly pushes in as waves gently lap the beach"},
    {"type": "image_url", "image_url": {"url": "https://example.com/first-frame.png"}, "role": "first_frame"}
  ],
  "resolution": "720p",
  "duration": 5
}
```

<Callout type="warn" title="Remarques">

- En mode première image (`role` vaut `first_frame`), **n'envoyez pas `ratio`** : le format d'image suit celui de la première image, et l'amont rejette la requête avec `400` si vous l'envoyez.
- `callback_url` n'est pas transmis à l'amont ; vous ne recevrez aucun callback même si vous le fournissez. Utilisez plutôt l'interrogation périodique.

</Callout>

## 5. Seedance · Interroger une tâche

### `GET /api/v3/contents/generations/tasks/{id}`

Valeurs de `status` : `queued` → `running` → `succeeded` / `failed` / `cancelled`. En cas de succès, l'URL de la vidéo se trouve dans `content.video_url`.

```bash
curl https://api.lmuai.com/api/v3/contents/generations/tasks/TASK_ID \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Réponse (succès) :

```json
{
  "id": "cgt-20261022103211-ab12c",
  "model": "seedance-2.5",
  "status": "succeeded",
  "content": {
    "video_url": "https://…/video.mp4"
  },
  "usage": {
    "completion_tokens": 108900,
    "total_tokens": 108900
  },
  "created_at": 1792629131,
  "updated_at": 1792629262
}
```

## 6. Seedance · Lister les tâches

### `GET /api/v3/contents/generations/tasks?limit=20&offset=0`

Renvoie les tâches créées avec la clé API actuelle (`limit` de 1 à 100, 20 par défaut). La réponse est de la forme `{object, data[], has_more}`. Les enregistrements de tâches restent consultables après l'expiration du lien vidéo.

## 7. Seedance · Annuler / supprimer

### `DELETE /api/v3/contents/generations/tasks/{id}`

- Les tâches encore en file d'attente (`queued`) peuvent être annulées sans frais.
- Les tâches dont la génération a commencé (`running`) ne peuvent pas être annulées et renvoient `409`.
- Les tâches terminées peuvent voir leur enregistrement amont supprimé, sans remboursement.

## 8. Wan · Créer une tâche

### `POST /api/v1/services/aigc/video-generation/video-synthesis`

Identique au protocole natif d'Alibaba Cloud Model Studio (DashScope). L'en-tête asynchrone `X-DashScope-Async: enable` est facultatif ; la plateforme l'ajoute automatiquement.

| Paramètre | Type | Obligatoire | Description |
|---|---|---|---|
| `model` | string | Oui | Par exemple `wan3.0-video` |
| `input.prompt` | string | Oui | Prompt |
| `input.media` | array | Non | Médias de référence, par exemple `[{"type":"first_frame","url":"…"}]` ; `type` peut valoir `first_frame` ou `reference_image` |
| `parameters.resolution` | string | Non | Palier de résolution : `480P` / `720P` / `1080P`, `1080P` par défaut |
| `parameters.duration` | integer | Non | Durée en secondes, 5 par défaut |
| `parameters.watermark` | boolean | Non | Défini de manière uniforme par la plateforme selon la politique du groupe ; une valeur fournie par le client peut être écrasée |

## 9. Wan · Interroger une tâche

### `GET /api/v1/tasks/{task_id}`

Valeurs de `output.task_status` : `PENDING` → `RUNNING` → `SUCCEEDED` / `FAILED` / `CANCELED`. En cas de succès, l'URL de la vidéo se trouve dans `output.video_url`, et les secondes facturées dans `usage.duration`. Il n'existe pas d'endpoint d'annulation : une fois soumise, une tâche s'exécute toujours jusqu'à son terme.

```bash
curl https://api.lmuai.com/api/v1/tasks/TASK_ID \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Réponse (succès) :

```json
{
  "request_id": "…",
  "output": {
    "task_id": "c65c77fe-323b-4140-8de6-5a7241d9ec44",
    "task_status": "SUCCEEDED",
    "video_url": "https://…/output.mp4"
  },
  "usage": {
    "duration": 2.0,
    "video_count": 1
  }
}
```

## 10. Facturation et filigranes

- Un montant estimé est gelé à la création de la tâche. Si votre solde est insuffisant, la requête est rejetée d'emblée (`402`) et aucune vidéo n'est générée.
- En cas de succès, la tâche est réglée une seule fois selon l'utilisation réelle, et tout excédent gelé est restitué automatiquement ; les tâches échouées et annulées sont intégralement remboursées et ne sont pas facturées.
- Seedance est facturé par tokens de sortie ; Wan est facturé par « secondes réelles × prix unitaire du palier de résolution ».
- Les vidéos terminées portent la mention « Généré par IA » de la plateforme, que les clients ne peuvent pas désactiver.

## 11. Limites de concurrence

Chaque utilisateur et chaque clé API peuvent avoir au maximum **5** tâches en cours de génération simultanément. Au-delà, les requêtes renvoient `429` avec un en-tête `Retry-After` (environ 60 secondes) ; patientez puis réessayez.

## 12. Codes d'erreur

| HTTP | Signification | Que faire |
|---|---|---|
| `401` | La clé API est invalide ou désactivée | Vérifiez votre clé API |
| `402` | Solde ou quota insuffisant pour geler le montant estimé | Rechargez votre compte et réessayez |
| `403` | La génération vidéo n'est pas activée pour le groupe, ou le modèle n'est pas disponible dans le groupe | Utilisez une clé API qui prend en charge la génération vidéo |
| `404 model_not_found` | Le modèle n'est pas encore disponible (un nom mal orthographié déclenche aussi cette erreur) | Utilisez le nom exact renvoyé par `GET /v1/models` |
| `409` | La génération de la tâche a commencé et elle ne peut pas être annulée | Attendez la fin de la tâche |
| `429` | Le nombre de tâches en cours a atteint la limite | Patientez selon `Retry-After` puis réessayez |

Pour les erreurs générales, consultez [Codes d'erreur](/fr/docs/guide/errors).

## 13. Exemple complet : créer et interroger

<Tabs items={['Seedance', 'Wan']}>
<Tab value="Seedance">

```python
import time, requests

BASE = "https://api.lmuai.com"
HEADERS = {"Authorization": "Bearer YOUR_API_KEY"}

# 1. Create the task
resp = requests.post(f"{BASE}/api/v3/contents/generations/tasks", headers=HEADERS, json={
    "model": "seedance-2.5",
    "content": [{"type": "text", "text": "Waves gently lapping the beach at dusk, slow motion"}],
    "resolution": "720p", "duration": 5, "ratio": "16:9",
})
resp.raise_for_status()
task_id = resp.json()["id"]

# 2. Poll until a final state (every 10 seconds)
while True:
    task = requests.get(f"{BASE}/api/v3/contents/generations/tasks/{task_id}", headers=HEADERS).json()
    status = task["status"]
    if status in ("succeeded", "failed", "cancelled", "canceled", "expired"):
        break
    time.sleep(10)

# 3. Download (the link is valid for 24 hours)
if status == "succeeded":
    url = task["content"]["video_url"]
    with open(f"{task_id}.mp4", "wb") as f:
        f.write(requests.get(url).content)
else:
    print("Generation failed:", task)
```
