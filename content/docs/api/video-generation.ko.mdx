LMU AI는 두 가지 **비동기** 동영상 생성 API를 제공하며, 둘 다 공급업체의 **네이티브 프로토콜**을 사용합니다. 공식 SDK 또는 curl 명령의 주소를 LMU AI 주소로, 키를 LMU AI API 키로 바꾸기만 하면 되며 요청 본문은 그대로 유지됩니다.

<Callout type="info" title="Base URL">

```text
https://api.lmuai.com
```

| 공급업체 | 작업 생성 | 작업 조회 |
|---|---|---|
| Seedance (Volcengine Ark) | `POST /api/v3/contents/generations/tasks` | `GET /api/v3/contents/generations/tasks/{id}` |
| Wan (Alibaba DashScope) | `POST /api/v1/services/aigc/video-generation/video-synthesis` | `GET /api/v1/tasks/{task_id}` |

</Callout>

<Callout type="warn" title="그룹에서 동영상 생성이 활성화되어 있어야 합니다">

API 키의 그룹에 "동영상 생성"이 활성화되어 있어야 하며, 그렇지 않으면 호출 시 `403`이 반환됩니다. 실제로 호출할 수 있는 모델은 API 키에 따라 다르며, `GET /v1/models`로 확인할 수 있습니다.

</Callout>

## 1. 개요

| 공급업체 | 예시 모델 | 과금 방식 |
|---|---|---|
| Seedance (Volcengine Ark) | `seedance-2.5` | 출력 토큰 기준 |
| Wan (Alibaba DashScope) | `wan3.0-video` | "초 × 해상도 등급" 기준 |

모델 이름은 그룹에 활성화된 이름과 **정확히** 일치해야 합니다(대소문자 구분).

## 2. 인증

모든 요청의 헤더에 API 키를 포함하세요:

```http
Authorization: Bearer YOUR_API_KEY
```

API 키를 브라우저 프런트엔드 코드, 공개 저장소, URL 쿼리 문자열 또는 로그에 넣지 마세요. 자체 서버에서 API를 호출하세요.

## 3. 비동기 작업 흐름

1. **생성**: `POST`는 작업 id만 반환하며, 동영상 생성을 기다리지 않습니다.
2. **폴링**: 최종 상태(성공 / 실패 / 취소)에 도달할 때까지 약 10초마다 작업을 `GET`합니다.
3. **참조 이미지**: API 호출 시에는 공개적으로 접근 가능한 이미지 URL(JPG / PNG / WebP)을 전달해야 합니다. 콘솔의 동영상 생성 페이지에서는 로컬 이미지 업로드가 가능합니다.
4. **다운로드**: 성공 시 응답에서 동영상 링크를 가져옵니다. 업스트림 링크는 **24시간 동안 유효**하므로 빠르게 다운로드하세요. 플랫폼은 완료된 각 동영상의 사본을 보관하며, 콘솔의 동영상 작업 페이지에서 재생 및 다운로드할 수 있습니다.

<Callout type="info" title="폴링을 중단해도 정산은 진행됩니다">

제출 후 플랫폼이 백그라운드에서 작업을 추적하므로, 조회를 중단하더라도 정상적으로 정산됩니다. 실패하거나 취소된 작업은 과금되지 않습니다.

</Callout>

## 4. Seedance · 작업 생성

### `POST /api/v3/contents/generations/tasks`

| 파라미터 | 타입 | 필수 | 설명 |
|---|---|---|---|
| `model` | string | 예 | 모델 이름. 그룹에 활성화된 이름과 정확히 일치해야 합니다(대소문자 구분) |
| `content` | array | 예 | 입력 콘텐츠. 텍스트: `{"type":"text","text":"…"}`; 참조 이미지: `{"type":"image_url","image_url":{"url":"…"},"role":"first_frame"}`. `role`은 `first_frame`(첫 프레임) 또는 `reference_image`(참조 이미지)일 수 있습니다 |
| `resolution` | string | 아니요 | 해상도 등급: `480p` / `720p` / `1080p` |
| `duration` | integer | 아니요 | 동영상 길이(초) |
| `ratio` | string | 아니요 | 화면 비율: `16:9` / `9:16` / `1:1` / `4:3` |
| `generate_audio` | boolean | 아니요 | 오디오를 함께 생성할지 여부 |

## 5. Seedance · 작업 조회

### `GET /api/v3/contents/generations/tasks/{id}`

`status` 값: `queued` → `running` → `succeeded` / `failed` / `cancelled`. 성공 시 동영상 URL은 `content.video_url`에 있습니다.

```bash
curl https://api.lmuai.com/api/v3/contents/generations/tasks/TASK_ID \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## 6. Seedance · 작업 목록

### `GET /api/v3/contents/generations/tasks?limit=20&offset=0`

현재 API 키로 생성한 작업을 반환합니다(`limit`는 1~100, 기본값 20). 응답 형식은 `{object, data[], has_more}`입니다. 동영상 링크가 만료된 후에도 작업 기록은 계속 조회할 수 있습니다.

## 7. Seedance · 취소 / 삭제

### `DELETE /api/v3/contents/generations/tasks/{id}`

- 아직 대기열에 있는(`queued`) 작업은 비용 없이 취소할 수 있습니다.
- 생성이 시작된(`running`) 작업은 취소할 수 없으며 `409`를 반환합니다.
- 완료된 작업은 업스트림 기록을 삭제할 수 있으나 환불되지 않습니다.

## 8. Wan · 작업 생성

### `POST /api/v1/services/aigc/video-generation/video-synthesis`

Alibaba Cloud Model Studio(DashScope)의 네이티브 프로토콜과 동일합니다. 비동기 헤더 `X-DashScope-Async: enable`은 선택 사항이며, 플랫폼이 자동으로 추가합니다.

| 파라미터 | 타입 | 필수 | 설명 |
|---|---|---|---|
| `model` | string | 예 | 예: `wan3.0-video` |
| `input.prompt` | string | 예 | 프롬프트 |
| `input.media` | array | 아니요 | 참조 미디어. 예: `[{"type":"first_frame","url":"…"}]`; `type`은 `first_frame` 또는 `reference_image`일 수 있습니다 |
| `parameters.resolution` | string | 아니요 | 해상도 등급: `480P` / `720P` / `1080P`, 기본값 `1080P` |
| `parameters.duration` | integer | 아니요 | 길이(초), 기본값 5 |
| `parameters.watermark` | boolean | 아니요 | 그룹 정책에 따라 플랫폼이 일괄 설정하며, 클라이언트가 전달한 값은 무시될 수 있습니다 |

## 9. Wan · 작업 조회

### `GET /api/v1/tasks/{task_id}`

`output.task_status` 값: `PENDING` → `RUNNING` → `SUCCEEDED` / `FAILED` / `CANCELED`. 성공 시 동영상 URL은 `output.video_url`에, 과금된 초 수는 `usage.duration`에 있습니다. 취소 엔드포인트는 없으며, 한 번 제출된 작업은 항상 끝까지 실행됩니다.

```bash
curl https://api.lmuai.com/api/v1/tasks/TASK_ID \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```json

  "output": {

    "task_status": "SUCCEEDED",
```

## 10. 과금 및 워터마크

- 작업 생성 시 예상 금액이 동결됩니다. 잔액이 부족하면 요청이 즉시 거부되며(`402`) 동영상은 생성되지 않습니다.
- 성공 시 실제 사용량에 따라 한 번 정산되며, 초과 동결된 금액은 자동으로 반환됩니다. 실패하거나 취소된 작업은 전액 환불되며 과금되지 않습니다.
- Seedance는 출력 토큰 기준으로, Wan은 "실제 초 수 × 해상도 등급 단가" 기준으로 과금됩니다.
- 완료된 동영상에는 플랫폼의 "AI 생성" 표시가 포함되며, 클라이언트에서 끌 수 없습니다.

## 11. 동시 실행 제한

각 사용자와 각 API 키는 동시에 최대 **5**개의 작업을 생성할 수 있습니다. 이를 초과하면 요청은 `Retry-After` 헤더(약 60초)와 함께 `429`를 반환하므로, 대기 후 다시 시도하세요.

## 12. 오류 코드

| HTTP | 의미 | 조치 |
|---|---|---|
| `401` | API 키가 유효하지 않거나 비활성화됨 | API 키를 확인하세요 |
| `402` | 예상 금액을 동결하기에 잔액 또는 할당량이 부족함 | 충전 후 다시 시도하세요 |
| `403` | 그룹에 동영상 생성이 활성화되어 있지 않거나, 그룹에서 해당 모델을 사용할 수 없음 | 동영상 생성을 지원하는 API 키를 사용하세요 |
| `404 model_not_found` | 모델을 아직 사용할 수 없음(모델 이름 오타로도 발생) | `GET /v1/models`가 반환하는 정확한 이름을 사용하세요 |
| `409` | 작업 생성이 이미 시작되어 취소할 수 없음 | 작업이 완료될 때까지 기다리세요 |
| `429` | 진행 중인 작업 수가 한도에 도달함 | `Retry-After`에 따라 대기 후 다시 시도하세요 |

일반 오류는 [오류 코드](/ko/docs/guide/errors)를 참조하세요.

## 13. 전체 예제: 생성 및 폴링

<Tabs items={['Seedance', 'Wan']}>
<Tab value="Seedance">

```python
import time, requests

BASE = "https://api.lmuai.com"
HEADERS = {"Authorization": "Bearer YOUR_API_KEY"}

# 1. Create the task
resp = requests.post(f"{BASE}/api/v3/contents/generations/tasks", headers=HEADERS, json={
    "model": "seedance-2.5",
    "content": [{"type": "text", "text": "Waves gently lapping the beach at dusk, slow motion"}],
    "resolution": "720p", "duration": 5, "ratio": "16:9",
})
resp.raise_for_status()
task_id = resp.json()["id"]

# 2. Poll until a final state (every 10 seconds)
while True:
    task = requests.get(f"{BASE}/api/v3/contents/generations/tasks/{task_id}", headers=HEADERS).json()
    status = task["status"]
    if status in ("succeeded", "failed", "cancelled", "canceled", "expired"):
        break
```
