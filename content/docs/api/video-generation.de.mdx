LMU AI bietet zwei Arten von **asynchronen** Videogenerierungs-APIs, die beide die **nativen Protokolle** der Anbieter verwenden: Ersetzen Sie im offiziellen SDK oder curl-Befehl die Adresse durch die LMU AI-Adresse und den Key durch Ihren LMU AI API-Key – der Request-Body bleibt unverändert. Diese Seite ist der Überblick: Wählen Sie in der folgenden Tabelle eine API aus und lesen Sie dann die zugehörige Anbieterseite. Die Regeln, die für beide Anbieter gelten (Authentifizierung, Abrechnung, Parallelitätslimits und Fehlercodes), finden Sie auf dieser Seite.

<Callout type="info" title="Basis-URL">

```text
https://api.lmuai.com
```

| Anbieter | Task erstellen | Task abfragen | Doku |
|---|---|---|---|
| Seedance (Volcengine Ark) | `POST /api/v3/contents/generations/tasks` | `GET /api/v3/contents/generations/tasks/{id}` | [Seedance Videogenerierungs-API](/de/docs/api/seedance-video) |
| Wan (Alibaba DashScope) | `POST /api/v1/services/aigc/video-generation/video-synthesis` | `GET /api/v1/tasks/{task_id}` | [Wan Videogenerierungs-API](/de/docs/api/wan-video) |

</Callout>

<Callout type="warn" title="Videogenerierung muss für Ihre Gruppe aktiviert sein">

Für die Gruppe des API-Keys muss „Videogenerierung“ aktiviert sein; andernfalls geben Aufrufe `403` zurück. Welche Modelle Sie tatsächlich aufrufen können, hängt von Ihrem API-Key ab; prüfen Sie dies mit `GET /v1/models`.

</Callout>

## 1. Die Wahl zwischen beiden [#compare]

| | Seedance (Volcengine Ark) | Wan (Alibaba DashScope) |
|---|---|---|
| Beispielmodell | `seedance-2.5` | `wan3.0-video` |
| Abrechnung | Nach Output-Tokens | Nach „tatsächliche Sekunden × Stückpreis der Auflösungsstufe“ |
| Auflösungswerte | `480p` / `720p` / `1080p` (Kleinbuchstaben) | `480P` / `720P` / `1080P` (Großbuchstaben), Standard `1080P` |
| Task-Status | `queued` → `running` → `succeeded` / `failed` / `cancelled` | `PENDING` → `RUNNING` → `SUCCEEDED` / `FAILED` / `CANCELED` |
| Feld für Video-URL | `content.video_url` | `output.video_url` |
| Task abbrechen | Wartende (`queued`) Tasks können abgebrochen werden | Kein Abbruch-Endpunkt; ein übermittelter Task läuft immer bis zum Ende |

Der Modellname muss **exakt** mit dem für Ihre Gruppe aktivierten Namen übereinstimmen (Groß-/Kleinschreibung beachten). Die beiden APIs verwenden ähnliche Feldnamen, aber unterschiedliche Schreibweisen und Pfade – verwechseln Sie sie also nicht beim Kopieren von Beispielen.

## 2. Authentifizierung [#auth]

Senden Sie Ihren API-Key im Header jeder Anfrage:

```http
Authorization: Bearer YOUR_API_KEY
```

Legen Sie Ihren API-Key nicht in Browser-Frontend-Code, öffentlichen Repositories, URL-Query-Strings oder Logs ab. Rufen Sie die API von Ihrem eigenen Server aus auf.

## 3. Ablauf asynchroner Tasks [#flow]

1. **Erstellen**: `POST` gibt nur eine Task-ID zurück; es wird nicht auf das Video gewartet.
2. **Abfragen**: Fragen Sie den Task etwa alle 10 Sekunden per `GET` ab, bis er einen Endzustand erreicht (erfolgreich / fehlgeschlagen / abgebrochen).
3. **Referenzbilder**: API-Aufrufe müssen eine öffentlich zugängliche Bild-URL übergeben (JPG / PNG / WebP); die Seite „Videogenerierung“ in der Konsole akzeptiert auch lokale Bild-Uploads.
4. **Herunterladen**: Entnehmen Sie bei Erfolg den Video-Link aus der Antwort. Upstream-Links sind **24 Stunden gültig**, laden Sie also zeitnah herunter; die Plattform bewahrt eine Kopie jedes fertigen Videos auf, die Sie auf der Seite „Video-Tasks“ in der Konsole abspielen und herunterladen können.

<Callout type="info" title="Die Abrechnung erfolgt auch, wenn Sie die Abfrage beenden">

Nach der Übermittlung verfolgt die Plattform den Task im Hintergrund weiter und rechnet ihn normal ab, auch wenn Sie keine Abfragen mehr senden; fehlgeschlagene und abgebrochene Tasks werden nicht berechnet.

</Callout>

Vollständige Beispiele zum Erstellen und Abfragen finden Sie auf den Seiten zu [Seedance](/de/docs/api/seedance-video#poll-example) und [Wan](/de/docs/api/wan-video#poll-example).

## 4. Abrechnung und Wasserzeichen [#billing]

- Beim Erstellen des Tasks wird ein geschätzter Betrag reserviert. Reicht Ihr Guthaben nicht aus, wird die Anfrage direkt abgelehnt (`402`) und kein Video generiert.
- Bei Erfolg wird der Task einmalig nach tatsächlicher Nutzung abgerechnet, und ein zu viel reservierter Betrag wird automatisch zurückgebucht; fehlgeschlagene und abgebrochene Tasks werden vollständig erstattet und nicht berechnet.
- Seedance wird nach Output-Tokens abgerechnet; Wan nach „tatsächliche Sekunden × Stückpreis der Auflösungsstufe“.
- Fertige Videos tragen die Plattformkennzeichnung „KI-generiert“, die Clients nicht deaktivieren können.

## 5. Parallelitätslimits [#limits]

Pro Benutzer und pro API-Key können höchstens **5** Tasks gleichzeitig generiert werden. Darüber hinaus geben Anfragen `429` mit einem `Retry-After`-Header (etwa 60 Sekunden) zurück; warten Sie ab und versuchen Sie es erneut.

## 6. Fehlercodes [#errors]

| HTTP | Bedeutung | Vorgehen |
|---|---|---|
| `401` | Der API-Key ist ungültig oder deaktiviert | Prüfen Sie Ihren API-Key |
| `402` | Guthaben oder Kontingent reicht nicht aus, um den geschätzten Betrag zu reservieren | Laden Sie Guthaben auf und versuchen Sie es erneut |
| `403` | Videogenerierung ist für die Gruppe nicht aktiviert, oder das Modell ist in der Gruppe nicht verfügbar | Verwenden Sie einen API-Key, der Videogenerierung unterstützt |
| `404 model_not_found` | Das Modell ist noch nicht verfügbar (auch ein falsch geschriebener Name löst dies aus) | Verwenden Sie den exakten Namen, den `GET /v1/models` zurückgibt |
| `409` | Die Generierung des Tasks hat bereits begonnen, er kann nicht abgebrochen werden (Seedance-Abbruch-Endpunkt) | Warten Sie, bis der Task abgeschlossen ist |
| `429` | Die Anzahl laufender Tasks hat das Limit erreicht | Warten Sie gemäß `Retry-After` und versuchen Sie es erneut |

Allgemeine Fehler finden Sie unter [Fehlercodes](/de/docs/guide/errors).
