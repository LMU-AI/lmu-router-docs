Adicione a ferramenta `google_search` a uma requisição nativa `generateContent` do Gemini e o modelo pesquisa na web quando precisar, respondendo com base nos resultados. A resposta também retorna **as consultas de pesquisa, as fontes citadas e qual fonte sustenta cada frase**. Use quando precisar de informações atualizadas ou quiser mostrar de onde veio uma resposta.

<Callout type="warn" title='As requisições precisam cair no grupo "Gemini-官方Vertex"'>

A pesquisa é executada pelo upstream, e apenas o grupo **Gemini-官方Vertex** a executa. Os upstreams por trás de outros grupos Gemini podem não executar pesquisas: a requisição ainda retorna 200, mas a resposta não tem `groundingMetadata` e a resposta não se baseia em resultados de pesquisa em tempo real.

- **Chave de grupo (recomendado)**: em "API Keys" no console, crie uma nova chave no grupo "Gemini-官方Vertex" e use-a apenas para pesquisa na web.
- **Chave unificada**: por padrão, ela não cai nesse grupo. Na lista "API Keys", clique no selo da chave unificada para abrir "Billing" e altere o nível pré-pago da "família Gemini" para "Gemini-官方Vertex". Depois disso, **todas** as chamadas Gemini feitas com essa chave vão para esse grupo e são cobradas pelo multiplicador de preço dele.

</Callout>

<CN>

<Callout type="info" title="Não encontra este grupo no site da China?">

O site da China não exibe o grupo "Gemini-官方Vertex". Crie uma API Key deste grupo no site internacional.

</Callout>

</CN>

## 1. Visão geral

| Item | Valor |
|---|---|
| URL base | `https://api.lmuai.com` |
| Sem streaming | `POST /v1beta/models/{model}:generateContent` |
| Streaming | `POST /v1beta/models/{model}:streamGenerateContent?alt=sse` |
| Autenticação | `x-goog-api-key: <your sk- API Key>` |
| Ativar a pesquisa | Adicione `"tools": [{"google_search": {}}]` ao corpo da requisição |
| Fontes | `candidates[0].groundingMetadata` na resposta |

---

## 2. Início rápido

```bash
curl -X POST \
  'https://api.lmuai.com/v1beta/models/gemini-3.5-flash-lite:generateContent' \
  -H 'x-goog-api-key: YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "contents": [{
      "role": "user",
      "parts": [{"text": "What is the website api.lmuai.com? Please cite sources."}]
    }],
    "tools": [{"google_search": {}}],
    "generationConfig": {"maxOutputTokens": 2048}
  }'
```

Exemplo de resposta (alguns campos omitidos):

```json
{
  "candidates": [{
    "content": {
      "role": "model",
      "parts": [{"text": "api.lmuai.com is the LLM API platform of LMU AI..."}]
    },
    "finishReason": "STOP",
    "groundingMetadata": {
      "webSearchQueries": ["api lmuai com", "lmuai com"],
      "groundingChunks": [
        {"web": {"uri": "https://vertexaisearch.cloud.google.com/grounding-api-redirect/...", "title": "lmuai.com", "domain": "lmuai.com"}},
        {"web": {"uri": "https://vertexaisearch.cloud.google.com/grounding-api-redirect/...", "title": "lmuai.ai", "domain": "lmuai.ai"}}
      ],
      "groundingSupports": [{
        "segment": {"endIndex": 52, "text": "api.lmuai.com is the LLM API platform of LMU AI"},
        "groundingChunkIndices": [0, 1]
      }],
      "searchEntryPoint": {"renderedContent": "<style>...</style><div>...</div>"}
    }
  }],
  "usageMetadata": {"promptTokenCount": 43, "candidatesTokenCount": 288}
}
```

## 3. Parâmetros da requisição

Em comparação com uma requisição Gemini normal, a única adição é `tools`:

| Campo | Obrigatório | Descrição |
|---|---|---|
| `contents` | Sim | A conversa, escrita da mesma forma que em uma requisição Gemini normal |
| `tools` | Sim | Sempre `[{"google_search": {}}]`. O modelo decide se vai pesquisar e quantas vezes |
| `generationConfig.maxOutputTokens` | Recomendado | No mínimo `2048`. Modelos de raciocínio (como `gemini-4-hydrogen`) precisam de mais; caso contrário, a resposta pode ser cortada com `MAX_TOKENS` e você não recebe nem a resposta nem as fontes |

<Callout type="info" title="Uma requisição pode executar várias pesquisas">

O modelo pode dividir uma pergunta em várias consultas de pesquisa. As pesquisas realmente executadas são listadas em `webSearchQueries` na resposta.

</Callout>

---

## 4. Campos da resposta: groundingMetadata

| Campo | Descrição |
|---|---|
| `webSearchQueries` | As consultas de pesquisa realmente executadas nesta requisição |
| `groundingChunks[].web.uri` | Link da fonte. É um link de redirecionamento do Google (`vertexaisearch.cloud.google.com/...`) que leva à página original |
| `groundingChunks[].web.title` | Título da fonte, geralmente o domínio do site |
| `groundingChunks[].web.domain` | O domínio do site de origem, como `lmuai.com` |
| `groundingSupports[].segment` | Um trecho da resposta: `text` é o conteúdo, `startIndex` / `endIndex` indicam sua posição (`startIndex` é omitido quando o trecho começa no início) |
| `groundingSupports[].groundingChunkIndices` | Quais fontes este trecho cita, como índices em `groundingChunks` |
| `searchEntryPoint.renderedContent` | Trecho HTML com as sugestões de pesquisa do Google |

<Callout type="warn" title="Ao mostrar respostas para usuários finais">

Se você mostrar respostas com pesquisa na web para usuários finais, o Google exige que você também exiba as sugestões de pesquisa de `searchEntryPoint.renderedContent`. Veja a [documentação do Google](https://ai.google.dev/gemini-api/docs/google-search).

</Callout>

## 5. Exemplo em Python: ler as fontes e as citações por frase

```python
import requests

API_KEY = "YOUR_API_KEY"
url = "https://api.lmuai.com/v1beta/models/gemini-3.5-flash-lite:generateContent"

resp = requests.post(
    url,
    headers={"x-goog-api-key": API_KEY},
    json={
        "contents": [{"role": "user", "parts": [{"text": "Which LLM API platforms are available in China? Please cite sources."}]}],
        "tools": [{"google_search": {}}],
        "generationConfig": {"maxOutputTokens": 2048},
    },
    timeout=180,
)
resp.raise_for_status()
cand = resp.json()["candidates"][0]

answer = "".join(p.get("text", "") for p in cand["content"]["parts"])
meta = cand.get("groundingMetadata", {})
chunks = meta.get("groundingChunks", [])

print("Answer:", answer)
print("Queries:", meta.get("webSearchQueries", []))

for i, c in enumerate(chunks):
    print(f"[{i}] {c['web'].get('domain')}  {c['web'].get('uri')}")

for s in meta.get("groundingSupports", []):
    refs = [chunks[i]["web"].get("domain") for i in s.get("groundingChunkIndices", [])]
    print(s["segment"].get("text"), "->", refs)

if not meta:
    print("No web search this time: the model saw no need to search, or this group does not support web search.")
```

## 6. Streaming

Troque o endpoint para `streamGenerateContent?alt=sse` e mantenha o corpo da requisição:

```bash
curl -N -X POST \
  'https://api.lmuai.com/v1beta/models/gemini-3.5-flash-lite:streamGenerateContent?alt=sse' \
  -H 'x-goog-api-key: YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "contents": [{"role": "user", "parts": [{"text": "What is in the AI industry news today?"}]}],
    "tools": [{"google_search": {}}],
    "generationConfig": {"maxOutputTokens": 2048}
  }'
```

Cada evento `data:` traz um pedaço do texto. **O `groundingMetadata` aparece apenas no último evento**: concatene o texto de todos os eventos e depois leia as fontes no último evento.

## 7. Modelos compatíveis

Os seguintes modelos foram testados com pesquisa na web:

| Modelo | Observações |
|---|---|
| `gemini-3.5-flash-lite` | O mais rápido e barato, bom para chamadas em lote |
| `gemini-3.8-flash` | Geralmente cita mais fontes, bom quando as citações importam |
| `gemini-3.6-flash` / `gemini-3.7-flash` | Semelhantes ao 3.8 Flash |
| `gemini-3-flash-preview` | Funciona |
| `gemini-4-hydrogen` | Executa muitas pesquisas e demora mais; defina um `maxOutputTokens` alto |

Os modelos realmente disponíveis no seu grupo estão listados na página "Available Models" do console.

## 8. Chamadas com o protocolo OpenAI ou Anthropic

Os modelos Gemini também podem ser chamados com o [protocolo OpenAI ou Anthropic](/pt/docs/guide/api-protocols), e a ferramenta de pesquisa de cada protocolo aciona uma pesquisa na web:

| Protocolo | Ferramenta de pesquisa | Pesquisa na web | Fontes estruturadas |
|---|---|---|---|
| Gemini nativo | `{"google_search": {}}` | ✅ | ✅ `groundingMetadata` |
| OpenAI Chat Completions | `{"type": "web_search"}` | ✅ | ❌ links apenas no texto da resposta |
| OpenAI Responses | `{"type": "web_search"}` | ✅ | ❌ links apenas no texto da resposta |
| Anthropic Messages | `{"type": "web_search_20250305", "name": "web_search"}` | ✅ | ❌ links apenas no texto da resposta |

**Se você precisa da lista de fontes ou das citações por frase, use o protocolo nativo do Gemini.**

<Callout type="info">

Uma ferramenta de função comum chamada `google_search` (`"type": "function"`) não aciona uma pesquisa na web. Ela continua sendo uma função executada pelo seu próprio programa.

</Callout>

---

## 9. Custo

Além do custo de tokens do modelo, as requisições com pesquisa na web **têm uma cobrança de pesquisa à parte para cada pesquisa realmente executada**. O número de pesquisas vem de `groundingMetadata.webSearchQueries` retornado pelo Gemini, e um termo repetido nessa lista conta uma única vez; se o modelo não executar nenhuma pesquisa, não há cobrança de pesquisa.

Uma requisição pode executar várias pesquisas, e a saída costuma ser mais longa que a de uma requisição normal. Na página "Usage" do console, os registros que executaram pesquisas mostram "Search N" ao lado do custo, em que N é o número de pesquisas; a cobrança de pesquisa já está incluída no custo desse registro.

## 10. Solução de problemas

| Sintoma | Causa | Solução |
|---|---|---|
| 200, mas sem `groundingMetadata` | O modelo não viu necessidade de pesquisar, ou o upstream do grupo não executa pesquisas | Use uma Key do grupo "Gemini-官方Vertex"; peça explicitamente no prompt uma pesquisa na web ou as fontes |
| A chave unificada nunca retorna `groundingMetadata` | A família Gemini da chave unificada ainda está no nível padrão e não cai em "Gemini-官方Vertex" | Altere o "Billing" conforme descrito no início desta página ou crie uma chave de grupo separada |
| `finishReason` é `MAX_TOKENS` e a resposta está vazia | O raciocínio consumiu o orçamento de saída | Aumente `maxOutputTokens` |
| `404 Not Found` | Caminho incorreto, ou o modelo não está no seu grupo | Verifique se o caminho é `/v1beta/models/{model}:generateContent` e confirme o nome do modelo na página "Available Models" |
| `401 Unauthorized` | Key incorreta, ou a Key não está no cabeçalho `x-goog-api-key` | Verifique o cabeçalho da requisição |

Para detalhes dos protocolos, veja [Protocolos de API](/pt/docs/guide/api-protocols); para erros comuns, veja [Códigos de erro](/pt/docs/guide/errors).
