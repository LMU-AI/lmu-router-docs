LMU AI предоставляет два вида **асинхронных** API генерации видео. Оба используют **нативные протоколы** поставщиков. В официальном SDK или команде curl замените адрес на адрес LMU AI, а ключ — на ваш API-ключ LMU AI. Тело запроса остаётся без изменений.

<Callout type="info" title="Базовый URL">

```text
https://api.lmuai.com
```

| Поставщик | Создание задачи | Запрос задачи |
|---|---|---|
| Seedance (Volcengine Ark) | `POST /api/v3/contents/generations/tasks` | `GET /api/v3/contents/generations/tasks/{id}` |
| Wan (Alibaba DashScope) | `POST /api/v1/services/aigc/video-generation/video-synthesis` | `GET /api/v1/tasks/{task_id}` |

</Callout>

<Callout type="warn" title="Для вашей группы должна быть включена генерация видео">

В группе API-ключа должна быть включена «Генерация видео», иначе вызовы возвращают `403`. Список доступных моделей зависит от API-ключа. Проверьте его через `GET /v1/models`.

</Callout>

## 1. Обзор

| Поставщик | Пример модели | Тарификация |
|---|---|---|
| Seedance (Volcengine Ark) | `seedance-2.5` | По выходным токенам |
| Wan (Alibaba DashScope) | `wan3.0-video` | По схеме «секунды × уровень разрешения» |

Имя модели должно **точно** совпадать с именем, включённым для вашей группы (с учётом регистра).

## 2. Аутентификация

Передавайте API-ключ в заголовке каждого запроса:

```http
Authorization: Bearer YOUR_API_KEY
```

Не размещайте API-ключ во фронтенд-коде браузера, в публичных репозиториях, в строках запроса URL или в логах. Вызывайте API со своего сервера.

## 3. Асинхронный процесс работы с задачей

1. **Создание**: `POST` возвращает только id задачи и не ждёт готовности видео.
2. **Опрос**: выполняйте `GET` для задачи примерно каждые 10 секунд, пока она не перейдёт в конечное состояние (succeeded / failed / cancelled).
3. **Референсные изображения**: при вызовах API передавайте общедоступный URL изображения (JPG / PNG / WebP). Страница «Генерация видео» в консоли принимает загрузку локальных изображений.
4. **Скачивание**: при успехе возьмите ссылку на видео из ответа. Ссылки от поставщика **действительны 24 часа**, поэтому скачивайте видео без промедления. Платформа сохраняет копию каждого готового видео. Его можно воспроизвести и скачать на странице «Задачи видео» в консоли.

<Callout type="info" title="Расчёт выполняется, даже если вы прекратили опрос">

После отправки платформа отслеживает задачу в фоне и выполняет расчёт в обычном порядке, даже если вы перестали запрашивать её статус. Плата за неудачные и отменённые задачи не взимается.

</Callout>

## 4. Seedance · Создание задачи

### `POST /api/v3/contents/generations/tasks`

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `model` | string | Да | Имя модели. Должно точно совпадать с именем, включённым для вашей группы (с учётом регистра) |
| `content` | array | Да | Входное содержимое. Текст: `{"type":"text","text":"…"}`. Референсное изображение: `{"type":"image_url","image_url":{"url":"…"},"role":"first_frame"}`, где `role` может быть `first_frame` (первый кадр) или `reference_image` (референсное изображение) |
| `resolution` | string | Нет | Уровень разрешения: `480p` / `720p` / `1080p` |
| `duration` | integer | Нет | Длительность видео в секундах |
| `ratio` | string | Нет | Соотношение сторон: `16:9` / `9:16` / `1:1` / `4:3` |
| `generate_audio` | boolean | Нет | Генерировать ли также аудио |

<Callout type="warn" title="Примечания">

- В режиме первого кадра (`role` равен `first_frame`) **не передавайте `ratio`**. Соотношение сторон берётся из изображения первого кадра. Если передать этот параметр, поставщик отклонит запрос с кодом `400`.
- `callback_url` не передаётся поставщику, поэтому обратный вызов не придёт, даже если вы его укажете. Используйте опрос.

## 5. Seedance · Запрос задачи

### `GET /api/v3/contents/generations/tasks/{id}`

Значения `status`: `queued` → `running` → `succeeded` / `failed` / `cancelled`. При успехе URL видео находится в `content.video_url`.

```bash
curl https://api.lmuai.com/api/v3/contents/generations/tasks/TASK_ID \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Ответ (успех):

```json
{
  "id": "cgt-20261022103211-ab12c",
  "model": "seedance-2.5",
  "status": "succeeded",
  "content": {
    "video_url": "https://…/video.mp4"
  },
  "usage": {
    "completion_tokens": 108900,
    "total_tokens": 108900
  },
  "created_at": 1792629131,
  "updated_at": 1792629262
}
```

## 6. Seedance · Список задач

### `GET /api/v3/contents/generations/tasks?limit=20&offset=0`

Возвращает задачи, созданные текущим API-ключом (`limit` от 1 до 100, по умолчанию 20). Ответ имеет вид `{object, data[], has_more}`. Записи о задачах остаются доступными для запроса после истечения срока действия ссылки на видео.

## 7. Seedance · Отмена / удаление

### `DELETE /api/v3/contents/generations/tasks/{id}`

- Задачи, которые ещё в очереди (`queued`), можно отменить бесплатно.
- Задачи, генерация которых уже началась (`running`), отменить нельзя: возвращается `409`.
- У завершённых задач можно удалить запись у поставщика, без возврата средств.

## 8. Wan · Создание задачи

### `POST /api/v1/services/aigc/video-generation/video-synthesis`

Полностью совпадает с нативным протоколом Alibaba Cloud Model Studio (DashScope). Асинхронный заголовок `X-DashScope-Async: enable` необязателен, платформа добавляет его автоматически.

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `model` | string | Да | Например, `wan3.0-video` |
| `input.prompt` | string | Да | Промпт |
| `input.media` | array | Нет | Референсные медиа, например `[{"type":"first_frame","url":"…"}]`. `type` может быть `first_frame` или `reference_image` |
| `parameters.resolution` | string | Нет | Уровень разрешения: `480P` / `720P` / `1080P`, по умолчанию `1080P` |
| `parameters.duration` | integer | Нет | Длительность в секундах, по умолчанию 5 |
| `parameters.watermark` | boolean | Нет | Задаётся платформой единообразно в соответствии с политикой группы. Значение от клиента может быть переопределено |

## 9. Wan · Запрос задачи

### `GET /api/v1/tasks/{task_id}`

Значения `output.task_status`: `PENDING` → `RUNNING` → `SUCCEEDED` / `FAILED` / `CANCELED`. При успехе URL видео находится в `output.video_url`, а оплачиваемые секунды — в `usage.duration`. Эндпоинта отмены нет: отправленная задача всегда выполняется до конца.

```bash
curl https://api.lmuai.com/api/v1/tasks/TASK_ID \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Ответ (успех):

```json
{
  "request_id": "…",
  "output": {
    "task_id": "c65c77fe-323b-4140-8de6-5a7241d9ec44",
    "task_status": "SUCCEEDED",
    "video_url": "https://…/output.mp4"
  },
  "usage": {
    "duration": 2.0,
    "video_count": 1
  }
}
```

## 10. Тарификация и водяные знаки

- При создании задачи замораживается оценочная сумма. Если баланса недостаточно, запрос сразу отклоняется (`402`), и видео не генерируется.
- При успехе задача рассчитывается один раз по фактическому использованию, а излишек замороженной суммы возвращается автоматически. За неудачные и отменённые задачи средства возвращаются полностью, плата не взимается.
- Seedance тарифицируется по выходным токенам. Wan тарифицируется по схеме «фактические секунды × цена за единицу для уровня разрешения».
- Готовые видео содержат метку платформы «Создано ИИ». Клиент не может её отключить.

## 11. Ограничения параллельности

Для каждого пользователя и каждого API-ключа одновременно может генерироваться не более **5** задач. При превышении лимита запросы возвращают `429` с заголовком `Retry-After` (около 60 секунд). Сделайте паузу и повторите запрос.

## 12. Коды ошибок

| HTTP | Значение | Что делать |
|---|---|---|
| `401` | API-ключ недействителен или отключён | Проверьте API-ключ |
| `402` | Недостаточно баланса или квоты для заморозки оценочной суммы | Пополните баланс и повторите запрос |
| `403` | Для группы не включена генерация видео, или модель недоступна в группе | Используйте API-ключ с поддержкой генерации видео |
| `404 model_not_found` | Модель пока недоступна (также возникает при опечатке в имени) | Используйте точное имя, возвращаемое `GET /v1/models` |
| `409` | Генерация задачи уже началась, отменить её нельзя | Дождитесь завершения задачи |
| `429` | Достигнут лимит одновременно выполняемых задач | Подождите время, указанное в `Retry-After`, и повторите запрос |

Общие ошибки описаны в разделе [Коды ошибок](/ru/docs/guide/errors).

## 13. Полный пример: создание и опрос

<Tabs items={['Seedance', 'Wan']}>
<Tab value="Seedance">

```python
import time, requests

BASE = "https://api.lmuai.com"
HEADERS = {"Authorization": "Bearer YOUR_API_KEY"}

# 1. Create the task
resp = requests.post(f"{BASE}/api/v3/contents/generations/tasks", headers=HEADERS, json={
    "model": "seedance-2.5",
    "content": [{"type": "text", "text": "Waves gently lapping the beach at dusk, slow motion"}],
    "resolution": "720p", "duration": 5, "ratio": "16:9",
})
resp.raise_for_status()
task_id = resp.json()["id"]

# 2. Poll until a final state (every 10 seconds)
while True:
    task = requests.get(f"{BASE}/api/v3/contents/generations/tasks/{task_id}", headers=HEADERS).json()
    status = task["status"]
    if status in ("succeeded", "failed", "cancelled", "canceled", "expired"):
        break
    time.sleep(10)

# 3. Download (the link is valid for 24 hours)
if status == "succeeded":
    url = task["content"]["video_url"]
    with open(f"{task_id}.mp4", "wb") as f:
        f.write(requests.get(url).content)
else:
    print("Generation failed:", task)
```
