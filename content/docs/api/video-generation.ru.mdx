LMU AI предоставляет два типа **асинхронных** API генерации видео, оба используют **нативные протоколы** провайдеров: замените адрес в официальном SDK или команде curl на адрес LMU AI, а ключ — на ваш API-ключ LMU AI; тело запроса остаётся без изменений. Эта страница — обзор: выберите API в таблице ниже, затем перейдите на страницу соответствующего провайдера. Общие для обоих провайдеров правила (аутентификация, тарификация, лимиты параллельности и коды ошибок) приведены на этой странице.

<Callout type="info" title="Базовый URL">

```text
https://api.lmuai.com
```

| Провайдер | Создание задачи | Запрос задачи | Документация |
|---|---|---|---|
| Seedance (Volcengine Ark) | `POST /api/v3/contents/generations/tasks` | `GET /api/v3/contents/generations/tasks/{id}` | [API генерации видео Seedance](/ru/docs/api/seedance-video) |
| Wan (Alibaba DashScope) | `POST /api/v1/services/aigc/video-generation/video-synthesis` | `GET /api/v1/tasks/{task_id}` | [API генерации видео Wan](/ru/docs/api/wan-video) |

</Callout>

<Callout type="warn" title="Для вашей группы должна быть включена генерация видео">

Для группы API-ключа должна быть включена функция «Генерация видео»; в противном случае вызовы возвращают `403`. Доступные для вызова модели зависят от вашего API-ключа; проверить их можно через `GET /v1/models`.

</Callout>

## 1. Выбор между двумя API [#compare]

| | Seedance (Volcengine Ark) | Wan (Alibaba DashScope) |
|---|---|---|
| Пример модели | `seedance-2.5` | `wan3.0-video` |
| Тарификация | По выходным токенам | По формуле «фактические секунды × цена за единицу для уровня разрешения» |
| Значения разрешения | `480p` / `720p` / `1080p` (строчными) | `480P` / `720P` / `1080P` (заглавными), по умолчанию `1080P` |
| Статус задачи | `queued` → `running` → `succeeded` / `failed` / `cancelled` | `PENDING` → `RUNNING` → `SUCCEEDED` / `FAILED` / `CANCELED` |
| Поле URL видео | `content.video_url` | `output.video_url` |
| Отмена задачи | Можно отменить задачи в очереди (`queued`) | Эндпоинта отмены нет; отправленная задача всегда выполняется до конца |

Название модели должно **точно** совпадать с названием, включённым для вашей группы (с учётом регистра). Оба API используют похожие названия полей, но с разным регистром и путями, поэтому не путайте их при копировании примеров.

## 2. Аутентификация [#auth]

Передавайте API-ключ в заголовке каждого запроса:

```http
Authorization: Bearer YOUR_API_KEY
```

Не размещайте API-ключ во фронтенд-коде браузера, публичных репозиториях, строках запроса URL или логах. Вызывайте API со своего сервера.

## 3. Асинхронный процесс выполнения задачи [#flow]

1. **Создание**: `POST` возвращает только id задачи и не ожидает готовности видео.
2. **Опрос**: выполняйте `GET` задачи примерно каждые 10 секунд, пока она не достигнет конечного состояния (успех / ошибка / отмена).
3. **Референсные изображения**: при вызовах API необходимо передавать общедоступный URL изображения (JPG / PNG / WebP); на странице «Генерация видео» в консоли можно загружать локальные изображения.
4. **Скачивание**: при успешном завершении возьмите ссылку на видео из ответа. Ссылки провайдера **действительны 24 часа**, поэтому скачивайте без промедления; платформа сохраняет копию каждого готового видео, которое можно просмотреть и скачать на странице «Задачи видео» в консоли.

<Callout type="info" title="Расчёт выполняется, даже если вы прекратили опрос">

После отправки платформа отслеживает задачу в фоновом режиме и производит расчёт в обычном порядке, даже если вы перестали запрашивать её статус; за неудачные и отменённые задачи плата не взимается.

</Callout>

Полные примеры создания и опроса см. на страницах [Seedance](/ru/docs/api/seedance-video#poll-example) и [Wan](/ru/docs/api/wan-video#poll-example).

## 4. Тарификация и водяные знаки [#billing]

- При создании задачи замораживается расчётная сумма. Если баланса недостаточно, запрос сразу отклоняется (`402`), и видео не генерируется.
- При успешном завершении задача рассчитывается один раз по фактическому использованию, а излишек замороженной суммы возвращается автоматически; за неудачные и отменённые задачи средства возвращаются полностью, плата не взимается.
- Seedance тарифицируется по выходным токенам; Wan — по формуле «фактические секунды × цена за единицу для уровня разрешения».
- Готовые видео содержат метку платформы «Сгенерировано ИИ», которую клиенты не могут отключить.

## 5. Лимиты параллельности [#limits]

Для каждого пользователя и каждого API-ключа одновременно может генерироваться не более **5** задач. При превышении лимита запросы возвращают `429` с заголовком `Retry-After` (около 60 секунд); подождите и повторите попытку.

## 6. Коды ошибок [#errors]

| HTTP | Значение | Что делать |
|---|---|---|
| `401` | API-ключ недействителен или отключён | Проверьте API-ключ |
| `402` | Недостаточно баланса или квоты для заморозки расчётной суммы | Пополните баланс и повторите попытку |
| `403` | Для группы не включена генерация видео, или модель недоступна в группе | Используйте API-ключ, поддерживающий генерацию видео |
| `404 model_not_found` | Модель пока недоступна (ошибка в названии также вызывает эту ошибку) | Используйте точное название, возвращаемое `GET /v1/models` |
| `409` | Генерация задачи уже началась, и её нельзя отменить (эндпоинт отмены Seedance) | Дождитесь завершения задачи |
| `429` | Достигнут лимит количества выполняемых задач | Подождите согласно `Retry-After` и повторите попытку |

Общие ошибки см. в разделе [Коды ошибок](/ru/docs/guide/errors).
