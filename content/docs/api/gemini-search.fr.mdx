Ajoutez l'outil `google_search` à une requête native Gemini `generateContent` et le modèle effectue une recherche sur le web lorsqu'il en a besoin, puis répond en s'appuyant sur les résultats. La réponse renvoie aussi **les requêtes de recherche, les sources citées et la source qui appuie chaque phrase**. Utilisez-le lorsque vous avez besoin d'informations à jour ou devez montrer d'où provient une réponse.

<Callout type="warn" title='Les requêtes doivent aboutir dans le groupe "Gemini-官方Vertex"'>

La recherche est effectuée par l'amont, et seul le groupe **Gemini-官方Vertex** l'exécute. Les amonts associés aux autres groupes Gemini peuvent ne pas effectuer de recherches : la requête renvoie quand même 200, mais la réponse ne contient pas de `groundingMetadata` et la réponse n'est pas fondée sur des résultats de recherche en direct.

- **Clé de groupe (recommandé)** : dans "API Keys" de la console, créez une nouvelle clé dans le groupe "Gemini-官方Vertex" et utilisez-la uniquement pour la recherche web.
- **Clé unifiée** : elle n'aboutit pas dans ce groupe par défaut. Dans la liste "API Keys", cliquez sur le badge de la clé unifiée pour ouvrir "Facturation", puis changez le niveau à l'usage de la "famille Gemini" en "Gemini-官方Vertex". Ensuite, **tous** les appels Gemini effectués avec cette clé vont vers ce groupe et sont facturés à son multiplicateur de tarif.

</Callout>

<CN>

<Callout type="info" title="Ce groupe n'apparaît pas sur le site Chine ?">

Le site Chine n'affiche pas le groupe « Gemini-官方Vertex ». Créez une API Key de ce groupe sur le site international.

## 1. Vue d'ensemble

| Élément | Valeur |
|---|---|
| URL de base | `https://api.lmuai.com` |
| Sans streaming | `POST /v1beta/models/{model}:generateContent` |
| Streaming | `POST /v1beta/models/{model}:streamGenerateContent?alt=sse` |
| Authentification | `x-goog-api-key: <your sk- API Key>` |
| Activer la recherche | Ajoutez `"tools": [{"google_search": {}}]` au corps de la requête |
| Sources | `candidates[0].groundingMetadata` dans la réponse |

## 2. Démarrage rapide

```bash
curl -X POST \
  'https://api.lmuai.com/v1beta/models/gemini-3.5-flash-lite:generateContent' \
  -H 'x-goog-api-key: YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "contents": [{
      "role": "user",
      "parts": [{"text": "What is the website api.lmuai.com? Please cite sources."}]
    }],
    "tools": [{"google_search": {}}],
    "generationConfig": {"maxOutputTokens": 2048}
  }'
```

Exemple de réponse (certains champs omis) :

```json
{
  "candidates": [{
    "content": {
      "role": "model",
      "parts": [{"text": "api.lmuai.com is the LLM API platform of LMU AI..."}]
    },
    "finishReason": "STOP",
    "groundingMetadata": {
      "webSearchQueries": ["api lmuai com", "lmuai com"],
      "groundingChunks": [
        {"web": {"uri": "https://vertexaisearch.cloud.google.com/grounding-api-redirect/...", "title": "lmuai.com", "domain": "lmuai.com"}},
        {"web": {"uri": "https://vertexaisearch.cloud.google.com/grounding-api-redirect/...", "title": "lmuai.ai", "domain": "lmuai.ai"}}
      ],
      "groundingSupports": [{
        "segment": {"endIndex": 52, "text": "api.lmuai.com is the LLM API platform of LMU AI"},
        "groundingChunkIndices": [0, 1]
      }],
      "searchEntryPoint": {"renderedContent": "<style>...</style><div>...</div>"}
    }
  }],
  "usageMetadata": {"promptTokenCount": 43, "candidatesTokenCount": 288}
}
```

## 3. Paramètres de la requête

Par rapport à une requête Gemini normale, le seul ajout est `tools` :

| Champ | Obligatoire | Description |
|---|---|---|
| `contents` | Oui | La conversation, rédigée de la même manière que dans une requête Gemini normale |
| `tools` | Oui | Toujours `[{"google_search": {}}]`. Le modèle décide s'il doit chercher et combien de fois |
| `generationConfig.maxOutputTokens` | Recommandé | Au moins `2048`. Les modèles de raisonnement (comme `gemini-4-hydrogen`) ont besoin de davantage, sinon la réponse peut être coupée avec `MAX_TOKENS` et vous n'obtenez ni la réponse ni les sources |

<Callout type="info" title="Une requête peut effectuer plusieurs recherches">

Le modèle peut découper une question en plusieurs requêtes de recherche. Les recherches réellement effectuées sont listées dans `webSearchQueries` dans la réponse.

</Callout>

---

## 4. Champs de la réponse : groundingMetadata

| Champ | Description |
|---|---|
| `webSearchQueries` | Les requêtes de recherche réellement effectuées pour cette requête |
| `groundingChunks[].web.uri` | Lien de la source. Il s'agit d'un lien de redirection Google (`vertexaisearch.cloud.google.com/...`) qui mène à la page d'origine |
| `groundingChunks[].web.title` | Titre de la source, généralement le domaine du site |
| `groundingChunks[].web.domain` | Le domaine du site source, comme `lmuai.com` |
| `groundingSupports[].segment` | Un fragment de la réponse : `text` est le contenu, `startIndex` / `endIndex` indiquent sa position (`startIndex` est omis lorsque le fragment commence au début) |
| `groundingSupports[].groundingChunkIndices` | Les sources citées par ce fragment, sous forme d'index dans `groundingChunks` |
| `searchEntryPoint.renderedContent` | Extrait HTML des suggestions de recherche Google |

<Callout type="warn" title="Lorsque vous affichez les réponses aux utilisateurs finaux">

Si vous affichez des réponses issues de la recherche web aux utilisateurs finaux, Google exige que vous affichiez aussi les suggestions de recherche contenues dans `searchEntryPoint.renderedContent`. Consultez la [documentation de Google](https://ai.google.dev/gemini-api/docs/google-search).

</Callout>

## 5. Exemple Python : lire les sources et les citations au niveau de la phrase

```python
import requests

API_KEY = "YOUR_API_KEY"
url = "https://api.lmuai.com/v1beta/models/gemini-3.5-flash-lite:generateContent"

resp = requests.post(
    url,
    headers={"x-goog-api-key": API_KEY},
    json={
        "contents": [{"role": "user", "parts": [{"text": "Which LLM API platforms are available in China? Please cite sources."}]}],
        "tools": [{"google_search": {}}],
        "generationConfig": {"maxOutputTokens": 2048},
    },
    timeout=180,
)
resp.raise_for_status()
cand = resp.json()["candidates"][0]

answer = "".join(p.get("text", "") for p in cand["content"]["parts"])
meta = cand.get("groundingMetadata", {})
chunks = meta.get("groundingChunks", [])

print("Answer:", answer)
print("Queries:", meta.get("webSearchQueries", []))

for i, c in enumerate(chunks):
    print(f"[{i}] {c['web'].get('domain')}  {c['web'].get('uri')}")

for s in meta.get("groundingSupports", []):
    refs = [chunks[i]["web"].get("domain") for i in s.get("groundingChunkIndices", [])]
    print(s["segment"].get("text"), "->", refs)

if not meta:
    print("No web search this time: the model saw no need to search, or this group does not support web search.")
```

## 6. Streaming

Passez au point de terminaison `streamGenerateContent?alt=sse` en conservant le corps de la requête :

```bash
curl -N -X POST \
  'https://api.lmuai.com/v1beta/models/gemini-3.5-flash-lite:streamGenerateContent?alt=sse' \
  -H 'x-goog-api-key: YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "contents": [{"role": "user", "parts": [{"text": "What is in the AI industry news today?"}]}],
    "tools": [{"google_search": {}}],
    "generationConfig": {"maxOutputTokens": 2048}
  }'
```

Chaque événement `data:` transporte un fragment de texte. **`groundingMetadata` n'apparaît que dans le dernier événement** : concaténez le texte de tous les événements, puis lisez les sources dans le dernier événement.

## 7. Modèles pris en charge

Les modèles suivants ont été testés avec la recherche web :

| Modèle | Remarques |
|---|---|
| `gemini-3.5-flash-lite` | Le plus rapide et le moins cher, adapté aux appels par lots |
| `gemini-3.8-flash` | Cite généralement davantage de sources, adapté lorsque les citations comptent |
| `gemini-3.6-flash` / `gemini-3.7-flash` | Comparable à 3.8 Flash |
| `gemini-3-flash-preview` | Fonctionne |
| `gemini-4-hydrogen` | Effectue de nombreuses recherches et prend plus de temps ; définissez un `maxOutputTokens` élevé |

Les modèles réellement disponibles dans votre groupe sont listés sur la page "Modèles disponibles" de la console.

## 8. Appel avec le protocole OpenAI ou Anthropic

Les modèles Gemini peuvent aussi être appelés avec le [protocole OpenAI ou Anthropic](/fr/docs/guide/api-protocols), et l'outil de recherche de chaque protocole déclenche une recherche web :

| Protocole | Outil de recherche | Recherche sur le web | Sources structurées |
|---|---|---|---|
| Gemini natif | `{"google_search": {}}` | ✅ | ✅ `groundingMetadata` |
| OpenAI Chat Completions | `{"type": "web_search"}` | ✅ | ❌ liens uniquement dans le texte de la réponse |
| OpenAI Responses | `{"type": "web_search"}` | ✅ | ❌ liens uniquement dans le texte de la réponse |
| Anthropic Messages | `{"type": "web_search_20250305", "name": "web_search"}` | ✅ | ❌ liens uniquement dans le texte de la réponse |

**Si vous avez besoin de la liste des sources ou des citations au niveau de la phrase, utilisez le protocole natif Gemini.**

<Callout type="info">

Un outil de fonction ordinaire nommé `google_search` (`"type": "function"`) ne déclenche pas de recherche web. Il reste une fonction exécutée par votre propre programme.

</Callout>

---

## 9. Coût

En plus du coût des tokens du modèle, les requêtes avec recherche web **font l'objet de frais de recherche distincts pour chaque recherche réellement effectuée**. Le nombre de recherches est tiré de `groundingMetadata.webSearchQueries` renvoyé par Gemini, et un terme répété dans cette liste ne compte qu'une fois ; si le modèle n'effectue aucune recherche, il n'y a pas de frais de recherche.

Une requête peut effectuer plusieurs recherches, et la sortie est généralement plus longue que pour une requête normale. Sur la page "Utilisation" de la console, les enregistrements ayant effectué des recherches affichent "Search N" à côté du coût, N étant le nombre de recherches ; les frais de recherche sont déjà inclus dans le coût de cet enregistrement.

## 10. Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| 200 mais pas de `groundingMetadata` | Le modèle n'a pas jugé utile de chercher, ou l'amont du groupe n'effectue pas de recherches | Utilisez une Key du groupe "Gemini-官方Vertex" ; demandez explicitement une recherche web ou des sources dans le prompt |
| La clé unifiée ne renvoie jamais de `groundingMetadata` | La famille Gemini de la clé unifiée est toujours sur son niveau par défaut et n'aboutit pas dans "Gemini-官方Vertex" | Modifiez la "Facturation" comme décrit en haut de cette page, ou créez une clé de groupe distincte |
| `finishReason` vaut `MAX_TOKENS` et la réponse est vide | Le raisonnement a épuisé le budget de sortie | Augmentez `maxOutputTokens` |
| `404 Not Found` | Chemin incorrect, ou le modèle ne fait pas partie de votre groupe | Vérifiez que le chemin est `/v1beta/models/{model}:generateContent` et confirmez le nom du modèle sur la page "Modèles disponibles" |
| `401 Unauthorized` | Key incorrecte, ou la Key n'est pas dans l'en-tête `x-goog-api-key` | Vérifiez l'en-tête de la requête |

Pour les détails des protocoles, consultez [Protocoles API](/fr/docs/guide/api-protocols) ; pour les erreurs courantes, consultez [Codes d'erreur](/fr/docs/guide/errors).
