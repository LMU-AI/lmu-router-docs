  - q: لماذا تبدأ روابط المصادر بـ vertexaisearch.cloud.google.com؟
    a: إنها روابط إعادة توجيه تعيدها Google وتقود إلى الصفحة الأصلية عند فتحها. نطاق الموقع المصدر موجود في الحقل domain.

أضف أداة `google_search` إلى طلب `generateContent` الأصلي في Gemini، وسيبحث النموذج على الويب عند الحاجة، ثم يجيب بناءً على النتائج. تعيد الاستجابة أيضًا **استعلامات البحث، والمصادر المستشهد بها، والمصدر الذي يدعم كل جملة**. استخدمها عندما تحتاج إلى معلومات حديثة أو إلى إظهار مصدر الإجابة.

<Callout type="warn" title='يجب أن تصل الطلبات إلى مجموعة "Gemini-官方Vertex"'>

تُجري الخدمة الأصلية البحث، ولا تُجريه سوى مجموعة **Gemini-官方Vertex**. قد لا تُجري الخدمات الأصلية خلف مجموعات Gemini الأخرى عمليات بحث: يظل الطلب يعيد 200، لكن الاستجابة لا تحتوي على `groundingMetadata` ولا تكون الإجابة مبنية على نتائج بحث حية.

- **مفتاح المجموعة (موصى به)**: ضمن "مفاتيح API" في لوحة التحكم، أنشئ مفتاحًا جديدًا في مجموعة "Gemini-官方Vertex" واستخدمه للبحث على الويب فقط.
- **المفتاح الموحّد**: لا يصل إلى هذه المجموعة افتراضيًا. في قائمة "مفاتيح API"، انقر على شارة المفتاح الموحّد لفتح "الفوترة"، ثم غيّر مستوى الدفع حسب الاستخدام لـ"عائلة Gemini" إلى "Gemini-官方Vertex". بعد ذلك، تذهب **جميع** استدعاءات Gemini التي تتم بهذا المفتاح إلى تلك المجموعة وتُفوتر بمضاعف سعرها.

</Callout>

## 1. نظرة عامة

| البند | القيمة |
|---|---|
| عنوان URL الأساسي | `https://api.lmuai.com` |
| بدون بث | `POST /v1beta/models/{model}:generateContent` |
| البث | `POST /v1beta/models/{model}:streamGenerateContent?alt=sse` |
| المصادقة | `x-goog-api-key: <your sk- API Key>` |
| تفعيل البحث | أضف `"tools": [{"google_search": {}}]` إلى نص الطلب |
| المصادر | `candidates[0].groundingMetadata` في الاستجابة |

## 2. البدء السريع

```bash
curl -X POST \
  'https://api.lmuai.com/v1beta/models/gemini-3.5-flash-lite:generateContent' \
  -H 'x-goog-api-key: YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "contents": [{
      "role": "user",
      "parts": [{"text": "What is the website api.lmuai.com? Please cite sources."}]
    }],
    "tools": [{"google_search": {}}],
    "generationConfig": {"maxOutputTokens": 2048}
  }'
```

مثال على الاستجابة (بعض الحقول محذوفة):

```json
{
  "candidates": [{
    "content": {
      "role": "model",
      "parts": [{"text": "api.lmuai.com is the LLM API platform of LMU AI..."}]
    },
    "finishReason": "STOP",
    "groundingMetadata": {
      "webSearchQueries": ["api lmuai com", "lmuai com"],
      "groundingChunks": [
        {"web": {"uri": "https://vertexaisearch.cloud.google.com/grounding-api-redirect/...", "title": "lmuai.com", "domain": "lmuai.com"}},
        {"web": {"uri": "https://vertexaisearch.cloud.google.com/grounding-api-redirect/...", "title": "lmuai.ai", "domain": "lmuai.ai"}}
      ],
      "groundingSupports": [{
        "segment": {"endIndex": 52, "text": "api.lmuai.com is the LLM API platform of LMU AI"},
        "groundingChunkIndices": [0, 1]
      }],
      "searchEntryPoint": {"renderedContent": "<style>...</style><div>...</div>"}
    }
  }],
  "usageMetadata": {"promptTokenCount": 43, "candidatesTokenCount": 288}
}
```

## 3. معاملات الطلب

مقارنةً بطلب Gemini العادي، الإضافة الوحيدة هي `tools`:

| الحقل | مطلوب | الوصف |
|---|---|---|
| `contents` | نعم | المحادثة، تُكتب بالطريقة نفسها كما في طلب Gemini العادي |
| `tools` | نعم | دائمًا `[{"google_search": {}}]`. يقرر النموذج ما إذا كان سيبحث وكم مرة |
| `generationConfig.maxOutputTokens` | موصى به | على الأقل `2048`. تحتاج نماذج التفكير (مثل `gemini-4-hydrogen`) إلى أكثر من ذلك، وإلا فقد تُقطع الاستجابة بـ `MAX_TOKENS` ولن تحصل على الإجابة ولا على المصادر |

<Callout type="info" title="قد يُجري طلب واحد عدة عمليات بحث">

قد يقسّم النموذج السؤال إلى عدة استعلامات بحث. تُدرج عمليات البحث التي أجراها فعليًا في `webSearchQueries` في الاستجابة.

</Callout>

## 4. حقول الاستجابة: groundingMetadata

| الحقل | الوصف |
|---|---|
| `webSearchQueries` | استعلامات البحث التي أُجريت فعليًا لهذا الطلب |
| `groundingChunks[].web.uri` | رابط المصدر. وهو رابط إعادة توجيه من Google (`vertexaisearch.cloud.google.com/...`) يقود إلى الصفحة الأصلية |
| `groundingChunks[].web.title` | عنوان المصدر، وعادةً ما يكون نطاق الموقع |
| `groundingChunks[].web.domain` | نطاق الموقع المصدر، مثل `lmuai.com` |
| `groundingSupports[].segment` | جزء من الإجابة: `text` هو المحتوى، و`startIndex` / `endIndex` يحددان موضعه (يُحذف `startIndex` عندما يبدأ الجزء من البداية) |
| `groundingSupports[].groundingChunkIndices` | المصادر التي يستشهد بها هذا الجزء، كفهارس في `groundingChunks` |
| `searchEntryPoint.renderedContent` | مقتطف HTML لاقتراحات بحث Google |

<Callout type="warn" title="عند عرض الإجابات على المستخدمين النهائيين">

إذا عرضت إجابات البحث على الويب على المستخدمين النهائيين، فإن Google تشترط أن تعرض أيضًا اقتراحات البحث الموجودة في `searchEntryPoint.renderedContent`. راجع [وثائق Google](https://ai.google.dev/gemini-api/docs/google-search).

</Callout>

## 5. مثال Python: قراءة المصادر والاستشهادات على مستوى الجملة

```python
import requests

API_KEY = "YOUR_API_KEY"
url = "https://api.lmuai.com/v1beta/models/gemini-3.5-flash-lite:generateContent"

resp = requests.post(
    url,
    headers={"x-goog-api-key": API_KEY},
    json={
        "contents": [{"role": "user", "parts": [{"text": "Which LLM API platforms are available in China? Please cite sources."}]}],
        "tools": [{"google_search": {}}],
        "generationConfig": {"maxOutputTokens": 2048},
    },
    timeout=180,
)
resp.raise_for_status()
cand = resp.json()["candidates"][0]

answer = "".join(p.get("text", "") for p in cand["content"]["parts"])
meta = cand.get("groundingMetadata", {})
chunks = meta.get("groundingChunks", [])

print("Answer:", answer)
print("Queries:", meta.get("webSearchQueries", []))

for i, c in enumerate(chunks):
    print(f"[{i}] {c['web'].get('domain')}  {c['web'].get('uri')}")

for s in meta.get("groundingSupports", []):
    refs = [chunks[i]["web"].get("domain") for i in s.get("groundingChunkIndices", [])]
    print(s["segment"].get("text"), "->", refs)

if not meta:
    print("No web search this time: the model saw no need to search, or this group does not support web search.")
```

## 6. البث

بدّل نقطة النهاية إلى `streamGenerateContent?alt=sse` واحتفظ بنص الطلب:

```bash
curl -N -X POST \
  'https://api.lmuai.com/v1beta/models/gemini-3.5-flash-lite:streamGenerateContent?alt=sse' \
  -H 'x-goog-api-key: YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "contents": [{"role": "user", "parts": [{"text": "What is in the AI industry news today?"}]}],
    "tools": [{"google_search": {}}],
    "generationConfig": {"maxOutputTokens": 2048}
  }'
```

يحمل كل حدث `data:` جزءًا من النص. **يظهر `groundingMetadata` في الحدث الأخير فقط**: اجمع النص من جميع الأحداث، ثم اقرأ المصادر من الحدث الأخير.

## 7. النماذج المدعومة

اختُبرت النماذج التالية مع البحث على الويب:

| النموذج | ملاحظات |
|---|---|
| `gemini-3.5-flash-lite` | الأسرع والأرخص، مناسب للاستدعاءات المجمّعة |
| `gemini-3.8-flash` | يستشهد عادةً بمصادر أكثر، مناسب عندما تكون الاستشهادات مهمة |
| `gemini-3.6-flash` / `gemini-3.7-flash` | مشابه لـ 3.8 Flash |
| `gemini-3-flash-preview` | يعمل |
| `gemini-4-hydrogen` | يُجري عمليات بحث كثيرة ويستغرق وقتًا أطول؛ اضبط قيمة كبيرة لـ `maxOutputTokens` |

النماذج المتاحة فعليًا في مجموعتك مدرجة في صفحة "النماذج المتاحة" في لوحة التحكم.

## 8. الاستدعاء باستخدام بروتوكول OpenAI أو Anthropic

يمكن أيضًا استدعاء نماذج Gemini باستخدام [بروتوكول OpenAI أو Anthropic](/ar/docs/guide/api-protocols)، وتُطلق أداة البحث في كل بروتوكول عملية بحث على الويب:

| البروتوكول | أداة البحث | يبحث على الويب | مصادر منظمة |
|---|---|---|---|
| Gemini الأصلي | `{"google_search": {}}` | ✅ | ✅ `groundingMetadata` |
| OpenAI Chat Completions | `{"type": "web_search"}` | ✅ | ❌ الروابط في نص الإجابة فقط |
| OpenAI Responses | `{"type": "web_search"}` | ✅ | ❌ الروابط في نص الإجابة فقط |
| Anthropic Messages | `{"type": "web_search_20250305", "name": "web_search"}` | ✅ | ❌ الروابط في نص الإجابة فقط |

**إذا كنت تحتاج إلى قائمة المصادر أو الاستشهادات على مستوى الجملة، فاستخدم بروتوكول Gemini الأصلي.**

<Callout type="info">

أداة الدالة العادية المسماة `google_search` (`"type": "function"`) لا تُطلق بحثًا على الويب. تظل دالة يشغّلها برنامجك الخاص.

</Callout>

## 9. التكلفة

تُفوتر طلبات البحث على الويب حسب النموذج المستخدم. يمكنك رؤية تكلفة كل طلب في صفحة "الاستخدام" في لوحة التحكم. قد يُجري طلب واحد عدة عمليات بحث، ويكون الناتج عادةً أطول من الطلب العادي.

## 10. استكشاف الأخطاء وإصلاحها

| العَرَض | السبب | الحل |
|---|---|---|
| 200 لكن بدون `groundingMetadata` | لم يرَ النموذج حاجة إلى البحث، أو أن الخدمة الأصلية للمجموعة لا تُجري عمليات بحث | استخدم مفتاحًا في مجموعة "Gemini-官方Vertex"؛ واطلب صراحةً البحث على الويب أو المصادر في الموجّه |
| المفتاح الموحّد لا يعيد `groundingMetadata` أبدًا | لا تزال عائلة Gemini في المفتاح الموحّد على مستواها الافتراضي ولا تصل إلى "Gemini-官方Vertex" | غيّر "الفوترة" كما هو موضح في أعلى هذه الصفحة، أو أنشئ مفتاح مجموعة منفصلًا |
| `finishReason` هو `MAX_TOKENS` والإجابة فارغة | استهلك التفكير ميزانية المخرجات | زِد قيمة `maxOutputTokens` |
| `404 Not Found` | مسار خاطئ، أو أن النموذج ليس في مجموعتك | تحقق من أن المسار هو `/v1beta/models/{model}:generateContent` وتأكد من اسم النموذج في صفحة "النماذج المتاحة" |
| `401 Unauthorized` | مفتاح خاطئ، أو أن المفتاح ليس في ترويسة `x-goog-api-key` | تحقق من ترويسة الطلب |

لتفاصيل البروتوكول راجع [بروتوكولات API](/ar/docs/guide/api-protocols)؛ وللأخطاء الشائعة راجع [رموز الأخطاء](/ar/docs/guide/errors).
