LMU AI ofrece dos tipos de API de generación de video **asíncronas**, ambas con los **protocolos nativos** de los proveedores: reemplaza la dirección en el SDK oficial o en el comando curl por la dirección de LMU AI y la clave por tu API key de LMU AI; el cuerpo de la solicitud no cambia. Esta página es la descripción general: elige una API en la tabla siguiente y luego lee la página de su proveedor. Las reglas que comparten ambos proveedores (autenticación, facturación, límites de concurrencia y códigos de error) están en esta página.

<Callout type="info" title="URL base">

```text
https://api.lmuai.com
```

| Proveedor | Crear tarea | Consultar tarea | Documentación |
|---|---|---|---|
| Seedance (Volcengine Ark) | `POST /api/v3/contents/generations/tasks` | `GET /api/v3/contents/generations/tasks/{id}` | [API de generación de video Seedance](/es/docs/api/seedance-video) |
| Wan (Alibaba DashScope) | `POST /api/v1/services/aigc/video-generation/video-synthesis` | `GET /api/v1/tasks/{task_id}` | [API de generación de video Wan](/es/docs/api/wan-video) |

</Callout>

<Callout type="warn" title="La generación de video debe estar habilitada para tu grupo">

El grupo de la API key debe tener habilitada la opción "Generación de video"; de lo contrario, las llamadas devuelven `403`. Los modelos que puedes llamar dependen de tu API key; consúltalos con `GET /v1/models`.

</Callout>

## 1. Cómo elegir entre las dos [#compare]

| | Seedance (Volcengine Ark) | Wan (Alibaba DashScope) |
|---|---|---|
| Modelo de ejemplo | `seedance-2.5` | `wan3.0-video` |
| Facturación | Por tokens de salida | Por "segundos reales × precio unitario del nivel de resolución" |
| Valores de resolución | `480p` / `720p` / `1080p` (minúsculas) | `480P` / `720P` / `1080P` (mayúsculas), predeterminado `1080P` |
| Estado de la tarea | `queued` → `running` → `succeeded` / `failed` / `cancelled` | `PENDING` → `RUNNING` → `SUCCEEDED` / `FAILED` / `CANCELED` |
| Campo de la URL del video | `content.video_url` | `output.video_url` |
| Cancelación de tareas | Se pueden cancelar las tareas en cola (`queued`) | No hay endpoint de cancelación; una tarea enviada siempre se ejecuta hasta completarse |

El nombre del modelo debe coincidir **exactamente** con el nombre habilitado para tu grupo (distingue mayúsculas y minúsculas). Las dos API usan nombres de campo similares, pero con distintas mayúsculas/minúsculas y rutas, así que no los confundas al copiar ejemplos.

## 2. Autenticación [#auth]

Envía tu API key en el encabezado de cada solicitud:

```http
Authorization: Bearer YOUR_API_KEY
```

No incluyas tu API key en código de front-end del navegador, repositorios públicos, parámetros de consulta de URL ni registros. Llama a la API desde tu propio servidor.

## 3. Flujo de tareas asíncronas [#flow]

1. **Crear**: `POST` solo devuelve un id de tarea; no espera a que el video esté listo.
2. **Consultar**: haz `GET` a la tarea aproximadamente cada 10 segundos hasta que llegue a un estado final (éxito / fallo / cancelación).
3. **Imágenes de referencia**: las llamadas a la API deben enviar una URL de imagen de acceso público (JPG / PNG / WebP); la página Generación de video de la consola acepta la carga de imágenes locales.
4. **Descargar**: si la tarea tiene éxito, toma el enlace del video de la respuesta. Los enlaces del proveedor son **válidos durante 24 horas**, así que descárgalos pronto; la plataforma conserva una copia de cada video terminado, que puedes reproducir y descargar en la página Tareas de video de la consola.

<Callout type="info" title="La facturación se liquida aunque dejes de consultar">

Tras el envío, la plataforma da seguimiento a la tarea en segundo plano y la liquida normalmente aunque dejes de consultarla; las tareas fallidas y canceladas no se cobran.

</Callout>

Para ver ejemplos completos de creación y consulta, consulta las páginas de [Seedance](/es/docs/api/seedance-video#poll-example) y [Wan](/es/docs/api/wan-video#poll-example).

## 4. Facturación y marcas de agua [#billing]

- Al crear la tarea se congela un monto estimado. Si tu saldo es insuficiente, la solicitud se rechaza directamente (`402`) y no se genera ningún video.
- Si la tarea tiene éxito, se liquida una sola vez según el uso real y cualquier excedente congelado se devuelve automáticamente; las tareas fallidas y canceladas se reembolsan por completo y no se cobran.
- Seedance se factura por tokens de salida; Wan se factura por "segundos reales × precio unitario del nivel de resolución".
- Los videos terminados llevan la etiqueta "Generado por IA" de la plataforma, que los clientes no pueden desactivar.

## 5. Límites de concurrencia [#limits]

Cada usuario y cada API key pueden tener como máximo **5** tareas generándose al mismo tiempo. Por encima de ese límite, las solicitudes devuelven `429` con un encabezado `Retry-After` (de unos 60 segundos); espera y vuelve a intentarlo.

## 6. Códigos de error [#errors]

| HTTP | Significado | Qué hacer |
|---|---|---|
| `401` | La API key no es válida o está deshabilitada | Revisa tu API key |
| `402` | Saldo o cuota insuficiente para congelar el monto estimado | Recarga saldo y vuelve a intentarlo |
| `403` | La generación de video no está habilitada para el grupo, o el modelo no está disponible en el grupo | Usa una API key que admita la generación de video |
| `404 model_not_found` | El modelo aún no está disponible (un nombre mal escrito también lo provoca) | Usa el nombre exacto que devuelve `GET /v1/models` |
| `409` | La tarea ya comenzó a generarse y no se puede cancelar (endpoint de cancelación de Seedance) | Espera a que la tarea termine |
| `429` | El número de tareas en curso alcanzó el límite | Espera según `Retry-After` y vuelve a intentarlo |

Para errores generales, consulta [Códigos de error](/es/docs/guide/errors).
