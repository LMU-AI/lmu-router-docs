faq:
  - q: Что такое LMU AI?
    a: LMU AI (Large Model Unified) — стабильный и надёжный релей для API Claude / GPT / Gemini. Один API-ключ позволяет использовать модели Anthropic / OpenAI / Google — а также ведущие китайские модели — внутри Claude Code, Codex CLI, Cursor, VS Code, OpenCode, Cherry Studio и других инструментов для AI-программирования.
  - q: Какие инструменты поддерживает LMU AI?
    a: Claude Code (CLI / десктоп / расширение VS Code), Codex CLI (Mac / Windows / сервер) и десктоп Codex, Cursor, Cherry Studio, OpenCode, Hermes Agent, IntelliJ IDEA Kilo Code, CC Switch и другие.
  - q: Нужен ли отдельный ключ для каждого инструмента?
    a: Нет. Один ключ LMU AI работает во всех поддерживаемых инструментах и с обоими протоколами — Anthropic и OpenAI.
