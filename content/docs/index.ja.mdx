faq:
  - q: LMU AI とは何ですか？
    a: LMU AI（Large Model Unified）は、Claude / GPT / Gemini API 向けの安定・信頼性の高いリレーです。1 つの API キーで、Anthropic / OpenAI / Google のモデル（および主要な中国製モデル）を、Claude Code、Codex CLI、Cursor、VS Code、OpenCode、Cherry Studio などの AI コーディングツール内で利用できます。
  - q: LMU AI はどのツールに対応していますか？
    a: Claude Code（CLI / デスクトップ / VS Code 拡張機能）、Codex CLI（Mac / Windows / サーバー）および Codex デスクトップ、Cursor、Cherry Studio、OpenCode、Hermes Agent、IntelliJ IDEA Kilo Code、CC Switch などに対応しています。
  - q: ツールごとに 1 つのキーが必要ですか？
    a: いいえ。1 つの LMU AI キーで、対応するすべてのツール、および Anthropic と OpenAI の両プロトコルで利用できます。
