faq:
  - q: ما هو LMU AI؟
    a: LMU AI (Large Model Unified) هو وسيط مستقر وموثوق لواجهات برمجة تطبيقات Claude / GPT / Gemini. يتيح لك مفتاح واجهة برمجة تطبيقات واحد استخدام نماذج Anthropic / OpenAI / Google — بالإضافة إلى النماذج الصينية الرائدة — داخل Claude Code وCodex CLI وCursor وVS Code وOpenCode وCherry Studio وأدوات البرمجة بالذكاء الاصطناعي الأخرى.
  - q: ما الأدوات التي يدعمها LMU AI؟
    a: Claude Code (CLI / سطح المكتب / امتداد VS Code) وCodex CLI (Mac / Windows / خادم) وسطح مكتب Codex وCursor وCherry Studio وOpenCode وHermes Agent وIntelliJ IDEA Kilo Code وCC Switch وغيرها.
  - q: هل أحتاج إلى مفتاح لكل أداة؟
    a: لا. يعمل مفتاح LMU AI واحد عبر كل أداة مدعومة وعبر بروتوكولي Anthropic وOpenAI معًا.
