faq:
  - q: LMU AI란 무엇인가요?
    a: LMU AI (Large Model Unified)는 Claude / GPT / Gemini API를 위한 안정적이고 신뢰할 수 있는 릴레이입니다. 단일 API 키로 Anthropic / OpenAI / Google 모델은 물론 주요 중국 모델까지 Claude Code, Codex CLI, Cursor, VS Code, OpenCode, Cherry Studio 및 기타 AI 코딩 도구 안에서 사용할 수 있습니다.
  - q: LMU AI는 어떤 도구를 지원하나요?
    a: Claude Code (CLI / 데스크톱 / VS Code 확장), Codex CLI (Mac / Windows / 서버) 및 Codex 데스크톱, Cursor, Cherry Studio, OpenCode, Hermes Agent, IntelliJ IDEA Kilo Code, CC Switch 등을 지원합니다.
  - q: 도구마다 별도의 키가 필요한가요?
    a: 아니요. 하나의 LMU AI 키가 지원되는 모든 도구와 Anthropic 및 OpenAI 프로토콜 양쪽에서 작동합니다.
