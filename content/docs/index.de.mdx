faq:
  - q: Was ist LMU AI?
    a: LMU AI (Large Model Unified) ist ein stabiles, zuverlässiges Relay für die Claude / GPT / Gemini APIs. Ein einziger API-Schlüssel ermöglicht die Nutzung von Anthropic- / OpenAI- / Google-Modellen — sowie führenden chinesischen Modellen — in Claude Code, Codex CLI, Cursor, VS Code, OpenCode, Cherry Studio und anderen KI-Coding-Tools.
  - q: Welche Tools unterstützt LMU AI?
    a: Claude Code (CLI / Desktop / VS Code-Erweiterung), Codex CLI (Mac / Windows / Server) und Codex Desktop, Cursor, Cherry Studio, OpenCode, Hermes Agent, IntelliJ IDEA Kilo Code, CC Switch und mehr.
  - q: Brauche ich einen Schlüssel pro Tool?
    a: Nein. Ein LMU AI Schlüssel funktioniert in jedem unterstützten Tool und sowohl im Anthropic- als auch im OpenAI-Protokoll.
