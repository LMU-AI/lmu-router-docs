Cursor peut diriger les requêtes du panneau Chat / Plan vers une API relais tierce via **Override OpenAI Base URL**. Cette page explique comment utiliser cette méthode native pour se connecter à LMU AI.

<Callout type="warn" title="Limitation clé : seul le panneau Chat / Plan est affecté">

Override OpenAI Base URL de Cursor **n'affecte que le panneau Chat / Plan** (la conversation ouverte avec Cmd/Ctrl + L). Les fonctionnalités d'agent centrales de Cursor — **Composer, Tab autocomplete, Apply, Inline Edit** — sont toutes verrouillées sur le backend officiel de Cursor et ne peuvent pas être prises en charge par un relais tiers.

Si vous avez besoin d'une expérience d'agent « pleine capacité » dans Cursor (y compris les fonctionnalités de type Composer), installez plutôt (Cursor est compatible avec la place de marché des extensions VS Code) :

- [Extension Codex officielle](/fr/docs/tools/vscode-plugin) — un agent Codex sur le protocole OpenAI de LMU AI
- [Extension Claude Code for VS Code](/fr/docs/tools/claude-code-vscode) — un agent Claude Code sur le protocole Anthropic de LMU AI

</Callout>

## Étapes de configuration

### Étape 1 — Ouvrir Cursor Settings

Appuyez sur **Cmd + Shift + J** (macOS) ou **Ctrl + Shift + J** (Windows / Linux) pour ouvrir Settings, et cliquez sur **Models** dans la barre latérale gauche.

### Étape 2 — Désactiver les modèles par défaut (recommandé)

Cursor est livré avec de nombreux modèles par défaut (GPT-4 / Claude-3.5, etc.) ; les laisser activés entre en conflit avec le routage personnalisé. Dans la liste des modèles de la page Models, désactivez-les tous (**off**) (bouton grisé à gauche).

### Étape 3 — Ajouter des modèles personnalisés

Cliquez sur **Add Model** et saisissez les IDs de modèles LMU AI que vous voulez, par exemple :

- `claude-opus-5`
- `claude-sonnet-5`
- `gpt-5.6-sol`
- `glm-5.2`
- `qwen3.8-max-preview`
- `deepseek-v4-pro`
- `kimi-k3`

**Ajoutez chaque modèle une fois.** Pour la liste complète des modèles disponibles, consultez la [Galerie de modèles](/fr/docs/guide/models).

### Étape 4 — Activer Override OpenAI Base URL

Faites défiler jusqu'à la zone **OpenAI API Key** sur la page Models :

1. Activez le bouton **OpenAI API Key**
2. Collez la clé de la console LMU AI (commençant par `sk-`) dans le champ API Key
3. Activez le bouton **Override OpenAI Base URL**
4. Définissez Base URL sur :
   ```
   https://api.lmuai.com/v1
   ```
5. Cliquez sur **Verify** pour vérifier la connexion

<Callout type="info" title="Un échec de Verify ne signifie pas que c'est mal configuré">

Verify de Cursor effectue la vérification avec le **nom de modèle** que vous avez saisi, et les noms non officiels d'OpenAI (`claude-opus-5`, `glm-5.2`, etc.) ne passeront pas. Solution de contournement : **ajoutez d'abord un `gpt-4` pour passer Verify** (confirmant que la Base URL + la clé se connectent), puis ajoutez séparément les IDs de modèles personnalisés que vous voulez ; Verify avertit mais cela fonctionne en pratique.

</Callout>

### Étape 5 — Basculer de modèle et l'utiliser

Appuyez sur **Cmd/Ctrl + L** pour ouvrir le panneau Chat → choisissez le modèle personnalisé que vous avez ajouté à l'étape 3 dans le menu déroulant des modèles en haut → commencez à discuter, et les requêtes passeront par LMU AI.

## Problèmes courants

### Vous voulez que Composer / Tab autocomplete utilisent aussi LMU AI ?

Le Override OpenAI Base URL natif ne peut pas le faire — ces fonctionnalités centrales de Cursor sont verrouillées sur le backend officiel. Pour tout router via LMU AI, utilisez :

- [Extension Codex officielle](/fr/docs/tools/vscode-plugin) — un agent protocole OpenAI
- [Extension Claude Code for VS Code](/fr/docs/tools/claude-code-vscode) — un agent protocole Anthropic

Cursor est compatible avec la place de marché des extensions VS Code, donc les deux extensions s'installent directement dans Cursor.

### La Base URL a-t-elle besoin de `/v1` ?

**Oui.** Saisissez `https://api.lmuai.com/v1`. Cursor ajoute `/chat/completions` pour une requête finale vers `https://api.lmuai.com/v1/chat/completions`. Omettre `/v1` donne une erreur 404.

### Le Claude 3.5 intégré renvoie des erreurs après avoir activé Override ?

Il s'agit d'un conflit de routage connu de Cursor — activer le remplacement de l'OpenAI Base URL interrompt la branche Anthropic. Pour continuer à utiliser Claude dans le panneau Chat, ajoutez l'ID du modèle Claude (p. ex. `claude-opus-5`) comme modèle personnalisé, et le backend LMU AI effectue la traduction de protocole OpenAI ↔ Anthropic.

### Erreurs 401 / 403 ?

Vérifiez dans l'ordre :

1. L'**API Key** est-elle la clé `sk-` générée dans la console LMU AI (et non une clé officielle OpenAI) ?
2. La **Base URL** est-elle `https://api.lmuai.com/v1` (**doit inclure `/v1`**) ?
3. L'**ID de modèle** est-il pris en charge par LMU AI (voir la [Galerie de modèles](/fr/docs/guide/models)) ?
4. Votre plan / groupe de facturation actuel inclut-il le modèle que vous appelez ?

### Le BYOK affecte-t-il mon abonnement Cursor ?

- L'usage BYOK **ne consomme pas** le quota mensuel de requêtes rapides de Cursor
- Les fonctionnalités centrales comme Composer / Tab autocomplete **consomment toujours** le quota d'abonnement Cursor (car elles n'utilisent pas BYOK)
- Pour abandonner entièrement l'abonnement Cursor, voir l'approche par extension Codex / Claude Code ci-dessus
