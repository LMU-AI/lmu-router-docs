Cursor は **Override OpenAI Base URL** を使って、Chat / Plan パネルのリクエストをサードパーティ中継 APIに向けることができます。このページでは、そのネイティブ手法を使って LMU AI に接続する方法を説明します。

<Callout type="warn" title="重要な制限：Chat / Plan パネルのみに影響">

Cursor の Override OpenAI Base URL は **Chat / Plan パネルのみに影響します**（Cmd/Ctrl + L で開く会話）。Cursor のコアエージェント機能 — **Composer、Tab 自動補完、Apply、Inline Edit** — はすべて Cursor 公式バックエンドに固定されており、サードパーティ中継が引き継ぐことはできません。

Cursor で「フル機能」のエージェント体験（Composer 系機能を含む）が必要な場合は、代わりに以下をインストールしてください（Cursor は VS Code 拡張機能マーケットプレイスと互換性があります）：

- [公式 Codex 拡張機能](/ja/docs/tools/vscode-plugin) — LMU AI の OpenAI プロトコル上で動く Codex エージェント
- [Claude Code for VS Code 拡張機能](/ja/docs/tools/claude-code-vscode) — LMU AI の Anthropic プロトコル上で動く Claude Code エージェント

</Callout>

## 設定手順

### ステップ 1 — Cursor の設定を開く

**Cmd + Shift + J**（macOS）または **Ctrl + Shift + J**（Windows / Linux）を押して設定を開き、左サイドバーの **Models** をクリックします。

### ステップ 2 — デフォルトモデルをオフにする（推奨）

Cursor には多くのデフォルトモデル（GPT-4 / Claude-3.5 など）が付属しており、有効のままだとカスタムルーティングと競合します。Models ページのモデルリストで、それらをすべて **オフ**（左側のトグルをグレーアウト）にします。

### ステップ 3 — カスタムモデルを追加する

**Add Model** をクリックし、使いたい LMU AI のモデル ID を入力します。例：

- `claude-opus-5`
- `claude-sonnet-5`
- `gpt-5.6-sol`
- `glm-5.2`
- `qwen3.8-max-preview`
- `deepseek-v4-pro`
- `kimi-k3`

**各モデルは一度だけ追加してください。** 利用可能なモデルの全リストは [モデルギャラリー](/ja/docs/guide/models) を参照してください。

### ステップ 4 — Override OpenAI Base URL をオンにする

Models ページの **OpenAI API Key** エリアまでスクロールします：

1. **OpenAI API Key** トグルをオンにする
2. LMU AI コンソールのキー（`sk-` で始まる）を API Key ボックスに貼り付ける
3. **Override OpenAI Base URL** トグルをオンにする
4. Base URL を以下に設定する：
   ```
   https://api.lmuai.com/v1
   ```
5. **Verify** をクリックして接続を確認する

<Callout type="info" title="Verify が失敗しても設定ミスとは限りません">

Cursor の Verify は入力した **モデル名** を使ってチェックするため、非公式の OpenAI 名（`claude-opus-5`、`glm-5.2` など）は通過しません。回避策：**まず `gpt-4` を追加して Verify を通過させ**（Base URL + キーが接続できることを確認）、その後で使いたいカスタムモデル ID を別途追加します。Verify は警告を出しますが、実際には正常に動作します。

</Callout>

### ステップ 5 — モデルを切り替えて使う

**Cmd/Ctrl + L** を押して Chat パネルを開く → 上部のモデルドロップダウンからステップ 3 で追加したカスタムモデルを選ぶ → チャットを開始すると、リクエストは LMU AI を経由します。

## よくある問題

### Composer / Tab 自動補完でも LMU AI を使いたい？

ネイティブの Override OpenAI Base URL ではできません — これらの Cursor コア機能は公式バックエンドに固定されています。すべてを LMU AI 経由にするには、以下を使ってください：

- [公式 Codex 拡張機能](/ja/docs/tools/vscode-plugin) — OpenAI プロトコルのエージェント
- [Claude Code for VS Code 拡張機能](/ja/docs/tools/claude-code-vscode) — Anthropic プロトコルのエージェント

Cursor は VS Code 拡張機能マーケットプレイスと互換性があるため、どちらの拡張機能も Cursor に直接インストールできます。

### Base URL に `/v1` は必要ですか？

**はい。** `https://api.lmuai.com/v1` を入力します。Cursor が `/chat/completions` を付加し、最終的なリクエストは `https://api.lmuai.com/v1/chat/completions` になります。`/v1` を省くと 404 になります。

### Override をオンにしたら組み込み Claude 3.5 がエラーになる？

これは既知の Cursor ルーティング競合です — OpenAI Base URL の上書きをオンにすると Anthropic ブランチが中断されます。Chat パネルで Claude を使い続けるには、Claude のモデル ID（例：`claude-opus-5`）をカスタムモデルとして追加してください。LMU AI バックエンドが OpenAI ↔ Anthropic のプロトコル変換を行います。

### 401 / 403 エラー？

以下の順に確認してください：

1. **API Key** は LMU AI コンソールで生成した `sk-` キーですか（公式 OpenAI のキーではなく）？
2. **Base URL** は `https://api.lmuai.com/v1` ですか（**必ず `/v1` を含める**）？
3. **モデル ID** は LMU AI がサポートするものですか（[モデルギャラリー](/ja/docs/guide/models) を参照）？
4. 現在のプラン / 課金グループに、呼び出そうとしているモデルが含まれていますか？

### BYOK は Cursor サブスクリプションに影響しますか？

- BYOK の使用は Cursor の月間ファストリクエストクォータを **消費しません**
- Composer / Tab 自動補完などのコア機能は引き続き Cursor サブスクリプションのクォータを **消費します**（これらは BYOK を使わないため）
- Cursor サブスクリプションを完全に手放すには、上記の Codex / Claude Code 拡張機能のアプローチを参照してください
