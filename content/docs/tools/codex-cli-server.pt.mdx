Para configurar o Codex CLI em um ambiente WSL2 ou de servidor remoto via SSH.

---

## Etapas de configuração

### Etapa 1 — Instalar o ambiente Node.js (com o volta)

No terminal do servidor, execute:

```bash
curl https://get.volta.sh | bash
```

### Etapa 2 — Instalar o Node 20

<Callout type="warn" title="Observação">

Depois que o volta for instalado com sucesso, você **precisa abrir uma nova janela de terminal** antes de executar o comando a seguir:

</Callout>

```bash
volta install node@20
```

### Etapa 3 — Instalar o Codex CLI

```bash
volta install @openai/codex
```

### Etapa 4 — Criar os arquivos de configuração

Execute o seguinte no terminal do servidor para escrever o `~/.codex/config.toml` de uma só vez (**lembre-se de substituir "your sk- key generated in the console" na última linha pela sua chave `sk-`, mantendo um espaço após `Bearer`**):

```bash
mkdir -p ~/.codex

cat > ~/.codex/config.toml <<'EOF'
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
sandbox_mode = "danger-full-access"
windows_wsl_setup_acknowledged = true
approval_policy = "never"
file_opener = "vscode"
model_provider = "codex"
web_search = "cached"
suppress_unstable_features_warning = true

[history]
persistence = "save-all"

[tui]
notifications = true

[shell_environment_policy]
inherit = "all"
ignore_default_excludes = false

[sandbox_workspace_write]
network_access = true

[features]
plan_tool = true
apply_patch_freeform = true
view_image_tool = true
unified_exec = false
streamable_shell = false
rmcp_client = true
elevated_windows_sandbox = true

[profiles.auto-max]
approval_policy = "never"
sandbox_mode = "workspace-write"

[profiles.review]
approval_policy = "on-request"
sandbox_mode = "workspace-write"

[notice]
hide_gpt5_1_migration_prompt = true

[model_providers.codex]
name = "codex"
base_url = "https://api.lmuai.com"
wire_api = "responses"

[model_providers.codex.http_headers]
Authorization = "Bearer your sk- key generated in the console"
EOF
```

O conteúdo da configuração é idêntico ao do [guia do Codex CLI (Mac/Linux)](/pt/docs/tools/codex-cli-mac) — você também pode criá-lo manualmente com `vim` / `nano`. As versões mais recentes do Codex não precisam mais do `~/.codex/auth.json`; deixar um arquivo antigo no lugar não causa problemas.

### Etapa 5 — Iniciar o Codex CLI

```bash
codex --dangerously-bypass-approvals-and-sandbox
```

Ou:

```bash
codex --yolo
```

## Habilitar o contexto de 1M (opcional)

O `gpt-5.4` suporta um contexto longo de 1M tokens, mas ele vem desativado por padrão. Edite o `~/.codex/config.toml`, adicione duas linhas no **nível superior** do arquivo (antes de qualquer `[section]`) e entre novamente no Codex:

```toml
model_context_window = 1000000
model_auto_compact_token_limit = 900000
```

Para o significado dos campos, como verificar e as ressalvas, veja [Habilitar o contexto de 1M no Codex](/pt/docs/tools/codex-cli-mac#enabling-the-1m-context-in-codex-optional).
