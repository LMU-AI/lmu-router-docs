ZCode — это настольное приложение Agentic Development Environment (ADE), созданное для долгосрочных задач. Оно поддерживает пользовательских провайдеров для любого модельного сервиса, говорящего на протоколе Anthropic или OpenAI — эта страница описывает подключение к LMU AI.

---

## Установка ZCode

Скачайте и установите сборку для вашей операционной системы с официального сайта:

- Сайт: [https://zcode.z.ai](https://zcode.z.ai)

---

## Добавьте LMU AI как провайдера

Откройте **Settings → Model Providers** и нажмите «**Add provider**» **внизу** списка провайдеров слева, затем заполните:

| Поле | Значение |
|------|------|
| **Name** | что угодно, например `LMU AI` |
| **Anthropic endpoint** | `https://api.lmuai.com` |
| **OpenAI endpoint** | `https://api.lmuai.com/v1` |
| **API Key** | ключ `sk-`, сгенерированный в консоли LMU AI |

<Callout type="warn" title="Два эндпоинта используют разные формы /v1">

- **Anthropic-эндпоинт**: `https://api.lmuai.com` — **без** `/v1`; клиент сам добавляет `/v1/messages`
- **OpenAI-эндпоинт**: `https://api.lmuai.com/v1` — **обязательно** с `/v1`

Их путаница приводит к ошибке 401 или 404. Оба адреса могут находиться в одной записи провайдера — ZCode использует тот протокол, который соответствует выбранной вами модели.

</Callout>

## Добавьте модели

Пользовательские провайдеры **не подтягивают список моделей автоматически**, поэтому добавляйте их вручную:

1. Сохраните конфигурацию провайдера
2. Нажмите «**Add model**»
3. Введите ID модели вручную, например `claude-opus-5`
4. Включите **переключатель активации**

Повторите для каждой нужной модели. Распространённые ID моделей:

| ID модели | Примечания |
|------|------|
| `claude-opus-5` | Claude Opus 5 (флагман, рекомендуется) |
| `claude-sonnet-5` | Claude Sonnet 5 (сбалансированная) |
| `claude-haiku-4-5` | Claude Haiku 4.5 (быстрая) |
| `gpt-5.6-sol` | GPT-5.6 Sol |
| `glm-5.2` | GLM-5.2 |
| `qwen3.8-max-preview` | Qwen 3.8 Max Preview |
| `deepseek-v4-pro` | DeepSeek V4 Pro |
| `kimi-k3` | Kimi K3 |

Не уверены, какую модель вводить? Перейдите в [Галерею моделей](/ru/docs/guide/models), чтобы увидеть все доступные ID моделей и скопировать их одним кликом.

## Включите окно контекста 1M

Основные модели, такие как `claude-opus-5` и `claude-sonnet-5`, поддерживают окно контекста в 1M токенов — добавьте суффикс `[1M]` к ID модели, чтобы включить его:

```
claude-opus-5[1M]
```

Введите полный ID с суффиксом, используя шаги «Add model» выше.

<Callout type="info" title="Окно контекста можно настроить для каждой модели">

В **Settings → Model Providers** откройте модель и разверните «**Advanced**», чтобы задать **окно контекста** и **максимальное число выходных токенов** для этой конкретной модели. Оба параметра редактируются для моделей пользовательского провайдера.

Оставлять максимальное число выходных токенов пустым рекомендуется (тогда оно следует собственному лимиту модели). Учтите, что пространство вывода делит общий контекст с историей вашего разговора, поэтому чем выше вы его задаёте, тем меньше истории можно нести и тем раньше срабатывает автоматическое уплотнение.

</Callout>

## Проверьте настройку

**Перезапустите ZCode** после настройки, выберите вновь добавленную модель в выборе моделей поля чата и отправьте простую инструкцию для проверки. Нормальный ответ означает, что всё готово.

<Callout type="info" title="Не удаётся подключиться? Проверьте сначала прокси">

HTTP-прокси в настройках ZCode не является глобальным прокси, но **запросы к моделям проходят через него**. Если прокси нарушает подключение, отключите его и повторите попытку. Переменные окружения `HTTP_PROXY` / `HTTPS_PROXY` также применяются, а после их изменения ZCode нужно перезапустить.

</Callout>

## Примечания

- LMU AI является сторонним / пользовательским провайдером, поэтому создавайте его через «**Add provider**» внизу списка — не изменяйте встроенные записи вендоров
- **Anthropic-эндпоинт** принимает `https://api.lmuai.com` (без `/v1`); **OpenAI-эндпоинт** принимает `https://api.lmuai.com/v1` (с `/v1`)
- В качестве API Key введите ключ `sk-`, сгенерированный в консоли LMU AI
- Пользовательские провайдеры требуют ручного добавления каждой модели и включения её переключателя активации, прежде чем она появится в выборе
- Стороннее развёртывание одноимённой модели может предлагать иные **уровни усилия размышления**, чем официальный эндпоинт; пользовательские модели обычно выставляют только пару вкл/выкл или вовсе не имеют уровней
- Если вы столкнулись с ошибками, связанными с изображениями, у пользовательской модели, убедитесь, что сама модель принимает изображения на вход, и объявите её способность работать с изображениями в конфигурации модели
