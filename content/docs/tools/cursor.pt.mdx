O Cursor pode direcionar as requisições do painel de Chat / Plan para uma API de relay de terceiros via **Override OpenAI Base URL**. Esta página explica como usar esse método nativo para conectar à LMU AI.

<Callout type="warn" title="Limitação principal: apenas o painel de Chat / Plan é afetado">

O Override OpenAI Base URL do Cursor **afeta apenas o painel de Chat / Plan** (a conversa aberta com Cmd/Ctrl + L). Os recursos centrais de agente do Cursor — **Composer, Tab autocomplete, Apply, Inline Edit** — estão todos travados no backend oficial do Cursor e não podem ser assumidos por um relay de terceiros.

Se você precisa de uma experiência de agente com "capacidade completa" no Cursor (incluindo recursos do tipo Composer), instale em vez disso (o Cursor é compatível com o marketplace de extensões do VS Code):

- [Extensão oficial do Codex](/pt/docs/tools/vscode-plugin) — um agente Codex sobre o protocolo OpenAI da LMU AI
- [Extensão Claude Code for VS Code](/pt/docs/tools/claude-code-vscode) — um agente Claude Code sobre o protocolo Anthropic da LMU AI

</Callout>

## Passos de configuração

### Passo 1 — Abra as configurações do Cursor

Pressione **Cmd + Shift + J** (macOS) ou **Ctrl + Shift + J** (Windows / Linux) para abrir Settings, e clique em **Models** na barra lateral esquerda.

### Passo 2 — Desative os modelos padrão (recomendado)

O Cursor vem com muitos modelos padrão (GPT-4 / Claude-3.5, etc.); deixá-los ativados entra em conflito com o roteamento personalizado. Na lista de modelos da página Models, desative todos eles (**off**) (toggle cinza à esquerda).

### Passo 3 — Adicione modelos personalizados

Clique em **Add Model** e insira os IDs de modelo da LMU AI que você quer, por exemplo:

- `claude-opus-5`
- `claude-sonnet-5`
- `gpt-5.6-sol`
- `glm-5.2`
- `qwen3.8-max-preview`
- `deepseek-v4-pro`
- `kimi-k3`

**Adicione cada modelo uma vez.** Para a lista completa de modelos disponíveis, veja a [Galeria de Modelos](/pt/docs/guide/models).

### Passo 4 — Ative o Override OpenAI Base URL

Role até a área **OpenAI API Key** na página Models:

1. Ative o toggle **OpenAI API Key**
2. Cole a chave do console da LMU AI (começa com `sk-`) na caixa API Key
3. Ative o toggle **Override OpenAI Base URL**
4. Defina o Base URL como:
   ```
   https://api.lmuai.com/v1
   ```
5. Clique em **Verify** para checar a conexão

<Callout type="info" title="Um Verify que falha não significa que está mal configurado">

O Verify do Cursor checa usando o **nome do modelo** que você inseriu, e nomes que não são oficiais da OpenAI (`claude-opus-5`, `glm-5.2`, etc.) não vão passar. Solução alternativa: **adicione um `gpt-4` primeiro para passar no Verify** (confirmando que o Base URL + chave conectam), depois adicione separadamente os IDs de modelo personalizados que você quer; o Verify avisa, mas funciona bem na prática.

</Callout>

### Passo 5 — Alterne o modelo e use-o

Pressione **Cmd/Ctrl + L** para abrir o painel de Chat → escolha o modelo personalizado que você adicionou no Passo 3 no dropdown de modelos no topo → comece a conversar, e as requisições passarão pela LMU AI.

## Problemas comuns

### Quer que o Composer / Tab autocomplete também use a LMU AI?

O Override OpenAI Base URL nativo não consegue fazer isso — esses recursos centrais do Cursor estão travados no backend oficial. Para rotear tudo pela LMU AI, use:

- [Extensão oficial do Codex](/pt/docs/tools/vscode-plugin) — um agente de protocolo OpenAI
- [Extensão Claude Code for VS Code](/pt/docs/tools/claude-code-vscode) — um agente de protocolo Anthropic

O Cursor é compatível com o marketplace de extensões do VS Code, então ambas as extensões instalam diretamente no Cursor.

### O Base URL precisa de `/v1`?

**Sim.** Insira `https://api.lmuai.com/v1`. O Cursor acrescenta `/chat/completions` para uma requisição final a `https://api.lmuai.com/v1/chat/completions`. Omitir `/v1` gera um 404.

### O Claude 3.5 embutido dá erro depois de ativar o Override?

Este é um conflito de roteamento conhecido do Cursor — ativar o override do OpenAI Base URL interrompe a ramificação Anthropic. Para continuar usando o Claude no painel de Chat, adicione o ID do modelo Claude (por exemplo `claude-opus-5`) como um modelo personalizado, e o backend da LMU AI faz a tradução de protocolo OpenAI ↔ Anthropic.

### Erros 401 / 403?

Verifique em ordem:

1. A **API Key** é a chave `sk-` gerada no console da LMU AI (não uma chave oficial da OpenAI)?
2. O **Base URL** é `https://api.lmuai.com/v1` (**deve incluir `/v1`**)?
3. O **ID do modelo** é um que a LMU AI suporta (veja a [Galeria de Modelos](/pt/docs/guide/models))?
4. Seu plano / grupo de cobrança atual inclui o modelo que você está chamando?

### O BYOK afeta minha assinatura do Cursor?

- O uso de BYOK **não consome** a cota mensal de requisições rápidas do Cursor
- Recursos centrais como Composer / Tab autocomplete **ainda consomem** a cota da assinatura do Cursor (porque eles não usam BYOK)
- Para abandonar completamente a assinatura do Cursor, veja a abordagem das extensões Codex / Claude Code acima
