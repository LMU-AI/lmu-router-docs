Después de instalar el Codex CLI, crea manualmente un archivo de configuración, `config.toml` (la clave va en un encabezado de solicitud dentro de él), para conectarte a la API de LMU AI — no se necesita ninguna herramienta de configuración de terceros.

---

## Paso 1 — Instalar Node.js

Necesitas **Node.js 20+** — descarga: [https://nodejs.org/en/download](https://nodejs.org/en/download)

Avanza por el instalador y luego verifica en la terminal:

```bash
node --version
# A version number (e.g. v23.7.0) means it installed correctly
```

## Paso 2 — Instalar el Codex CLI

```bash
npm i -g @openai/codex
```

Si tienes problemas de red, cambia primero a un mirror de China:

```bash
npm config set registry https://registry.npmmirror.com
npm i -g @openai/codex
```

Verifica la instalación:

```bash
codex --version
# A version number means it installed correctly
```

## Paso 3 — Crear los archivos de configuración

El directorio de configuración es **`~/.codex/`** (créalo si no existe; sobrescribe cualquier archivo antiguo). Crea/sobrescribe `config.toml` dentro de él:

### config.toml

```toml
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
sandbox_mode = "danger-full-access"
windows_wsl_setup_acknowledged = true
approval_policy = "never"
file_opener = "vscode"
model_provider = "codex"
web_search = "cached"
suppress_unstable_features_warning = true

[history]
persistence = "save-all"

[tui]
notifications = true

[shell_environment_policy]
inherit = "all"
ignore_default_excludes = false

[sandbox_workspace_write]
network_access = true

[features]
plan_tool = true
apply_patch_freeform = true
view_image_tool = true
unified_exec = false
streamable_shell = false
rmcp_client = true
elevated_windows_sandbox = true

[profiles.auto-max]
approval_policy = "never"
sandbox_mode = "workspace-write"

[profiles.review]
approval_policy = "on-request"
sandbox_mode = "workspace-write"

[notice]
hide_gpt5_1_migration_prompt = true

[model_providers.codex]
name = "codex"
base_url = "https://api.lmuai.com"
wire_api = "responses"

[model_providers.codex.http_headers]
Authorization = "Bearer your sk- key generated in the console"
```

<Callout type="warn" title="La clave va en un encabezado de solicitud">

- Reemplaza "tu clave sk- generada en la consola" de la última línea con tu clave `sk-`, **manteniendo un espacio entre `Bearer` y la clave**, por ejemplo `Authorization = "Bearer sk-xxxx"`
- Coloca la sección `[model_providers.codex.http_headers]` al **final absoluto** del archivo, sin ninguna otra configuración después
- Las versiones más nuevas de Codex ya no necesitan `auth.json`. Si creaste uno con la guía anterior, dejarlo no causa problemas, o puedes eliminarlo (consérvalo si usas la [habilidad de generación de imágenes de Codex App](/es/docs/tools/codex-api-image))
- Si tu configuración antigua tiene `requires_openai_auth = true` en la sección `[model_providers.codex]`, simplemente elimina esa línea

</Callout>

## Paso 4 — Iniciar el Codex CLI

Después de guardar los archivos de configuración, vuelve a abrir la terminal y ejecuta lo siguiente para iniciar e iniciar sesión automáticamente:

```bash
codex --dangerously-bypass-approvals-and-sandbox
```

O la forma corta:

```bash
codex --yolo
```

> Este comando de inicio omite las aprobaciones de seguridad, así que no apruebas cada paso ejecutado automáticamente.

Cuando el inicio es exitoso, la interfaz muestra el modelo actual como `gpt-5.4 xhigh` (el modelo definido por el campo `model` en `config.toml`).

<Callout type="info" title="Sobre el cambio de modelos">

Si por accidente cambias a otro modelo en una sesión, vuelve a poner `gpt-5.4` en el campo `model` de `~/.codex/config.toml` y reinicia la terminal para restaurarlo.

</Callout>

## Habilitar el contexto de 1M en Codex (opcional)

`gpt-5.4` soporta una **ventana de contexto largo de 1M tokens** (272K por defecto), útil para revisión de repositorios grandes, análisis de logs extensos y refactorizaciones entre archivos. Codex **no** habilita la ventana de 1M por defecto; debes declararla explícitamente en `config.toml`.

### Cómo configurarlo: agrega dos líneas a config.toml

Edita `~/.codex/config.toml` y agrega lo siguiente en el **nivel superior** (antes de cualquier `[sección]`, por ejemplo justo después de `model = "gpt-5.4"`):

```toml
model_context_window = 1000000
model_auto_compact_token_limit = 900000
```

Guarda, vuelve a abrir la terminal y entra de nuevo a Codex para aplicarlo.

**Referencia de campos**

| Campo | Propósito |
|------|------|
| `model_context_window` | Declara la ventana de contexto utilizable del modelo en tokens; `1000000` es 1M. Sin definir, usa el valor por defecto del modelo (272K) |
| `model_auto_compact_token_limit` | El umbral de tokens que dispara la compactación automática del historial; defínelo en alrededor del 90% de la ventana (`900000` para 1M). Los valores por encima del 90% de la ventana son limitados por Codex, así que un número mayor no sirve de nada |

### Verificar que tomó efecto

Después de volver a entrar a Codex, escribe `/status` y revisa si `context window` muestra alrededor de 1M (algunas versiones muestran unos 950K — un margen de seguridad reservado del 5% por parte de Codex). También puedes usar `/statusline` para agregar el uso de contexto a la barra de estado y monitorearlo en vivo.

### Si usas CC Switch

Si administras la configuración de Codex con [CC Switch](/es/docs/tools/cc-switch), agrega las mismas dos líneas en su editor de configuración de Codex y aplica — el efecto es idéntico:

![Configurar model_context_window = 1000000 y model_auto_compact_token_limit = 900000 para la configuración de Codex en CC Switch para habilitar el contexto largo de 1M tokens](/images/tools/codex/codex-ccs.png)

<Callout type="warn" title="Notas de uso">

- **Deben estar en el nivel superior**: estos dos campos no toman efecto dentro de una sección `[profiles.xxx]` (una limitación conocida de Codex); además colócalos en el `~/.codex/config.toml` a nivel de usuario, ya que un `.codex/config.toml` a nivel de proyecto puede ser ignorado
- **Soporte de modelos**: `gpt-5.4` y `gpt-5.5` soportan 1M por el canal de API; modelos como `gpt-5.3-codex` están limitados a 272K, y ningún valor de configuración puede exceder el límite propio del modelo
- **Mayor costo**: un contexto más largo usa más tokens por solicitud; la porción por encima de 272K se cobra en el nivel tarifario más alto de contexto largo, así que no lo dejes activo salvo para tareas muy extensas
- **Diferencias de versión**: algunas versiones más nuevas de Codex leen primero el tamaño de la ventana desde el catálogo de modelos; si `/status` sigue mostrando el valor antiguo, actualiza a la última versión (`npm i -g @openai/codex@latest`) y vuelve a intentar

</Callout>
