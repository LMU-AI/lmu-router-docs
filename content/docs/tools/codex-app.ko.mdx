Codex CLI를 설치하지 않고 **Codex App 데스크톱 클라이언트**만 사용하고 싶다면 이 방법을 따르세요.

<Callout type="warn" title="참고">

- 이전에 본인 계정으로 로그인한 적이 있다면, 먼저 Codex App에서 **현재 계정을 로그아웃**한 다음 다시 설정하세요.
- API로 전환하면 기존 대화 기록은 사라집니다(계정 방식의 대화 기록은 로컬이 아니라 GPT 계정 공간에 저장됩니다).
- **API 로그인으로 전환한 이후의 모든 대화 기록은 로컬에 저장되므로 사라지지 않습니다!**

</Callout>

---

## 1단계 — 설정 파일 만들기

설정 파일 위치:
- **Mac/Linux**: 홈 디렉터리(`~`)의 `.codex` 폴더
- **Windows**: `C:\users\your-username\.codex\`

폴더가 이미 있다면, 기존 설정의 간섭을 피하기 위해 안에 있는 `config.toml`(그리고 이전 가이드에서 남은 `auth.json`)을 삭제하고 다시 만드는 것이 좋습니다.

**터미널 명령으로 폴더 만들기:**

```bash
# Mac/Linux
rm -rf ~/.codex && mkdir ~/.codex
```

`.codex` 폴더에 `config.toml`을 만드세요.

### config.toml

서비스 제공자를 설정합니다. API 키는 파일 맨 끝의 요청 헤더에 넣습니다:

```toml
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
sandbox_mode = "danger-full-access"
windows_wsl_setup_acknowledged = true
approval_policy = "never"
file_opener = "vscode"
model_provider = "codex"
web_search = "cached"
suppress_unstable_features_warning = true

[history]
persistence = "save-all"

[tui]
notifications = true

[shell_environment_policy]
inherit = "all"
ignore_default_excludes = false

[sandbox_workspace_write]
network_access = true

[features]
plan_tool = true
apply_patch_freeform = true
view_image_tool = true
unified_exec = false
streamable_shell = false
rmcp_client = true
elevated_windows_sandbox = true

[profiles.auto-max]
approval_policy = "never"
sandbox_mode = "workspace-write"

[profiles.review]
approval_policy = "on-request"
sandbox_mode = "workspace-write"

[notice]
hide_gpt5_1_migration_prompt = true

[model_providers.codex]
name = "codex"
base_url = "https://api.lmuai.com"
wire_api = "responses"

[model_providers.codex.http_headers]
Authorization = "Bearer your sk- key generated in the console"
```

마지막 줄을 본인의 `sk-` 키로 바꾸고, `Bearer`와 키 사이에 공백 한 칸을 유지하세요. `[model_providers.codex.http_headers]` 섹션은 파일 맨 끝에 두고, 그 뒤에 다른 설정을 넣지 마세요.

<Callout type="info">

보통 홈 디렉터리의 `.codex` 폴더 안에 있습니다. 거기서 `.codex` 폴더를 찾을 수 없다면 폴더를 직접 만들고, 그 안에 `config.toml`을 만들면 됩니다.

설정 파일 내용은 [Codex CLI Mac/Linux 설정 가이드](/ko/docs/tools/codex-cli-mac)와 동일합니다 — 해당 가이드를 따라 터미널에서 만들 수 있으며, Codex App을 재시작하면 똑같이 적용됩니다.

</Callout>

## 2단계 — Codex App 다시 열기

설정 파일을 저장한 후 Codex App을 다시 열면 자동으로 로그인되어 바로 사용할 수 있습니다.

## 1M 컨텍스트 활성화(선택)

`gpt-5.4`는 1M 토큰 롱 컨텍스트를 지원하지만 기본적으로 꺼져 있습니다. 위 `config.toml`의 **최상위 레벨**(어떤 `[section]`보다 앞)에 두 줄을 추가한 뒤 Codex App을 재시작하세요:

```toml
model_context_window = 1000000
model_auto_compact_token_limit = 900000
```

각 필드의 의미, 확인 방법, 주의 사항은 [Codex에서 1M 컨텍스트 활성화](/ko/docs/tools/codex-cli-mac#enabling-the-1m-context-in-codex-optional)를 참고하세요.

## 자주 발생하는 오류

**401 오류, 잘못된 키:**

원인: 요청이 우리 API 중계가 아니라 여전히 OpenAI 공식 엔드포인트로 가고 있거나, 도구를 재시작하지 않아 설정 파일이 다시 로드되지 않았습니다.

해결: 가이드를 다시 따라 `config.toml`을 만들거나 교체한 다음 앱을 다시 열어 보세요.

**401 API_KEY_REQUIRED 오류:**

원인: 최신 Codex 버전은 `auth.json`에서 키를 더 이상 읽지 않을 수 있어, 요청에 키가 실려 가지 않습니다.

해결: 위에서 설명한 대로 `config.toml` 끝에 `[model_providers.codex.http_headers]` 섹션을 추가하세요. [FAQ · 문제 10](/ko/docs/guide/faq#issue-10)을 참고하세요.
