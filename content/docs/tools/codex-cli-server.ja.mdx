WSL2 または SSH リモートサーバー環境で Codex CLI を設定する場合の手順です。

---

## 設定手順

### ステップ 1 — Node.js 環境をインストールする（volta を使用）

サーバーのターミナルで次を実行します:

```bash
curl https://get.volta.sh | bash
```

### ステップ 2 — Node 20 をインストールする

<Callout type="warn" title="注意">

volta のインストールが成功したら、次のコマンドを実行する前に **必ず新しいターミナルウィンドウを開いてください**:

</Callout>

```bash
volta install node@20
```

### ステップ 3 — Codex CLI をインストールする

```bash
volta install @openai/codex
```

### ステップ 4 — 設定ファイルを作成する

サーバーのターミナルで次を実行すると、`~/.codex/config.toml` を一度に書き込めます（**最後の行の「コンソールで生成した sk- キー」を自分の `sk-` キーに置き換えるのを忘れないでください。`Bearer` の後のスペース 1 つは残します**）:

```bash
mkdir -p ~/.codex

cat > ~/.codex/config.toml <<'EOF'
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
sandbox_mode = "danger-full-access"
windows_wsl_setup_acknowledged = true
approval_policy = "never"
file_opener = "vscode"
model_provider = "codex"
web_search = "cached"
suppress_unstable_features_warning = true

[history]
persistence = "save-all"

[tui]
notifications = true

[shell_environment_policy]
inherit = "all"
ignore_default_excludes = false

[sandbox_workspace_write]
network_access = true

[features]
plan_tool = true
apply_patch_freeform = true
view_image_tool = true
unified_exec = false
streamable_shell = false
rmcp_client = true
elevated_windows_sandbox = true

[profiles.auto-max]
approval_policy = "never"
sandbox_mode = "workspace-write"

[profiles.review]
approval_policy = "on-request"
sandbox_mode = "workspace-write"

[notice]
hide_gpt5_1_migration_prompt = true

[model_providers.codex]
name = "codex"
base_url = "https://api.lmuai.com"
wire_api = "responses"

[model_providers.codex.http_headers]
Authorization = "Bearer your sk- key generated in the console"
EOF
```

設定内容は [Codex CLI（Mac/Linux）ガイド](/ja/docs/tools/codex-cli-mac) と同じです。`vim` / `nano` で手動作成してもかまいません。新しいバージョンの Codex では `~/.codex/auth.json` は不要になっており、古いものが残っていても問題ありません。

### ステップ 5 — Codex CLI を起動する

```bash
codex --dangerously-bypass-approvals-and-sandbox
```

または:

```bash
codex --yolo
```

---

## 1M コンテキストを有効にする（任意）

`gpt-5.4` は 100 万トークンのロングコンテキストに対応していますが、デフォルトでは無効です。`~/.codex/config.toml` を編集し、ファイルの **トップレベル**（どの `[section]` よりも前）に 2 行を追加して、Codex に再度入り直してください:

```toml
model_context_window = 1000000
model_auto_compact_token_limit = 900000
```

各フィールドの意味、確認方法、注意点については [Codex で 1M コンテキストを有効にする](/ja/docs/tools/codex-cli-mac#enabling-the-1m-context-in-codex-optional) を参照してください。
