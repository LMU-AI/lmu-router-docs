WSL2 または SSH リモートサーバー環境で Codex CLI を設定するための手順です。

---

## 設定手順

### ステップ 1 — Node.js 環境をインストール（volta を使用）

サーバーのターミナルで、次を実行します：

```bash
curl https://get.volta.sh | bash
```

### ステップ 2 — Node 20 をインストール

<Callout type="warn" title="注意">

volta のインストールが成功したら、次のコマンドを実行する前に**必ず新しいターミナルウィンドウを開いて**ください：

</Callout>

```bash
volta install node@20
```

### ステップ 3 — Codex CLI をインストール

```bash
volta install @openai/codex
```

### ステップ 4 — 設定ファイルを作成

サーバーのターミナルで次を実行して、`~/.codex/config.toml` と `~/.codex/auth.json` の両方を一度に書き込みます（**auth.json のキーは、コンソールで生成した `sk-` キーに置き換えることを忘れないでください**）：

```bash
mkdir -p ~/.codex

cat > ~/.codex/config.toml <<'EOF'
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
sandbox_mode = "danger-full-access"
windows_wsl_setup_acknowledged = true
approval_policy = "never"
file_opener = "vscode"
model_provider = "codex"
web_search = "cached"
suppress_unstable_features_warning = true

[history]
persistence = "save-all"

[tui]
notifications = true

[shell_environment_policy]
inherit = "all"
ignore_default_excludes = false

[sandbox_workspace_write]
network_access = true

[features]
plan_tool = true
apply_patch_freeform = true
view_image_tool = true
unified_exec = false
streamable_shell = false
rmcp_client = true
elevated_windows_sandbox = true

[profiles.auto-max]
approval_policy = "never"
sandbox_mode = "workspace-write"

[profiles.review]
approval_policy = "on-request"
sandbox_mode = "workspace-write"

[notice]
hide_gpt5_1_migration_prompt = true

[model_providers.codex]
name = "codex"
base_url = "https://api.lmuai.com"
wire_api = "responses"
requires_openai_auth = true
EOF

cat > ~/.codex/auth.json <<'EOF'
{
  "OPENAI_API_KEY": "your sk- key generated in the console"
}
EOF
```

設定内容は [Codex CLI（Mac/Linux）ガイド](/ja/docs/tools/codex-cli-mac) と同一です — `vim` / `nano` で手動で 2 つのファイルを作成することもできます。

### ステップ 5 — Codex CLI を起動

```bash
codex --dangerously-bypass-approvals-and-sandbox
```

または：

```bash
codex --yolo
```

## 1M コンテキストを有効化する（オプション）

`gpt-5.4` は 1M トークンのロングコンテキストをサポートしていますが、デフォルトでは無効です。`~/.codex/config.toml` を編集し、ファイルの**トップレベル**（すべての `[section]` より前）に 2 行を追加して、Codex に再度入り直してください：

```toml
model_context_window = 1000000
model_auto_compact_token_limit = 900000
```

各フィールドの意味、確認方法、および注意事項については、[Codex での 1M コンテキストの有効化](/ja/docs/tools/codex-cli-mac#enabling-the-1m-context-in-codex-optional) を参照してください。
