После установки Codex CLI создайте вручную один файл конфигурации, `config.toml` (ключ размещается в заголовке запроса внутри него), чтобы подключиться к API LMU AI — сторонний инструмент настройки не нужен.

---

## Шаг 1 — Установка Node.js

Вам нужен **Node.js 20+** — загрузка: [https://nodejs.org/en/download](https://nodejs.org/en/download)

Пройдите установщик, затем проверьте в терминале:

```bash
node --version
# A version number (e.g. v23.7.0) means it installed correctly
```

## Шаг 2 — Установка Codex CLI

```bash
npm i -g @openai/codex
```

Если возникают проблемы с сетью, сначала переключитесь на зеркало в Китае:

```bash
npm config set registry https://registry.npmmirror.com
npm i -g @openai/codex
```

Проверьте установку:

```bash
codex --version
# A version number means it installed correctly
```

## Шаг 3 — Создание файлов конфигурации

Каталог конфигурации — **`~/.codex/`** (создайте его, если отсутствует; перезапишите любые старые файлы). Создайте/перезапишите в нём `config.toml`:

### config.toml

```toml
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
sandbox_mode = "danger-full-access"
windows_wsl_setup_acknowledged = true
approval_policy = "never"
file_opener = "vscode"
model_provider = "codex"
web_search = "cached"
suppress_unstable_features_warning = true

[history]
persistence = "save-all"

[tui]
notifications = true

[shell_environment_policy]
inherit = "all"
ignore_default_excludes = false

[sandbox_workspace_write]
network_access = true

[features]
plan_tool = true
apply_patch_freeform = true
view_image_tool = true
unified_exec = false
streamable_shell = false
rmcp_client = true
elevated_windows_sandbox = true

[profiles.auto-max]
approval_policy = "never"
sandbox_mode = "workspace-write"

[profiles.review]
approval_policy = "on-request"
sandbox_mode = "workspace-write"

[notice]
hide_gpt5_1_migration_prompt = true

[model_providers.codex]
name = "codex"
base_url = "https://api.lmuai.com"
wire_api = "responses"

[model_providers.codex.http_headers]
Authorization = "Bearer your sk- key generated in the console"
```

<Callout type="warn" title="Ключ размещается в заголовке запроса">

- Замените «your sk- key generated in the console» в последней строке на свой ключ `sk-`, **сохранив один пробел между `Bearer` и ключом**, например `Authorization = "Bearer sk-xxxx"`
- Разместите раздел `[model_providers.codex.http_headers]` в **самом конце** файла, без каких-либо других настроек после него
- Новым версиям Codex больше не нужен `auth.json`. Если вы создали его по старому руководству, оставить его безвредно, либо можно удалить (оставьте, если используете [навык генерации изображений Codex App](/ru/docs/tools/codex-api-image))
- Если в вашей старой конфигурации в разделе `[model_providers.codex]` есть `requires_openai_auth = true`, просто удалите эту строку

</Callout>

## Шаг 4 — Запуск Codex CLI

После сохранения файлов конфигурации снова откройте терминал и выполните следующее, чтобы запустить и автоматически выполнить вход:

```bash
codex --dangerously-bypass-approvals-and-sandbox
```

Или короткая форма:

```bash
codex --yolo
```

> Эта команда запуска пропускает подтверждения безопасности, поэтому вам не нужно подтверждать каждый автоматически выполняемый шаг.

При успешном запуске в интерфейсе отображается текущая модель `gpt-5.4 xhigh` (модель, заданная полем `model` в `config.toml`).

<Callout type="info" title="О переключении моделей">

Если вы случайно переключились на другую модель в сессии, верните полю `model` в `~/.codex/config.toml` значение `gpt-5.4` и перезапустите терминал, чтобы восстановить настройку.

</Callout>

## Включение контекста 1M в Codex (необязательно)

`gpt-5.4` поддерживает **длинное контекстное окно на 1M токенов** (по умолчанию 272K), что полезно для ревью большого репозитория, анализа длинных логов и рефакторинга по нескольким файлам. Codex **не** включает окно 1M по умолчанию; его нужно объявить явно в `config.toml`.

### Как настроить: добавьте две строки в config.toml

Отредактируйте `~/.codex/config.toml` и добавьте следующее на **верхнем уровне** (до любого `[section]`, например сразу после `model = "gpt-5.4"`):

```toml
model_context_window = 1000000
model_auto_compact_token_limit = 900000
```

Сохраните, снова откройте терминал и войдите в Codex заново, чтобы изменения применились.

**Описание полей**

| Поле | Назначение |
|------|------|
| `model_context_window` | Объявляет доступное контекстное окно модели в токенах; `1000000` — это 1M. Если не задано, используется значение модели по умолчанию (272K) |
| `model_auto_compact_token_limit` | Порог в токенах, при котором запускается автоматическое сжатие истории; задайте его примерно на уровне 90% от размера окна (`900000` для 1M). Значения выше 90% от окна Codex ограничивает, поэтому большее число бессмысленно |

### Проверка, что настройка применилась

После повторного входа в Codex введите `/status` и проверьте, показывает ли `context window` около 1M (некоторые версии показывают около 950K — зарезервированный Codex запас в 5%). Также можно использовать `/statusline`, чтобы добавить расход контекста в строку состояния для наблюдения в реальном времени.

### Если вы используете CC Switch

Если вы управляете конфигурацией Codex через [CC Switch](/ru/docs/tools/cc-switch), добавьте те же две строки в его редакторе конфигурации Codex и примените — эффект идентичен:

![Установка model_context_window = 1000000 и model_auto_compact_token_limit = 900000 для конфигурации Codex в CC Switch для включения длинного контекста на 1M токенов](/images/tools/codex/codex-ccs.png)

<Callout type="warn" title="Замечания по использованию">

- **Должно быть на верхнем уровне**: эти два поля не действуют внутри раздела `[profiles.xxx]` (известное ограничение Codex); также размещайте их в пользовательском `~/.codex/config.toml`, поскольку файл уровня проекта `.codex/config.toml` может игнорироваться
- **Поддержка моделями**: `gpt-5.4` и `gpt-5.5` поддерживают 1M через канал API; модели вроде `gpt-5.3-codex` ограничены 272K, и никакое значение в конфигурации не может превысить собственный лимит модели
- **Выше стоимость**: более длинный контекст расходует больше токенов на запрос; часть свыше 272K тарифицируется по более высокому тарифу длинного контекста, поэтому не оставляйте его включённым ни для чего, кроме очень длинных задач
- **Различия версий**: некоторые новые версии Codex сначала считывают размер окна из каталога моделей; если `/status` всё ещё показывает старое значение, обновитесь до последней версии (`npm i -g @openai/codex@latest`) и повторите попытку

</Callout>
