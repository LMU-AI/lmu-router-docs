**CC Switch**는 Claude Code, Codex, OpenCode, Gemini CLI 같은 AI 코딩 도구 전반에서 API 제공자 구성을 관리하고 원클릭으로 전환할 수 있는 오픈 소스 크로스 플랫폼 데스크톱 도구입니다.

LMU AI 콘솔의 "**Import to CCS**" 버튼과 결합하면, **`settings.json`을 손으로 만들거나 편집할 필요 없이** 클릭 한 번으로 Claude Code를 API에 연결합니다.

---

## 1단계 — CC Switch 설치

공식 저장소의 Releases 페이지에서 사용 중인 플랫폼용 설치 프로그램을 다운로드하세요:

- **GitHub Releases**: [https://github.com/farion1231/cc-switch/releases](https://github.com/farion1231/cc-switch/releases)

Windows / macOS / Linux가 지원됩니다. 설치 후, 시스템이 사용자 지정 URL 스킴을 등록하도록 CC Switch를 최소 한 번 실행하세요.

<Callout type="info">

첫 실행 후에는 "Import to CCS"를 클릭할 때 올바르게 호출할 수 있도록 CC Switch를 실행 상태로 유지(또는 백그라운드에 상주)하세요.

</Callout>

---

## 2단계 — LMU AI 콘솔에서 API 키 생성

[시작하기 - API 키 생성](/ko/docs/guide/getting-started#create-key)을 참조하세요:

1. 왼쪽 메뉴에서 "**API Keys**"를 엽니다
2. "**Create key**"를 클릭하고 임의의 이름을 지정합니다
3. 교환한 플랜의 **그룹**을 선택한 뒤 생성을 완료합니다

---

## 3단계 — 원클릭으로 CC Switch에 가져오기

API 키 목록에서 방금 생성한 키를 찾아, 해당 행 오른쪽의 "**Actions**" 열에 있는 "**Import to CCS**" 버튼을 클릭하세요:

![LMU AI 콘솔 API 키 목록의 "Import to CCS" 버튼 위치](/images/tools/cc-switch/ccs.avif)


- 브라우저에 "이 사이트가 CC Switch를 여는 것을 허용하시겠습니까?"라는 프롬프트가 표시됩니다 — "**허용 / 열기**"를 클릭하세요
- CC Switch가 LMU AI `Base URL`과 API 키를 자동으로 감지하여 입력합니다
- 해당 구성을 CC Switch에서 활성 항목으로 설정하세요

<Callout type="info" title="첫 실행 시 프롬프트">

브라우저마다(Chrome / Edge / Safari) 확인 문구가 조금씩 다르지만, 모두 외부 애플리케이션 CC Switch를 실행할지 여부를 묻습니다. "내 선택 기억하기"를 체크하면 다시 묻지 않습니다.

</Callout>

---

## 4단계 — Claude Code에 적용하기

CC Switch는 선택한 구성을 Claude Code의 `settings.json`에 기록합니다(또는 실행 시 환경 변수를 주입합니다). 따라서:

- Claude Code가 **이미 열려 있다면**, 새 구성이 적용되도록 한 번 재시작하세요
- 그 후에는 `claude`를 실행하기만 하면 됩니다 — 어떤 구성 파일도 손으로 편집할 필요가 없습니다

`/status` 명령으로 Base URL이 `https://api.lmuai.com`인지 확인하세요.

## 자주 발생하는 문제

### "Import to CCS" 버튼이 아무 반응이 없음

**원인:** 시스템이 CC Switch의 URL 스킴을 등록하지 못했습니다.

**해결:**
1. CC Switch를 완전히 설치했는지(압축을 풀어 직접 실행한 포터블 빌드가 아님) 확인하세요
2. CC Switch를 한 번 실행한 뒤 완전히 종료하고 "Import to CCS"를 다시 클릭하세요
3. Windows에서 여전히 실패한다면 CC Switch 설정에서 "프로토콜 등록 / 링크 연결" 옵션을 찾아보세요

### 브라우저가 프로토콜 이동을 차단함

일부 브라우저는 알 수 없는 프로토콜을 기본적으로 차단합니다. 대화 상자에서 "**문서 / 콘솔 도메인이 이런 링크를 항상 열도록 허용**"을 선택하세요.

### 구성을 수동으로 추가하려는 경우

CC Switch는 사용자 지정 제공자 수동 추가도 지원합니다:

- **Name**: 아무거나(예: `LMU AI`)
- **Base URL**: `https://api.lmuai.com`
- **API Key**: 콘솔에서 생성한 `sk-` 키

저장한 뒤 메인 화면에서 활성 항목으로 설정하세요.

---

## 권장 사항

- CC Switch는 여러 그룹 / 플랜의 키를 저장하고 클릭 한 번으로 전환할 수 있어, **다중 플랜 사용자에게는 `settings.json` 편집보다 낫습니다**
- 트레이 상주 모드에서는 리소스를 거의 사용하지 않으므로, 부팅 시 자동 시작으로 설정하는 것을 권장합니다
- 주로 커맨드라인을 사용하고 구성 파일 편집이 번거롭지 않다면, [Claude Code 가이드](/ko/docs/tools/claude-code)에 따라 계속 수동으로 구성해도 됩니다 — 둘 다 효과는 동일합니다
