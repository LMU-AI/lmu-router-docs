<Callout type="info" title="Wenn Sie den Trae-Editor nutzen">

Wenn Sie **Claude oder chinesische Modelle (GLM / Qwen usw.)** verwenden möchten, bietet Trae eine einfachere native Methode (keine Erweiterung, nur ein paar Klicks in der GUI) — siehe [Native Modellkonfiguration in Trae](/de/docs/tools/trae).

Die Methode mit der Codex-Erweiterung auf dieser Seite eignet sich für Nutzer, die die **GPT-/Codex**-Serie verwenden möchten.

</Callout>

## Häufige Fehler

**Fehler: Nach der Konfiguration erhalten Sie einen 401 mit dem Hinweis, der Key sei falsch**

Ursache: Die Anfrage geht weiterhin an das offizielle OpenAI-Backend statt an unser API-Relay, oder Sie haben das Tool nicht neu gestartet, damit die Konfigurationsdatei neu geladen wird.

Lösung: Folgen Sie der Anleitung erneut, um `config.toml` **neu zu erstellen oder zu ersetzen**, und starten Sie dann das IDE-Tool neu.

<Callout type="info" title="Wenn ein Fehler auftritt">

Machen Sie einen Screenshot der Fehlermeldung und übersetzen Sie sie — dann erkennen Sie selbst, wodurch der Fehler verursacht wurde!

</Callout>

## Konfiguration

### Schritt 1 — Konfigurationsdateien erstellen / überschreiben

Speicherort der Konfigurationsdatei:
- **Mac/Linux**: das Verzeichnis `~/.codex/`
- **Windows**: das Verzeichnis `C:\users\YourUsername\.codex\`

<Callout type="warn" title="Hinweis für Windows">

Wenn Sie sich zuvor mit dem offiziellen Konto oder einer anderen Plattform angemeldet haben, melden Sie sich zuerst ab und konfigurieren Sie dann!

</Callout>

Falls Sie keinen `.codex`-Ordner haben, erstellen Sie ihn mit einem Terminal-Befehl:

```bash
# Mac/Linux
rm -rf ~/.codex && mkdir ~/.codex
```

```powershell
# Windows (run in the terminal)
rm -rf C:\users\YourUsername\.codex
mkdir C:\users\YourUsername\.codex
```

### Schritt 2 — config.toml schreiben

Erstellen oder überschreiben Sie im Verzeichnis `.codex` die Datei `config.toml`:

```toml
model_provider = "OpenAI"
model = "gpt-5.4"
review_model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
network_access = "enabled"
windows_wsl_setup_acknowledged = true
model_context_window = 1000000
model_auto_compact_token_limit = 900000

[model_providers.OpenAI]
name = "OpenAI"
base_url = "https://api.lmuai.com"
wire_api = "responses"

[model_providers.OpenAI.http_headers]
Authorization = "Bearer your sk- key generated in the console"
```

Ersetzen Sie die letzte Zeile durch Ihren `sk-`-Key, lassen Sie ein Leerzeichen zwischen `Bearer` und dem Key und setzen Sie den Abschnitt `http_headers` ganz an das Ende der Datei. Neuere Codex-Versionen benötigen keine `auth.json` mehr; eine verbliebene alte Datei ist unschädlich.

Nach der Konfiguration öffnen Sie VS Code, Cursor oder Trae, und die darin enthaltene Codex-Erweiterung meldet sich automatisch an.

## Installation der Visual Studio Code-Erweiterung

### Erweiterung installieren

1. Öffnen Sie VS Code und öffnen Sie zuerst einen beliebigen Projektordner als Workspace (**andernfalls werden Sie per Popup aufgefordert, einen Projektordner zu öffnen!**)
2. Klicken Sie links auf das Erweiterungen-Panel (das Extensions-Symbol)
3. Suchen Sie nach **Codex**, wählen Sie die offizielle Erweiterung von OpenAI „Codex – OpenAI's coding agent" und klicken Sie auf Installieren
4. Nach der Installation erscheint ein Codex-Eintrag in der linken Seitenleiste (falls nicht, schauen Sie oben rechts in der Oberfläche)

### Vom alten Konto abmelden

<Callout type="warn" title="Wichtig">

Wenn Sie sich zuvor mit dem offiziellen Konto oder einer anderen Plattform angemeldet haben, melden Sie sich zuerst ab und konfigurieren Sie dann!

</Callout>

1. Klicken Sie oben rechts im Codex-Panel auf das Einstellungssymbol
2. Klicken Sie auf **Log out**, um sich abzumelden

### Konfiguration abschließen

Nachdem Sie `config.toml` eingerichtet haben, öffnen Sie die Codex-Erweiterung erneut und klicken Sie auf **Continue**, um den Anmeldevorgang abzuschließen.

<Callout type="info" title="Zur Modellanzeige">

Das Modell GPT-5.3 erscheint nicht in der Dropdown-Liste; fahren Sie mit der Maus über „Custom", um das aktuell verwendete Modell zu sehen.

Sie können das tatsächlich angefragte Modell außerdem in der Konsole unter „Nutzungsaufzeichnungen" prüfen.

</Callout>

## Möchten Sie Claude oder chinesische Modelle nutzen?

Wenn Sie nur Trae verwenden und Modelle wie **Claude / GLM / Qwen** Ihr Ziel sind, benötigen Sie die Codex-Erweiterung nicht — die [native Modellkonfiguration in Trae](/de/docs/tools/trae) (Anthropic-Protokoll, nur einige Felder in der GUI ausfüllen) ist einfacher.
