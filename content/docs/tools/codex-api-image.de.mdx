[api-image](https://github.com/yc-duan/api-image) ist ein Community-Skill (MIT-Lizenz): Die Codex App hat im API-Modus keine integrierte Bildgenerierung, und sobald dieser Skill installiert ist, kann sie Bilder über den selbst konfigurierten OpenAI-kompatiblen Image-Endpunkt erzeugen. Er verwendet den Key und den Endpunkt aus Ihrem `~/.codex` wieder, und ein Satz im Gespräch genügt.

<Callout type="warn" title="Drittanbieter-Community-Skill">

Er läuft auf Ihrem Rechner, liest den Key aus `~/.codex/auth.json` und sendet Ihren Prompt sowie Referenzbilder an den Provider — stellen Sie vor der Installation sicher, dass Sie damit einverstanden sind. Der Autor weist außerdem darauf hin, dass die Kompatibilität zwischen Providern variiert; behandeln Sie echte Fehlermeldungen daher als maßgeblich.

</Callout>

---

## Vorbereitung: auth.json behalten

Dieser Skill liest den Key aus `~/.codex/auth.json` (unter Windows `%USERPROFILE%\.codex\auth.json`). Die aktualisierte [Codex App Anleitung](/de/docs/tools/codex-app) legt den Key inzwischen in einen Request-Header in `config.toml` und benötigt `auth.json` nicht mehr; um diesen Skill zu nutzen, müssen Sie jedoch eine behalten, die denselben Key enthält:

```json
{
  "OPENAI_API_KEY": "your sk- key generated in the console"
}
```

Wenn Sie `auth.json` bereits nach der alten Anleitung erstellt haben, lassen Sie sie einfach so.

## Installation: ein Satz an Codex

Öffnen Sie die Codex App und sagen Sie einfach:

> Installiere den Skill unter https://github.com/yc-duan/api-image — ich möchte Bilder mit der OpenAI Image 2 Standard-API generieren; die Nutzungshinweise findest du unter https://github.com/yc-duan/api-image

Codex legt das Repository selbst in `~/.codex/skills/api-image` ab (unter Windows `%USERPROFILE%\.codex\skills\api-image`); **starten Sie die Codex App** danach **neu**.

Die manuelle Installation funktioniert auch:

```bash
git clone https://github.com/yc-duan/api-image.git ~/.codex/skills/api-image
```

## Nutzung: weiterhin ein Satz

| Was Sie möchten | Sagen Sie das |
|------|------|
| Text zu Bild | Nutze api-image, um ein cineastisches Foto in 2048x1152 zu generieren: eine regnerische Straße in Tokio bei Nacht, Neon-Reflexionen, realistischer Fotografie-Stil |
| Bild zu Bild | Nutze Komposition und Pose dieses Bildes als Referenz und generiere eine warme Illustration — behalte die Pose des Motivs bei, kopiere das Original nicht |
| Inpainting | Ändere die rote Tasse in diesem Bild zu grün und behalte die originale Form, Komposition und Beleuchtung bei |
| Explizite Optionen | Nutze api-image, um eine flache Illustration in 1024x1024 zu generieren, Qualität low, zwei Bilder, gespeichert nach ./public/cover.png |

Die Standardwerte sind `gpt-image-2`, `2048x1152`, Qualität high, ein Bild; Größe, Qualität, Anzahl und Ausgabepfad lassen sich alle direkt im Gespräch ändern. Die Ausgabe landet standardmäßig im aktuellen Arbeitsverzeichnis (`provider-image-<timestamp>.png`).

## Hinweise

- **Bei LMU AI einfach `auth.json` behalten**: Der Skill liest `auth.json` (Key) und `config.toml` (Endpunkt), was den vollständigen Endpunkten `https://api.lmuai.com/v1/images/generations` und `/v1/images/edits` entspricht
- `model_not_found` / 403: Die Gruppe Ihres Keys enthält das Bildmodell nicht — prüfen Sie „Verfügbare Modelle" in der Konsole oder wechseln Sie die Gruppe
- `gpt-image-2` unterstützt keine transparenten Hintergründe; der Upstream kann angeforderte Größen normalisieren, vertrauen Sie daher der tatsächlichen Ausgabe
