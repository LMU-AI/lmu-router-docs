## Voraussetzungen

Stellen Sie vor dem Start sicher, dass Sie Folgendes haben:

1. Ein LMU AI-Konto registriert und aufgeladen ([Schnellstart](/de/docs/guide/getting-started))
2. Einen API-Schlüssel, der mit `sk-` beginnt
3. Hermes Agent installiert ([GitHub](https://github.com/nousresearch/hermes-agent))

## LMU AI-Modelle konfigurieren

### Methode 1 — Die Konfiguration mit einem Befehl erstellen

Öffnen Sie ein Terminal und führen Sie den folgenden Befehl aus:

```bash
mkdir -p ~/.hermes
cat > ~/.hermes/config.yaml << 'EOF'
providers:
  lumai:
    name: lumai
    base_url: https://api.lmuai.com/v1
    api_key: YOUR_API_KEY
    model: glm-5.2

model:
  provider: lumai
  model: glm-5.2
EOF
```

<Callout type="warn" title="Hinweis">

Ersetzen Sie `YOUR_API_KEY` durch den tatsächlichen `sk-`-Schlüssel, den Sie in der LMU AI-Konsole erstellt haben.

</Callout>

### Methode 2 — Die Konfigurationsdatei manuell bearbeiten

Wenn `~/.hermes/config.yaml` bereits existiert, öffnen Sie sie in einem Editor:

```bash
hermes config edit
```

Fügen Sie Folgendes in der Datei hinzu oder ändern Sie es:

```yaml
providers:
  lumai:
    name: lumai
    base_url: https://api.lmuai.com/v1
    api_key: sk-your-actual-key
    model: glm-5.2

model:
  provider: lumai
  model: glm-5.2
```

Speichern und beenden.

## Verfügbare Modelle

Im Feld `model` können Sie jeden von LMU AI unterstützten Modellnamen einsetzen. Die vollständige Modellliste finden Sie in der [Modell-Galerie](/de/docs/guide/models).

## Die Konfiguration überprüfen

Führen Sie den folgenden Befehl aus, um zu testen, ob die Konfiguration funktioniert:

```bash
hermes chat -q 'Hello, please reply in one sentence' -Q
```

Wenn Sie eine Antwort von der KI erhalten, funktioniert die Konfiguration.

## Häufige Probleme

### Fehler 401 Unauthorized

Der API-Schlüssel ist falsch oder abgelaufen. Überprüfen Sie den Status des Schlüssels in der LMU AI-Konsole.

### Fehler 404 Not Found

Die `base_url` ist falsch. Hermes verwendet das OpenAI-Protokoll, daher muss die Adresse das Suffix `/v1` enthalten:

```
https://api.lmuai.com/v1    ✅ Correct
https://api.lmuai.com       ❌ Wrong
```
