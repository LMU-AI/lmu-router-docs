## Errores comunes

**Error: después de configurar, recibes un 401 que indica que la clave es incorrecta**

Causa: la solicitud sigue yendo al backend oficial de OpenAI en lugar de a nuestro relay de API, o no reiniciaste la herramienta para que recargue el archivo de configuración.

Solución: sigue la guía de nuevo para **crear o reemplazar** `config.toml` y luego reinicia la herramienta o IDE.

<Callout type="info" title="Cuando te encuentres con un error">

Toma una captura del mensaje de error y tradúcelo: ¡podrás identificar por tu cuenta la causa del error!

</Callout>

## Configuración

### Paso 1 — Crear / sobrescribir los archivos de configuración

Ubicación del archivo de configuración:
- **Mac/Linux**: el directorio `~/.codex/`
- **Windows**: el directorio `C:\users\YourUsername\.codex\`

<Callout type="warn" title="Nota para Windows">

Si antes iniciaste sesión con la cuenta oficial o con otra plataforma, ¡cierra sesión primero y luego configura!

</Callout>

Si no tienes una carpeta `.codex`, créala con un comando en la terminal:

```bash
# Mac/Linux
rm -rf ~/.codex && mkdir ~/.codex
```

```powershell
# Windows (run in the terminal)
rm -rf C:\users\YourUsername\.codex
mkdir C:\users\YourUsername\.codex
```

### Paso 2 — Escribir config.toml

En el directorio `.codex`, crea o sobrescribe `config.toml`:

```toml
model_provider = "OpenAI"
model = "gpt-5.4"
review_model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
network_access = "enabled"
windows_wsl_setup_acknowledged = true
model_context_window = 1000000
model_auto_compact_token_limit = 900000

[model_providers.OpenAI]
name = "OpenAI"
base_url = "https://api.lmuai.com"
wire_api = "responses"

[model_providers.OpenAI.http_headers]
Authorization = "Bearer your sk- key generated in the console"
```

Reemplaza la última línea con tu clave `sk-`, dejando un espacio entre `Bearer` y la clave, y coloca la sección `http_headers` al final del archivo. Las versiones más recientes de Codex ya no necesitan `auth.json`; si quedó uno antiguo, no causa problemas.

Una vez configurado, abre VS Code, Cursor o Trae, y la extensión Codex iniciará sesión automáticamente.

## Instalar la extensión en Visual Studio Code

### Instalar la extensión

1. Abre VS Code y primero abre cualquier carpeta de proyecto como tu espacio de trabajo (**de lo contrario, aparecerá una ventana pidiéndote abrir una carpeta de proyecto**)
2. Haz clic en el panel de extensiones a la izquierda (el icono de Extensions)
3. Busca **Codex**, encuentra la extensión oficial de OpenAI "Codex – OpenAI's coding agent" y haz clic en Install
4. Después de instalarla, aparecerá una entrada de Codex en la barra lateral izquierda (si no, revisa la parte superior derecha de la interfaz)

### Cerrar sesión de la cuenta anterior

<Callout type="warn" title="Importante">

Si antes iniciaste sesión con la cuenta oficial o con otra plataforma, ¡cierra sesión primero y luego configura!

</Callout>

1. Haz clic en el icono de configuración en la parte superior derecha del panel de Codex
2. Haz clic en **Log out** para cerrar sesión

### Terminar la configuración

Después de configurar `config.toml`, vuelve a abrir la extensión Codex y haz clic en **Continue** para completar el flujo de inicio de sesión.

<Callout type="info" title="Sobre la visualización del modelo">

El modelo GPT-5.3 no aparece en el menú desplegable; pasa el cursor sobre "Custom" para ver el modelo que se está usando.

También puedes verificar el modelo realmente solicitado en la consola, en "Registros de uso".

</Callout>

## ¿Quieres usar Claude o modelos chinos?

Si solo usas Trae y tu objetivo son modelos como **Claude / GLM / Qwen**, no necesitas la extensión Codex: la [configuración nativa de modelos en Trae](/es/docs/tools/trae) (protocolo Anthropic, solo completas algunos campos en la interfaz gráfica) es más simple.
