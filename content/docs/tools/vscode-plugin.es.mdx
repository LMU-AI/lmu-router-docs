Si quieres usar **Claude o modelos chinos (GLM / Qwen, etc.)**, Trae tiene un método nativo más sencillo (sin extensión, solo unos clics en la interfaz gráfica) — consulta [Configuración nativa de modelos en Trae](/es/docs/tools/trae).

El método de la extensión de Codex de esta página es adecuado para usuarios que quieren usar la serie **GPT / Codex**.

</Callout>

## Errores comunes

**Error: después de configurar, obtienes un 401 que dice que la clave es incorrecta**

Causa: la solicitud aún se dirige al backend oficial de OpenAI en lugar de a nuestro relay de la API, o no reiniciaste la herramienta para recargar el archivo de configuración.

Solución: sigue la guía de nuevo para **crear o reemplazar** los dos archivos `config.toml` y `auth.json`, luego reinicia la herramienta del IDE.

<Callout type="info" title="Cuando te encuentres con un error">

Toma una captura de pantalla del mensaje de error y tradúcelo — ¡podrás determinar por ti mismo qué causó el error!

</Callout>

## Configuración

### Paso 1 — Crear / sobrescribir los archivos de configuración

Ubicación del archivo de configuración:
- **Mac/Linux**: el directorio `~/.codex/`
- **Windows**: el directorio `C:\users\TuNombreDeUsuario\.codex\`

<Callout type="warn" title="Nota para Windows">

Si antes iniciaste sesión con la cuenta oficial u otra plataforma, ¡cierra sesión primero y luego configura!

</Callout>

Si no tienes una carpeta `.codex`, créala con un comando de terminal:

```bash
# Mac/Linux
rm -rf ~/.codex && mkdir ~/.codex
```

```powershell
# Windows (run in the terminal)
rm -rf C:\users\YourUsername\.codex
mkdir C:\users\YourUsername\.codex
```

### Paso 2 — Escribe config.toml

En el directorio `.codex`, crea o sobrescribe `config.toml`:

```toml
model_provider = "OpenAI"
model = "gpt-5.4"
review_model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
network_access = "enabled"
windows_wsl_setup_acknowledged = true
model_context_window = 1000000
model_auto_compact_token_limit = 900000

[model_providers.OpenAI]
name = "OpenAI"
base_url = "https://api.lmuai.com"
wire_api = "responses"
requires_openai_auth = true
```

### Paso 3 — Escribe auth.json

En el directorio `.codex`, crea o sobrescribe `auth.json`:

```json
{
  "OPENAI_API_KEY": "your sk- key generated in the console"
}
```

Una vez configurado, abre VS Code, Cursor o Trae, y la extensión de Codex que contienen iniciará sesión automáticamente.

## Instalar la extensión de Visual Studio Code

### Instalar la extensión

1. Abre VS Code y primero abre cualquier carpeta de proyecto como tu espacio de trabajo (**¡de lo contrario aparecerá un aviso emergente que te pedirá abrir una carpeta de proyecto!**)
2. Haz clic en el panel de extensiones a la izquierda (el icono de Extensiones)
3. Busca **Codex**, encuentra la extensión oficial de OpenAI "Codex – OpenAI's coding agent", y haz clic en Instalar
4. Después de instalar, aparece una entrada de Codex en la barra lateral izquierda (si no, búscala en la parte superior derecha de la interfaz)

### Cerrar sesión de la cuenta anterior

<Callout type="warn" title="Importante">

Si antes iniciaste sesión con la cuenta oficial u otra plataforma, ¡cierra sesión primero y luego configura!

</Callout>

1. Haz clic en el icono de configuración en la parte superior derecha del panel de Codex
2. Haz clic en **Log out** para cerrar sesión

### Finalizar la configuración

Después de configurar `config.toml` y `auth.json`, vuelve a abrir la extensión de Codex y haz clic en **Continue** para completar el flujo de inicio de sesión.

<Callout type="info" title="Acerca de la visualización del modelo">

El modelo GPT-5.3 no aparece en el menú desplegable; pasa el cursor sobre "Custom" para ver el modelo actualmente en uso.

También puedes verificar el modelo realmente solicitado en la consola, en "Registros de uso".

</Callout>

## ¿Quieres usar Claude o modelos chinos?

Si solo usas Trae y tu objetivo son modelos como **Claude / GLM / Qwen**, no necesitas la extensión de Codex — la [configuración nativa de modelos en Trae](/es/docs/tools/trae) (protocolo de Anthropic, solo completa unos campos en la interfaz gráfica) es más sencilla.
