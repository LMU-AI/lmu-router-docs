Cursor может направить запросы панели Chat / Plan на сторонний релейный API через **Override OpenAI Base URL**. Эта страница объясняет, как использовать этот нативный метод для подключения к LMU AI.

<Callout type="warn" title="Ключевое ограничение: затрагивается только панель Chat / Plan">

Override OpenAI Base URL в Cursor **затрагивает только панель Chat / Plan** (беседа, открытая через Cmd/Ctrl + L). Основные агентские функции Cursor — **Composer, Tab-автодополнение, Apply, Inline Edit** — все привязаны к официальному бэкенду Cursor и не могут быть переняты сторонним релеем.

Если вам нужен «полнофункциональный» агентский опыт в Cursor (включая функции типа Composer), установите вместо этого (Cursor совместим с маркетплейсом расширений VS Code):

- [Официальное расширение Codex](/ru/docs/tools/vscode-plugin) — агент Codex поверх протокола OpenAI LMU AI
- [Расширение Claude Code for VS Code](/ru/docs/tools/claude-code-vscode) — агент Claude Code поверх протокола Anthropic LMU AI

</Callout>

## Шаги настройки

### Шаг 1 — Откройте настройки Cursor

Нажмите **Cmd + Shift + J** (macOS) или **Ctrl + Shift + J** (Windows / Linux), чтобы открыть Settings, и нажмите **Models** в левой боковой панели.

### Шаг 2 — Отключите модели по умолчанию (рекомендуется)

Cursor поставляется со множеством моделей по умолчанию (GPT-4 / Claude-3.5 и т. д.); если оставить их включёнными, это конфликтует с пользовательской маршрутизацией. В списке моделей на странице Models отключите их все (переключатель слева станет серым).

### Шаг 3 — Добавьте пользовательские модели

Нажмите **Add Model** и введите нужные вам ID моделей LMU AI, например:

- `claude-opus-5`
- `claude-sonnet-5`
- `gpt-5.6-sol`
- `glm-5.2`
- `qwen3.8-max-preview`
- `deepseek-v4-pro`
- `kimi-k3`

**Добавьте каждую модель один раз.** Полный список доступных моделей см. в [Галерее моделей](/ru/docs/guide/models).

### Шаг 4 — Включите Override OpenAI Base URL

Прокрутите до области **OpenAI API Key** на странице Models:

1. Включите переключатель **OpenAI API Key**
2. Вставьте ключ из консоли LMU AI (начинается с `sk-`) в поле API Key
3. Включите переключатель **Override OpenAI Base URL**
4. Установите Base URL на:
   ```
   https://api.lmuai.com/v1
   ```
5. Нажмите **Verify** для проверки соединения

<Callout type="info" title="Неудачный Verify не означает неправильную настройку">

Verify в Cursor проверяет по введённому вами **имени модели**, и неофициальные имена OpenAI (`claude-opus-5`, `glm-5.2` и т. д.) не пройдут. Обходной путь: **сначала добавьте `gpt-4`, чтобы пройти Verify** (подтверждая, что Base URL + ключ соединяются), затем отдельно добавьте нужные вам пользовательские ID моделей; Verify предупреждает, но на практике всё работает нормально.

</Callout>

### Шаг 5 — Переключите модель и используйте её

Нажмите **Cmd/Ctrl + L**, чтобы открыть панель Chat → выберите добавленную на шаге 3 пользовательскую модель из выпадающего списка моделей вверху → начните общение, и запросы пойдут через LMU AI.

## Распространённые проблемы

### Хотите, чтобы Composer / Tab-автодополнение тоже использовали LMU AI?

Нативный Override OpenAI Base URL не может этого сделать — эти основные функции Cursor привязаны к официальному бэкенду. Чтобы направить всё через LMU AI, используйте:

- [Официальное расширение Codex](/ru/docs/tools/vscode-plugin) — агент протокола OpenAI
- [Расширение Claude Code for VS Code](/ru/docs/tools/claude-code-vscode) — агент протокола Anthropic

Cursor совместим с маркетплейсом расширений VS Code, поэтому оба расширения устанавливаются прямо в Cursor.

### Нужен ли Base URL с `/v1`?

**Да.** Введите `https://api.lmuai.com/v1`. Cursor добавит `/chat/completions` для финального запроса к `https://api.lmuai.com/v1/chat/completions`. Пропуск `/v1` даёт 404.

### Встроенный Claude 3.5 выдаёт ошибку после включения Override?

Это известный конфликт маршрутизации Cursor — включение переопределения OpenAI Base URL прерывает ветку Anthropic. Чтобы продолжить использовать Claude в панели Chat, добавьте ID модели Claude (например, `claude-opus-5`) как пользовательскую модель, а бэкенд LMU AI выполнит перевод протоколов OpenAI ↔ Anthropic.

### Ошибки 401 / 403?

Проверьте по порядку:

1. Является ли **API Key** ключом `sk-`, сгенерированным в консоли LMU AI (а не официальным ключом OpenAI)?
2. Является ли **Base URL** `https://api.lmuai.com/v1` (**должен включать `/v1`**)?
3. Является ли **ID модели** одним из поддерживаемых LMU AI (см. [Галерею моделей](/ru/docs/guide/models))?
4. Включает ли ваш текущий план / биллинговая группа модель, которую вы вызываете?

### Влияет ли BYOK на мою подписку Cursor?

- Использование BYOK **не расходует** ежемесячную квоту быстрых запросов Cursor
- Основные функции, такие как Composer / Tab-автодополнение, **по-прежнему расходуют** квоту подписки Cursor (поскольку они не используют BYOK)
- Чтобы полностью отказаться от подписки Cursor, см. подход с расширениями Codex / Claude Code выше
