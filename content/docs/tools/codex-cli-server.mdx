适用于在 WSL2 或 SSH 远程服务器环境下配置 Codex CLI。

---

## 配置步骤

### 第1步：安装 Node.js 环境（使用 volta）

在服务器终端输入：

```bash
curl https://get.volta.sh | bash
```

### 第2步：安装 Node 20

<Callout type="warn" title="注意">

安装 volta 环境成功后，**必须新建一个终端窗口**再输入以下命令：

</Callout>

```bash
volta install node@20
```

### 第3步：安装 Codex CLI

```bash
volta install @openai/codex
```

### 第4步：创建配置文件

在服务器终端直接执行以下命令，一次性写入 `~/.codex/config.toml` 与 `~/.codex/auth.json`（**注意把 auth.json 中的密钥替换为后台生成的 `sk-` 开头密钥**）：

```bash
mkdir -p ~/.codex

cat > ~/.codex/config.toml <<'EOF'
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
sandbox_mode = "danger-full-access"
windows_wsl_setup_acknowledged = true
approval_policy = "never"
file_opener = "vscode"
model_provider = "codex"
web_search = "cached"
suppress_unstable_features_warning = true

[history]
persistence = "save-all"

[tui]
notifications = true

[shell_environment_policy]
inherit = "all"
ignore_default_excludes = false

[sandbox_workspace_write]
network_access = true

[features]
plan_tool = true
apply_patch_freeform = true
view_image_tool = true
unified_exec = false
streamable_shell = false
rmcp_client = true
elevated_windows_sandbox = true

[profiles.auto-max]
approval_policy = "never"
sandbox_mode = "workspace-write"

[profiles.review]
approval_policy = "on-request"
sandbox_mode = "workspace-write"

[notice]
hide_gpt5_1_migration_prompt = true

[model_providers.codex]
name = "codex"
base_url = "https://api.lmuai.com"
wire_api = "responses"
requires_openai_auth = true
EOF

cat > ~/.codex/auth.json <<'EOF'
{
  "OPENAI_API_KEY": "这里填入后台生成的sk-开头的密钥"
}
EOF
```

配置内容与 [Codex CLI（Mac/Linux）教程](./codex-cli-mac) 完全一致，也可以用 `vim` / `nano` 手动创建这两个文件。

### 第5步：启动 Codex CLI

```bash
codex --dangerously-bypass-approvals-and-sandbox
```

或：

```bash
codex --yolo
```

---

## 启用 1M 上下文（可选）

`gpt-5.4` 支持 1M token 长上下文，但默认不开启。编辑 `~/.codex/config.toml`，在文件**顶层**（任意 `[section]` 之前）追加两行，重新进入 Codex 即可：

```toml
model_context_window = 1000000
model_auto_compact_token_limit = 900000
```

字段含义、验证方法与注意事项详见 [Codex 启用 1M 上下文](./codex-cli-mac#codex-启用-1m-上下文可选)。
