Si vous ne voulez pas installer le Codex CLI et que vous souhaitez simplement utiliser le **client de bureau Codex App**, suivez cette méthode.

<Callout type="warn" title="Remarque">

- Si vous vous êtes déjà connecté avec votre propre compte, **déconnectez-vous d'abord du compte actuel** dans la Codex App, puis reconfigurez.
- Après avoir changé d'API, votre historique de conversations aura disparu (l'historique de conversations de type compte est stocké dans l'espace de votre compte GPT, et non localement).
- **Après être passé à la connexion par API, tout l'historique de conversations à partir de ce moment est enregistré localement et ne sera pas perdu !**

</Callout>

---

## Étape 1 — Créer les fichiers de configuration

Emplacement des fichiers de configuration :
- **Mac/Linux** : le dossier `.codex` dans votre répertoire personnel (`~`)
- **Windows** : `C:\users\votre-nom-utilisateur\.codex\`

Si le dossier existe déjà, il est préférable de supprimer les fichiers `auth.json` et `config.toml` qu'il contient et de les recréer, afin d'éviter toute interférence avec l'ancienne configuration.

**Créez le dossier avec une commande de terminal :**

```bash
# Mac/Linux
rm -rf ~/.codex && mkdir ~/.codex
```

Créez deux fichiers dans le dossier `.codex` :

### auth.json

Contient votre clé API :

```json
{
  "OPENAI_API_KEY": "your sk- key generated in the console"
}
```

### config.toml

Configure le fournisseur de service :

```toml
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
sandbox_mode = "danger-full-access"
windows_wsl_setup_acknowledged = true
approval_policy = "never"
file_opener = "vscode"
model_provider = "codex"
web_search = "cached"
suppress_unstable_features_warning = true

[history]
persistence = "save-all"

[tui]
notifications = true

[shell_environment_policy]
inherit = "all"
ignore_default_excludes = false

[sandbox_workspace_write]
network_access = true

[features]
plan_tool = true
apply_patch_freeform = true
view_image_tool = true
unified_exec = false
streamable_shell = false
rmcp_client = true
elevated_windows_sandbox = true

[profiles.auto-max]
approval_policy = "never"
sandbox_mode = "workspace-write"

[profiles.review]
approval_policy = "on-request"
sandbox_mode = "workspace-write"

[notice]
hide_gpt5_1_migration_prompt = true

[model_providers.codex]
name = "codex"
base_url = "https://api.lmuai.com"
wire_api = "responses"
requires_openai_auth = true
```

<Callout type="info">

Il se trouve généralement dans le dossier `.codex` de votre répertoire personnel. Si vous ne trouvez pas le dossier `.codex` là-bas, vous pouvez créer le dossier manuellement, ainsi que `config.toml` et `auth.json`.

Le contenu des fichiers de configuration est identique à celui du [guide de configuration du Codex CLI pour Mac/Linux](/fr/docs/tools/codex-cli-mac) — vous pouvez suivre ce guide pour les créer dans le terminal, et ils prennent effet après le redémarrage de la Codex App de la même manière.

</Callout>

## Étape 2 — Rouvrir la Codex App

Après avoir enregistré les fichiers de configuration, rouvrez la Codex App et elle se connectera et sera prête à l'emploi automatiquement.

---

## Activer le contexte de 1M (facultatif)

`gpt-5.4` prend en charge un contexte long de 1M tokens, mais il est désactivé par défaut. Ajoutez deux lignes au **niveau supérieur** du `config.toml` ci-dessus (avant toute `[section]`), puis redémarrez la Codex App :

```toml
model_context_window = 1000000
model_auto_compact_token_limit = 900000
```

Pour la signification des champs, comment vérifier et les mises en garde, consultez [Activer le contexte de 1M dans Codex](/fr/docs/tools/codex-cli-mac#enabling-the-1m-context-in-codex-optional).

## Erreurs courantes

**Erreur 401, clé incorrecte :**

Cause : la requête est toujours envoyée au point de terminaison officiel d'OpenAI plutôt qu'à notre relais API, ou vous n'avez pas redémarré l'outil pour recharger le fichier de configuration.

Solution : suivez à nouveau le guide pour créer ou remplacer les fichiers `config.toml` et `auth.json`, puis rouvrez l'application.
