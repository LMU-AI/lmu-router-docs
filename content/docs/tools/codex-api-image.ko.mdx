[api-image](https://github.com/yc-duan/api-image)는 커뮤니티가 관리하는 Codex 스킬로, **API 모드의 Codex App**을 위한 이미지 생성을 복원합니다: API 키로 로그인하면 내장 imagegen을 사용할 수 없으므로, 직접 구성한 OpenAI 호환 이미지 엔드포인트를 호출하고 웹 버전의 흐름을 그대로 재현합니다 — 메인 모델이 요청을 이해하고, 필요할 때 참조 이미지를 검색하거나 분석한 뒤 이미지 모델을 호출합니다.

LMU AI를 가리키도록 설정하면 이미 Codex 디렉터리에 있는 설정을 읽으므로, **추가 base URL이나 키 설정이 필요 없습니다**.

<Callout type="warn" title="이것은 서드파티 커뮤니티 스킬이며 공식 LMU AI 구성 요소가 아닙니다">

- 이 스킬은 사용자의 컴퓨터에서 Python 스크립트로 실행되며, **`~/.codex/auth.json`에서 키를 읽고**, 프롬프트(및 참조 이미지)를 구성된 프로바이더로 전송합니다. 설치하기 전에 이 점을 충분히 이해하고 있는지 확인하세요
- **Python 3.11 이상**이 필요합니다: 스크립트가 `tomllib`로 `config.toml`을 파싱하는데, 오래된 Python은 즉시 `ModuleNotFoundError: No module named 'tomllib'` 오류를 냅니다
- 저장소는 MIT 라이선스이며, 작성자는 이를 정리된 개인 스킬이라고 설명합니다 — 프로바이더 간 호환성은 다르므로, 실제 오류 메시지를 진실의 원천으로 삼으세요

</Callout>

## 사전 준비

### 1. Codex App이 이미 LMU AI에 연결되어 있음

[Codex App (데스크톱)](./codex-app)을 따라 `~/.codex/config.toml`과 `~/.codex/auth.json`을 만드세요 — 즉, Codex App이 이미 일반적인 대화를 할 수 있어야 합니다.

api-image는 자체 자격 증명을 저장하지 않습니다. 실행 시 정확히 이 두 파일을 읽습니다:

| 읽는 항목 | 위치 | 이 사이트 가이드의 값 |
|------|------|------|
| API 키 | `~/.codex/auth.json`의 `OPENAI_API_KEY` | LMU AI 콘솔에서 생성한 `sk-` 키 |
| 현재 프로바이더 | `~/.codex/config.toml`의 `model_provider` | `codex` |
| 엔드포인트 | `[model_providers.<provider>].base_url` | `https://api.lmuai.com` |

그런 다음 `<base_url>/images/generations`(텍스트→이미지)와 `<base_url>/images/edits`(이미지→이미지 / 인페인팅)를 호출합니다.

### 2. Python 3.11+

```bash
python3 --version
# needs to print 3.11 or later; older versions fail with "No module named 'tomllib'"
```

macOS에서는 Homebrew로 설치하거나 업그레이드하세요:

```bash
brew install python@3.12
```

Windows에서는 [python.org](https://www.python.org/downloads/)에서 3.11+ 설치 프로그램을 다운로드하거나 다음을 실행하세요:

```powershell
winget install Python.Python.3.12
```

<Callout type="warn" title="여러 Python이 설치되어 있을 때 주의하세요">

Codex는 찾은 인터프리터로 스크립트를 실행합니다. `python3 --version`이 여전히 오래된 3.9를 가리키면 위의 `tomllib` 오류가 발생합니다 — 업그레이드 후 `python3`(또는 `python3.12`)가 실제로 3.11+인지 확인하세요. 여러 개가 나란히 설치되어 있다면 대화에서 인터프리터를 지정하세요. 예: "python3.12로 api-image 스크립트를 실행해".

</Callout>

## 2단계 — 대화에서 이미지 생성

이후에는 명령어가 필요 없습니다 — 평소처럼 자연어로 요청하기만 하면 됩니다:

<Tabs items={['텍스트→이미지', '참조 이미지 / 이미지→이미지', '인페인팅', '먼저 조사한 뒤 그리기']}>
<Tab value="텍스트→이미지">

```text
Use api-image to generate a 2048x1152 cinematic photo: a rainy Tokyo street at night, neon reflections, realistic photography style.
```

</Tab>
<Tab value="참조 이미지 / 이미지→이미지">

```text
Using this image's composition and pose as a reference, generate a warm cinematic illustration — keep the subject's pose, but don't copy the original.
```

</Tab>
<Tab value="인페인팅">

```text
Change the red cup in this image to green, keeping the original shape, composition and lighting, with no text added.
```

</Tab>
<Tab value="먼저 조사한 뒤 그리기">

```text
Look up the structure and terrain around the Huajiang Canyon Bridge first, then generate an aerial view that keeps the real bridge shape and canyon environment.
```

</Tab>
</Tabs>

기본값은 `2048x1152`, `quality` high, `gpt-image-2` 모델입니다. 다른 것이 필요하면 직접 요청하세요:

```text
Use api-image to generate a 1024x1024 flat illustration, quality low, two images, saved to ./public/cover.png
```

<Callout type="info" title="생성된 파일은 현재 작업 디렉터리에 저장됩니다">

출력 경로가 없으면 이미지는 Codex의 현재 작업 디렉터리에 `provider-image-20260918-153512.png`와 같은 이름으로 기록됩니다. 여러 이미지를 요청하면 파일 이름에 `-v1`, `-v2` 등이 붙습니다. 실수로 커밋하지 않도록 하세요 — 고정된 위치에 두려면 명시적인 경로를 지정하세요.

</Callout>

## 일반 옵션

Codex가 스킬을 호출할 때 이 옵션들을 전달하므로, 원하는 것을 자연어로 설명하기만 하면 됩니다. 사용 가능한 옵션을 알면 정확하게 표현하는 데 도움이 됩니다:

| 옵션 | 비고 |
|------|------|
| `--model` | 기본값 `gpt-image-2` |
| `--size` | 기본값 `2048x1152`; 그 외 `1024x1024`, `1024x1536`, `3840x2160`, `auto` 등 — 양쪽 변은 16의 배수여야 하고, 긴 변은 최대 3840, 종횡비는 3:1보다 넓지 않아야 함 |
| `--quality` | `low` / `medium` / `high`(기본값) / `auto` |
| `--n` | 프롬프트당 이미지 수, 1–10 |
| `--output-format` | `png`(기본값) / `jpeg` / `webp` |
| `--image` / `--mask` | 참조 이미지와 마스크, 최대 16개; 참조 이미지를 제공하면 자동으로 edit 엔드포인트로 전환됨 |
| `--base-url` | 해당 호출 한 번에만 엔드포인트를 재정의, 예: `https://api.lmuai.com/v1` |
| `--api-key-env` | 지정된 환경 변수에서 키를 읽음(`--api-key`보다 안전함) |
| `--codex-home` | 특정 Codex 디렉터리를 가리킴, 기본값은 `~/.codex` |

<Callout type="info" title="base_url과 LMU AI의 전체 엔드포인트">

LMU AI는 OpenAI 호환 base URL을 `/v1`을 *포함해* 문서화합니다(전체 엔드포인트는 `https://api.lmuai.com/v1/images/generations`). 반면 Codex 가이드의 `config.toml`은 호스트명만 사용합니다 — 이 스킬은 이 둘을 있는 그대로 연결하며 자체적으로 `/v1`을 추가하지 않습니다. LMU AI는 두 형식을 모두 허용하므로, **이 사이트의 가이드를 따랐다면 변경할 것이 없습니다**. 문서화된 엔드포인트를 명시하고 싶다면 대화에 한 문장만 추가하면 해당 호출에 `--base-url`을 전달합니다:

```text
Use api-image to generate ..., with base_url https://api.lmuai.com/v1
```

</Callout>

## 지원 모델

| 모델 ID | 비고 |
|------|------|
| `gpt-image-2` | 스킬의 기본 모델, 텍스트→이미지, 이미지→이미지, 인페인팅을 모두 지원 |

`--model`에는 허용 목록이 없습니다 — 다른 이미지 모델 ID는 주어진 대로 전송되며, 작동 여부는 LMU AI에 달려 있습니다(그룹의 "사용 가능한 모델"을 확인하세요). `gpt-image-2`의 기능과 제한은 [GPT image API](/ko/docs/api/gpt-image)를 참고하세요: 투명 배경을 지원하지 않으며, `input_fidelity`는 전송하지 않아야 합니다.

## 일반 오류

| 오류 텍스트 | 원인 | 해결 |
|------|------|------|
| `ModuleNotFoundError: No module named 'tomllib'` | 스크립트를 실행하는 Python이 3.11보다 오래됨 | 3.11+로 업그레이드하거나 더 새로운 인터프리터를 지정 |
| `OPENAI_API_KEY is missing in .../auth.json` | `auth.json`이 없거나 키가 없음 | [Codex App 가이드](./codex-app)에 따라 설정하거나 `--api-key-env`로 키 전달 |
| `Missing required file: .../config.toml` | Codex 디렉터리에 `config.toml`이 없음 | 위와 동일 — 먼저 Codex App이 대화할 수 있게 만들기 |
| `model_not_found` (HTTP 404) | 키의 그룹이 해당 이미지 모델을 노출하지 않음 | 콘솔에서 그룹의 모델 목록 확인 |
| HTTP 403 | 그룹에 이미지 생성이 활성화되어 있지 않음 | 관리자에게 문의하거나 그룹 전환 |
| HTTP 401 | 유효하지 않은 키 | `auth.json`의 `sk-` 키가 완전한지 확인 |

이미지 엔드포인트 오류 매핑에 대한 자세한 내용은 [GPT image API](/ko/docs/api/gpt-image)를 참고하세요.

## 참고 사항

- 이것은 **서드파티 커뮤니티 스킬**(MIT 라이선스, 저장소 [yc-duan/api-image](https://github.com/yc-duan/api-image))이며 공식 LMU AI 구성 요소가 아닙니다. 사용자로서 요청을 보내고 로컬의 `~/.codex/auth.json`을 읽습니다
- **Python 3.11+**가 필요합니다. macOS는 Python 3.9를 `python3`로 제공하는데, 이는 즉시 `No module named 'tomllib'`로 실패합니다
- 키를 채팅, 저장소, 스크린샷에 절대 붙여넣지 마세요. 키를 일시적으로 전환하려면 `--api-key` 대신 `--api-key-env`로 환경 변수에서 읽으세요. `--api-key`는 셸 기록과 프로세스 목록에 평문을 남깁니다
- 출력은 기본적으로 **현재 작업 디렉터리**로 저장됩니다 — 실수로 저장소에 커밋하지 마세요
- `--size`는 확정적인 보장이 아닙니다: 업스트림이 치수를 정규화할 수 있습니다(테스트에서 `1024x1024` 요청이 1370×1148 이미지를 만들었습니다). 실제 출력 크기를 확인하고, 정확한 픽셀이 필요하면 잘라내세요
- 이미지→이미지는 참조 이미지를 업스트림 서비스로 업로드합니다 — 저작권과 프라이버시에 유의하세요
