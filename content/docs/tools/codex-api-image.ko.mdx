[api-image](https://github.com/yc-duan/api-image)는 커뮤니티 스킬(MIT 라이선스)입니다. API 모드의 Codex App에는 기본 이미지 생성 기능이 없지만, 이 스킬을 설치하면 직접 구성한 OpenAI 호환 이미지 엔드포인트를 통해 이미지를 생성할 수 있습니다. LMU AI에서는 **추가 설정이 전혀 필요하지 않습니다** — 이미 `~/.codex`에 있는 키와 엔드포인트를 재사용하며, 대화에서 한 문장만 입력하면 됩니다.

<Callout type="warn" title="서드파티 커뮤니티 스킬">

이 스킬은 사용자의 컴퓨터에서 실행되고 `~/.codex/auth.json`에서 키를 읽으며 프롬프트와 참조 이미지를 제공자에게 전송합니다 — 설치하기 전에 이 점을 감수할 수 있는지 확인하세요. 작성자도 제공자마다 호환성이 다르다고 안내하고 있으므로, 실제 오류 메시지를 가장 신뢰할 수 있는 기준으로 삼으세요.

</Callout>

## 설치: Codex에 한 문장만 입력

Codex App을 열고 다음과 같이 말하기만 하세요:

> https://github.com/yc-duan/api-image에서 스킬을 설치해 줘 — OpenAI 이미지 2 표준 API로 이미지를 생성하고 싶어. 사용 지침은 https://github.com/yc-duan/api-image에서 확인해 줘

Codex가 저장소를 직접 `~/.codex/skills/api-image`에 저장합니다(Windows에서는 `%USERPROFILE%\.codex\skills\api-image`). 이후 **Codex App을 다시 시작하세요**.

수동 설치도 가능합니다:

```bash
git clone https://github.com/yc-duan/api-image.git ~/.codex/skills/api-image
```

## 사용: 여전히 한 문장만 입력

| 원하는 작업 | 이렇게 말하세요 |
|------|------|
| 텍스트를 이미지로 변환 | api-image를 사용해 2048x1152 시네마틱 사진을 생성해 줘: 밤의 비 내리는 도쿄 거리, 네온사인 반사, 사실적인 사진 스타일 |
| 이미지를 이미지로 변환 | 이 이미지의 구도와 포즈를 참조하여 따뜻한 일러스트를 생성해 줘 — 피사체의 포즈는 유지하되 원본을 그대로 복사하지 마 |
| 인페인팅 | 이 이미지의 빨간 컵을 초록색으로 바꿔 줘. 원래 형태, 구도와 조명은 유지해 |
| 옵션 명시 | api-image를 사용해 1024x1024 플랫 일러스트를 생성해 줘. 품질은 낮게, 이미지 두 장, `./public/cover.png`에 저장해 줘 |

기본값은 `gpt-image-2`, `2048x1152`, 높은 품질, 이미지 한 장입니다. 크기, 품질, 수량 및 출력 경로는 모두 대화에서 바로 변경할 수 있습니다. 출력은 기본적으로 현재 작업 디렉터리에 저장됩니다(`provider-image-<timestamp>.png`).

## 참고

- **LMU AI에서는 구성할 것이 없습니다**: 이 스킬은 LMU AI에 연결할 때 이미 설정한 `auth.json`(키)과 `config.toml`(엔드포인트)을 읽으며, 전체 엔드포인트는 `https://api.lmuai.com/v1/images/generations` 및 `/v1/images/edits`에 해당합니다.
- `model_not_found` / 403: 키가 속한 그룹에 이미지 모델이 포함되어 있지 않습니다 — 콘솔에서 "사용 가능한 모델"을 확인하거나 그룹을 전환하세요.
- `gpt-image-2`는 투명한 배경을 지원하지 않습니다. 또한 업스트림에서 요청한 크기를 정규화할 수 있으므로 실제 출력 결과를 기준으로 판단하세요.
