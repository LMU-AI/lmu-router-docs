[api-image](https://github.com/yc-duan/api-image) 는 커뮤니티 스킬(MIT 라이선스)입니다. API 모드의 Codex App에는 내장 imagegen이 없는데, 이 스킬을 설치하면 직접 설정한 OpenAI 호환 이미지 엔드포인트를 통해 이미지를 생성할 수 있습니다. `~/.codex` 에 있는 키와 엔드포인트를 그대로 재사용하므로, 대화에서 한 문장이면 충분합니다.

<Callout type="warn" title="서드파티 커뮤니티 스킬">

이 스킬은 사용자의 컴퓨터에서 실행되며, `~/.codex/auth.json` 에서 키를 읽고, 프롬프트와 참조 이미지를 공급자에게 전송합니다 — 설치 전에 이 점을 감안하시기 바랍니다. 작성자도 공급자마다 호환성이 다르다고 언급하고 있으니, 실제 오류 메시지를 기준으로 판단하세요.

</Callout>

## 준비: auth.json 유지하기

이 스킬은 `~/.codex/auth.json` (Windows에서는 `%USERPROFILE%\.codex\auth.json`)에서 키를 읽습니다. 갱신된 [Codex App 가이드](/ko/docs/tools/codex-app)는 이제 키를 `config.toml` 의 요청 헤더에 넣고 `auth.json` 이 더 이상 필요하지 않지만, 이 스킬을 쓰려면 동일한 키를 담은 `auth.json` 을 하나 유지해야 합니다:

```json
{
  "OPENAI_API_KEY": "your sk- key generated in the console"
}
```

이전 가이드대로 이미 `auth.json` 을 만들어 두었다면 그대로 두면 됩니다.

## 설치: Codex에게 한 문장

Codex App을 열고 이렇게만 말하세요:

> https://github.com/yc-duan/api-image 의 스킬을 설치해 줘 — OpenAI image 2 표준 API로 이미지를 생성하고 싶어. 사용법은 https://github.com/yc-duan/api-image 를 참고해

Codex가 저장소를 `~/.codex/skills/api-image` (Windows에서는 `%USERPROFILE%\.codex\skills\api-image`)에 알아서 넣어 줍니다. 그 다음 **Codex App을 재시작**하세요.

직접 설치해도 됩니다:

```bash
git clone https://github.com/yc-duan/api-image.git ~/.codex/skills/api-image
```

## 사용: 역시 한 문장

| 원하는 작업 | 이렇게 말하세요 |
|------|------|
| 텍스트 → 이미지 | api-image로 2048x1152 시네마틱 사진을 생성해 줘: 비 내리는 밤의 도쿄 거리, 네온 반사, 실사 사진 스타일 |
| 이미지 → 이미지 | 이 이미지의 구도와 포즈를 참고해서 따뜻한 느낌의 일러스트를 생성해 줘 — 피사체의 포즈는 유지하고 원본을 그대로 베끼지는 말아 줘 |
| 인페인팅 | 이 이미지의 빨간 컵을 초록색으로 바꿔 줘. 원래 형태, 구도, 조명은 유지해 줘 |
| 옵션 명시 | api-image로 1024x1024 플랫 일러스트를 생성해 줘. quality low, 2장, ./public/cover.png 에 저장 |

기본값은 `gpt-image-2`, `2048x1152`, quality high, 1장입니다. 크기, 품질, 장수, 출력 경로는 모두 대화에서 바로 바꿀 수 있습니다. 출력물은 기본적으로 현재 작업 디렉터리에 저장됩니다(`provider-image-<timestamp>.png`).

## 참고 사항

- **LMU AI에서는 `auth.json` 만 유지하면 됩니다**: 스킬은 `auth.json` (키)과 `config.toml` (엔드포인트)을 읽으며, 이는 전체 엔드포인트 `https://api.lmuai.com/v1/images/generations` 및 `/v1/images/edits` 에 해당합니다
- `model_not_found` / 403: 사용 중인 키의 그룹에 이미지 모델이 포함되어 있지 않습니다 — 콘솔의 "사용 가능한 모델"을 확인하거나 그룹을 전환하세요
- `gpt-image-2` 는 투명 배경을 지원하지 않으며, 업스트림이 요청한 크기를 정규화할 수 있으므로 실제 출력물을 기준으로 판단하세요
