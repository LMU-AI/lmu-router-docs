[api-image](https://github.com/yc-duan/api-image) مهارة مجتمعية (رخصة MIT): تطبيق Codex في وضع API لا يحتوي على imagegen مدمج، وبعد تثبيت هذه المهارة يولّد الصور عبر واجهة متوافقة مع OpenAI تضبطها بنفسك. مع LMU AI لا يلزم **أي إعداد إضافي** — فهو يعيد استخدام المفتاح والواجهة الموجودين أصلًا في `~/.codex`، وتكفي جملة واحدة في المحادثة.

<Callout type="warn" title="مهارة مجتمعية من طرف ثالث">

تعمل على جهازك، وتقرأ المفتاح من `~/.codex/auth.json`، وترسل المطالبة والصور المرجعية إلى المزوّد — تأكد من موافقتك على ذلك قبل التثبيت. ينبّه المؤلف أيضًا إلى أن التوافق يختلف بين المزوّدين؛ فاعتمد على رسائل الخطأ الفعلية.

</Callout>

## التثبيت: جملة واحدة لـ Codex

افتح Codex App وقل ببساطة:

> ثبّت المهارة من https://github.com/yc-duan/api-image — أريد توليد الصور عبر واجهة OpenAI image 2 القياسية؛ تعليمات الاستخدام على https://github.com/yc-duan/api-image

سيضع Codex المستودع بنفسه في `~/.codex/skills/api-image` (وفي Windows `%USERPROFILE%\.codex\skills\api-image`)؛ ثم **أعد تشغيل Codex App**.

التثبيت اليدوي ممكن أيضًا:

```bash
git clone https://github.com/yc-duan/api-image.git ~/.codex/skills/api-image
```

## الاستخدام: جملة واحدة أيضًا

| ما تريد | قل ببساطة |
|------|------|
| نص إلى صورة | ولّد باستخدام api-image صورة سينمائية بأبعاد 2048x1152: شارع طوكيو ممطر ليلًا، انعكاسات النيون، أسلوب تصوير واقعي |
| صورة إلى صورة | خذ تكوين ووضعية هذه الصورة كمرجع وولّد رسمة دافئة — حافظ على الوضعية دون نسخ الأصل |
| التنقيح (Inpainting) | غيّر لون الكوب الأحمر في هذه الصورة إلى الأخضر مع الحفاظ على الشكل والتكوين والإضاءة |
| خيارات صريحة | ولّد باستخدام api-image رسمة مسطحة بأبعاد 1024x1024، جودة low، صورتين، واحفظها في ./public/cover.png |

الافتراضي هو `gpt-image-2` و`2048x1152` وجودة high وصورة واحدة؛ الحجم والجودة والعدد ومسار الحفظ تتغير كلها من داخل المحادثة. افتراضيًا تُحفظ النتيجة في مجلد العمل الحالي (`provider-image-<طابع زمني>.png`).

## ملاحظات

- **لا شيء يُضبط لـ LMU AI**: تقرأ المهارة `auth.json` (المفتاح) و`config.toml` (الواجهة) التي جهزتها مسبقًا عند الربط مع LMU AI — وهي تقابل الواجهتين الكاملتين `https://api.lmuai.com/v1/images/generations` و`/v1/images/edits`
- `model_not_found` / 403: مجموعتك لا تتضمن نموذج الصور — تحقق من «النماذج المتاحة» في لوحة التحكم أو غيّر المجموعة
- `gpt-image-2` لا يدعم الخلفيات الشفافة؛ قد يطبّع المزوّد الأبعاد المطلوبة — فاعتمد على الصورة الفعلية الناتجة
