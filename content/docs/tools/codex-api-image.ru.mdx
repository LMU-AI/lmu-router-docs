[api-image](https://github.com/yc-duan/api-image) — это навык Codex, поддерживаемый сообществом, который восстанавливает генерацию изображений для **Codex App в режиме API**: встроенный imagegen недоступен, когда вы входите с ключом API, поэтому он вызывает совместимый с OpenAI эндпоинт изображений, который вы настраиваете сами, и повторяет процесс веб-версии — основная модель понимает запрос, при необходимости ищет или анализирует эталонные изображения, а затем вызывает модель изображений.

После того как он указывает на LMU AI, он читает конфигурацию, уже находящуюся в вашем каталоге Codex, **без дополнительной настройки base URL или ключа**.

<Callout type="warn" title="Это сторонний навык сообщества, а не официальный компонент LMU AI">

- Он выполняется как скрипт на Python на вашей машине, **читает ключ из `~/.codex/auth.json`** и отправляет ваш промпт (плюс любые эталонные изображения) настроенному провайдеру. Убедитесь, что вас это устраивает, прежде чем устанавливать
- Требуется **Python 3.11 или новее**: скрипт разбирает `config.toml` с помощью `tomllib`, и на более старом Python сразу возникает ошибка `ModuleNotFoundError: No module named 'tomllib'`
- Репозиторий под лицензией MIT, и автор описывает его как приведённый в порядок личный навык — совместимость варьируется между провайдерами, поэтому считайте реальные сообщения об ошибках источником истины

</Callout>

## Предварительные требования

### 1. Codex App уже подключён к LMU AI

Следуйте [Codex App (для настольных ПК)](./codex-app), чтобы создать `~/.codex/config.toml` и `~/.codex/auth.json` — иными словами, Codex App уже может вести обычный разговор.

api-image не хранит собственных учётных данных; во время работы он читает именно эти два файла:

| Что он читает | Откуда | Значение из руководства этого сайта |
|------|------|------|
| Ключ API | `OPENAI_API_KEY` в `~/.codex/auth.json` | ключ `sk-`, сгенерированный в консоли LMU AI |
| Текущий провайдер | `model_provider` в `~/.codex/config.toml` | `codex` |
| Эндпоинт | `[model_providers.<provider>].base_url` | `https://api.lmuai.com` |

Затем он вызывает `<base_url>/images/generations` (текст в изображение) и `<base_url>/images/edits` (изображение в изображение / дорисовка).

### 2. Python 3.11+

```bash
python3 --version
# needs to print 3.11 or later; older versions fail with "No module named 'tomllib'"
```

Установите или обновите его с помощью Homebrew на macOS:

```bash
brew install python@3.12
```

В Windows скачайте установщик 3.11+ с [python.org](https://www.python.org/downloads/) или выполните:

```powershell
winget install Python.Python.3.12
```

<Callout type="warn" title="Будьте внимательны, когда установлено несколько версий Python">

Codex запускает скрипт с тем интерпретатором, который находит. Если `python3 --version` всё ещё указывает на старую версию 3.9, вы столкнётесь с ошибкой `tomllib` выше — после обновления убедитесь, что `python3` (или `python3.12`) действительно 3.11+. Если у вас установлено несколько версий рядом, укажите интерпретатор в разговоре, например «запусти скрипт api-image с python3.12».

</Callout>

## Шаг 2 — Генерируйте изображения в разговоре

После этого команды не нужны — просто попросите обычным языком, ровно так, как вы обычно это делаете:

<Tabs items={['Текст в изображение', 'Эталонное изображение / изображение в изображение', 'Дорисовка', 'Сначала изучить, потом рисовать']}>
<Tab value="Текст в изображение">

```text
Use api-image to generate a 2048x1152 cinematic photo: a rainy Tokyo street at night, neon reflections, realistic photography style.
```

</Tab>
<Tab value="Эталонное изображение / изображение в изображение">

```text
Using this image's composition and pose as a reference, generate a warm cinematic illustration — keep the subject's pose, but don't copy the original.
```

</Tab>
<Tab value="Дорисовка">

```text
Change the red cup in this image to green, keeping the original shape, composition and lighting, with no text added.
```

</Tab>
<Tab value="Сначала изучить, потом рисовать">

```text
Look up the structure and terrain around the Huajiang Canyon Bridge first, then generate an aerial view that keeps the real bridge shape and canyon environment.
```

</Tab>
</Tabs>

По умолчанию используются `2048x1152`, `quality` high и модель `gpt-image-2`. Запрашивайте что-либо иное напрямую:

```text
Use api-image to generate a 1024x1024 flat illustration, quality low, two images, saved to ./public/cover.png
```

<Callout type="info" title="Сгенерированные файлы попадают в текущий рабочий каталог">

Без указания пути вывода изображения записываются в текущий рабочий каталог Codex с именами вроде `provider-image-20260918-153512.png`. Когда вы запрашиваете несколько изображений, к именам файлов добавляются `-v1`, `-v2` и так далее. Не закоммитьте их случайно — укажите явный путь, если хотите разместить их в определённом месте.

</Callout>

## Распространённые опции

Codex передаёт их при вызове навыка, поэтому вам нужно только описать желаемое обычным языком; знание доступных опций поможет вам сформулировать запрос точнее:

| Опция | Примечания |
|------|------|
| `--model` | По умолчанию `gpt-image-2` |
| `--size` | По умолчанию `2048x1152`; также `1024x1024`, `1024x1536`, `3840x2160`, `auto` и другие — обе стороны должны быть кратны 16, длинная сторона максимум 3840, а соотношение сторон не шире 3:1 |
| `--quality` | `low` / `medium` / `high` (по умолчанию) / `auto` |
| `--n` | Изображений на промпт, 1–10 |
| `--output-format` | `png` (по умолчанию) / `jpeg` / `webp` |
| `--image` / `--mask` | Эталонные изображения и маски, до 16; предоставление эталонного изображения автоматически переключает на эндпоинт редактирования |
| `--base-url` | Переопределяет эндпоинт только для одного этого вызова, например `https://api.lmuai.com/v1` |
| `--api-key-env` | Читает ключ из именованной переменной окружения (безопаснее, чем `--api-key`) |
| `--codex-home` | Указывает на определённый каталог Codex, по умолчанию `~/.codex` |

<Callout type="info" title="base_url и полный эндпоинт LMU AI">

LMU AI документирует свой совместимый с OpenAI base URL *с* `/v1` (полный эндпоинт — `https://api.lmuai.com/v1/images/generations`), тогда как `config.toml` в руководстве по Codex использует голое имя хоста — этот навык соединяет их как есть и не добавляет `/v1` сам. LMU AI принимает обе формы, поэтому **если вы следовали руководству этого сайта, ничего менять не нужно**; если вы предпочитаете указать документированный эндпоинт полностью, просто добавьте предложение в разговоре, и он передаст `--base-url` для этого вызова:

```text
Use api-image to generate ..., with base_url https://api.lmuai.com/v1
```

</Callout>

## Поддерживаемые модели

| ID модели | Примечания |
|------|------|
| `gpt-image-2` | Модель навыка по умолчанию, охватывает текст в изображение, изображение в изображение и дорисовку |

У `--model` нет списка разрешённых значений — другие ID моделей изображений отправляются как есть, и будут ли они работать, зависит от LMU AI (проверьте «Доступные модели» для вашей группы). О возможностях и ограничениях `gpt-image-2` см. [GPT image API](/ru/docs/api/gpt-image): он не поддерживает прозрачный фон, и `input_fidelity` отправлять не следует.

## Распространённые ошибки

| Текст ошибки | Причина | Исправление |
|------|------|------|
| `ModuleNotFoundError: No module named 'tomllib'` | Python, запускающий скрипт, старше 3.11 | Обновитесь до 3.11+ или укажите более новый интерпретатор |
| `OPENAI_API_KEY is missing in .../auth.json` | `auth.json` отсутствует или в нём нет ключа | Настройте его согласно [руководству по Codex App](./codex-app) или передайте ключ через `--api-key-env` |
| `Missing required file: .../config.toml` | В каталоге Codex нет `config.toml` | То же, что выше — сначала заставьте Codex App работать |
| `model_not_found` (HTTP 404) | Группа вашего ключа не предоставляет эту модель изображений | Проверьте список моделей группы в консоли |
| HTTP 403 | Генерация изображений не включена для группы | Свяжитесь с администратором или смените группу |
| HTTP 401 | Неверный ключ | Проверьте, что ключ `sk-` в `auth.json` полный |

Дополнительное сопоставление ошибок эндпоинта изображений см. в [GPT image API](/ru/docs/api/gpt-image).

## Примечания

- Это **сторонний навык сообщества** (под лицензией MIT, репозиторий [yc-duan/api-image](https://github.com/yc-duan/api-image)), а не официальный компонент LMU AI; он делает запросы от вашего имени и читает ваш локальный `~/.codex/auth.json`
- Требуется **Python 3.11+**; macOS поставляет Python 3.9 как `python3`, который сразу завершается с ошибкой `No module named 'tomllib'`
- Никогда не вставляйте свой ключ в чат, репозиторий или скриншот; чтобы временно сменить ключ, читайте его из переменной окружения с помощью `--api-key-env`, а не `--api-key`, который оставляет открытый текст в истории вашей оболочки и списке процессов
- Вывод по умолчанию направляется в **текущий рабочий каталог** — не закоммитьте его случайно в ваш репозиторий
- `--size` не является жёсткой гарантией: вышестоящий сервис может нормализовать размеры (запрос `1024x1024` дал изображение 1370×1148 в нашем тесте), поэтому читайте реальный размер вывода и обрезайте, если нужны точные пиксели
- Изображение в изображение загружает ваши эталонные изображения на вышестоящий сервис — учитывайте авторские права и конфиденциальность
