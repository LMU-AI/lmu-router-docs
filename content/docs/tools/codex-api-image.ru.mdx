[api-image](https://github.com/yc-duan/api-image) — это навык от сообщества (лицензия MIT): в режиме API у Codex App нет встроенной генерации изображений, но после установки этого навыка он может создавать изображения через OpenAI-совместимую конечную точку изображений, которую вы настраиваете сами. Он переиспользует ключ и конечную точку из вашего `~/.codex`, и одной фразы в диалоге достаточно.

<Callout type="warn" title="Сторонний навык от сообщества">

Он работает на вашей машине, читает ключ из `~/.codex/auth.json` и отправляет ваш промпт и референсные изображения провайдеру — убедитесь, что это вас устраивает, прежде чем устанавливать. Автор также отмечает, что совместимость различается между провайдерами, поэтому ориентируйтесь на реальные сообщения об ошибках как на источник истины.

</Callout>

## Подготовка: сохраните auth.json

Этот навык читает ключ из `~/.codex/auth.json` (в Windows — `%USERPROFILE%\.codex\auth.json`). В обновлённом [руководстве по Codex App](/ru/docs/tools/codex-app) ключ теперь передаётся в заголовке запроса в `config.toml`, и `auth.json` больше не нужен, но для работы этого навыка файл нужно сохранить с тем же ключом:

```json
{
  "OPENAI_API_KEY": "your sk- key generated in the console"
}
```

Если вы уже создали `auth.json` по старому руководству, просто оставьте его как есть.

## Установка: одна фраза для Codex

Откройте Codex App и просто скажите:

> Установи навык по адресу https://github.com/yc-duan/api-image — я хочу генерировать изображения через стандартный API OpenAI image 2; инструкции по использованию смотри на https://github.com/yc-duan/api-image

Codex сам положит репозиторий в `~/.codex/skills/api-image` (в Windows — `%USERPROFILE%\.codex\skills\api-image`); после этого **перезапустите Codex App**.

Ручная установка тоже работает:

```bash
git clone https://github.com/yc-duan/api-image.git ~/.codex/skills/api-image
```

## Использование: тоже одна фраза

| Что нужно | Скажите так |
|------|------|
| Текст в изображение | Используй api-image, чтобы сгенерировать кинематографичное фото 2048x1152: ночная дождливая улица Токио, отражения неона, стиль реалистичной фотографии |
| Изображение в изображение | Опираясь на композицию и позу с этого изображения, сгенерируй тёплую иллюстрацию — сохрани позу персонажа, не копируй оригинал |
| Перерисовка области | Измени красную чашку на этом изображении на зелёную, сохранив исходную форму, композицию и освещение |
| Явные параметры | Используй api-image, чтобы сгенерировать плоскую иллюстрацию 1024x1024, качество low, два изображения, сохранить в ./public/cover.png |

По умолчанию используются `gpt-image-2`, `2048x1152`, качество high, одно изображение; размер, качество, количество и путь вывода можно изменить прямо в диалоге. Результат по умолчанию попадает в текущий рабочий каталог (`provider-image-<timestamp>.png`).

## Примечания

- **Для LMU AI достаточно сохранить `auth.json`**: навык читает `auth.json` (ключ) и `config.toml` (конечную точку), что соответствует полным адресам `https://api.lmuai.com/v1/images/generations` и `/v1/images/edits`
- `model_not_found` / 403: в группе вашего ключа нет модели изображений — проверьте «Доступные модели» в консоли или переключите группу
- `gpt-image-2` не поддерживает прозрачный фон; апстрим может нормализовать запрошенные размеры, поэтому ориентируйтесь на фактический результат
