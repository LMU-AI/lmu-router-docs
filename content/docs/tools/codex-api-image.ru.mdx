[api-image](https://github.com/yc-duan/api-image) — навык от сообщества (лицензия MIT): в Codex App в режиме API нет встроенного imagegen, а с этим навыком она генерирует изображения через совместимый с OpenAI эндпоинт, который вы настраиваете сами. С LMU AI — **ноль дополнительной настройки**: он использует ключ и эндпоинт, уже лежащие в вашем `~/.codex`, и достаточно одной фразы в диалоге.

<Callout type="warn" title="Сторонний навык от сообщества">

Он выполняется на вашем компьютере, читает ключ из `~/.codex/auth.json` и отправляет промпт и референсные изображения провайдеру — убедитесь, что вы с этим согласны, прежде чем устанавливать. Автор также отмечает, что совместимость зависит от провайдера; ориентируйтесь на реальные сообщения об ошибках.

</Callout>

## Установка: одна фраза для Codex

Откройте Codex App и просто скажите:

> Установи навык с https://github.com/yc-duan/api-image — хочу создавать изображения через стандартный API OpenAI image 2; инструкция по использованию на https://github.com/yc-duan/api-image

Codex сам положит репозиторий в `~/.codex/skills/api-image` (в Windows — `%USERPROFILE%\.codex\skills\api-image`); после этого **перезапустите Codex App**.

Можно установить и вручную:

```bash
git clone https://github.com/yc-duan/api-image.git ~/.codex/skills/api-image
```

## Использование: тоже одна фраза

| Что нужно | Просто скажите |
|------|------|
| Текст в изображение | Сгенерируй с помощью api-image кинематографичное фото 2048x1152: дождливая улица Токио ночью, отражения неона, реалистичный фотографический стиль |
| Изображение в изображение | Возьми композицию и позу этого изображения как референс и сгенерируй тёплую иллюстрацию — сохрани позу, не копируя оригинал |
| Inpainting | Перекрась красную чашку на этом изображении в зелёный, сохранив форму, композицию и свет |
| Явные параметры | Сгенерируй с помощью api-image плоскую иллюстрацию 1024x1024, качество low, два изображения, сохрани в ./public/cover.png |

По умолчанию: `gpt-image-2`, `2048x1152`, качество high, одно изображение; размер, качество, количество и путь сохранения меняются прямо в диалоге. Результат по умолчанию попадает в текущую рабочую директорию (`provider-image-<метка времени>.png`).

## Примечания

- **Для LMU AI настраивать ничего не нужно**: навык читает `auth.json` (ключ) и `config.toml` (эндпоинт), которые вы уже настроили при подключении к LMU AI — это соответствует полным эндпоинтам `https://api.lmuai.com/v1/images/generations` и `/v1/images/edits`
- `model_not_found` / 403: в вашей группе нет модели генерации изображений — проверьте «Доступные модели» в консоли или смените группу
- `gpt-image-2` не поддерживает прозрачный фон; запрошенный размер апстрим может нормализовать — ориентируйтесь на фактический результат
