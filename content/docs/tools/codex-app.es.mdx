Si no quieres instalar la Codex CLI y solo deseas usar el **cliente de escritorio Codex App**, sigue este método.

<Callout type="warn" title="Nota">

- Si iniciaste sesión previamente con tu propia cuenta, primero **cierra sesión de la cuenta actual** en la Codex App y luego vuelve a configurar.
- Después de cambiar la API, tu historial de chat desaparecerá (el historial de chat del tipo cuenta se almacena en el espacio de tu cuenta GPT, no localmente).
- **¡Después de cambiar al inicio de sesión con API, todo el historial de chat a partir de ese momento se guarda localmente y no se perderá!**

</Callout>

---

## Paso 1 — Crea los archivos de configuración

Ubicación del archivo de configuración:
- **Mac/Linux**: la carpeta `.codex` en tu directorio de inicio (`~`)
- **Windows**: `C:\users\tu-nombre-de-usuario\.codex\`

Si la carpeta ya existe, lo mejor es eliminar los archivos `auth.json` y `config.toml` que hay dentro y volver a crearlos, para evitar interferencias de configuraciones antiguas.

**Crea la carpeta con un comando de terminal:**

```bash
# Mac/Linux
rm -rf ~/.codex && mkdir ~/.codex
```

Crea dos archivos en la carpeta `.codex`:

### auth.json

Contiene tu clave de API:

```json
{
  "OPENAI_API_KEY": "your sk- key generated in the console"
}
```

### config.toml

Configura el proveedor del servicio:

```toml
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
sandbox_mode = "danger-full-access"
windows_wsl_setup_acknowledged = true
approval_policy = "never"
file_opener = "vscode"
model_provider = "codex"
web_search = "cached"
suppress_unstable_features_warning = true

[history]
persistence = "save-all"

[tui]
notifications = true

[shell_environment_policy]
inherit = "all"
ignore_default_excludes = false

[sandbox_workspace_write]
network_access = true

[features]
plan_tool = true
apply_patch_freeform = true
view_image_tool = true
unified_exec = false
streamable_shell = false
rmcp_client = true
elevated_windows_sandbox = true

[profiles.auto-max]
approval_policy = "never"
sandbox_mode = "workspace-write"

[profiles.review]
approval_policy = "on-request"
sandbox_mode = "workspace-write"

[notice]
hide_gpt5_1_migration_prompt = true

[model_providers.codex]
name = "codex"
base_url = "https://api.lmuai.com"
wire_api = "responses"
requires_openai_auth = true
```

<Callout type="info">

Normalmente está dentro de la carpeta `.codex` en tu directorio de inicio. Si no encuentras la carpeta `.codex` allí, puedes crear la carpeta manualmente, junto con `config.toml` y `auth.json`.

El contenido de los archivos de configuración es idéntico al de la [guía de configuración de Codex CLI para Mac/Linux](/es/docs/tools/codex-cli-mac) — puedes seguir esa guía para crearlos en la terminal, y surten efecto después de reiniciar la Codex App de igual manera.

</Callout>

---

## Paso 2 — Vuelve a abrir la Codex App

Después de guardar los archivos de configuración, vuelve a abrir la Codex App y iniciará sesión y estará lista para usar automáticamente.

---

## Habilitar el contexto de 1M (opcional)

`gpt-5.4` admite un contexto largo de 1M tokens, pero está desactivado de forma predeterminada. Agrega dos líneas en el **nivel superior** del `config.toml` anterior (antes de cualquier `[section]`) y luego reinicia la Codex App:

```toml
model_context_window = 1000000
model_auto_compact_token_limit = 900000
```

Para el significado de los campos, cómo verificar y las advertencias, consulta [Habilitar el contexto de 1M en Codex](/es/docs/tools/codex-cli-mac#enabling-the-1m-context-in-codex-optional).

---

## Errores comunes

**Error 401, clave incorrecta:**

Causa: la solicitud sigue yendo al endpoint oficial de OpenAI en lugar de a nuestro relé de API, o no reiniciaste la herramienta para recargar el archivo de configuración.

Solución: sigue la guía nuevamente para crear o reemplazar los archivos `config.toml` y `auth.json`, luego vuelve a abrir la app.
