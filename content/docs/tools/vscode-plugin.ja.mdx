<Callout type="info" title="Trae エディタを使う場合">

**Claude または中国国内モデル（GLM / Qwen など）** を使いたい場合、Trae にはよりシンプルなネイティブ設定方法があります（拡張機能不要、GUI で数クリックするだけ） — [Trae ネイティブモデル設定](/ja/docs/tools/trae) を参照してください。

このページの Codex 拡張機能による方法は、**GPT / Codex** シリーズを使いたいユーザーに向いています。

</Callout>

## よくあるエラー

**エラー：設定後に 401 が返り、キーが正しくないと表示される**

原因：リクエストが当社の API 中継ではなく、依然として OpenAI 公式のバックエンドに送られている、またはツールを再起動して設定ファイルを再読み込みしていない。

対処：ガイドに従って `config.toml` を **作成または置き換え** し、その後 IDE ツールを再起動してください。

<Callout type="info" title="エラーが発生したとき">

エラーメッセージをスクリーンショットして翻訳すれば、原因を自分で判断できます！

</Callout>

## 設定

### ステップ 1 — 設定ファイルを作成 / 上書きする

設定ファイルの場所：
- **Mac/Linux**：`~/.codex/` ディレクトリ
- **Windows**：`C:\users\YourUsername\.codex\` ディレクトリ

<Callout type="warn" title="Windows での注意">

以前に公式アカウントや他のプラットフォームでサインインしていた場合は、先にサインアウトしてから設定してください！

</Callout>

`.codex` フォルダがない場合は、ターミナルコマンドで作成します：

```bash
# Mac/Linux
rm -rf ~/.codex && mkdir ~/.codex
```

```powershell
# Windows (run in the terminal)
rm -rf C:\users\YourUsername\.codex
mkdir C:\users\YourUsername\.codex
```

### ステップ 2 — config.toml を書く

`.codex` ディレクトリ内に `config.toml` を作成または上書きします：

```toml
model_provider = "OpenAI"
model = "gpt-5.4"
review_model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
network_access = "enabled"
windows_wsl_setup_acknowledged = true
model_context_window = 1000000
model_auto_compact_token_limit = 900000

[model_providers.OpenAI]
name = "OpenAI"
base_url = "https://api.lmuai.com"
wire_api = "responses"

[model_providers.OpenAI.http_headers]
Authorization = "Bearer your sk- key generated in the console"
```

最後の行をご自身の `sk-` キーに置き換え、`Bearer` とキーの間にはスペースを 1 つ入れ、`http_headers` セクションはファイルの末尾に配置してください。新しいバージョンの Codex では `auth.json` は不要です。古いものが残っていても問題ありません。

設定が完了したら、VS Code、Cursor、または Trae を開くと、内部の Codex 拡張機能が自動的にサインインします。

## Visual Studio Code 拡張機能のインストール

### 拡張機能をインストールする

1. VS Code を開き、まず任意のプロジェクトフォルダをワークスペースとして開きます（**開かないと、プロジェクトフォルダを開くよう促すポップアップが表示されます！**）
2. 左側の拡張機能パネル（Extensions アイコン）をクリックします
3. **Codex** を検索し、OpenAI 公式の拡張機能「Codex – OpenAI's coding agent」を見つけて、インストールをクリックします
4. インストール後、左サイドバーに Codex の項目が表示されます（表示されない場合は、画面右上を確認してください）

### 以前のアカウントからサインアウトする

<Callout type="warn" title="重要">

以前に公式アカウントや他のプラットフォームでサインインしていた場合は、先にサインアウトしてから設定してください！

</Callout>

1. Codex パネル右上の設定アイコンをクリックします
2. **Log out** をクリックしてサインアウトします

### 設定を完了する

`config.toml` を設定したら、Codex 拡張機能を再度開き、**Continue** をクリックしてサインインフローを完了します。

<Callout type="info" title="モデル表示について">

GPT-5.3 モデルはドロップダウンに表示されません。「Custom」にカーソルを合わせると、現在使用中のモデルを確認できます。

また、コンソールの「使用記録」で実際にリクエストされたモデルを確認できます。

</Callout>

## Claude や中国国内モデルを使いたい場合

Trae のみを使用し、目的が **Claude / GLM / Qwen** などのモデルであれば、Codex 拡張機能は不要です。[Trae ネイティブモデル設定](/ja/docs/tools/trae)（Anthropic プロトコル、GUI でいくつかの項目を入力するだけ）のほうがシンプルです。
