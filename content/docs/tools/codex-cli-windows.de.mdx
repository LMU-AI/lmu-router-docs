Nach der Installation der Codex CLI erstellen Sie von Hand eine einzige Konfigurationsdatei, `config.toml` (der Key kommt darin in einen Request-Header), um sich mit der LMU AI API zu verbinden — ein Konfigurationstool von Drittanbietern ist nicht nötig.

---

## Schritt 1 — Windows Terminal installieren

Unter Windows empfehlen wir für die Codex CLI **Windows Terminal** anstelle von CMD — es unterstützt mehrere Fenster und ist bequemer.

- Download über China-Cloud-Speicher (empfohlen, schnell): [https://www.ilanzou.com/s/MzWnpE05](https://www.ilanzou.com/s/MzWnpE05)
- Download über GitHub: [https://github.com/microsoft/terminal/releases/tag/v1.23.20211.0](https://github.com/microsoft/terminal/releases/tag/v1.23.20211.0)

Laden Sie `Microsoft.WindowsTerminal_1.23.20211.0_x64.zip` herunter, entpacken Sie es und starten Sie es per Doppelklick auf `WindowsTerminal.exe` — es ist sinnvoll, eine Desktop-Verknüpfung anzulegen.

## Schritt 2 — Node.js installieren

> Falls bereits installiert, können Sie diesen Schritt überspringen; prüfen mit: `node -v`

Sie benötigen **Node.js 20+** — Download: [https://nodejs.org/en/download](https://nodejs.org/en/download)

Achten Sie während der Installation darauf, **"Automatically install the necessary tools"** zu aktivieren.

Prüfen Sie nach der Installation im Terminal:

```bash
node -v
# A version number (e.g. v24.4.1) means it installed correctly
```

<Callout type="info" title="Sonderfall">

Wenn `node.js` nicht installiert ist oder Sie es früher installiert haben, die Umgebung aber falsch konfiguriert ist, laden Sie es einmal herunter, installieren Sie es neu und öffnen Sie das Terminal erneut.

</Callout>

**Wenn ein Fehler auftritt, dass die Skriptausführung blockiert ist, führen Sie den folgenden Befehl aus:**

```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
```

## Schritt 3 — Codex CLI installieren

```bash
npm i -g @openai/codex
```

Bei Netzwerkproblemen wechseln Sie zuerst auf einen China-Mirror und installieren dann:

```bash
npm config set registry https://registry.npmmirror.com
npm i -g @openai/codex
```

Installation überprüfen:

```bash
codex --version
# A version number means it installed correctly
```

## Schritt 4 — Konfigurationsdateien erstellen

Das Konfigurationsverzeichnis ist **`C:\users\your-username\.codex\`** (erstellen Sie es, falls es fehlt; überschreiben Sie alte Dateien). Erstellen bzw. überschreiben Sie darin `config.toml`:

### config.toml

```toml
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
sandbox_mode = "danger-full-access"
windows_wsl_setup_acknowledged = true
approval_policy = "never"
file_opener = "vscode"
model_provider = "codex"
web_search = "cached"
suppress_unstable_features_warning = true

[history]
persistence = "save-all"

[tui]
notifications = true

[shell_environment_policy]
inherit = "all"
ignore_default_excludes = false

[sandbox_workspace_write]
network_access = true

[features]
plan_tool = true
apply_patch_freeform = true
view_image_tool = true
unified_exec = false
streamable_shell = false
rmcp_client = true
elevated_windows_sandbox = true

[profiles.auto-max]
approval_policy = "never"
sandbox_mode = "workspace-write"

[profiles.review]
approval_policy = "on-request"
sandbox_mode = "workspace-write"

[notice]
hide_gpt5_1_migration_prompt = true

[model_providers.codex]
name = "codex"
base_url = "https://api.lmuai.com"
wire_api = "responses"

[model_providers.codex.http_headers]
Authorization = "Bearer your sk- key generated in the console"
```

<Callout type="warn" title="Der Key kommt in einen Request-Header">

- Ersetzen Sie in der letzten Zeile "your sk- key generated in the console" durch Ihren `sk-`-Key und **lassen Sie ein Leerzeichen zwischen `Bearer` und dem Key**, z. B. `Authorization = "Bearer sk-xxxx"`
- Setzen Sie den Abschnitt `[model_providers.codex.http_headers]` **ganz an das Ende** der Datei, ohne weitere Einstellungen danach
- Neuere Codex-Versionen benötigen kein `auth.json` mehr. Wenn Sie nach der alten Anleitung eines erstellt haben, ist es unschädlich, es liegen zu lassen, oder Sie können es löschen (behalten Sie es, wenn Sie den [Skill zur Bildgenerierung der Codex App](/de/docs/tools/codex-api-image) nutzen)
- Wenn Ihre alte Konfiguration im Abschnitt `[model_providers.codex]` die Zeile `requires_openai_auth = true` enthält, löschen Sie einfach diese Zeile

</Callout>

## Schritt 5 — Codex CLI starten

Öffnen Sie nach dem Speichern der Konfigurationsdateien das Terminal erneut und führen Sie Folgendes aus, um automatisch zu starten und sich anzumelden:

```bash
codex --dangerously-bypass-approvals-and-sandbox
```

Oder die Kurzform:

```bash
codex --yolo
```

> Dieser Startbefehl überspringt die Sicherheitsbestätigungen, sodass Sie nicht jeden automatisch ausgeführten Schritt bestätigen müssen.

Bei erfolgreichem Start zeigt die Oberfläche als aktuelles Modell `gpt-5.4 xhigh` an (das über das Feld `model` in `config.toml` eingestellte Modell).

## 1M-Kontext in Codex aktivieren (optional)

`gpt-5.4` unterstützt ein **Langkontextfenster von 1M Token** (standardmäßig nur 272K), nützlich für das Durchsehen sehr großer Repos, die Analyse langer Logs, Refactoring über mehrere Dateien hinweg und ähnliche Aufgaben. Codex aktiviert das 1M-Fenster **nicht** standardmäßig; Sie müssen es explizit in `config.toml` deklarieren.

### So konfigurieren Sie es: zwei Zeilen in config.toml ergänzen

Bearbeiten Sie `C:\users\your-username\.codex\config.toml` und fügen Sie Folgendes auf der **obersten Ebene** ein (vor jedem `[section]`, z. B. direkt nach `model = "gpt-5.4"`):

```toml
model_context_window = 1000000
model_auto_compact_token_limit = 900000
```

Speichern, das Terminal erneut öffnen und Codex neu starten, damit es wirksam wird.

**Feldreferenz**

| Feld | Zweck |
|------|------|
| `model_context_window` | Deklariert das nutzbare Kontextfenster des Modells in Token; `1000000` entspricht 1M. Ohne Angabe wird der Modellstandard (272K) verwendet |
| `model_auto_compact_token_limit` | Der Token-Schwellenwert, der die automatische Verdichtung des Verlaufs (Auto-Compact) auslöst; setzen Sie ihn auf etwa 90 % des Fensters (`900000` bei 1M). Werte über 90 % des Fensters werden von Codex begrenzt, ein größerer Wert ist also sinnlos |

### Wirksamkeit überprüfen

Geben Sie nach dem Neustart von Codex `/status` ein und prüfen Sie, ob `context window` etwa 1M anzeigt (manche Versionen zeigen rund 950K — eine von Codex reservierte Sicherheitsmarge von 5 %). Sie können außerdem `/statusline` verwenden, um die Kontextnutzung in der Statusleiste für die laufende Überwachung anzuzeigen.

### Wenn Sie CC Switch verwenden

Wenn Sie die Codex-Konfiguration mit [CC Switch](/de/docs/tools/cc-switch) verwalten, fügen Sie dieselben zwei Zeilen in dessen Codex-Konfigurationseditor ein und übernehmen Sie die Änderung — der Effekt ist identisch:

![Setzen von model_context_window = 1000000 und model_auto_compact_token_limit = 900000 für die Codex-Konfiguration in CC Switch, um den 1M-Token-Langkontext zu aktivieren](/images/tools/codex/codex-ccs.png)

<Callout type="warn" title="Hinweise zur Nutzung">

- **Muss auf der obersten Ebene stehen**: Diese zwei Felder werden innerhalb eines `[profiles.xxx]`-Abschnitts nicht wirksam (eine bekannte Codex-Einschränkung); legen Sie sie außerdem in die benutzerbezogene `C:\users\your-username\.codex\config.toml`, da eine projektbezogene `.codex\config.toml` ignoriert werden kann
- **Modellunterstützung**: `gpt-5.4` und `gpt-5.5` unterstützen 1M über den API-Kanal; Modelle wie `gpt-5.3-codex` sind auf 272K begrenzt, und kein Konfigurationswert kann das Limit des Modells selbst überschreiten
- **Höhere Kosten**: Je länger der Kontext, desto mehr Token verbraucht jede Anfrage; der Anteil über 272K wird zur höheren Langkontext-Stufe abgerechnet, lassen Sie es also nur für sehr lange Aufgaben aktiviert
- **Versionsunterschiede**: Einige neuere Codex-Versionen lesen die Fenstergröße zuerst aus dem Modellkatalog; wenn `/status` weiterhin den alten Wert anzeigt, aktualisieren Sie auf die neueste Version (`npm i -g @openai/codex@latest`) und versuchen Sie es erneut

</Callout>
