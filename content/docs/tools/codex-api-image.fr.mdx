[api-image](https://github.com/yc-duan/api-image) est un skill communautaire (sous licence MIT) : en mode API, l'app Codex n'intègre pas de génération d'images, et une fois ce skill installé, elle peut générer des images via le point de terminaison d'images compatible OpenAI que vous configurez vous-même. Il réutilise la clé et le point de terminaison présents dans votre `~/.codex`, et une seule phrase dans la conversation suffit.

<Callout type="warn" title="Skill communautaire tiers">

Il s'exécute sur votre machine, lit la clé depuis `~/.codex/auth.json` et envoie votre prompt et vos images de référence au fournisseur — assurez-vous que cela vous convient avant de l'installer. L'auteur signale également que la compatibilité varie d'un fournisseur à l'autre : traitez donc les messages d'erreur réels comme la source de vérité.

</Callout>

---

## Préparation : conserver auth.json

Ce skill lit la clé depuis `~/.codex/auth.json` (sous Windows, `%USERPROFILE%\.codex\auth.json`). Le [guide de l'app Codex](/fr/docs/tools/codex-app) mis à jour place désormais la clé dans un en-tête de requête dans `config.toml` et n'a plus besoin de `auth.json`, mais pour utiliser ce skill vous devez en conserver un, contenant la même clé :

```json
{
  "OPENAI_API_KEY": "your sk- key generated in the console"
}
```

Si vous avez déjà créé `auth.json` en suivant l'ancien guide, laissez-le tel quel.

---

## Installation : une phrase à Codex

Ouvrez l'app Codex et dites simplement :

> Installe le skill depuis https://github.com/yc-duan/api-image — je veux générer des images avec l'API standard OpenAI image 2 ; consulte les instructions d'utilisation sur https://github.com/yc-duan/api-image

Codex place lui-même le dépôt dans `~/.codex/skills/api-image` (`%USERPROFILE%\.codex\skills\api-image` sous Windows) ; **redémarrez ensuite l'app Codex**.

L'installation manuelle fonctionne aussi :

```bash
git clone https://github.com/yc-duan/api-image.git ~/.codex/skills/api-image
```

## Utilisation : toujours une seule phrase

| Ce que vous voulez | Ce qu'il faut dire |
|------|------|
| Texte vers image | Utilise api-image pour générer une photo cinématographique 2048x1152 : une rue de Tokyo sous la pluie la nuit, reflets de néons, style photographie réaliste |
| Image vers image | En prenant la composition et la pose de cette image comme référence, génère une illustration chaleureuse — conserve la pose du sujet, ne copie pas l'original |
| Retouche localisée | Change la tasse rouge de cette image en vert, en conservant la forme, la composition et l'éclairage d'origine |
| Options explicites | Utilise api-image pour générer une illustration plate 1024x1024, qualité low, deux images, enregistrées dans ./public/cover.png |

Les valeurs par défaut sont `gpt-image-2`, `2048x1152`, qualité high, une image ; la taille, la qualité, le nombre d'images et le chemin de sortie peuvent tous être modifiés directement dans la conversation. Le résultat arrive par défaut dans le répertoire de travail courant (`provider-image-<timestamp>.png`).

---

## Remarques

- **Pour LMU AI, conservez simplement `auth.json`** : le skill lit `auth.json` (la clé) et `config.toml` (le point de terminaison), ce qui correspond aux points de terminaison complets `https://api.lmuai.com/v1/images/generations` et `/v1/images/edits`
- `model_not_found` / 403 : le groupe associé à votre clé n'inclut pas le modèle d'image — vérifiez « Modèles disponibles » dans la console ou changez de groupe
- `gpt-image-2` ne prend pas en charge les fonds transparents ; le service en amont peut normaliser les tailles demandées, fiez-vous donc au résultat réel
