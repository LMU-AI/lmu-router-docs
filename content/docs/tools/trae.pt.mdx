O editor [Trae](https://www.trae.ai/) **suporta nativamente a conexão a uma API de terceiros** (o protocolo compatível com Anthropic), sem plugin para instalar e sem arquivo de configuração para escrever — a maneira mais simples de conectar uma API de terceiros de qualquer editor. **Ele suporta tanto os modelos oficiais Claude quanto os grandes modelos chineses (GLM, Qwen, DeepSeek, Kimi, etc.)**.

<Callout type="info" title="Método nativo vs plugin Codex — qual escolher?">

- **Quer Claude / modelos chineses** → o método nativo desta página (protocolo Anthropic, alguns cliques na interface gráfica)
- **Quer a série GPT-5 / Codex** → veja o [plugin oficial Codex](/pt/docs/tools/vscode-plugin) (protocolo OpenAI, arquivo de configuração escrito à mão)

As duas abordagens podem coexistir — se você quiser usar ambos os tipos de modelo, basta configurar os dois.

</Callout>

## Passos de configuração

1. Abra o Trae e vá em **Configurações → Modelos → Adicionar Modelo**
2. Defina **Provedor** como **Anthropic**
3. Defina **Modelo** como **Modelo Personalizado** (no fim do menu suspenso), depois insira o nome do modelo na caixa **ID do Modelo** abaixo (veja a tabela de modelos comuns adiante)
4. Defina a **URL de requisição personalizada** como:
   ```
   https://api.lmuai.com/v1/messages
   ```
5. Defina a **chave de API** como a chave que você gerou no console da LMU AI (começa com `sk-`)
6. Clique em **Confirmar** para salvar, depois mude para esse modelo para começar a usá-lo

## Problemas comuns

### Método nativo ou o plugin Codex?

- **Método nativo (esta página)**: usa o protocolo Anthropic e leva apenas alguns cliques na interface gráfica — melhor para usuários que querem modelos como **Claude / GLM / Qwen**
- **[Método do plugin Codex](/pt/docs/tools/vscode-plugin)**: usa o protocolo OpenAI e requer um arquivo de configuração escrito à mão — melhor para usuários que querem a série **GPT / Codex**

As duas abordagens podem coexistir — se você quiser usar ambos os tipos de modelo, basta configurar os dois.

### Por que a URL de requisição precisa terminar em `/v1/messages`?

A URL de requisição personalizada do Trae exige o **endpoint completo** (ao contrário de ferramentas como o Chatbox, que anexam o caminho automaticamente). O endpoint de chat do protocolo Anthropic é sempre `/v1/messages`, então a URL completa é `https://api.lmuai.com/v1/messages`.

### Onde encontro os IDs dos modelos?

Veja a lista completa de modelos disponíveis na [Galeria de Modelos](/pt/docs/guide/models). Clique em qualquer card para copiar seu ID de modelo e cole-o diretamente na caixa ID do Modelo do Trae.

### Sem resposta ou erro após adicionar?

- O provedor está definido como **Anthropic** (não OpenAI)?
- Você escolheu Modelo Personalizado no menu suspenso de modelos e depois digitou o ID do modelo manualmente?
- A URL de requisição termina em `/v1/messages`?
- A chave de API é a chave `sk-` gerada no console da LMU AI?

Salve e reinicie o cliente Trae uma vez.
