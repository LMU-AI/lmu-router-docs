لتهيئة Codex CLI في بيئة خادم WSL2 أو SSH البعيد.

---

## خطوات التهيئة

### الخطوة 1 — تثبيت بيئة Node.js (باستخدام volta)

في طرفية الخادم، نفّذ:

```bash
curl https://get.volta.sh | bash
```

### الخطوة 2 — تثبيت Node 20

<Callout type="warn" title="ملاحظة">

بعد تثبيت volta بنجاح، **يجب أن تفتح نافذة طرفية جديدة** قبل تنفيذ الأمر التالي:

</Callout>

```bash
volta install node@20
```

### الخطوة 3 — تثبيت Codex CLI

```bash
volta install @openai/codex
```

### الخطوة 4 — إنشاء ملفات التهيئة

نفّذ ما يلي في طرفية الخادم لكتابة كلٍّ من `~/.codex/config.toml` و `~/.codex/auth.json` دفعة واحدة (**تذكّر استبدال المفتاح في auth.json بمفتاح `sk-` المُنشأ في لوحة التحكم**):

```bash
mkdir -p ~/.codex

cat > ~/.codex/config.toml <<'EOF'
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
sandbox_mode = "danger-full-access"
windows_wsl_setup_acknowledged = true
approval_policy = "never"
file_opener = "vscode"
model_provider = "codex"
web_search = "cached"
suppress_unstable_features_warning = true

[history]
persistence = "save-all"

[tui]
notifications = true

[shell_environment_policy]
inherit = "all"
ignore_default_excludes = false

[sandbox_workspace_write]
network_access = true

[features]
plan_tool = true
apply_patch_freeform = true
view_image_tool = true
unified_exec = false
streamable_shell = false
rmcp_client = true
elevated_windows_sandbox = true

[profiles.auto-max]
approval_policy = "never"
sandbox_mode = "workspace-write"

[profiles.review]
approval_policy = "on-request"
sandbox_mode = "workspace-write"

[notice]
hide_gpt5_1_migration_prompt = true

[model_providers.codex]
name = "codex"
base_url = "https://api.lmuai.com"
wire_api = "responses"
requires_openai_auth = true
EOF

cat > ~/.codex/auth.json <<'EOF'
{
  "OPENAI_API_KEY": "your sk- key generated in the console"
}
EOF
```

محتوى التهيئة مطابق لدليل [Codex CLI (Mac/Linux)](/ar/docs/tools/codex-cli-mac) — يمكنك أيضًا إنشاء الملفين يدويًا باستخدام `vim` / `nano`.

### الخطوة 5 — تشغيل Codex CLI

```bash
codex --dangerously-bypass-approvals-and-sandbox
```

أو:

```bash
codex --yolo
```

## تفعيل سياق 1M (اختياري)

يدعم `gpt-5.4` سياقًا طويلًا يصل إلى 1M توكن، لكنه معطّل افتراضيًا. عدّل `~/.codex/config.toml`، وأضِف سطرين على **المستوى الأعلى** من الملف (قبل أي `[section]`)، ثم أعد الدخول إلى Codex:

```toml
model_context_window = 1000000
model_auto_compact_token_limit = 900000
```

لمعرفة معاني الحقول وكيفية التحقق والملاحظات المهمة، راجع [تفعيل سياق 1M في Codex](/ar/docs/tools/codex-cli-mac#enabling-the-1m-context-in-codex-optional).
