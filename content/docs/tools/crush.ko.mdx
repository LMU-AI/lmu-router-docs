Crush는 [Charm](https://charm.land)에서 만든 터미널 AI 코딩 도구로, 명령줄에서 코드 생성, 디버깅, 대화, 파일 작업, 멀티태스킹을 위한 CLI와 TUI를 모두 제공합니다. 커스텀 프로바이더를 지원하며 — 이 페이지에서는 LMU AI에 연결하는 방법을 다룹니다.

## LMU AI 구성

Crush는 **Bash 스크립트**로 구성됩니다. 전역 설정 파일을 편집하세요:

- **macOS / Linux**: `~/.config/crush/crushrc`
- **Windows**: `%USERPROFILE%\.config\crush\crushrc`

두 단계가 있습니다: `provider add`로 LMU AI를 프로바이더로 추가한 다음, `model add`로 사용하려는 모델을 등록하세요. 사용할 모델에 맞는 프로토콜을 선택하세요:

<Tabs items={['GPT / 일반 (openai-compat)', 'Claude / 중국 모델 (anthropic)']}>
<Tab value="GPT / general (openai-compat)">

`gpt-5.6-sol` 및 `gpt-5.5` 같은 OpenAI 모델에 적합합니다. Claude 및 중국 모델도 이 프로토콜을 통해 사용할 수 있습니다(LMU AI 백엔드가 프로토콜 변환을 처리합니다).

```bash
# Add LMU AI as a provider (OpenAI-compatible protocol)
provider add lmuai \
  --type openai-compat \
  --base-url "https://api.lmuai.com/v1" \
  --api-key "sk-your-lmu-ai-api-key"

# Register the models you want
model add lmuai/gpt-5.6-sol --name "GPT-5.6 Sol" --context-window 400000
model add lmuai/claude-opus-5 --name "Claude Opus 5" --context-window 200000

# Set it as the default large-model slot
model large lmuai/claude-opus-5
```

<Callout type="warn" title="유형은 openai가 아니라 openai-compat입니다">

Crush에는 두 가지 OpenAI 유형이 있습니다. 공식 문서에 따르면 `openai`는 **OpenAI 자체를 통해** 요청을 프록시하거나 라우팅하기 위한 것이고, `openai-compat`은 **OpenAI 호환 API를 제공하는 비OpenAI 프로바이더**를 위한 것입니다. LMU AI는 후자이므로 `openai-compat`을 사용하세요.

</Callout>

</Tab>
<Tab value="Claude / Chinese models (anthropic)">

`claude-opus-5`, `claude-sonnet-5`, `qwen3.8-max-preview`, `deepseek-v4-pro`, `glm-5.2`, `kimi-k3`와 같이 Anthropic 프로토콜로 제공되는 모델에 적합합니다.

```bash
# Add LMU AI as a provider (Anthropic protocol)
provider add lmuai-anthropic \
  --type anthropic \
  --base-url "https://api.lmuai.com" \
  --api-key "sk-your-lmu-ai-api-key" \
  --extra-header anthropic-version 2023-06-01

# Register the models you want
model add lmuai-anthropic/claude-opus-5 \
  --name "Claude Opus 5" \
  --context-window 200000 \
  --can-reason true \
  --supports-images true

model add lmuai-anthropic/glm-5.2 --name "GLM-5.2" --context-window 200000

# Set it as the default large-model slot
model large lmuai-anthropic/claude-opus-5
```

<Callout type="warn" title="Anthropic base URL에 /v1을 추가하지 마세요">

`--base-url`을 `https://api.lmuai.com`으로 설정하세요 — `https://api.lmuai.com/v1`이 **아닙니다**. Crush가 스스로 `/v1/messages`를 덧붙이므로, 추가 세그먼트가 있으면 `/v1/v1/messages`를 요청하게 되어 다음과 같이 실패합니다:

```
not found: POST "https://api.lmuai.com/v1/v1/messages": 404 Not Found
```

이것은 `openai-compat`(이쪽은 `/v1`이 필요함)과 정반대입니다 — 혼동하지 마세요.

</Callout>

</Tab>
</Tabs>

<Callout type="warn" title="설정 파일은 신뢰된 코드입니다">

공식 경고: `crushrc`는 UI가 나타나기 전에 셸 권한으로 실행되며, `crush.json`의 모든 `$(...)`는 로드 시점에 실행됩니다. **검토하지 않은 설정이 있는 디렉터리에서 Crush를 실행하지 마세요**. 그리고 출처를 알 수 없는 설정 파일을 `source`하지 마세요.

</Callout>

## 사용 시작

구성 후 Crush를 다시 시작하세요:

```bash
crush
```

세션 내에서 다음으로 모델을 전환하세요:

```
/models
```

<Callout type="info" title="LMU AI 모델이 /models에 없나요?">

Crush의 내장 모델 목록은 [Catwalk](https://github.com/charmbracelet/catwalk) 데이터베이스에서 가져오는데, 여기에는 LMU AI 모델 ID가 포함되어 있지 않습니다. 먼저 `model add <provider>/<model-id>`로 등록해야 하며 — 다시 시작한 후 `/models` 목록에 나타납니다.

</Callout>

## 레거시 JSON 설정

<Callout type="warn" title="crush.json은 공식적으로 더 이상 사용되지 않습니다">

Crush는 원래 `crush.json`을 사용했지만, 이제 **더 이상 사용되지 않습니다(deprecated)** — 관리자들은 계속 지원할 것이라고 밝혔지만, 새로운 설정 옵션은 Bash 설정(`crushrc`)에만 추가됩니다. 많은 튜토리얼이 여전히 JSON 형식을 가르치지만, **새 설정은 위에서 보여준 대로 `crushrc`를 사용해야 합니다**.

이미 JSON 설정이 있고 마이그레이션하고 싶나요? Crush를 실행하고 일상 언어로 변환해 달라고 요청하기만 하면 됩니다.

</Callout>

JSON을 사용하려는 경우 형식은 다음과 같습니다(프로젝트 디렉터리 또는 `~/.config/crush/` 아래의 `crush.json`에):

```json
{
  "$schema": "https://charm.land/crush.json",
  "providers": {
    "lmuai": {
      "id": "lmuai",
      "name": "LMU AI",
      "type": "openai-compat",
      "base_url": "https://api.lmuai.com/v1",
      "api_key": "sk-your-lmu-ai-api-key",
      "models": [
        {
          "id": "claude-opus-5",
          "name": "Claude Opus 5",
          "context_window": 200000,
          "default_max_tokens": 32000
        }
      ]
    }
  }
}
```

<Callout type="warn" title="JSON에서 type과 models를 생략하지 마세요">

`id` / `name` / `base_url` / `api_key`만으로는 작동하지 않습니다: `type`은 사용할 프로토콜을 결정하고(생략하면 기본 추측으로 폴백함), `models`는 `/models`에서 선택할 수 있는 것을 결정합니다. 이것이 복사·붙여넣기한 최소 예제가 실패하는 가장 흔한 이유입니다.

</Callout>

## 참고 사항

- 설정 파일은 `~/.config/crush/crushrc`(Windows에서는 `%USERPROFILE%\.config\crush\crushrc`)입니다. `~/.local/share/crush/crush.json`은 머신 소유 상태이므로 **편집하지 마세요**
- LMU AI의 OpenAI 호환 엔드포인트에는 `--type openai-compat`을 사용하고(`openai`가 **아님**), Anthropic 프로토콜에는 `--type anthropic`을 사용하세요
- **두 유형은 반대 형태의 `--base-url`을 취합니다**: `anthropic`은 `https://api.lmuai.com`(`/v1` 없음)을, `openai-compat`은 `https://api.lmuai.com/v1`(`/v1` 포함)을 취합니다. Anthropic 쪽에 `/v1`을 추가하면 `/v1/v1/messages`가 되어 404가 발생합니다
- API 키의 경우 LMU AI 콘솔에서 생성한 `sk-` 키를 입력하기만 하면 됩니다
- LMU AI 모델은 Crush의 내장 목록에 없으므로 `/models`에 나타나려면 `model add`로 등록해야 합니다
