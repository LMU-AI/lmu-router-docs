## Requisitos previos

Antes de comenzar, asegúrate de tener:

1. Una cuenta de LMU AI registrada y con saldo ([Inicio rápido](/es/docs/guide/getting-started))
2. Una clave de API que empieza con `sk-`
3. Hermes Agent instalado ([GitHub](https://github.com/nousresearch/hermes-agent))

## Configurar los modelos de LMU AI

### Método 1 — Crear la configuración con un solo comando

Abre una terminal y ejecuta el siguiente comando:

```bash
mkdir -p ~/.hermes
cat > ~/.hermes/config.yaml << 'EOF'
providers:
  lumai:
    name: lumai
    base_url: https://api.lmuai.com/v1
    api_key: YOUR_API_KEY
    model: glm-5.2

model:
  provider: lumai
  model: glm-5.2
EOF
```

<Callout type="warn" title="Nota">

Reemplaza `YOUR_API_KEY` con la clave `sk-` real que creaste en la consola de LMU AI.

</Callout>

### Método 2 — Editar el archivo de configuración manualmente

Si `~/.hermes/config.yaml` ya existe, ábrelo en un editor:

```bash
hermes config edit
```

Agrega o modifica lo siguiente en el archivo:

```yaml
providers:
  lumai:
    name: lumai
    base_url: https://api.lmuai.com/v1
    api_key: sk-your-actual-key
    model: glm-5.2

model:
  provider: lumai
  model: glm-5.2
```

Guarda y sal.

## Modelos disponibles

En el campo `model`, puedes sustituir por cualquier nombre de modelo que LMU AI admita. Para ver la lista completa de modelos, consulta la [Galería de modelos](/es/docs/guide/models).

## Verificar la configuración

Ejecuta el siguiente comando para probar si la configuración funciona:

```bash
hermes chat -q 'Hello, please reply in one sentence' -Q
```

Si recibes una respuesta de la IA, la configuración funciona.

## Problemas comunes

### Error 401 Unauthorized

La clave de API es incorrecta o expiró. Verifica el estado de la clave en la consola de LMU AI.

### Error 404 Not Found

El `base_url` es incorrecto. Hermes usa el protocolo de OpenAI, por lo que la dirección debe incluir el sufijo `/v1`:

```
https://api.lmuai.com/v1    ✅ Correct
https://api.lmuai.com       ❌ Wrong
```
