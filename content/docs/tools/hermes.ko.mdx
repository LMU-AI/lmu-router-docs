## 사전 준비 사항

시작하기 전에 다음을 준비하세요:

1. LMU AI 계정을 등록하고 충전을 완료했는지 확인 ([빠른 시작](/ko/docs/guide/getting-started))
2. `sk-`로 시작하는 API 키
3. 설치된 Hermes Agent ([GitHub](https://github.com/nousresearch/hermes-agent))

## LMU AI 모델 설정

### 방법 1 — 명령어 하나로 설정 파일 생성

터미널을 열고 다음 명령어를 실행하세요:

```bash
mkdir -p ~/.hermes
cat > ~/.hermes/config.yaml << 'EOF'
providers:
  lumai:
    name: lumai
    base_url: https://api.lmuai.com/v1
    api_key: YOUR_API_KEY
    model: glm-5.2

model:
  provider: lumai
  model: glm-5.2
EOF
```

<Callout type="warn" title="참고">

`YOUR_API_KEY`를 LMU AI 콘솔에서 생성한 실제 `sk-` 키로 교체하세요.

</Callout>

### 방법 2 — 설정 파일을 수동으로 편집

`~/.hermes/config.yaml`이 이미 존재하는 경우 편집기에서 여세요:

```bash
hermes config edit
```

파일에 다음 내용을 추가하거나 수정하세요:

```yaml
providers:
  lumai:
    name: lumai
    base_url: https://api.lmuai.com/v1
    api_key: sk-your-actual-key
    model: glm-5.2

model:
  provider: lumai
  model: glm-5.2
```

저장하고 종료하세요.

## 사용 가능한 모델

`model` 필드에서 LMU AI가 지원하는 모든 모델 이름으로 대체할 수 있습니다. 전체 모델 목록은 [모델 갤러리](/ko/docs/guide/models)를 참고하세요.

## 설정 확인

다음 명령어를 실행하여 설정이 정상적으로 작동하는지 테스트하세요:

```bash
hermes chat -q 'Hello, please reply in one sentence' -Q
```

AI로부터 응답을 받으면 설정이 정상적으로 작동하는 것입니다.

## 자주 발생하는 문제

### 401 Unauthorized 오류

API 키가 잘못되었거나 만료되었습니다. LMU AI 콘솔에서 키의 상태를 확인하세요.

### 404 Not Found 오류

`base_url`이 잘못되었습니다. Hermes는 OpenAI 프로토콜을 사용하므로 주소에 `/v1` 접미사가 포함되어야 합니다:

```
https://api.lmuai.com/v1    ✅ Correct
https://api.lmuai.com       ❌ Wrong
```
