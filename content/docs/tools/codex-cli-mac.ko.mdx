Codex CLI를 설치한 뒤 설정 파일 하나인 `config.toml`만 직접 만들면(키는 이 파일 안의 요청 헤더에 들어갑니다) LMU AI API에 연결할 수 있습니다 — 서드파티 설정 도구는 필요하지 않습니다.

---

## 1단계 — Node.js 설치

**Node.js 20+** 가 필요합니다 — 다운로드: [https://nodejs.org/en/download](https://nodejs.org/en/download)

설치 프로그램을 따라 진행한 뒤 터미널에서 확인하세요:

```bash
node --version
# A version number (e.g. v23.7.0) means it installed correctly
```

## 2단계 — Codex CLI 설치

```bash
npm i -g @openai/codex
```

네트워크 문제가 발생하면 먼저 중국 미러로 전환하세요:

```bash
npm config set registry https://registry.npmmirror.com
npm i -g @openai/codex
```

설치를 확인하세요:

```bash
codex --version
# A version number means it installed correctly
```

## 3단계 — 설정 파일 만들기

설정 디렉터리는 **`~/.codex/`** 입니다(없으면 만들고, 기존 파일은 덮어쓰세요). 이 디렉터리에 `config.toml`을 생성하거나 덮어쓰세요:

### config.toml

```toml
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
sandbox_mode = "danger-full-access"
windows_wsl_setup_acknowledged = true
approval_policy = "never"
file_opener = "vscode"
model_provider = "codex"
web_search = "cached"
suppress_unstable_features_warning = true

[history]
persistence = "save-all"

[tui]
notifications = true

[shell_environment_policy]
inherit = "all"
ignore_default_excludes = false

[sandbox_workspace_write]
network_access = true

[features]
plan_tool = true
apply_patch_freeform = true
view_image_tool = true
unified_exec = false
streamable_shell = false
rmcp_client = true
elevated_windows_sandbox = true

[profiles.auto-max]
approval_policy = "never"
sandbox_mode = "workspace-write"

[profiles.review]
approval_policy = "on-request"
sandbox_mode = "workspace-write"

[notice]
hide_gpt5_1_migration_prompt = true

[model_providers.codex]
name = "codex"
base_url = "https://api.lmuai.com"
wire_api = "responses"

[model_providers.codex.http_headers]
Authorization = "Bearer your sk- key generated in the console"
```

<Callout type="warn" title="키는 요청 헤더에 들어갑니다">

- 마지막 줄의 "콘솔에서 생성한 sk- 키"를 본인의 `sk-` 키로 바꾸고, **`Bearer`와 키 사이에 공백 한 칸을 유지하세요**. 예: `Authorization = "Bearer sk-xxxx"`
- `[model_providers.codex.http_headers]` 섹션은 파일의 **가장 마지막**에 두고, 그 뒤에 다른 설정을 넣지 마세요
- 최신 Codex 버전에서는 `auth.json`이 더 이상 필요하지 않습니다. 예전 가이드대로 만들어 두었다면 그대로 둬도 문제없고, 삭제해도 됩니다([Codex App 이미지 생성 스킬](/ko/docs/tools/codex-api-image)을 사용한다면 남겨 두세요)
- 기존 설정의 `[model_providers.codex]` 섹션에 `requires_openai_auth = true`가 있다면 그 줄만 삭제하세요

</Callout>

## 4단계 — Codex CLI 실행

설정 파일을 저장한 뒤 터미널을 다시 열고 다음을 실행하면 자동으로 실행 및 로그인됩니다:

```bash
codex --dangerously-bypass-approvals-and-sandbox
```

또는 짧은 형태로:

```bash
codex --yolo
```

> 이 실행 명령은 보안 승인을 건너뛰므로, 자동 실행되는 각 단계를 일일이 승인하지 않아도 됩니다.

정상적으로 실행되면 인터페이스에 현재 모델이 `gpt-5.4 xhigh`로 표시됩니다(`config.toml`의 `model` 필드에서 설정한 모델입니다).

<Callout type="info" title="모델 전환에 대하여">

세션 중에 실수로 다른 모델로 전환한 경우, `~/.codex/config.toml`의 `model` 필드를 다시 `gpt-5.4`로 바꾸고 터미널을 재시작하면 복원됩니다.

</Callout>

## Codex에서 1M 컨텍스트 활성화(선택)

`gpt-5.4`는 **1M 토큰 롱 컨텍스트 윈도**를 지원합니다(기본값은 272K). 대규모 리포지터리 리뷰, 긴 로그 분석, 파일 간 리팩터링에 유용합니다. Codex는 1M 윈도를 기본으로 활성화하지 **않으므로**, `config.toml`에 명시적으로 선언해야 합니다.

### 설정 방법: config.toml에 두 줄 추가

`~/.codex/config.toml`을 편집해 **최상위 레벨**(어떤 `[section]`보다 앞, 예를 들어 `model = "gpt-5.4"` 바로 뒤)에 다음을 추가하세요:

```toml
model_context_window = 1000000
model_auto_compact_token_limit = 900000
```

저장하고 터미널을 다시 열어 Codex에 재진입하면 적용됩니다.

**필드 설명**

| 필드 | 용도 |
|------|------|
| `model_context_window` | 모델이 사용할 수 있는 컨텍스트 윈도를 토큰 단위로 선언합니다. `1000000`은 1M입니다. 설정하지 않으면 모델 기본값(272K)을 사용합니다 |
| `model_auto_compact_token_limit` | 대화 기록 자동 압축을 트리거하는 토큰 임계값입니다. 윈도의 약 90%로 설정하세요(1M이면 `900000`). 윈도의 90%를 초과하는 값은 Codex가 제한하므로 더 큰 숫자를 넣어도 의미가 없습니다 |

### 적용 여부 확인

Codex에 재진입한 뒤 `/status`를 입력해 `context window`가 약 1M으로 표시되는지 확인하세요(일부 버전은 약 950K로 표시되며, Codex가 5%의 안전 여유를 예약한 것입니다). `/statusline`으로 상태 바에 컨텍스트 사용량을 추가해 실시간으로 모니터링할 수도 있습니다.

### CC Switch를 사용하는 경우

[CC Switch](/ko/docs/tools/cc-switch)로 Codex 설정을 관리한다면, 해당 도구의 Codex 설정 편집기에 같은 두 줄을 추가하고 적용하면 동일한 효과를 얻습니다:

![CC Switch에서 Codex 설정에 model_context_window = 1000000과 model_auto_compact_token_limit = 900000을 설정해 1M 토큰 롱 컨텍스트를 활성화하는 모습](/images/tools/codex/codex-ccs.png)

<Callout type="warn" title="사용 시 유의사항">

- **최상위 레벨에 있어야 합니다**: 이 두 필드는 `[profiles.xxx]` 섹션 안에서는 적용되지 않습니다(알려진 Codex 제한). 또한 프로젝트 레벨 `.codex/config.toml`은 무시될 수 있으므로 사용자 레벨 `~/.codex/config.toml`에 넣으세요
- **모델 지원**: `gpt-5.4`와 `gpt-5.5`는 API 채널에서 1M을 지원합니다. `gpt-5.3-codex` 같은 모델은 272K로 제한되며, 어떤 설정값도 모델 자체의 한계를 넘을 수는 없습니다
- **비용 증가**: 컨텍스트가 길어지면 요청당 토큰 사용량이 늘어납니다. 272K를 초과하는 부분은 더 높은 롱 컨텍스트 요율로 과금되므로, 아주 긴 작업이 아니라면 계속 켜두지 마세요
- **버전 차이**: 일부 최신 Codex 버전은 모델 카탈로그에서 윈도 크기를 먼저 읽습니다. `/status`에 여전히 예전 값이 표시되면 최신 버전으로 업그레이드(`npm i -g @openai/codex@latest`)한 뒤 다시 시도하세요

</Callout>
