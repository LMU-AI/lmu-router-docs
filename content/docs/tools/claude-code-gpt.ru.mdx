Claude Code может вызывать модели GPT через LMU AI API, например `gpt-5.6-sol`, `gpt-5.6-terra` и `gpt-5.5`.

<Callout type="warn" title="Предварительные требования">

Вам необходимо выполнить одно из следующих условий:

- Подписаться на **план GPT**
- Использовать оплату по факту использования и выбрать **группу GPT** в консоли LMU AI

Если ваш текущий план или группа не включает модели GPT, вы можете получить ошибку отсутствия прав или недоступности модели даже после настройки.

</Callout>

## Вариант 1 — Полная конфигурация (рекомендуется)

Полная конфигурация сопоставляет внутренние модели по умолчанию Claude Code (Opus / Sonnet / Haiku) с моделями GPT. После настройки запуск Claude Code по умолчанию использует соответствующую модель GPT.

Откройте `settings.json` в текстовом редакторе и добавьте следующее (замените ключ на свой собственный LMU AI API Key):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "sk-your-lmu-ai-api-key",
    "ANTHROPIC_BASE_URL": "https://api.lmuai.com",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "gpt-5.4",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL_NAME": "gpt-5.4",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "gpt-5.6-sol",
    "ANTHROPIC_DEFAULT_OPUS_MODEL_NAME": "gpt-5.6-sol",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "gpt-5.5",
    "ANTHROPIC_DEFAULT_SONNET_MODEL_NAME": "gpt-5.5"
  },
  "skipDangerousModePermissionPrompt": true,
  "model": "opus"
}
```

**Справочник по полям:**

| Поле | Описание |
|------|------|
| `ANTHROPIC_AUTH_TOKEN` | LMU AI API Key — введите свой собственный ключ `sk-` |
| `ANTHROPIC_BASE_URL` | Адрес LMU AI API; для Claude Code используйте `https://api.lmuai.com`, без `/v1` |
| `ANTHROPIC_DEFAULT_OPUS_MODEL` / `ANTHROPIC_DEFAULT_OPUS_MODEL_NAME` | Сопоставляет модель Opus по умолчанию в Claude Code с `gpt-5.6-sol` |
| `ANTHROPIC_DEFAULT_SONNET_MODEL` / `ANTHROPIC_DEFAULT_SONNET_MODEL_NAME` | Сопоставляет модель Sonnet по умолчанию с `gpt-5.5` |
| `ANTHROPIC_DEFAULT_HAIKU_MODEL` / `ANTHROPIC_DEFAULT_HAIKU_MODEL_NAME` | Сопоставляет модель Haiku по умолчанию с `gpt-5.4` |
| `model` | Уровень модели, выбираемый при запуске Claude Code; здесь это `opus`, который сопоставляется с `gpt-5.6-sol` выше |

<Callout type="info" title="Сопоставление моделей">

С полной конфигурацией выше:

- Выбор `opus` в Claude Code → фактически вызывает `gpt-5.6-sol`
- Выбор `sonnet` в Claude Code → фактически вызывает `gpt-5.5`
- Выбор `haiku` в Claude Code → фактически вызывает `gpt-5.4`

</Callout>

## Вариант 2 — Минимальная конфигурация

Если вы просто хотите сначала настроить ключ и Base URL, можете использовать минимальную конфигурацию:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "sk-your-lmu-ai-api-key",
    "ANTHROPIC_BASE_URL": "https://api.lmuai.com"
  },
  "skipDangerousModePermissionPrompt": true,
  "model": "opus"
}
```

Минимальная конфигурация не сопоставляет `opus` с `gpt-5.6-sol` заранее. После запуска Claude Code выполните вручную в Claude Code:

```bash
/model gpt-5.6-sol
```

Текущая сессия затем переключится на `gpt-5.6-sol`.

<Callout type="info" title="Когда использовать минимальную конфигурацию?">

Если вы часто переключаетесь между разными моделями GPT, используйте минимальную конфигурацию и указывайте нужную с помощью `/model <имя-модели>` после каждого запуска, например `/model gpt-5.6-sol`.

Если вы хотите, чтобы `gpt-5.6-sol` был моделью по умолчанию при каждом запуске, используйте полную конфигурацию выше.

</Callout>

## Распространённые проблемы

### Должен ли Base URL включать `/v1`?

Claude Code подключается к LMU AI API по протоколу Anthropic, поэтому используйте:

```text
https://api.lmuai.com
```

Не используйте `https://api.lmuai.com/v1`.

### Могу ли я просто указать `model` как `gpt-5.6-sol`?

Мы рекомендуем один из двух подходов вместо этого:

- Использовать полную конфигурацию, сопоставив `ANTHROPIC_DEFAULT_OPUS_MODEL` с `gpt-5.6-sol` и оставив `"model": "opus"`
- Использовать минимальную конфигурацию и запустить `/model gpt-5.6-sol` после старта

Оба подхода лучше соответствуют принципу настройки уровней моделей в Claude Code и делают переключение и откат более понятными.

### Что делать, если после настройки всё ещё не работает?

Проверьте следующее:

1. Является ли API Key ключом, сгенерированным в консоли LMU AI
2. Является ли `ANTHROPIC_BASE_URL` значением `https://api.lmuai.com`
3. Подписаны ли вы на план GPT или, при оплате по факту использования, выбрали ли группу GPT
4. Правильно ли написано имя модели, например `gpt-5.6-sol`

Чтобы увидеть текущие поддерживаемые модели, откройте [Галерею моделей](/ru/docs/guide/models).
