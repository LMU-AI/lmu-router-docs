Редактор [Trae](https://www.trae.ai/) **нативно поддерживает подключение к стороннему API** (протокол, совместимый с Anthropic), без установки плагина и без написания конфигурационного файла — это простейший способ подключить сторонний API среди всех редакторов. **Он поддерживает как официальные модели Claude, так и китайские большие модели (GLM, Qwen, DeepSeek, Kimi и т. д.)**.

<Callout type="info" title="Нативный метод или плагин Codex — что выбрать?">

- **Нужны Claude / китайские модели** → нативный метод на этой странице (протокол Anthropic, несколько кликов в графическом интерфейсе)
- **Нужна серия GPT-5 / Codex** → см. [официальный плагин Codex](/ru/docs/tools/vscode-plugin) (протокол OpenAI, конфигурационный файл, написанный вручную)

Оба подхода могут сосуществовать — если вы хотите использовать оба типа моделей, просто настройте оба.

</Callout>

## Шаги настройки

1. Откройте Trae и перейдите в **Settings → Models → Add Model**
2. Задайте **Provider** как **Anthropic**
3. Задайте **Model** как **Custom Model** (внизу выпадающего списка), затем введите имя модели в поле **Model ID** ниже (см. таблицу распространённых моделей ниже)
4. Задайте **Custom request URL** как:
   ```
   https://api.lmuai.com/v1/messages
   ```
5. Задайте **API key** как ключ, сгенерированный вами в консоли LMU AI (начинается с `sk-`)
6. Нажмите **Confirm**, чтобы сохранить, затем переключитесь на эту модель, чтобы начать её использовать

## Частые проблемы

### Нативный метод или плагин Codex?

- **Нативный метод (эта страница)**: использует протокол Anthropic и требует всего нескольких кликов в графическом интерфейсе — лучше всего для пользователей, которым нужны модели вроде **Claude / GLM / Qwen**
- **[Метод с плагином Codex](/ru/docs/tools/vscode-plugin)**: использует протокол OpenAI и требует конфигурационного файла, написанного вручную — лучше всего для пользователей, которым нужна серия **GPT / Codex**

Оба подхода могут сосуществовать — если вы хотите использовать оба типа моделей, просто настройте оба.

### Почему URL запроса должен заканчиваться на `/v1/messages`?

Custom request URL в Trae требует **полного эндпоинта** (в отличие от инструментов вроде Chatbox, которые добавляют путь автоматически). Эндпоинт чата в протоколе Anthropic всегда `/v1/messages`, поэтому полный URL — `https://api.lmuai.com/v1/messages`.

### Где найти идентификаторы моделей?

Полный список доступных моделей см. в [Галерее моделей](/ru/docs/guide/models). Нажмите на любую карточку, чтобы скопировать её идентификатор модели, и вставьте его прямо в поле Model ID в Trae.

### Нет ответа или ошибка после добавления?

- Задан ли провайдер как **Anthropic** (а не OpenAI)?
- Выбрали ли вы Custom Model в выпадающем списке моделей и затем ввели идентификатор модели вручную?
- Заканчивается ли URL запроса на `/v1/messages`?
- Является ли API-ключ ключом `sk-`, сгенерированным в консоли LMU AI?

Сохраните и перезапустите клиент Trae один раз.
