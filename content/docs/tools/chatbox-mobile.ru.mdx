Мобильный Chatbox (iOS / Android) использует ту же логику настройки, что и настольная версия — различаются лишь точка входа и названия полей. Это руководство проходит её экран за экраном для мобильного устройства; для настольной версии см. [Chatbox — все платформы](./chatbox).

<Callout type="info" title="Почти то же, что и на десктопе">

- **Другая точка входа**: на мобильном устройстве вы открываете Settings через **меню ☰ в верхнем левом углу**; на десктопе это Settings в нижнем левом углу.
- **Те же поля**: на мобильном устройстве они называются **API Host** и **API Path**, полностью совпадая с настольной версией — просто следуйте шагам ниже.

</Callout>

## Загрузка и установка

- **Официальный сайт**: [https://chatboxai.app](https://chatboxai.app)
- Установите из App Store (iOS) либо из магазина приложений / официального APK (Android) — для режима bring-your-own-key (BYOK) аккаунт не требуется.

---

## Открытие точки входа в настройки

Откройте Chatbox → нажмите **значок меню ☰ в верхнем левом углу**, чтобы открыть боковую панель → нажмите **Settings** → перейдите в **Model Provider** → нажмите **Add** внизу.

Оказавшись на экране настройки, заполните его, следуя Способу 1 / Способу 2 ниже.

---

## Два протокола

LMU AI поддерживает два протокола подключения; выберите один в зависимости от типа модели:

| Протокол | Модели | API Host | API Path |
|------|----------|----------|----------|
| **Claude API (Anthropic Compatible)** | Модели Claude, китайские модели (DeepSeek, Qwen, GLM, Kimi и др.) | `https://api.lmuai.com` | По умолчанию подходит |
| **OpenAI Responses API Compatible** | Модели OpenAI (GPT-5.6 / GPT-5.5 и др.) | `https://api.lmuai.com` | `/responses` |

<Callout type="info" title="API Host никогда не включает /v1">

Chatbox добавляет путь автоматически, поэтому **всегда вводите API Host только до домена — не включайте `/v1`**. После заполнения полный собранный адрес отображается вживую под полями — например, для протокола OpenAI Responses получается `https://api.lmuai.com/v1/responses`. **Если домен не `api.lmuai.com`, значит API Host указан неверно.**

</Callout>

## Способ 1: протокол Anthropic (Claude и китайские модели)

1. **API Mode**: выберите **`Claude API (Anthropic Compatible)`**
2. **Name**: любое на ваш выбор (например, `LMU AI`)
3. **API Host**: введите `https://api.lmuai.com` (**без** `/v1`)
4. **API Key**: введите ключ `sk-`, сгенерированный в консоли
5. **Добавление моделей**: предустановленный список на мобильном устройстве может не включать новейшие модели, поэтому в разделе Model нажмите New / Add Model и введите ID модели, например:

   - `claude-opus-5`
   - `claude-sonnet-5`
   - `claude-haiku-4-5`
   - `deepseek-v4-pro`
   - `qwen3.8-max-preview`
   - `glm-5.2`
   - `kimi-k3`

   Полный список доступных моделей см. в [Галерее моделей](/ru/docs/guide/models).

## Способ 2: протокол OpenAI (модели GPT)

<Callout type="warn" title="Требования">

Вам нужно выполнить одно из этих условий:

- Вы оформили **план GPT**
- Вы используете оплату по факту использования и выбрали **группу GPT** в консоли LMU AI

</Callout>

1. **API Mode**: выберите **`OpenAI Responses API Compatible`** (не `OpenAI API Compatible`)
2. **Name**: любое на ваш выбор (например, `LMUAI-GPT`)
3. **API Host**: введите `https://api.lmuai.com`
4. **API Path**: введите `/responses`
5. **API Key**: введите ключ `sk-`, сгенерированный в консоли
6. **Добавление моделей**: в разделе Model нажмите New и введите ID модели, например `gpt-5.6-sol`, `gpt-5.6-terra`, `gpt-5.5`, `gpt-5.4`.

Chatbox объединяет API Host, `/v1` и API Path в полный адрес `https://api.lmuai.com/v1/responses`, отображаемый вживую под полями.

## Устранение неполадок

- **Изменения не вступают в силу**: после сохранения перезапустите Chatbox один раз или заново выберите модель на экране чата; на мобильном устройстве иногда также нужно перезапустить после переключения между Wi-Fi и сотовой связью.
- **Ошибки 401 / 403**: проверьте по порядку, является ли API Key ключом `sk-` из консоли LMU AI, правильно ли указан API Host (без `/v1`), верны ли API Mode и API Path для протокола OpenAI и включает ли ваш текущий план / группа биллинга модель, которую вы вызываете.
- Подробнее о протоколах, ID моделей и распространённых проблемах см. общую для настольной и мобильной версий страницу [Chatbox — все платформы](./chatbox).
