[Trae](https://www.trae.ai/) 에디터는 **서드파티 API 연결을 네이티브로 지원**하며(Anthropic 호환 프로토콜), 설치할 플러그인도 작성할 설정 파일도 없습니다 — 어떤 에디터에서든 서드파티 API를 연결하는 가장 간단한 방법입니다. **공식 Claude 모델과 중국어 대형 모델(GLM, Qwen, DeepSeek, Kimi 등)을 모두 지원합니다**.

<Callout type="info" title="네이티브 방식 vs Codex 플러그인 — 어느 것을 선택할까?">

- **Claude / 중국어 모델을 원한다면** → 이 페이지의 네이티브 방식(Anthropic 프로토콜, GUI에서 몇 번의 클릭)
- **GPT-5 / Codex 시리즈를 원한다면** → [공식 Codex 플러그인](/ko/docs/tools/vscode-plugin) 참조(OpenAI 프로토콜, 수동 작성 설정 파일)

두 방식은 공존할 수 있습니다 — 두 종류의 모델을 모두 사용하고 싶다면 둘 다 설정하세요.

</Callout>

## 설정 단계

1. Trae를 열고 **설정 → 모델 → 모델 추가**로 이동합니다
2. **제공자**를 **Anthropic**으로 설정합니다
3. **모델**을 **Custom Model**(드롭다운 하단)로 설정한 다음, 아래의 **모델 ID** 상자에 모델 이름을 입력합니다(아래 일반 모델 표 참조)
4. **사용자 지정 요청 URL**을 다음으로 설정합니다:
   ```
   https://api.lmuai.com/v1/messages
   ```
5. **API 키**를 LMU AI 콘솔에서 생성한 키(`sk-`로 시작)로 설정합니다
6. **확인**을 클릭해 저장한 다음, 해당 모델로 전환하여 사용을 시작합니다

## 자주 발생하는 문제

### 네이티브 방식인가 Codex 플러그인인가?

- **네이티브 방식(이 페이지)**: Anthropic 프로토콜을 사용하며 GUI에서 몇 번의 클릭만 필요 — **Claude / GLM / Qwen** 같은 모델을 원하는 사용자에게 가장 적합
- **[Codex 플러그인 방식](/ko/docs/tools/vscode-plugin)**: OpenAI 프로토콜을 사용하며 설정 파일을 수동으로 작성해야 함 — **GPT / Codex** 시리즈를 원하는 사용자에게 가장 적합

두 방식은 공존할 수 있습니다 — 두 종류의 모델을 모두 사용하고 싶다면 둘 다 설정하세요.

### 요청 URL이 왜 `/v1/messages`로 끝나야 하나요?

Trae의 사용자 지정 요청 URL은 **전체 엔드포인트**를 요구합니다(Chatbox 같은 도구는 경로를 자동으로 추가하는 것과 다릅니다). Anthropic 프로토콜의 채팅 엔드포인트는 항상 `/v1/messages`이므로 전체 URL은 `https://api.lmuai.com/v1/messages`입니다.

### 모델 ID는 어디서 찾나요?

[모델 갤러리](/ko/docs/guide/models)에서 사용 가능한 모델의 전체 목록을 확인하세요. 아무 카드나 클릭하면 해당 모델 ID가 복사되며, Trae의 모델 ID 상자에 바로 붙여넣을 수 있습니다.

### 추가 후 응답이 없거나 오류가 나나요?

- 제공자가 **Anthropic**(OpenAI가 아님)으로 설정되어 있나요?
- 모델 드롭다운에서 Custom Model을 선택하고 모델 ID를 직접 입력했나요?
- 요청 URL이 `/v1/messages`로 끝나나요?
- API 키가 LMU AI 콘솔에서 생성한 `sk-` 키인가요?

저장하고 Trae 클라이언트를 한 번 재시작하세요.
