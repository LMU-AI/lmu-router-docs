## 플러그인 설치

1. IntelliJ IDEA를 열고 **Settings → Plugins → Marketplace**로 이동합니다
2. **Kilo Code**를 검색하고, 플러그인을 찾으면 Install을 클릭합니다
3. 설치가 완료되면 IDEA를 재시작합니다

---

## 플러그인 설정

Kilo Code 설정 패널을 열고 사용하려는 모델 유형에 맞는 옵션을 선택하세요:

<Tabs items={['중국 모델 / Claude (Anthropic)', 'OpenAI 모델 (OpenAI Compatible)']}>
<Tab value="Chinese models / Claude (Anthropic)">

`claude-opus-5`, `claude-sonnet-5`, `qwen3.8-max-preview`, `deepseek-v4-pro`, `glm-5.2`, `kimi-k3`와 같은 모든 Claude 및 중국 모델에서 작동합니다.

| 필드 | 값 |
|------|------|
| **API Provider** | `Anthropic` |
| **Anthropic API Key** | LMU AI 콘솔에서 생성한 `sk-` 키 |
| **Use custom base URL** | ✅ 체크 |
| **Base URL** | `https://api.lmuai.com` |
| **Model** | `claude-opus-5`, `qwen3.7-max` 등 최신 모델 |

![Kilo Code에서 Anthropic 프로바이더가 선택되고, Use custom base URL이 체크되어 https://api.lmuai.com로 설정되었으며, 모델이 claude-opus-4-6으로 설정된 화면](/images/tools/Kilo/kilo.png)

<Callout type="info">

반드시 **Use custom base URL**을 체크해야 합니다. 그렇지 않으면 플러그인이 LMU AI 릴레이 대신 공식 Anthropic 엔드포인트로 요청합니다.

</Callout>

</Tab>
<Tab value="OpenAI models (OpenAI Compatible)">

`gpt-5.6-sol`, `gpt-5.6-terra`, `gpt-5.5`, `gpt-5.4`와 같은 모든 OpenAI 모델에서 작동합니다.

| 필드 | 값 |
|------|------|
| **API Provider** | `OpenAI Compatible (Responses)` |
| **Base URL** | `https://api.lmuai.com/v1` |
| **API Key** | LMU AI 콘솔에서 생성한 `sk-` 키 |
| **Model** | 예: `gpt-5.5` |

![Kilo Code에서 OpenAI Compatible (Responses) 프로바이더가 선택되고, Base URL이 https://api.lmuai.com/v1로 설정되었으며, 모델이 gpt-5.5로 설정된 화면](/images/tools/Kilo/kilo-openai.png)

<Callout type="warn">

OpenAI 모델의 Base URL은 **반드시 `/v1`로 끝나야 합니다**. Anthropic 프로토콜(`/v1` 없음)과 다르니 혼동하지 마세요.

</Callout>

</Tab>
</Tabs>

## 모델 이름 참조

어떤 모델을 입력해야 할지 모르겠나요? [모델 갤러리](/ko/docs/guide/models)에서 사용 가능한 모든 모델 ID를 확인하고 한 번의 클릭으로 복사하세요.

## 참고 사항

- **Claude / 중국 모델** 사용 시 → `Anthropic` 프로토콜을 선택하고, Base URL은 `https://api.lmuai.com`(`/v1` 없음)
- **OpenAI 모델** 사용 시 → `OpenAI Compatible (Responses)` 프로토콜을 선택하고, Base URL은 `https://api.lmuai.com/v1`(`/v1` 포함)
- API Key는 두 프로토콜 모두 LMU AI 콘솔에서 생성한 `sk-` 키를 입력하세요
- 설정이 완료되면 오른쪽 상단의 **Save**를 클릭하여 설정을 저장하고 사용을 시작하세요
