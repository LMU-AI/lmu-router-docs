[api-image](https://github.com/yc-duan/api-image) es un skill comunitario (con licencia MIT): Codex App en modo API no tiene generación de imágenes integrada y, una vez instalado este skill, puede generar imágenes mediante el endpoint de imágenes compatible con OpenAI que configures tú mismo. Con LMU AI es **cero configuración adicional**: reutiliza la clave y el endpoint que ya están en tu `~/.codex`, y basta con una frase en la conversación.

<Callout type="warn" title="Skill comunitario de terceros">

Se ejecuta en tu máquina, lee la clave de `~/.codex/auth.json` y envía tu solicitud e imágenes de referencia al proveedor; asegúrate de estar de acuerdo con esto antes de instalarlo. El autor también señala que la compatibilidad varía entre proveedores, así que considera los mensajes de error reales como la fuente de verdad.

</Callout>

## Instalar: una sola frase para Codex

Abre Codex App y solo di:

> Instala el skill en https://github.com/yc-duan/api-image — quiero generar imágenes con la API estándar de imágenes 2 de OpenAI; consulta las instrucciones de uso en https://github.com/yc-duan/api-image

Codex coloca el repositorio en `~/.codex/skills/api-image` por sí mismo (`%USERPROFILE%\.codex\skills\api-image` en Windows); **reinicia Codex App** después.

La instalación manual también funciona:

```bash
git clone https://github.com/yc-duan/api-image.git ~/.codex/skills/api-image
```

## Usar: sigue siendo una sola frase

| Lo que quieres | Di esto |
|------|------|
| De texto a imagen | Usa api-image para generar una foto cinematográfica de 2048x1152: una calle lluviosa de Tokio de noche, reflejos de neón, estilo de fotografía realista |
| De imagen a imagen | Usa la composición y la pose de esta imagen como referencia para generar una ilustración cálida; conserva la pose del sujeto, no copies el original |
| Relleno | Cambia la taza roja de esta imagen a verde, conservando la forma, composición e iluminación originales |
| Opciones explícitas | Usa api-image para generar una ilustración plana de 1024x1024, calidad baja, dos imágenes, guardadas en ./public/cover.png |

Los valores predeterminados son `gpt-image-2`, `2048x1152`, calidad alta y una imagen; el tamaño, la calidad, la cantidad y la ruta de salida se pueden cambiar directamente en la conversación. De forma predeterminada, el resultado se guarda en el directorio de trabajo actual (`provider-image-<timestamp>.png`).

## Notas

- **No hay nada que configurar para LMU AI**: el skill lee el `auth.json` (clave) y el `config.toml` (endpoint) que ya configuraste al conectar Codex App con LMU AI, correspondientes a los endpoints completos `https://api.lmuai.com/v1/images/generations` y `/v1/images/edits`
- `model_not_found` / 403: el grupo de tu clave no incluye el modelo de imágenes; consulta "Available models" en la consola o cambia de grupo
- `gpt-image-2` no admite fondos transparentes; el servicio ascendente puede normalizar los tamaños solicitados, así que confía en el resultado real
