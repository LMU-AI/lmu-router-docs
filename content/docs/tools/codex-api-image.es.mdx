[api-image](https://github.com/yc-duan/api-image) es una skill comunitaria (con licencia MIT): la Codex App en modo API no trae imagegen integrado, y una vez instalada esta skill puede generar imágenes a través del endpoint de imágenes compatible con OpenAI que tú mismo configures. Reutiliza la key y el endpoint que tienes en tu `~/.codex`, y basta con una frase en la conversación.

<Callout type="warn" title="Skill comunitaria de terceros">

Se ejecuta en tu máquina, lee la key desde `~/.codex/auth.json` y envía tu prompt y tus imágenes de referencia al proveedor — asegúrate de estar de acuerdo con eso antes de instalarla. El autor también señala que la compatibilidad varía entre proveedores, así que toma los mensajes de error reales como la fuente de verdad.

</Callout>

---

## Preparación: conserva auth.json

Esta skill lee la key desde `~/.codex/auth.json` (en Windows, `%USERPROFILE%\.codex\auth.json`). La [guía de Codex App](/es/docs/tools/codex-app) actualizada ahora coloca la key en un encabezado de solicitud en `config.toml` y ya no necesita `auth.json`, pero para usar esta skill necesitas conservar uno, con la misma key:

```json
{
  "OPENAI_API_KEY": "your sk- key generated in the console"
}
```

Si ya creaste `auth.json` con la guía anterior, simplemente déjalo como está.

---

## Instalación: una frase para Codex

Abre la Codex App y simplemente di:

> Instala la skill en https://github.com/yc-duan/api-image — quiero generar imágenes con la API estándar de OpenAI image 2; consulta las instrucciones de uso en https://github.com/yc-duan/api-image

Codex coloca el repositorio por sí solo en `~/.codex/skills/api-image` (`%USERPROFILE%\.codex\skills\api-image` en Windows); después **reinicia la Codex App**.

La instalación manual también funciona:

```bash
git clone https://github.com/yc-duan/api-image.git ~/.codex/skills/api-image
```

## Uso: también una frase

| Lo que quieres | Di esto |
|------|------|
| Texto a imagen | Usa api-image para generar una foto cinematográfica de 2048x1152: una calle de Tokio de noche bajo la lluvia, reflejos de neón, estilo de fotografía realista |
| Imagen a imagen | Tomando la composición y la pose de esta imagen como referencia, genera una ilustración cálida — mantén la pose del sujeto, no copies el original |
| Inpainting | Cambia la taza roja de esta imagen a verde, conservando la forma, la composición y la iluminación originales |
| Opciones explícitas | Usa api-image para generar una ilustración plana de 1024x1024, calidad low, dos imágenes, guardadas en ./public/cover.png |

Los valores por defecto son `gpt-image-2`, `2048x1152`, calidad high y una imagen; el tamaño, la calidad, la cantidad y la ruta de salida se pueden cambiar directamente en la conversación. La salida queda por defecto en el directorio de trabajo actual (`provider-image-<timestamp>.png`).

## Notas

- **Para LMU AI, basta con conservar `auth.json`**: la skill lee `auth.json` (key) y `config.toml` (endpoint), que corresponden a los endpoints completos `https://api.lmuai.com/v1/images/generations` y `/v1/images/edits`
- `model_not_found` / 403: el grupo de tu key no incluye el modelo de imágenes — revisa "Modelos disponibles" en la consola o cambia de grupo
- `gpt-image-2` no admite fondos transparentes; el upstream puede normalizar los tamaños solicitados, así que confía en la salida real
