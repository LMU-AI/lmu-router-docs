## 설정 단계

### 1단계 — Cursor Settings 열기

**Cmd + Shift + J**(macOS) 또는 **Ctrl + Shift + J**(Windows / Linux)를 눌러 Settings를 열고, 왼쪽 사이드바에서 **Models**를 클릭합니다.

### 2단계 — 기본 모델 끄기 (권장)

Cursor는 여러 기본 모델(GPT-4 / Claude-3.5 등)을 기본 제공합니다. 이를 켜 둔 채로 두면 커스텀 라우팅과 충돌합니다. Models 페이지의 모델 목록에서 모두 **끄세요**(왼쪽 토글이 회색으로 비활성화).

### 3단계 — 커스텀 모델 추가

**Add Model**을 클릭하고 원하는 LMU AI 모델 ID를 입력합니다. 예:

- `claude-opus-5`
- `claude-sonnet-5`
- `gpt-5.6-sol`
- `glm-5.2`
- `qwen3.8-max-preview`
- `deepseek-v4-pro`
- `kimi-k3`

**각 모델을 한 번씩 추가하세요.** 사용 가능한 전체 모델 목록은 [모델 갤러리](/ko/docs/guide/models)를 참고하세요.

### 4단계 — Override OpenAI Base URL 켜기

Models 페이지의 **OpenAI API Key** 영역으로 스크롤합니다:

1. **OpenAI API Key** 토글을 켭니다
2. LMU AI 콘솔 키(`sk-`로 시작)를 API Key 상자에 붙여넣습니다
3. **Override OpenAI Base URL** 토글을 켭니다
4. Base URL을 다음으로 설정합니다:
   ```
   https://api.lmuai.com/v1
   ```
5. **Verify**를 클릭해 연결을 확인합니다

<Callout type="info" title="Verify 실패가 곧 설정 오류를 의미하지는 않습니다">

Cursor의 Verify는 입력한 **모델명**으로 검사하며, 비공식 OpenAI 이름(`claude-opus-5`, `glm-5.2` 등)은 통과하지 못합니다. 해결 방법: **먼저 `gpt-4`를 추가해 Verify를 통과**시킨 뒤(Base URL + 키가 연결되는지 확인), 원하는 커스텀 모델 ID를 따로 추가하세요. Verify는 경고를 표시하지만 실제로는 정상 작동합니다.

</Callout>

### 5단계 — 모델 전환 후 사용

**Cmd/Ctrl + L**을 눌러 Chat 패널을 엽니다 → 상단 모델 드롭다운에서 3단계에서 추가한 커스텀 모델을 선택합니다 → 대화를 시작하면 요청이 LMU AI를 거칩니다.

## 자주 발생하는 문제

### Composer / Tab 자동완성도 LMU AI를 사용하고 싶다면?

네이티브 Override OpenAI Base URL로는 불가능합니다 — 이러한 Cursor 핵심 기능은 공식 백엔드에 고정되어 있습니다. 모든 것을 LMU AI로 라우팅하려면 다음을 사용하세요:

- [공식 Codex 확장](/ko/docs/tools/vscode-plugin) — OpenAI 프로토콜 에이전트
- [Claude Code for VS Code 확장](/ko/docs/tools/claude-code-vscode) — Anthropic 프로토콜 에이전트

Cursor는 VS Code 확장 마켓플레이스와 호환되므로 두 확장 모두 Cursor에 바로 설치됩니다.

### Base URL에 `/v1`이 필요한가요?

**네.** `https://api.lmuai.com/v1`을 입력하세요. Cursor가 `/chat/completions`를 덧붙여 최종적으로 `https://api.lmuai.com/v1/chat/completions`로 요청합니다. `/v1`을 생략하면 404가 발생합니다.

### Override를 켠 후 내장 Claude 3.5에서 오류가 발생하나요?

이는 알려진 Cursor 라우팅 충돌입니다 — OpenAI Base URL 재정의를 켜면 Anthropic 분기가 중단됩니다. Chat 패널에서 계속 Claude를 사용하려면 Claude 모델 ID(예: `claude-opus-5`)를 커스텀 모델로 추가하세요. LMU AI 백엔드가 OpenAI ↔ Anthropic 프로토콜 변환을 수행합니다.

### 401 / 403 오류가 발생하나요?

다음 순서로 확인하세요:

1. **API Key**가 LMU AI 콘솔에서 생성한 `sk-` 키인가요(공식 OpenAI 키가 아님)?
2. **Base URL**이 `https://api.lmuai.com/v1`인가요(**반드시 `/v1` 포함**)?
3. **모델 ID**가 LMU AI가 지원하는 것인가요([모델 갤러리](/ko/docs/guide/models) 참고)?
4. 현재 플랜 / 과금 그룹에 호출하려는 모델이 포함되어 있나요?

### BYOK가 Cursor 구독에 영향을 주나요?

- BYOK 사용은 Cursor의 월간 빠른 요청 할당량을 **소모하지 않습니다**
- Composer / Tab 자동완성 같은 핵심 기능은 **여전히** Cursor 구독 할당량을 소모합니다(BYOK를 사용하지 않기 때문)
- Cursor 구독을 완전히 없애려면 위의 Codex / Claude Code 확장 방식을 참고하세요
