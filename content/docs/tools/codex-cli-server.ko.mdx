WSL2 또는 SSH 원격 서버 환경에서 Codex CLI를 설정할 때 사용합니다.

---

## 설정 단계

### 1단계 — Node.js 환경 설치 (volta 사용)

서버 터미널에서 다음을 실행합니다:

```bash
curl https://get.volta.sh | bash
```

### 2단계 — Node 20 설치

<Callout type="warn" title="참고">

volta 설치가 완료된 뒤에는 **반드시 새 터미널 창을 열고** 아래 명령을 실행해야 합니다:

</Callout>

```bash
volta install node@20
```

### 3단계 — Codex CLI 설치

```bash
volta install @openai/codex
```

### 4단계 — 설정 파일 생성

서버 터미널에서 아래를 실행하면 `~/.codex/config.toml`을 한 번에 작성할 수 있습니다 (**마지막 줄의 "your sk- key generated in the console" 부분을 콘솔에서 발급한 `sk-` 키로 바꾸고, `Bearer` 뒤의 공백 한 칸은 그대로 유지하세요**):

```bash
mkdir -p ~/.codex

cat > ~/.codex/config.toml <<'EOF'
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
sandbox_mode = "danger-full-access"
windows_wsl_setup_acknowledged = true
approval_policy = "never"
file_opener = "vscode"
model_provider = "codex"
web_search = "cached"
suppress_unstable_features_warning = true

[history]
persistence = "save-all"

[tui]
notifications = true

[shell_environment_policy]
inherit = "all"
ignore_default_excludes = false

[sandbox_workspace_write]
network_access = true

[features]
plan_tool = true
apply_patch_freeform = true
view_image_tool = true
unified_exec = false
streamable_shell = false
rmcp_client = true
elevated_windows_sandbox = true

[profiles.auto-max]
approval_policy = "never"
sandbox_mode = "workspace-write"

[profiles.review]
approval_policy = "on-request"
sandbox_mode = "workspace-write"

[notice]
hide_gpt5_1_migration_prompt = true

[model_providers.codex]
name = "codex"
base_url = "https://api.lmuai.com"
wire_api = "responses"

[model_providers.codex.http_headers]
Authorization = "Bearer your sk- key generated in the console"
EOF
```

설정 내용은 [Codex CLI (Mac/Linux) 가이드](/ko/docs/tools/codex-cli-mac)와 동일합니다 — `vim` / `nano`로 직접 작성해도 됩니다. 최신 Codex 버전에서는 `~/.codex/auth.json`이 더 이상 필요하지 않으며, 예전 파일이 남아 있어도 문제가 되지 않습니다.

### 5단계 — Codex CLI 실행

```bash
codex --dangerously-bypass-approvals-and-sandbox
```

또는:

```bash
codex --yolo
```

## 1M 컨텍스트 활성화 (선택)

`gpt-5.4`는 1M 토큰 장문 컨텍스트를 지원하지만 기본값은 비활성화 상태입니다. `~/.codex/config.toml`을 편집해 파일의 **최상위 레벨**(모든 `[section]` 앞)에 두 줄을 추가한 뒤 Codex에 다시 진입하세요:

```toml
model_context_window = 1000000
model_auto_compact_token_limit = 900000
```

각 필드의 의미, 확인 방법, 주의 사항은 [Codex에서 1M 컨텍스트 활성화하기](/ko/docs/tools/codex-cli-mac#enabling-the-1m-context-in-codex-optional)를 참고하세요.
