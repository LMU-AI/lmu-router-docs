Cursor puede dirigir las solicitudes del panel de Chat / Plan a una API relay de terceros mediante **Override OpenAI Base URL**. Esta página explica cómo usar ese método nativo para conectarse a LMU AI.

<Callout type="warn" title="Limitación clave: solo afecta al panel de Chat / Plan">

El Override OpenAI Base URL de Cursor **solo afecta al panel de Chat / Plan** (la conversación abierta con Cmd/Ctrl + L). Las funciones principales de agente de Cursor — **Composer, Tab autocomplete, Apply, Inline Edit** — están todas bloqueadas al backend oficial de Cursor y no pueden ser controladas por un relay de terceros.

Si necesitas una experiencia de agente de "capacidad completa" en Cursor (incluidas las funciones tipo Composer), instala en su lugar (Cursor es compatible con el marketplace de extensiones de VS Code):

- [Extensión oficial de Codex](/es/docs/tools/vscode-plugin) — un agente Codex sobre el protocolo OpenAI de LMU AI
- [Extensión Claude Code for VS Code](/es/docs/tools/claude-code-vscode) — un agente Claude Code sobre el protocolo Anthropic de LMU AI

</Callout>

## Pasos de configuración

### Paso 1 — Abrir Settings de Cursor

Presiona **Cmd + Shift + J** (macOS) o **Ctrl + Shift + J** (Windows / Linux) para abrir Settings, y haz clic en **Models** en la barra lateral izquierda.

### Paso 2 — Desactivar los modelos predeterminados (recomendado)

Cursor viene con muchos modelos predeterminados (GPT-4 / Claude-3.5, etc.); dejarlos activados genera conflictos con el enrutamiento personalizado. En la lista de modelos de la página Models, desactívalos **todos** (interruptor grisado a la izquierda).

### Paso 3 — Agregar modelos personalizados

Haz clic en **Add Model** e ingresa los IDs de modelo de LMU AI que quieras, por ejemplo:

- `claude-opus-5`
- `claude-sonnet-5`
- `gpt-5.6-sol`
- `glm-5.2`
- `qwen3.8-max-preview`
- `deepseek-v4-pro`
- `kimi-k3`

**Agrega cada modelo una vez.** Para ver la lista completa de modelos disponibles, consulta la [Galería de modelos](/es/docs/guide/models).

### Paso 4 — Activar Override OpenAI Base URL

Desplázate hasta el área **OpenAI API Key** en la página Models:

1. Activa el interruptor **OpenAI API Key**
2. Pega la clave de la consola de LMU AI (comienza con `sk-`) en el cuadro de API Key
3. Activa el interruptor **Override OpenAI Base URL**
4. Establece Base URL en:
   ```
   https://api.lmuai.com/v1
   ```
5. Haz clic en **Verify** para comprobar la conexión

<Callout type="info" title="Un Verify fallido no significa que esté mal configurado">

El Verify de Cursor comprueba usando el **nombre del modelo** que ingresaste, y los nombres que no son oficiales de OpenAI (`claude-opus-5`, `glm-5.2`, etc.) no pasarán. Solución: **agrega primero un `gpt-4` para pasar Verify** (confirmando que Base URL + clave conectan), luego agrega por separado los IDs de modelo personalizados que quieras; Verify advierte pero en la práctica funciona bien.

</Callout>

### Paso 5 — Cambiar de modelo y usarlo

Presiona **Cmd/Ctrl + L** para abrir el panel de Chat → selecciona el modelo personalizado que agregaste en el Paso 3 desde el menú desplegable de modelos en la parte superior → comienza a chatear, y las solicitudes pasarán por LMU AI.

## Problemas comunes

### ¿Quieres que Composer / Tab autocomplete también usen LMU AI?

El Override OpenAI Base URL nativo no puede hacerlo — estas funciones principales de Cursor están bloqueadas al backend oficial. Para enrutar todo a través de LMU AI, usa:

- [Extensión oficial de Codex](/es/docs/tools/vscode-plugin) — un agente de protocolo OpenAI
- [Extensión Claude Code for VS Code](/es/docs/tools/claude-code-vscode) — un agente de protocolo Anthropic

Cursor es compatible con el marketplace de extensiones de VS Code, por lo que ambas extensiones se instalan directamente en Cursor.

### ¿La Base URL necesita `/v1`?

**Sí.** Ingresa `https://api.lmuai.com/v1`. Cursor agrega `/chat/completions` para una solicitud final a `https://api.lmuai.com/v1/chat/completions`. Omitir `/v1` da un 404.

### ¿El Claude 3.5 integrado da error después de activar Override?

Este es un conflicto de enrutamiento conocido de Cursor: activar el override de OpenAI Base URL interrumpe la rama Anthropic. Para seguir usando Claude en el panel de Chat, agrega el ID del modelo Claude (por ejemplo `claude-opus-5`) como modelo personalizado, y el backend de LMU AI realiza la traducción de protocolo OpenAI ↔ Anthropic.

### ¿Errores 401 / 403?

Comprueba en orden:

1. ¿Es la **API Key** la clave `sk-` generada en la consola de LMU AI (no una clave oficial de OpenAI)?
2. ¿Es la **Base URL** `https://api.lmuai.com/v1` (**debe incluir `/v1`**)?
3. ¿Es el **ID de modelo** uno que admite LMU AI (consulta la [Galería de modelos](/es/docs/guide/models))?
4. ¿Tu plan / grupo de facturación actual incluye el modelo que estás llamando?

### ¿BYOK afecta mi suscripción de Cursor?

- El uso de BYOK **no consume** la cuota mensual de solicitudes rápidas de Cursor
- Las funciones principales como Composer / Tab autocomplete **siguen consumiendo** la cuota de la suscripción de Cursor (porque no usan BYOK)
- Para prescindir por completo de la suscripción de Cursor, consulta el enfoque de las extensiones Codex / Claude Code más arriba
