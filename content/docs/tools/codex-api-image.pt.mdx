[api-image](https://github.com/yc-duan/api-image) é uma skill comunitária (licenciada pelo MIT): o Codex App no modo API não tem um recurso integrado de geração de imagens e, depois que essa skill é instalada, pode gerar imagens por meio do endpoint de imagens compatível com a OpenAI que você mesmo configurar. Com o LMU AI, não é necessária **nenhuma configuração extra** — ele reutiliza a chave e o endpoint já existentes em `~/.codex`, e uma única frase na conversa é suficiente.

<Callout type="warn" title="Skill comunitária de terceiros">

Ela é executada na sua máquina, lê a chave de `~/.codex/auth.json` e envia seu prompt e as imagens de referência ao provedor — certifique-se de estar confortável com isso antes de instalar. O autor também observa que a compatibilidade varia entre os provedores; portanto, considere as mensagens de erro reais como a fonte de verdade.

</Callout>

## Instalação: uma frase para o Codex

Abra o Codex App e diga:

> Instale a skill em https://github.com/yc-duan/api-image — quero gerar imagens com a API padrão de imagens 2 da OpenAI; consulte as instruções de uso em https://github.com/yc-duan/api-image

O Codex coloca o repositório em `~/.codex/skills/api-image` por conta própria (`%USERPROFILE%\.codex\skills\api-image` no Windows); **reinicie o Codex App** depois.

A instalação manual também funciona:

```bash
git clone https://github.com/yc-duan/api-image.git ~/.codex/skills/api-image
```

## Uso: ainda uma frase

| O que você quer | Diga isto |
|------|------|
| Texto para imagem | Use api-image para gerar uma foto cinematográfica de 2048x1152: uma rua chuvosa de Tóquio à noite, reflexos de neon, estilo de fotografia realista |
| Imagem para imagem | Usando a composição e a pose desta imagem como referência, gere uma ilustração acolhedora — mantenha a pose do sujeito, não copie o original |
| Inpainting | Mude o copo vermelho desta imagem para verde, mantendo a forma, a composição e a iluminação originais |
| Opções explícitas | Use api-image para gerar uma ilustração plana de 1024x1024, qualidade baixa, duas imagens, salvas em ./public/cover.png |

Os padrões são `gpt-image-2`, `2048x1152`, qualidade alta e uma imagem; tamanho, qualidade, quantidade e caminho de saída podem ser alterados diretamente na conversa. Por padrão, a saída vai para o diretório de trabalho atual (`provider-image-<timestamp>.png`).

## Observações

- **Nada para configurar no LMU AI**: a skill lê o `auth.json` (chave) e o `config.toml` (endpoint) que você já configurou ao conectar-se ao LMU AI, correspondentes aos endpoints completos `https://api.lmuai.com/v1/images/generations` e `/v1/images/edits`
- `model_not_found` / 403: o grupo da sua chave não inclui o modelo de imagens — verifique "Modelos disponíveis" no console ou mude de grupo
- `gpt-image-2` não oferece suporte a fundos transparentes; o upstream pode normalizar os tamanhos solicitados, portanto confie na saída real
