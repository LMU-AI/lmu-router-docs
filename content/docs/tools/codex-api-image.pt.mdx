O [api-image](https://github.com/yc-duan/api-image) é uma skill comunitária (licença MIT): o Codex App no modo API não tem imagegen embutido e, assim que essa skill é instalada, ele consegue gerar imagens através do endpoint de imagens compatível com OpenAI que você mesmo configurar. Ela reaproveita a chave e o endpoint que já estão no seu `~/.codex`, e uma única frase na conversa já basta.

<Callout type="warn" title="Skill comunitária de terceiros">

Ela roda na sua máquina, lê a chave de `~/.codex/auth.json` e envia seu prompt e imagens de referência para o provedor — certifique-se de que você está confortável com isso antes de instalar. O autor também observa que a compatibilidade varia entre provedores, então trate as mensagens de erro reais como a fonte da verdade.

</Callout>

---

## Preparação: mantenha o auth.json

Essa skill lê a chave de `~/.codex/auth.json` (no Windows, `%USERPROFILE%\.codex\auth.json`). O [guia do Codex App](/pt/docs/tools/codex-app) atualizado agora coloca a chave em um cabeçalho de requisição no `config.toml` e não precisa mais do `auth.json`, mas, para usar essa skill, você precisa manter um, com a mesma chave:

```json
{
  "OPENAI_API_KEY": "your sk- key generated in the console"
}
```

Se você já criou o `auth.json` seguindo o guia antigo, basta deixá-lo como está.

---

## Instalação: uma frase para o Codex

Abra o Codex App e simplesmente diga:

> Instale a skill em https://github.com/yc-duan/api-image — quero gerar imagens com a API padrão OpenAI image 2; veja as instruções de uso em https://github.com/yc-duan/api-image

O Codex coloca o repositório em `~/.codex/skills/api-image` por conta própria (`%USERPROFILE%\.codex\skills\api-image` no Windows); depois disso, **reinicie o Codex App**.

A instalação manual também funciona:

```bash
git clone https://github.com/yc-duan/api-image.git ~/.codex/skills/api-image
```

## Uso: também uma frase

| O que você quer | Diga isto |
|------|------|
| Texto para imagem | Use o api-image para gerar uma foto cinematográfica 2048x1152: uma rua de Tóquio à noite sob chuva, reflexos de neon, estilo de fotografia realista |
| Imagem para imagem | Usando a composição e a pose desta imagem como referência, gere uma ilustração em tons quentes — mantenha a pose do personagem, não copie o original |
| Inpainting | Mude a caneca vermelha desta imagem para verde, mantendo a forma, a composição e a iluminação originais |
| Opções explícitas | Use o api-image para gerar uma ilustração flat 1024x1024, quality low, duas imagens, salvas em ./public/cover.png |

Os padrões são `gpt-image-2`, `2048x1152`, quality high, uma imagem; tamanho, qualidade, quantidade e caminho de saída podem todos ser alterados diretamente na conversa. A saída vai por padrão para o diretório de trabalho atual (`provider-image-<timestamp>.png`).

## Observações

- **Para a LMU AI, basta manter o `auth.json`**: a skill lê o `auth.json` (chave) e o `config.toml` (endpoint), correspondendo aos endpoints completos `https://api.lmuai.com/v1/images/generations` e `/v1/images/edits`
- `model_not_found` / 403: o grupo da sua chave não inclui o modelo de imagem — verifique "Modelos disponíveis" no console ou troque de grupo
- O `gpt-image-2` não suporta fundos transparentes; o upstream pode normalizar os tamanhos solicitados, então confie na saída real
