<Callout type="info" title="إذا كنت تستخدم محرّر Trae">

إذا أردت استخدام **Claude أو الموديلات الصينية (GLM / Qwen، وغيرها)**، فإنّ Trae يوفّر طريقة أصلية أبسط (بدون إضافة، فقط بضع نقرات في الواجهة الرسومية) — راجع [إعداد الموديلات الأصلي في Trae](/ar/docs/tools/trae).

طريقة إضافة Codex الموضّحة في هذه الصفحة تناسب المستخدمين الذين يريدون استخدام سلسلة **GPT / Codex**.

</Callout>

## الأخطاء الشائعة

**خطأ: بعد الإعداد تحصل على 401 يفيد بأن المفتاح غير صحيح**

السبب: الطلب لا يزال يتوجّه إلى خدمة OpenAI الرسمية بدلاً من وسيط API الخاص بنا، أو أنك لم تُعِد تشغيل الأداة لإعادة تحميل ملف الإعداد.

الحل: اتبع الدليل مرة أخرى لـ **إنشاء أو استبدال** `config.toml`، ثم أعد تشغيل أداة بيئة التطوير.

<Callout type="info" title="عند مواجهة خطأ">

خُذ لقطة شاشة لرسالة الخطأ وترجمها — ستتمكّن من معرفة سبب الخطأ بنفسك!

</Callout>

## الإعداد

### الخطوة 1 — إنشاء / استبدال ملفات الإعداد

موقع ملف الإعداد:
- **Mac/Linux**: المجلد `~/.codex/`
- **Windows**: المجلد `C:\users\YourUsername\.codex\`

<Callout type="warn" title="ملاحظة بخصوص Windows">

إذا كنت قد سجّلت الدخول سابقًا بالحساب الرسمي أو بمنصّة أخرى، فسجّل الخروج أولًا، ثم أجرِ الإعداد!

</Callout>

إذا لم يكن لديك مجلد `.codex`، فأنشئه عبر أمر في الطرفية:

```bash
# Mac/Linux
rm -rf ~/.codex && mkdir ~/.codex
```

```powershell
# Windows (run in the terminal)
rm -rf C:\users\YourUsername\.codex
mkdir C:\users\YourUsername\.codex
```

### الخطوة 2 — كتابة config.toml

في المجلد `.codex`، أنشئ أو استبدل `config.toml`:

```toml
model_provider = "OpenAI"
model = "gpt-5.4"
review_model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
network_access = "enabled"
windows_wsl_setup_acknowledged = true
model_context_window = 1000000
model_auto_compact_token_limit = 900000

[model_providers.OpenAI]
name = "OpenAI"
base_url = "https://api.lmuai.com"
wire_api = "responses"

[model_providers.OpenAI.http_headers]
Authorization = "Bearer your sk- key generated in the console"
```

استبدل السطر الأخير بمفتاحك الذي يبدأ بـ `sk-`، مع الإبقاء على مسافة واحدة بين `Bearer` والمفتاح، وضع قسم `http_headers` في نهاية الملف تمامًا. الإصدارات الأحدث من Codex لم تعد بحاجة إلى `auth.json`؛ ووجود ملف قديم منه لا يسبب أي ضرر.

بعد إتمام الإعداد، افتح VS Code أو Cursor أو Trae، وستُسجّل إضافة Codex داخلها الدخول تلقائيًا.

## تثبيت إضافة Visual Studio Code

### تثبيت الإضافة

1. افتح VS Code وافتح أولًا أي مجلد مشروع كمساحة عمل لك (**وإلّا ستظهر نافذة منبثقة تطالبك بفتح مجلد مشروع!**)
2. انقر على لوحة الإضافات على اليسار (أيقونة Extensions)
3. ابحث عن **Codex**، واعثر على الإضافة الرسمية من OpenAI باسم "Codex – OpenAI's coding agent"، ثم انقر على التثبيت
4. بعد التثبيت، سيظهر مدخل Codex في الشريط الجانبي الأيسر (وإن لم يظهر، فابحث عنه في أعلى يمين الواجهة)

### تسجيل الخروج من الحساب القديم

<Callout type="warn" title="مهم">

إذا كنت قد سجّلت الدخول سابقًا بالحساب الرسمي أو بمنصّة أخرى، فسجّل الخروج أولًا، ثم أجرِ الإعداد!

</Callout>

1. انقر على أيقونة الإعدادات في أعلى يمين لوحة Codex
2. انقر على **Log out** لتسجيل الخروج

### إتمام الإعداد

بعد تهيئة `config.toml`، أعد فتح إضافة Codex وانقر على **Continue** لإكمال عملية تسجيل الدخول.

<Callout type="info" title="بخصوص عرض الموديل">

لا يظهر الموديل GPT-5.3 في القائمة المنسدلة؛ مرّر المؤشر فوق "Custom" لرؤية الموديل المستخدم حاليًا.

يمكنك أيضًا التحقق من الموديل المطلوب فعليًا في لوحة التحكم ضمن "سجلات الاستخدام".

</Callout>

## تريد استخدام Claude أو الموديلات الصينية؟

إذا كنت تستخدم Trae فقط وهدفك موديلات مثل **Claude / GLM / Qwen**، فلا حاجة لإضافة Codex — فـ [إعداد الموديلات الأصلي في Trae](/ar/docs/tools/trae) (بروتوكول Anthropic، ويكفي تعبئة بضعة حقول في الواجهة الرسومية) أبسط.
