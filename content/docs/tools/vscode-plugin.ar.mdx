<Callout type="info" title="إذا كنت تستخدم محرر Trae">

إذا كنت تريد استخدام **Claude أو النماذج الصينية (GLM / Qwen، إلخ)**، فإن لدى Trae طريقة أصلية أبسط (بدون إضافة، مجرد بضع نقرات في الواجهة الرسومية) — راجع [إعداد النموذج الأصلي في Trae](/ar/docs/tools/trae).

طريقة إضافة Codex في هذه الصفحة تناسب المستخدمين الذين يرغبون في استخدام سلسلة **GPT / Codex**.

</Callout>

## الأخطاء الشائعة

**خطأ: بعد الإعداد، تحصل على 401 يقول إن المفتاح غير صحيح**

السبب: لا يزال الطلب يذهب إلى خادم OpenAI الرسمي بدلاً من مُرحّل API الخاص بنا، أو أنك لم تُعِد تشغيل الأداة لإعادة تحميل ملف الإعداد.

الحل: اتبع الدليل مرة أخرى لـ **إنشاء أو استبدال** الملفين `config.toml` و`auth.json`، ثم أعد تشغيل أداة IDE.

<Callout type="info" title="عندما تواجه خطأً">

التقط لقطة شاشة لرسالة الخطأ وترجمها — ستتمكن من معرفة سبب الخطأ بنفسك!

</Callout>

## الإعداد

### الخطوة 1 — إنشاء / استبدال ملفات الإعداد

موقع ملف الإعداد:
- **Mac/Linux**: الدليل `~/.codex/`
- **Windows**: الدليل `C:\users\YourUsername\.codex\`

<Callout type="warn" title="ملاحظة لنظام Windows">

إذا سبق لك تسجيل الدخول بالحساب الرسمي أو منصة أخرى، فسجّل الخروج أولاً، ثم قم بالإعداد!

</Callout>

إذا لم يكن لديك مجلد `.codex`، فأنشئه باستخدام أمر طرفية:

```bash
# Mac/Linux
rm -rf ~/.codex && mkdir ~/.codex
```

```powershell
# Windows (run in the terminal)
rm -rf C:\users\YourUsername\.codex
mkdir C:\users\YourUsername\.codex
```

### الخطوة 2 — اكتب config.toml

في الدليل `.codex`، أنشئ أو استبدل `config.toml`:

```toml
model_provider = "OpenAI"
model = "gpt-5.4"
review_model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
network_access = "enabled"
windows_wsl_setup_acknowledged = true
model_context_window = 1000000
model_auto_compact_token_limit = 900000

[model_providers.OpenAI]
name = "OpenAI"
base_url = "https://api.lmuai.com"
wire_api = "responses"
requires_openai_auth = true
```

### الخطوة 3 — اكتب auth.json

في الدليل `.codex`، أنشئ أو استبدل `auth.json`:

```json
{
  "OPENAI_API_KEY": "your sk- key generated in the console"
}
```

بمجرد الإعداد، افتح VS Code أو Cursor أو Trae، وستقوم إضافة Codex بداخلها بتسجيل الدخول تلقائيًا.

## تثبيت إضافة Visual Studio Code

### تثبيت الإضافة

1. افتح VS Code وافتح أولاً أي مجلد مشروع كمساحة عمل خاصة بك (**وإلا ستظهر نافذة منبثقة تطالبك بفتح مجلد مشروع!**)
2. انقر على لوحة الإضافات على اليسار (أيقونة Extensions)
3. ابحث عن **Codex**، اعثر على إضافة OpenAI الرسمية "Codex – OpenAI's coding agent"، وانقر على Install
4. بعد التثبيت، يظهر إدخال Codex في الشريط الجانبي الأيسر (إذا لم يظهر، فابحث في أعلى يمين الواجهة)

### سجّل الخروج من الحساب القديم

<Callout type="warn" title="مهم">

إذا سبق لك تسجيل الدخول بالحساب الرسمي أو منصة أخرى، فسجّل الخروج أولاً، ثم قم بالإعداد!

</Callout>

1. انقر على أيقونة الإعدادات في أعلى يمين لوحة Codex
2. انقر على **Log out** لتسجيل الخروج

### أكمل الإعداد

بعد إعداد `config.toml` و`auth.json`، أعد فتح إضافة Codex وانقر على **Continue** لإكمال تدفق تسجيل الدخول.

<Callout type="info" title="حول عرض النموذج">

نموذج GPT-5.3 لا يظهر في القائمة المنسدلة؛ مرّر المؤشر فوق "Custom" لرؤية النموذج المستخدم حاليًا.

يمكنك أيضًا التحقق من النموذج المطلوب فعليًا في وحدة التحكم ضمن "سجلات الاستخدام".

</Callout>
