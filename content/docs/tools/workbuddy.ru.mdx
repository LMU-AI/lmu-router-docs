WorkBuddy — это ИИ-ассистент для программирования от Tencent (из того же семейства, что и CodeBuddy). Он поддерживает подключение к любому OpenAI-совместимому API через **кастомную (OpenAI-совместимую) модель**, поэтому вы можете направить его на ретранслятор LMU AI и использовать один ключ `sk-` для вызова Claude, GPT и китайских моделей.

---

## Перед началом

- API-ключ LMU AI, начинающийся с `sk-`: зарегистрируйтесь и создайте его в [консоли LMU AI](https://api.lmuai.com).
- Запишите OpenAI-совместимый адрес LMU AI (Base URL), **с** `/v1`:

  ```
  https://api.lmuai.com/v1
  ```

- Убедитесь, что у группы вашего ключа есть апстрим для нужной модели (доступные модели зависят от группы).

<Callout type="warn" title="Не используйте ключ группы Claude Max">

Группа Claude Max поддерживает только протокол Anthropic и **не может** быть указана в адресе OpenAI-протокола вроде `https://api.lmuai.com/v1`, поэтому она не будет работать с кастомной моделью WorkBuddy. Используйте вместо этого ключ группы с **оплатой по факту** или **стандартной подписки**.

</Callout>

## Способ 1: Добавить кастомную модель в интерфейсе (рекомендуется)

1. Откройте WorkBuddy и перейдите в настройки модели: либо через **Settings → Model**, либо откройте список моделей в поле чата, прокрутите вниз и выберите **Configure custom models**.
2. Нажмите **Add Model** и установите поставщика / тип как **Custom**.
3. Заполните эти три поля:

   | Поле | Значение |
   |------|------|
   | Endpoint / Base URL | `https://api.lmuai.com/v1` |
   | API Key | ключ `sk-`, созданный в консоли |
   | Model Name | идентификатор модели LMU AI, например `gpt-5.6-sol` или `claude-sonnet-5` |

4. (Опционально) Включите Tool Call, Image input и т. д. в соответствии с возможностями модели.
5. Сохраните, вернитесь в список моделей, выберите только что добавленную модель и начните общение.

![Диалог "Add Model" в WorkBuddy заполнен: поставщик установлен как Custom, эндпоинт останавливается на `https://api.lmuai.com/v1`](/images/tools/workbuddy/workbuddy-add-model.png)

<Callout type="info" title="Не пишите /chat/completions в эндпоинт дважды">

WorkBuddy автоматически добавляет `/chat/completions` к эндпоинту. Поэтому остановите эндпоинт на `https://api.lmuai.com/v1` и не добавляйте `/chat/completions` — иначе получится `…/v1/chat/completions/chat/completions` и вернётся ошибка 404.

</Callout>

## Способ 2: Редактировать models.json (точный, с контролем версий)

WorkBuddy / CodeBuddy также хранит кастомные модели в конфигурационном файле, что подходит для массовой или командной настройки.

Конфигурационный файл находится в папке `.codebuddy` в вашем домашнем каталоге (некоторые версии используют `.workbuddy` — используйте ту, которая фактически существует на вашем компьютере):

- **Windows (уровень пользователя)**: `C:\Users\<your-username>\.codebuddy\models.json`
- **macOS / Linux (уровень пользователя)**: `~/.codebuddy/models.json`
- **Уровень проекта**: `<your-project-dir>\.codebuddy\models.json`

При первом использовании установите, войдите и откройте любой проект один раз, чтобы был создан конфигурационный каталог. Пример (замените `apiKey` на ваш собственный ключ `sk-`):

```json
{
  "models": [
    {
      "id": "gpt-5.6-sol",
      "name": "LMU AI GPT-5.6 Sol",
      "vendor": "LMU AI",
      "url": "https://api.lmuai.com/v1/chat/completions",
      "apiKey": "sk-your-key",
      "maxInputTokens": 128000,
      "maxOutputTokens": 8192,
      "supportsToolCall": true,
      "supportsImages": false
    },
    {
      "id": "claude-sonnet-5",
      "name": "LMU AI Claude Sonnet 5",
      "vendor": "LMU AI",
      "url": "https://api.lmuai.com/v1/chat/completions",
      "apiKey": "sk-your-key",
      "maxInputTokens": 128000,
      "maxOutputTokens": 8192,
      "supportsToolCall": true,
      "supportsImages": false
    }
  ],
  "availableModels": ["gpt-5.6-sol", "claude-sonnet-5"]
}
```

Примечания:

- Здесь `url` должен быть **полным путём** `https://api.lmuai.com/v1/chat/completions` (в отличие от Способа 1, здесь `/chat/completions` включается).
- `maxInputTokens`, `maxOutputTokens`, `supportsToolCall` и `supportsImages` — это **значения, объявляемые на стороне клиента** — настройте их в соответствии с фактическими возможностями выбранной модели.
- Сохраните файл в **UTF-8 без BOM**; BOM может привести к сбою загрузки.
- Вы также можете задать ключ как переменную окружения и ссылаться на неё, например `"apiKey": "${LMU_API_KEY}"` (`setx LMU_API_KEY "sk-..."` в Windows, `export LMU_API_KEY=sk-...` в macOS / Linux).
- После редактирования **полностью закройте и перезапустите** WorkBuddy, затем выберите модель в списке.

## Доступные модели

Распространённые идентификаторы моделей (те, которые вы реально можете использовать, зависят от вашей группы; полный список см. на странице [Models](../guide/models)):

- **GPT**: `gpt-5.6-sol`, `gpt-5.6-terra`, `gpt-5.6-luna`, `gpt-5.5`
- **Claude**: `claude-opus-5`, `claude-sonnet-5`, `claude-haiku-4-5`
- **Китайские**: `deepseek-v4-pro`, `qwen3.8-max-preview`, `glm-5.2`, `kimi-k3`

WorkBuddy использует OpenAI-совместимый протокол, а бэкенд LMU AI выполняет конвертацию протокола автоматически, поэтому идентификаторы моделей Claude / китайских моделей тоже работают — при условии, что у вашей группы есть соответствующий апстрим.

## FAQ

### Ошибка 401 / 403

Проверьте по порядку:

1. Является ли API Key ключом `sk-`, созданным в консоли LMU AI (а не официальным ключом OpenAI / Anthropic).
2. Корректен ли эндпоинт: `https://api.lmuai.com/v1` (с `/v1`).
3. Включает ли группа вашего ключа вызываемую модель.

### 404 / Not Found

Обычно `/chat/completions` написан в эндпоинте дважды, или отсутствует `/v1`:

- Способ 1 (интерфейс): остановите эндпоинт на `https://api.lmuai.com/v1`; WorkBuddy добавит `/chat/completions`.
- Способ 2 (models.json): задайте `url` как полный путь `https://api.lmuai.com/v1/chat/completions`.

### "Model unavailable" / "No available accounts"

Вы вызвали модель за пределами диапазона вашей группы (например, использовали группу Claude Max для вызова GPT). Проверьте модели, которые может вызывать ваша текущая группа, в разделе "Available models" в консоли, или смените группу. См. [Протоколы API](../guide/api-protocols).

### Изменения не действуют

После редактирования `models.json` **полностью закройте и перезапустите** WorkBuddy; сохраните файл в **UTF-8 без BOM**. Для модели, добавленной через интерфейс, просто выберите её снова в списке моделей после сохранения.
