[api-image](https://github.com/yc-duan/api-image) はコミュニティ製のスキル（MIT ライセンス）です。API モードの Codex App には imagegen が内蔵されていませんが、このスキルをインストールすると、自分で設定した OpenAI 互換の画像エンドポイント経由で画像を生成できるようになります。`~/.codex` にあるキーとエンドポイントをそのまま使うので、会話で一言伝えるだけで済みます。

<Callout type="warn" title="サードパーティのコミュニティスキル">

このスキルはあなたのマシン上で動作し、`~/.codex/auth.json` からキーを読み取り、プロンプトと参照画像をプロバイダーへ送信します。インストールする前に、その点に納得できるか確認してください。作者もプロバイダーごとに互換性が異なると述べているため、実際のエラーメッセージを判断の基準にしてください。

</Callout>

## 準備：auth.json を残しておく

このスキルは `~/.codex/auth.json`（Windows では `%USERPROFILE%\.codex\auth.json`）からキーを読み取ります。更新後の [Codex App ガイド](/ja/docs/tools/codex-app) ではキーを `config.toml` のリクエストヘッダーに置くようになり、`auth.json` は不要になりましたが、このスキルを使うには同じキーを入れた `auth.json` を残しておく必要があります：

```json
{
  "OPENAI_API_KEY": "your sk- key generated in the console"
}
```

以前のガイドで `auth.json` を作成済みなら、そのままにしておけば大丈夫です。

## インストール：Codex に一言伝えるだけ

Codex App を開いて、こう伝えるだけです：

> https://github.com/yc-duan/api-image のスキルをインストールして。OpenAI image 2 標準 API で画像を生成したい。使い方は https://github.com/yc-duan/api-image を見て

Codex が自分でリポジトリを `~/.codex/skills/api-image`（Windows では `%USERPROFILE%\.codex\skills\api-image`）に配置します。その後、**Codex App を再起動**してください。

手動インストールでも動作します：

```bash
git clone https://github.com/yc-duan/api-image.git ~/.codex/skills/api-image
```

## 使い方：こちらも一言だけ

| やりたいこと | こう伝える |
|------|------|
| テキストから画像生成 | api-image を使って 2048x1152 の映画的な写真を生成して：雨の夜の東京の街、ネオンの反射、リアルな写真スタイル |
| 画像から画像生成 | この画像の構図とポーズを参考に、温かみのあるイラストを生成して。被写体のポーズは保ち、元画像をそのまま複製しないで |
| インペイント | この画像の赤いカップを緑に変えて。元の形、構図、ライティングは保って |
| オプションを明示 | api-image を使って 1024x1024 のフラットイラストを生成して。quality は low、2 枚、./public/cover.png に保存 |

デフォルトは `gpt-image-2`、`2048x1152`、quality high、1 枚です。サイズ、品質、枚数、出力先はすべて会話の中で変更できます。出力はデフォルトで現在の作業ディレクトリに保存されます（`provider-image-<timestamp>.png`）。

## 注意事項

- **LMU AI では `auth.json` を残しておくだけ**：このスキルは `auth.json`（キー）と `config.toml`（エンドポイント）を読み取り、完全なエンドポイントは `https://api.lmuai.com/v1/images/generations` と `/v1/images/edits` になります
- `model_not_found` / 403：キーのグループに画像モデルが含まれていません。コンソールの「利用可能なモデル」を確認するか、グループを切り替えてください
- `gpt-image-2` は透過背景に対応していません。また上流でリクエストしたサイズが正規化される場合があるため、実際の出力を基準にしてください
