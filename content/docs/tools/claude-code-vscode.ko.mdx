공식 VS Code 확장 프로그램 **Claude Code for VS Code**를 사용하면 터미널로 전환하지 않고도 편집기 사이드바에서 바로 Claude Code를 사용할 수 있습니다. 이 확장 프로그램은 Claude Code CLI와 **하나의 설정 파일을 공유**하므로, CLI에서 설정한 키 / Base URL이 확장 프로그램에서도 그대로 작동합니다 — 다시 설정할 필요가 없습니다.

<Callout type="info" title="Cursor / Trae / Antigravity 등 다른 편집기에서도 작동합니다">

VS Code 코어를 기반으로 만들어진 편집기(**Cursor, Trae, Antigravity** 등)라면 무엇이든 **내장된 확장 프로그램 스토어에서 동일한 `Claude Code for VS Code` 확장 프로그램을 검색**하여 설치하고 설정할 수 있습니다 — 절차는 VS Code와 완전히 동일합니다.

이 페이지의 모든 스크린샷과 명령어는 VS Code를 예시로 사용합니다; Cursor / Trae / Antigravity 사용자도 그대로 따라 하면 됩니다.

</Callout>

## VS Code 다운로드 및 설치

<Callout type="info" title="Cursor / Trae / Antigravity를 사용 중인가요?">

이들은 독립형 편집기입니다 — VS Code가 아니라 각 편집기의 공식 사이트에서 알맞은 설치 파일을 다운로드하고, 설치가 끝나면 곧바로 다음 섹션 [확장 프로그램 설치](#install-the-extension)로 넘어가세요 — 확장 프로그램 마켓플레이스와 설치 절차는 VS Code와 동일합니다.

</Callout>

[code.visualstudio.com](https://code.visualstudio.com/)으로 이동하여 **Download** 버튼을 클릭하세요; 사이트가 자동으로 운영체제를 감지합니다. 아래의 공식 직접 링크를 사용할 수도 있습니다(버전 번호가 없으며 항상 최신 안정 릴리스를 가리키므로 사이트를 먼저 방문할 필요가 없습니다):

<Tabs items={['Windows', 'macOS', 'Linux']}>
<Tab value="Windows">

**다운로드**: [Windows 사용자 설치 파일 (x64)](https://update.code.visualstudio.com/latest/win32-x64-user/stable) — 관리자 권한이 필요 없고, 현재 사용자 디렉터리에 설치되며, 공식 권장 방식입니다. ARM 기기의 경우 [ARM64 빌드](https://update.code.visualstudio.com/latest/win32-arm64-user/stable)를 사용하세요.

**설치**:

1. 다운로드한 `VSCodeUserSetup-*.exe`를 더블클릭합니다
2. 단계를 따라 "Next"를 클릭하고, "Select Additional Tasks"에서 **다음을 체크**하세요:
   - "Add to PATH"(기본으로 체크되어 있음, 그대로 유지) — 터미널에서 `code` 명령어를 사용할 수 있게 합니다
   - "Register Code as an editor for supported file types"
   - "Add 'Open with Code' action to the Windows Explorer context menu"(선택, 편리함)
3. 완료되면 VS Code를 실행합니다

</Tab>
<Tab value="macOS">

**다운로드**: [macOS 유니버설 빌드](https://update.code.visualstudio.com/latest/darwin-universal/stable) — Apple Silicon과 Intel 칩을 모두 지원하는 하나의 패키지입니다.

**설치**:

1. `VSCode-darwin-universal.zip`을 받게 됩니다; 더블클릭하여 압축을 풉니다
2. 압축을 푼 **Visual Studio Code.app**을 Finder의 **Applications** 폴더로 드래그합니다
3. Launchpad에서 VS Code를 엽니다
4. (권장) `Cmd+Shift+P`를 눌러 명령 팔레트를 열고 **Shell Command: Install 'code' command in PATH**를 실행하세요; 이후 터미널에서 `code .`로 현재 디렉터리를 열 수 있습니다

</Tab>
<Tab value="Linux">

배포판에 따라 선택하세요:

- **Debian / Ubuntu**: [.deb 패키지](https://update.code.visualstudio.com/latest/linux-deb-x64/stable)를 다운로드한 뒤 `sudo apt install ./code_*.deb`
- **RHEL / Fedora / openSUSE**: [.rpm 패키지](https://update.code.visualstudio.com/latest/linux-rpm-x64/stable)를 다운로드한 뒤 `sudo rpm -i code-*.rpm` (또는 `sudo dnf install code-*.rpm`)

`.deb` / `.rpm` 설치는 자동으로 `code`를 PATH에 추가하고 시스템 소프트웨어 업데이트에 연동합니다. 설치가 끝나면 터미널에서 `code`를 실행하거나 애플리케이션 메뉴에서 실행하세요.

</Tab>
</Tabs>

<Callout type="info" title="공식 사이트나 다운로드가 느린가요?">

설치 파일은 100~200MB이며, 중국에서는 단일 스레드 브라우저 다운로드가 이따금 느릴 수 있습니다. 위의 **공식 직접 링크**를 멀티스레드를 지원하는 다운로드 도구에 복사해 넣으면 대개 훨씬 빠릅니다 — 이 직접 링크에는 버전 번호가 없으며 항상 최신 안정 릴리스를 가리킵니다.

</Callout>

## 확장 프로그램 설치

1. VS Code(또는 Cursor / Trae / Antigravity)를 열고 확장 프로그램 패널로 이동합니다(단축키 `Cmd+Shift+X` / `Ctrl+Shift+X`)
2. **`Claude Code for VS Code`**를 검색하고, 공식 Anthropic 릴리스가 맞는지 확인하세요
3. **Install**을 클릭합니다; 설치가 완료되면 사이드바에 Claude 아이콘이 나타납니다

<Callout type="warn" title="Cursor / Trae / Antigravity 사용자를 위한 참고 사항">

일부 VS Code 파생 편집기는 비공개 확장 프로그램 스토어(예: Open VSX)를 사용합니다. `Claude Code for VS Code`를 찾을 수 없다면:

1. 공식 VS Code 확장 프로그램 마켓플레이스 페이지로 이동하여 `.vsix` 패키지를 다운로드하세요
2. 편집기의 확장 프로그램 패널 오른쪽 상단 `…` 메뉴에서 **VSIX에서 설치**를 선택하세요

</Callout>

## LMU AI API 설정

<Callout type="info" title="이미 Claude Code CLI를 설정했다면 이 섹션을 건너뛰어도 됩니다">

확장 프로그램은 CLI와 완전히 동일하게 `~/.claude/settings.json`을 읽습니다. **[Claude Code CLI 설정](/ko/docs/tools/claude-code)에서 설정한 키와 Base URL을 확장 프로그램이 자동으로 재사용합니다 — 추가 단계가 필요 없습니다.**

이는 곧 **VS Code, Cursor, Trae, Antigravity가 모두 동일한 설정을 공유한다**는 의미이기도 합니다 — 어느 편집기에서든 한 번 변경하면 다른 편집기와 CLI에도 적용됩니다.

</Callout>

처음 설정하는 경우, 다음과 같이 설정 파일을 만드세요:

<Tabs items={['Mac/Linux', 'Windows']}>
<Tab value="Mac/Linux">

```bash
mkdir -p ~/.claude && touch ~/.claude/settings.json
```

</Tab>
<Tab value="Windows">

```powershell
mkdir "$env:USERPROFILE\.claude" -Force
New-Item "$env:USERPROFILE\.claude\settings.json" -Force
```

</Tab>
</Tabs>

다음을 추가하세요(키를 본인 것으로 교체하세요):

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.lmuai.com",
    "ANTHROPIC_AUTH_TOKEN": "sk-your-lmu-ai-api-key",
    "API_TIMEOUT_MS": "3000000",
    "CLAUDE_CODE_ATTRIBUTION_HEADER": "0"
  }
}
```

자세한 내용(기본 중국어 모델 설정, `effortLevel` 조정 등 포함)은 [Claude Code CLI 설정](/ko/docs/tools/claude-code)을 참고하세요; **모든 설정 옵션이 적용됩니다**.

## 확장 프로그램 실행

1. 편집기에서 `Cmd+Shift+P` / `Ctrl+Shift+P`를 눌러 명령 팔레트를 엽니다
2. **`Claude Code: Open`**을 입력하거나, 사이드바의 Claude 아이콘을 클릭하세요
3. 열리는 채팅 패널에서 Claude Code와 대화하고, 코드를 생성하고, 파일을 자동으로 편집하게 할 수 있습니다

<Callout type="info" title="한 번 설정하면 어디서나 사용 가능">

- 터미널에서 `claude` 실행 → Claude Code CLI 사용
- **VS Code / Cursor / Trae / Antigravity** 사이드바의 Claude 아이콘 클릭 → 확장 프로그램 사용

**둘은 동일한 `~/.claude/settings.json`을 읽으므로**, 한 곳에서 변경하면 키, Base URL, 모델, 타임아웃 설정이 모든 곳에 적용됩니다.

</Callout>

## 자주 발생하는 문제

### 확장 프로그램에서 401 / Unauthorized

CLI와 동일한 방식입니다 — 보통 셸 환경 변수 `ANTHROPIC_BASE_URL` / `ANTHROPIC_API_KEY`가 `settings.json`을 덮어쓰기 때문입니다. [Claude Code CLI 설정 → 자주 발생하는 문제](/ko/docs/tools/claude-code#common-issues)를 참고하여 해결하세요.

### 중국어 모델 사용 / 기본 모델 전환

`settings.json`에 `"model": "qwen3.8-max-preview"`를 추가하면 CLI와 모든 VS Code 계열 편집기가 자동으로 해당 모델을 사용합니다. 사용 가능한 모델 목록은 [모델 갤러리](/ko/docs/guide/models)를 참고하세요.

### Cursor / Trae / Antigravity에서 확장 프로그램을 찾을 수 없음

앞의 "Cursor / Trae / Antigravity 사용자를 위한 참고 사항"을 따라 VSIX로 오프라인 설치하세요.

### 확장 프로그램과 CLI — 무엇을 선택해야 하나요?

- 편집기 안에서 코딩하는 것을 선호 → 확장 프로그램을 사용하면 모든 컨텍스트가 편집기에 남습니다
- 여러 편집기를 넘나들거나, 스크립트 작성, 배치 작업 → 더 유연한 CLI를 사용하세요

**어느 쪽도 기능적으로 더 낫지 않습니다** — 자신에게 맞는 것을 고르세요.
