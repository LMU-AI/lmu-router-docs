Crush — это терминальный AI-инструмент для кодинга от [Charm](https://charm.land), предлагающий как CLI, так и TUI для генерации кода, отладки, общения, работы с файлами и многозадачности из командной строки. Он поддерживает кастомные провайдеры — на этой странице описано его подключение к LMU AI.

## Настройка LMU AI

Crush настраивается с помощью **Bash-скрипта**. Отредактируйте глобальный файл конфигурации:

- **macOS / Linux**: `~/.config/crush/crushrc`
- **Windows**: `%USERPROFILE%\.config\crush\crushrc`

Есть два шага: добавить LMU AI как провайдер с помощью `provider add`, затем зарегистрировать нужные модели с помощью `model add`. Выберите протокол, соответствующий моделям, которые вы планируете использовать:

<Tabs items={['GPT / общее (openai-compat)', 'Claude / китайские модели (anthropic)']}>
<Tab value="GPT / общее (openai-compat)">

Подходит для моделей OpenAI, таких как `gpt-5.6-sol` и `gpt-5.5`. Claude и китайские модели тоже могут работать через этот протокол (бэкенд LMU AI выполняет преобразование протокола).

```bash
# Add LMU AI as a provider (OpenAI-compatible protocol)
provider add lmuai \
  --type openai-compat \
  --base-url "https://api.lmuai.com/v1" \
  --api-key "sk-your-lmu-ai-api-key"

# Register the models you want
model add lmuai/gpt-5.6-sol --name "GPT-5.6 Sol" --context-window 400000
model add lmuai/claude-opus-5 --name "Claude Opus 5" --context-window 200000

# Set it as the default large-model slot
model large lmuai/claude-opus-5
```

<Callout type="warn" title="Тип — openai-compat, а не openai">

В Crush есть два типа OpenAI. Согласно официальной документации, `openai` предназначен для проксирования или маршрутизации запросов **через сам OpenAI**, тогда как `openai-compat` — для **не-OpenAI провайдеров, предлагающих OpenAI-совместимые API**. LMU AI относится ко второй категории, поэтому используйте `openai-compat`.

</Callout>

</Tab>
<Tab value="Claude / китайские модели (anthropic)">

Подходит для моделей, обслуживаемых по протоколу Anthropic, таких как `claude-opus-5`, `claude-sonnet-5`, `qwen3.8-max-preview`, `deepseek-v4-pro`, `glm-5.2` и `kimi-k3`.

```bash
# Add LMU AI as a provider (Anthropic protocol)
provider add lmuai-anthropic \
  --type anthropic \
  --base-url "https://api.lmuai.com" \
  --api-key "sk-your-lmu-ai-api-key" \
  --extra-header anthropic-version 2023-06-01

# Register the models you want
model add lmuai-anthropic/claude-opus-5 \
  --name "Claude Opus 5" \
  --context-window 200000 \
  --can-reason true \
  --supports-images true

model add lmuai-anthropic/glm-5.2 --name "GLM-5.2" --context-window 200000

# Set it as the default large-model slot
model large lmuai-anthropic/claude-opus-5
```

<Callout type="warn" title="Не добавляйте /v1 к Anthropic base URL">

Установите `--base-url` равным `https://api.lmuai.com` — **не** `https://api.lmuai.com/v1`. Crush сам добавляет `/v1/messages`, поэтому лишний сегмент приводит к запросу `/v1/v1/messages`, который завершается ошибкой:

```
not found: POST "https://api.lmuai.com/v1/v1/messages": 404 Not Found
```

Это противоположно `openai-compat` (которому `/v1` нужен) — не перепутайте.

</Callout>

</Tab>
</Tabs>

<Callout type="warn" title="Файлы конфигурации — это доверенный код">

Официальное предупреждение: `crushrc` выполняется с привилегиями вашей оболочки ещё до появления интерфейса, а любые `$(...)` в `crush.json` выполняются во время загрузки. **Не запускайте Crush в каталоге, чью конфигурацию вы не проверили**, и не выполняйте `source` для файлов конфигурации неизвестного происхождения.

</Callout>

## Начало работы

После настройки перезапустите Crush:

```bash
crush
```

Переключайте модели внутри сессии командой:

```
/models
```

<Callout type="info" title="Модели LMU AI отсутствуют в /models?">

Встроенный список моделей Crush берётся из базы данных [Catwalk](https://github.com/charmbracelet/catwalk), которая не содержит идентификаторов моделей LMU AI. Сначала их нужно зарегистрировать с помощью `model add <provider>/<model-id>` — после перезапуска они появятся в списке `/models`.

</Callout>

## Устаревшая JSON-конфигурация

<Callout type="warn" title="crush.json официально устарел">

Изначально Crush использовал `crush.json`, который теперь **устарел** — сопровождающие заявили, что продолжат его поддерживать, но новые опции конфигурации будут добавляться только в Bash-конфигурацию (`crushrc`). Многие руководства всё ещё обучают формату JSON, но **новые настройки следует делать через `crushrc`, как показано выше**.

Уже есть JSON-конфигурация и хотите её мигрировать? Запустите Crush и просто попросите его на обычном языке сконвертировать её за вас.

</Callout>

Если вы всё же хотите использовать JSON, формат выглядит так (в файле `crush.json` в каталоге вашего проекта или в `~/.config/crush/`):

```json
{
  "$schema": "https://charm.land/crush.json",
  "providers": {
    "lmuai": {
      "id": "lmuai",
      "name": "LMU AI",
      "type": "openai-compat",
      "base_url": "https://api.lmuai.com/v1",
      "api_key": "sk-your-lmu-ai-api-key",
      "models": [
        {
          "id": "claude-opus-5",
          "name": "Claude Opus 5",
          "context_window": 200000,
          "default_max_tokens": 32000
        }
      ]
    }
  }
}
```

<Callout type="warn" title="Не пропускайте type и models в JSON">

Только `id` / `name` / `base_url` / `api_key` не сработают: `type` определяет, какой протокол используется (при его отсутствии происходит откат к предположению по умолчанию), а `models` определяет, что можно выбрать в `/models`. Это самая частая причина, по которой скопированный минимальный пример не работает.

</Callout>

## Примечания

- Файл конфигурации — `~/.config/crush/crushrc` (`%USERPROFILE%\.config\crush\crushrc` в Windows); `~/.local/share/crush/crush.json` — это состояние, принадлежащее машине, **не редактируйте его**
- Используйте `--type openai-compat` для OpenAI-совместимого эндпоинта LMU AI (**не** `openai`) и `--type anthropic` для протокола Anthropic
- **Эти два типа принимают противоположные формы `--base-url`**: `anthropic` принимает `https://api.lmuai.com` (без `/v1`), тогда как `openai-compat` принимает `https://api.lmuai.com/v1` (с `/v1`). Добавление `/v1` на стороне Anthropic даёт `/v1/v1/messages` и 404
- В качестве API-ключа просто введите ключ `sk-`, сгенерированный в консоли LMU AI
- Модели LMU AI отсутствуют во встроенном списке Crush, поэтому их нужно зарегистрировать с помощью `model add`, прежде чем они появятся в `/models`
