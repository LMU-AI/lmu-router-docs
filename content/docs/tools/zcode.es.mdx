ZCode es una aplicación de escritorio de Entorno de Desarrollo Agéntico (ADE) creada para tareas de largo horizonte. Admite proveedores personalizados para cualquier servicio de modelos que hable el protocolo de Anthropic o de OpenAI — esta página cubre cómo conectarlo a LMU AI.

---

## Instalar ZCode

Descarga e instala la versión para tu sistema operativo desde el sitio oficial:

- Sitio web: [https://zcode.z.ai](https://zcode.z.ai)

---

## Agregar LMU AI como proveedor

Abre **Configuración → Proveedores de modelos** y haz clic en "**Agregar proveedor**" al **final** de la lista de proveedores a la izquierda, luego completa:

| Campo | Valor |
|------|------|
| **Nombre** | lo que quieras, por ejemplo, `LMU AI` |
| **Endpoint de Anthropic** | `https://api.lmuai.com` |
| **Endpoint de OpenAI** | `https://api.lmuai.com/v1` |
| **Clave API** | la clave `sk-` generada en la consola de LMU AI |

<Callout type="warn" title="Los dos endpoints toman formas distintas de /v1">

- **Endpoint de Anthropic**: `https://api.lmuai.com` — **sin** `/v1`; el cliente agrega `/v1/messages` por sí mismo
- **Endpoint de OpenAI**: `https://api.lmuai.com/v1` — **debe** incluir `/v1`

Confundirlos produce un 401 o 404. Ambas direcciones pueden coexistir en la misma entrada de proveedor — ZCode usa el protocolo que coincida con el modelo que elijas.

</Callout>

---

## Agregar modelos

Los proveedores personalizados **no obtienen una lista de modelos automáticamente**, así que agrégalos a mano:

1. Guarda la configuración del proveedor
2. Haz clic en "**Agregar modelo**"
3. Ingresa el ID del modelo manualmente, por ejemplo, `claude-opus-5`
4. Activa el **interruptor de habilitación**

Repite para cada modelo que quieras. IDs de modelo comunes:

| ID de modelo | Notas |
|------|------|
| `claude-opus-5` | Claude Opus 5 (insignia, recomendado) |
| `claude-sonnet-5` | Claude Sonnet 5 (equilibrado) |
| `claude-haiku-4-5` | Claude Haiku 4.5 (rápido) |
| `gpt-5.6-sol` | GPT-5.6 Sol |
| `glm-5.2` | GLM-5.2 |
| `qwen3.8-max-preview` | Qwen 3.8 Max Preview |
| `deepseek-v4-pro` | DeepSeek V4 Pro |
| `kimi-k3` | Kimi K3 |

¿No estás seguro de qué modelo ingresar? Ve a la [Galería de modelos](/es/docs/guide/models) para ver todos los IDs de modelo disponibles y copiarlos con un solo clic.

## Habilitar la ventana de contexto de 1M

Los modelos principales como `claude-opus-5` y `claude-sonnet-5` admiten una ventana de contexto de 1M tokens — agrega el sufijo `[1M]` al ID del modelo para habilitarla:

```
claude-opus-5[1M]
```

Ingresa el ID completo con el sufijo usando los pasos de "Agregar modelo" anteriores.

<Callout type="info" title="La ventana de contexto se puede ajustar por modelo">

En **Configuración → Proveedores de modelos**, abre un modelo y expande "**Avanzado**" para establecer la **ventana de contexto** y los **tokens máximos de salida** para ese modelo individual. Ambos son editables para los modelos de un proveedor personalizado.

Se recomienda dejar los tokens máximos de salida vacíos (entonces sigue el propio límite del modelo). Ten en cuenta que el espacio de salida comparte el mismo contexto que tu historial de conversación, así que cuanto más alto lo establezcas, menos historial se puede llevar y más pronto se activa la compactación automática.

</Callout>

## Verificar la configuración

**Reinicia ZCode** una vez configurado, selecciona el modelo recién agregado en el selector de modelos del cuadro de chat y envía una instrucción simple para probar. Una respuesta normal significa que está todo listo.

<Callout type="info" title="¿No puedes conectarte? Revisa primero el proxy">

El proxy HTTP en la configuración de ZCode no es un proxy global, pero **las solicitudes de modelo sí pasan por él**. Si un proxy está rompiendo la conexión, apágalo y vuelve a intentarlo. Las variables de entorno `HTTP_PROXY` / `HTTPS_PROXY` también aplican, y ZCode necesita un reinicio después de que las cambies.

</Callout>

## Notas

- LMU AI es un proveedor de terceros / personalizado, así que créalo con "**Agregar proveedor**" al final de la lista — no modifiques las entradas de proveedores integradas
- El **endpoint de Anthropic** toma `https://api.lmuai.com` (sin `/v1`); el **endpoint de OpenAI** toma `https://api.lmuai.com/v1` (con `/v1`)
- Para la Clave API, ingresa la clave `sk-` generada en la consola de LMU AI
- Los proveedores personalizados requieren agregar cada modelo a mano y activar su interruptor de habilitación antes de que aparezca en el selector
- Un despliegue de terceros de un modelo con el mismo nombre puede ofrecer **niveles de esfuerzo de razonamiento** diferentes a los del endpoint oficial; los modelos personalizados suelen exponer solo un par de encendido/apagado, o ninguno
- Si te topas con errores relacionados con imágenes con un modelo personalizado, confirma que el modelo en sí acepta entrada de imágenes y declara su capacidad de imagen en la configuración del modelo
