## Erros comuns

**Erro: depois de configurar, você recebe um 401 dizendo que a chave está incorreta**

Causa: a requisição ainda está indo para o backend oficial da OpenAI em vez do nosso relay de API, ou você não reiniciou a ferramenta para recarregar o arquivo de configuração.

Solução: siga o guia novamente para **criar ou substituir** o `config.toml` e, depois, reinicie a ferramenta de IDE.

<Callout type="info" title="Quando você se deparar com um erro">

Tire uma captura de tela da mensagem de erro e traduza — você mesmo vai conseguir identificar o que causou o erro!

</Callout>

## Configuração

### Passo 1 — Criar / sobrescrever os arquivos de configuração

Local do arquivo de configuração:
- **Mac/Linux**: o diretório `~/.codex/`
- **Windows**: o diretório `C:\users\YourUsername\.codex\`

<Callout type="warn" title="Observação para Windows">

Se você já tinha feito login com a conta oficial ou com outra plataforma, saia da conta primeiro e só depois configure!

</Callout>

Se você não tem a pasta `.codex`, crie-a com um comando no terminal:

```bash
# Mac/Linux
rm -rf ~/.codex && mkdir ~/.codex
```

```powershell
# Windows (run in the terminal)
rm -rf C:\users\YourUsername\.codex
mkdir C:\users\YourUsername\.codex
```

### Passo 2 — Escrever o config.toml

No diretório `.codex`, crie ou sobrescreva o `config.toml`:

```toml
model_provider = "OpenAI"
model = "gpt-5.4"
review_model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
network_access = "enabled"
windows_wsl_setup_acknowledged = true
model_context_window = 1000000
model_auto_compact_token_limit = 900000

[model_providers.OpenAI]
name = "OpenAI"
base_url = "https://api.lmuai.com"
wire_api = "responses"

[model_providers.OpenAI.http_headers]
Authorization = "Bearer your sk- key generated in the console"
```

Substitua a última linha pela sua chave `sk-`, mantendo um espaço entre `Bearer` e a chave, e coloque a seção `http_headers` bem no final do arquivo. Versões mais recentes do Codex não precisam mais do `auth.json`; se um antigo continuar lá, não causa problema.

Depois de configurar, abra o VS Code, o Cursor ou o Trae, e a extensão Codex dentro deles fará login automaticamente.

## Instalando a extensão no Visual Studio Code

### Instalar a extensão

1. Abra o VS Code e primeiro abra qualquer pasta de projeto como seu workspace (**caso contrário, um pop-up vai pedir que você abra uma pasta de projeto!**)
2. Clique no painel de extensões à esquerda (o ícone Extensions)
3. Busque por **Codex**, encontre a extensão oficial da OpenAI "Codex – OpenAI's coding agent" e clique em Install
4. Após a instalação, uma entrada Codex aparece na barra lateral esquerda (se não aparecer, procure no canto superior direito da interface)

### Sair da conta antiga

<Callout type="warn" title="Importante">

Se você já tinha feito login com a conta oficial ou com outra plataforma, saia da conta primeiro e só depois configure!

</Callout>

1. Clique no ícone de configurações no canto superior direito do painel do Codex
2. Clique em **Log out** para sair da conta

### Concluir a configuração

Depois de configurar o `config.toml`, reabra a extensão Codex e clique em **Continue** para concluir o fluxo de login.

<Callout type="info" title="Sobre a exibição do modelo">

O modelo GPT-5.3 não aparece na lista suspensa; passe o mouse sobre "Custom" para ver o modelo em uso no momento.

Você também pode verificar o modelo realmente solicitado no console, em "Registros de uso".

</Callout>

## Quer usar Claude ou modelos chineses?

Se você usa somente o Trae e seu objetivo são modelos como **Claude / GLM / Qwen**, você não precisa da extensão Codex — a [configuração nativa de modelos no Trae](/pt/docs/tools/trae) (protocolo Anthropic, basta preencher alguns campos na interface gráfica) é mais simples.
