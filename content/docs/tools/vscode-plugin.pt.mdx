<Callout type="info" title="Se você usa o editor Trae">

Se você quiser usar **Claude ou modelos chineses (GLM / Qwen, etc.)**, o Trae tem um método nativo mais simples (sem extensão, apenas alguns cliques na interface gráfica) — veja [Configuração nativa de modelos do Trae](/pt/docs/tools/trae).

O método da extensão Codex nesta página é adequado para usuários que querem usar a série **GPT / Codex**.

## Erros comuns

**Erro: depois de configurar, você recebe um 401 dizendo que a chave está incorreta**

Causa: a requisição ainda está indo para o backend oficial da OpenAI em vez do nosso relay de API, ou você não reiniciou a ferramenta para recarregar o arquivo de configuração.

Correção: siga o guia novamente para **criar ou substituir** os dois arquivos `config.toml` e `auth.json`, depois reinicie a ferramenta de IDE.

<Callout type="info" title="Quando você encontrar um erro">

Faça uma captura de tela da mensagem de erro e traduza-a — você mesmo conseguirá identificar o que causou o erro!

</Callout>

## Configuração

### Passo 1 — Crie / sobrescreva os arquivos de configuração

Local dos arquivos de configuração:
- **Mac/Linux**: o diretório `~/.codex/`
- **Windows**: o diretório `C:\users\SeuNomeDeUsuário\.codex\`

<Callout type="warn" title="Observação para Windows">

Se você já fez login anteriormente com a conta oficial ou outra plataforma, saia primeiro e depois configure!

</Callout>

Se você não tiver uma pasta `.codex`, crie-a com um comando de terminal:

```bash
# Mac/Linux
rm -rf ~/.codex && mkdir ~/.codex
```

```powershell
# Windows (run in the terminal)
rm -rf C:\users\YourUsername\.codex
mkdir C:\users\YourUsername\.codex
```

### Passo 2 — Escreva o config.toml

No diretório `.codex`, crie ou sobrescreva `config.toml`:

```toml
model_provider = "OpenAI"
model = "gpt-5.4"
review_model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
network_access = "enabled"
windows_wsl_setup_acknowledged = true
model_context_window = 1000000
model_auto_compact_token_limit = 900000

[model_providers.OpenAI]
name = "OpenAI"
base_url = "https://api.lmuai.com"
wire_api = "responses"
requires_openai_auth = true
```

### Passo 3 — Escreva o auth.json

No diretório `.codex`, crie ou sobrescreva `auth.json`:

```json
{
  "OPENAI_API_KEY": "your sk- key generated in the console"
}
```

Uma vez configurado, abra o VS Code, Cursor ou Trae, e a extensão Codex dentro dele fará login automaticamente.

## Instalando a extensão do Visual Studio Code

### Instale a extensão

1. Abra o VS Code e primeiro abra qualquer pasta de projeto como seu workspace (**caso contrário, um popup solicitará que você abra uma pasta de projeto!**)
2. Clique no painel de extensões à esquerda (o ícone de Extensões)
3. Pesquise por **Codex**, encontre a extensão oficial da OpenAI "Codex – OpenAI's coding agent", e clique em Instalar
4. Após instalar, uma entrada Codex aparece na barra lateral esquerda (se não aparecer, procure no canto superior direito da interface)

### Saia da conta antiga

<Callout type="warn" title="Importante">

Se você já fez login anteriormente com a conta oficial ou outra plataforma, saia primeiro e depois configure!

</Callout>

1. Clique no ícone de configurações no canto superior direito do painel Codex
2. Clique em **Log out** para sair

### Conclua a configuração

Após configurar `config.toml` e `auth.json`, reabra a extensão Codex e clique em **Continue** para concluir o fluxo de login.

<Callout type="info" title="Sobre a exibição do modelo">

O modelo GPT-5.3 não aparece no menu suspenso; passe o mouse sobre "Custom" para ver o modelo em uso atualmente.

Você também pode verificar o modelo realmente solicitado no console, em "Registros de uso".

</Callout>

## Quer usar Claude ou modelos chineses?

Se você só usa o Trae e seu objetivo são modelos como **Claude / GLM / Qwen**, você não precisa da extensão Codex — a [Configuração nativa de modelos do Trae](/pt/docs/tools/trae) (protocolo Anthropic, basta preencher alguns campos na interface gráfica) é mais simples.
