El editor [Trae](https://www.trae.ai/) **admite de forma nativa la conexión a una API de terceros** (el protocolo compatible con Anthropic), sin plugin que instalar ni archivo de configuración que escribir — la forma más sencilla de conectar una API de terceros de cualquier editor. **Admite tanto modelos Claude oficiales como grandes modelos chinos (GLM, Qwen, DeepSeek, Kimi, etc.)**.

<Callout type="info" title="Método nativo vs. el plugin de Codex — ¿cuál elegir?">

- **Quieres modelos Claude / chinos** → el método nativo de esta página (protocolo Anthropic, unos pocos clics en la GUI)
- **Quieres la serie GPT-5 / Codex** → consulta el [plugin oficial de Codex](/es/docs/tools/vscode-plugin) (protocolo OpenAI, archivo de configuración escrito a mano)

Ambos enfoques pueden coexistir — si quieres usar ambos tipos de modelo, solo configura los dos.

</Callout>

## Pasos de configuración

1. Abre Trae y ve a **Configuración → Modelos → Agregar modelo**
2. Establece **Proveedor** en **Anthropic**
3. Establece **Modelo** en **Modelo personalizado** (al final del menú desplegable), luego ingresa el nombre del modelo en el campo **ID de modelo** debajo (consulta la tabla de modelos comunes más abajo)
4. Establece la **URL de solicitud personalizada** en:
   ```
   https://api.lmuai.com/v1/messages
   ```
5. Establece la **clave de API** con la clave que generaste en la consola de LMU AI (comienza con `sk-`)
6. Haz clic en **Confirmar** para guardar, luego cambia a ese modelo para empezar a usarlo

## Problemas comunes

### ¿Método nativo o el plugin de Codex?

- **Método nativo (esta página)**: usa el protocolo Anthropic y solo requiere unos pocos clics en la GUI — ideal para usuarios que quieren modelos como **Claude / GLM / Qwen**
- **[Método del plugin de Codex](/es/docs/tools/vscode-plugin)**: usa el protocolo OpenAI y requiere un archivo de configuración escrito a mano — ideal para usuarios que quieren la serie **GPT / Codex**

Ambos enfoques pueden coexistir — si quieres usar ambos tipos de modelo, solo configura los dos.

### ¿Por qué la URL de solicitud debe terminar en `/v1/messages`?

La URL de solicitud personalizada de Trae requiere el **endpoint completo** (a diferencia de herramientas como Chatbox, que agregan la ruta automáticamente). El endpoint de chat del protocolo Anthropic siempre es `/v1/messages`, por lo que la URL completa es `https://api.lmuai.com/v1/messages`.

### ¿Dónde encuentro los ID de modelo?

Consulta la lista completa de modelos disponibles en la [Galería de modelos](/es/docs/guide/models). Haz clic en cualquier tarjeta para copiar su ID de modelo y pégalo directamente en el campo ID de modelo de Trae.

### ¿No hay respuesta o aparece un error después de agregarlo?

- ¿El proveedor está configurado como **Anthropic** (no OpenAI)?
- ¿Elegiste Modelo personalizado en el menú desplegable de modelos y luego escribiste el ID de modelo manualmente?
- ¿La URL de solicitud termina en `/v1/messages`?
- ¿La clave de API es la clave `sk-` generada en la consola de LMU AI?

Guarda y reinicia el cliente de Trae una vez.
