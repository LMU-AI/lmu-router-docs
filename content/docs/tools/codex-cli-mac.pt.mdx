Depois de instalar o Codex CLI, crie manualmente um arquivo de configuração, `config.toml` (a chave vai em um cabeçalho de requisição dentro dele), para conectar à API da LMU AI — sem precisar de nenhuma ferramenta de configuração de terceiros.

---

## Passo 1 — Instale o Node.js

Você precisa do **Node.js 20+** — download: [https://nodejs.org/en/download](https://nodejs.org/en/download)

Avance pelo instalador e depois verifique no terminal:

```bash
node --version
# A version number (e.g. v23.7.0) means it installed correctly
```

## Passo 2 — Instale o Codex CLI

```bash
npm i -g @openai/codex
```

Se tiver problemas de rede, troque primeiro para um mirror da China:

```bash
npm config set registry https://registry.npmmirror.com
npm i -g @openai/codex
```

Verifique a instalação:

```bash
codex --version
# A version number means it installed correctly
```

## Passo 3 — Crie os arquivos de configuração

O diretório de configuração é **`~/.codex/`** (crie-o se não existir; sobrescreva quaisquer arquivos antigos). Crie/sobrescreva o `config.toml` nele:

### config.toml

```toml
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
sandbox_mode = "danger-full-access"
windows_wsl_setup_acknowledged = true
approval_policy = "never"
file_opener = "vscode"
model_provider = "codex"
web_search = "cached"
suppress_unstable_features_warning = true

[history]
persistence = "save-all"

[tui]
notifications = true

[shell_environment_policy]
inherit = "all"
ignore_default_excludes = false

[sandbox_workspace_write]
network_access = true

[features]
plan_tool = true
apply_patch_freeform = true
view_image_tool = true
unified_exec = false
streamable_shell = false
rmcp_client = true
elevated_windows_sandbox = true

[profiles.auto-max]
approval_policy = "never"
sandbox_mode = "workspace-write"

[profiles.review]
approval_policy = "on-request"
sandbox_mode = "workspace-write"

[notice]
hide_gpt5_1_migration_prompt = true

[model_providers.codex]
name = "codex"
base_url = "https://api.lmuai.com"
wire_api = "responses"

[model_providers.codex.http_headers]
Authorization = "Bearer your sk- key generated in the console"
```

<Callout type="warn" title="A chave vai em um cabeçalho de requisição">

- Substitua "sua chave sk- gerada no console" na última linha pela sua chave `sk-`, **mantendo um espaço entre `Bearer` e a chave**, por exemplo `Authorization = "Bearer sk-xxxx"`
- Coloque a seção `[model_providers.codex.http_headers]` no **final absoluto** do arquivo, sem nenhuma outra configuração depois dela
- Versões mais novas do Codex não precisam mais do `auth.json`. Se você criou um seguindo o guia antigo, deixá-lo no lugar não causa problema, ou você pode excluí-lo (mantenha-o se usar a [skill de geração de imagens do Codex App](/pt/docs/tools/codex-api-image))
- Se sua configuração antiga tiver `requires_openai_auth = true` na seção `[model_providers.codex]`, basta excluir essa linha

</Callout>

## Passo 4 — Inicie o Codex CLI

Depois de salvar os arquivos de configuração, reabra o terminal e execute o comando abaixo para iniciar e entrar automaticamente:

```bash
codex --dangerously-bypass-approvals-and-sandbox
```

Ou na forma curta:

```bash
codex --yolo
```

> Esse comando de inicialização pula as aprovações de segurança, então você não aprova cada etapa executada automaticamente.

Em uma inicialização bem-sucedida, a interface mostra o modelo atual como `gpt-5.4 xhigh` (o modelo definido pelo campo `model` no `config.toml`).

<Callout type="info" title="Sobre a troca de modelos">

Se você trocar acidentalmente para outro modelo em uma sessão, altere o campo `model` em `~/.codex/config.toml` de volta para `gpt-5.4` e reinicie o terminal para restaurá-lo.

</Callout>

## Ativando o contexto de 1M no Codex (opcional)

O `gpt-5.4` suporta uma **janela de contexto longo de 1M tokens** (272K por padrão), útil para revisão de repositórios grandes, análise de logs longos e refatorações entre arquivos. O Codex **não** ativa a janela de 1M por padrão; você precisa declará-la explicitamente no `config.toml`.

### Como configurar: adicione duas linhas ao config.toml

Edite o `~/.codex/config.toml` e adicione o seguinte no **nível superior** (antes de qualquer `[seção]`, por exemplo logo depois de `model = "gpt-5.4"`):

```toml
model_context_window = 1000000
model_auto_compact_token_limit = 900000
```

Salve, reabra o terminal e entre novamente no Codex para aplicar.

**Referência dos campos**

| Campo | Função |
|------|------|
| `model_context_window` | Declara a janela de contexto utilizável do modelo em tokens; `1000000` é 1M. Sem definição, usa o padrão do modelo (272K) |
| `model_auto_compact_token_limit` | O limite de tokens que dispara a compactação automática do histórico; defina em cerca de 90% da janela (`900000` para 1M). Valores acima de 90% da janela são limitados pelo Codex, então um número maior não tem efeito |

### Verifique se funcionou

Depois de entrar novamente no Codex, digite `/status` e confira se `context window` mostra cerca de 1M (algumas versões mostram cerca de 950K — uma margem de segurança de 5% reservada pelo Codex). Você também pode usar `/statusline` para adicionar o uso de contexto à barra de status e monitorar em tempo real.

### Se você usa o CC Switch

Se você gerencia a configuração do Codex com o [CC Switch](/pt/docs/tools/cc-switch), adicione as mesmas duas linhas no editor de configuração do Codex dele e aplique — o efeito é idêntico:

<Callout type="warn" title="Observações de uso">

- **Precisa estar no nível superior**: esses dois campos não têm efeito dentro de uma seção `[profiles.xxx]` (uma limitação conhecida do Codex); além disso, coloque-os no `~/.codex/config.toml` de nível de usuário, já que um `.codex/config.toml` de nível de projeto pode ser ignorado
- **Suporte dos modelos**: `gpt-5.4` e `gpt-5.5` suportam 1M pelo canal da API; modelos como o `gpt-5.3-codex` são limitados a 272K, e nenhum valor de configuração pode exceder o limite do próprio modelo
- **Custo maior**: um contexto mais longo consome mais tokens por requisição; a parte acima de 272K é cobrada na faixa mais alta de contexto longo, então não deixe isso ativo para nada além de tarefas muito longas
- **Diferenças entre versões**: algumas versões mais novas do Codex leem o tamanho da janela primeiro no catálogo de modelos; se o `/status` ainda mostrar o valor antigo, atualize para a versão mais recente (`npm i -g @openai/codex@latest`) e tente novamente

</Callout>
