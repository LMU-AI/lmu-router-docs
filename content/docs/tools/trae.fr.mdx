L'éditeur [Trae](https://www.trae.ai/) **prend en charge nativement la connexion à une API tierce** (le protocole compatible Anthropic), sans plugin à installer ni fichier de configuration à écrire — la façon la plus simple de connecter une API tierce parmi tous les éditeurs. **Il prend en charge à la fois les modèles Claude officiels et les grands modèles chinois (GLM, Qwen, DeepSeek, Kimi, etc.)**.

<Callout type="info" title="Méthode native ou plugin Codex — laquelle choisir ?">

- **Vous voulez Claude / des modèles chinois** → la méthode native de cette page (protocole Anthropic, quelques clics dans l'interface graphique)
- **Vous voulez la série GPT-5 / Codex** → voir le [plugin Codex officiel](/fr/docs/tools/vscode-plugin) (protocole OpenAI, fichier de configuration écrit à la main)

Les deux approches peuvent coexister — si vous voulez utiliser les deux types de modèles, configurez simplement les deux.

</Callout>

---

## Étapes de configuration

1. Ouvrez Trae et allez dans **Paramètres → Modèles → Ajouter un modèle**
2. Réglez **Fournisseur** sur **Anthropic**
3. Réglez **Modèle** sur **Modèle personnalisé** (au bas du menu déroulant), puis saisissez le nom du modèle dans le champ **ID de modèle** en dessous (voir le tableau des modèles courants ci-dessous)
4. Réglez l'**URL de requête personnalisée** sur :
   ```
   https://api.lmuai.com/v1/messages
   ```
5. Réglez la **clé API** sur la clé que vous avez générée dans la console LMU AI (commence par `sk-`)
6. Cliquez sur **Confirmer** pour enregistrer, puis basculez sur ce modèle pour commencer à l'utiliser

## Problèmes courants

### Méthode native ou plugin Codex ?

- **Méthode native (cette page)** : utilise le protocole Anthropic et ne demande que quelques clics dans l'interface graphique — idéale pour les utilisateurs qui veulent des modèles comme **Claude / GLM / Qwen**
- **[Méthode par plugin Codex](/fr/docs/tools/vscode-plugin)** : utilise le protocole OpenAI et nécessite un fichier de configuration écrit à la main — idéale pour les utilisateurs qui veulent la série **GPT / Codex**

Les deux approches peuvent coexister — si vous voulez utiliser les deux types de modèles, configurez simplement les deux.

### Pourquoi l'URL de requête doit-elle se terminer par `/v1/messages` ?

L'URL de requête personnalisée de Trae requiert le **point de terminaison complet** (contrairement à des outils comme Chatbox, qui ajoutent le chemin automatiquement). Le point de terminaison de conversation du protocole Anthropic est toujours `/v1/messages`, donc l'URL complète est `https://api.lmuai.com/v1/messages`.

### Où trouver les ID de modèles ?

Consultez la liste complète des modèles disponibles dans la [Galerie de modèles](/fr/docs/guide/models). Cliquez sur n'importe quelle carte pour copier son ID de modèle et le coller directement dans le champ ID de modèle de Trae.

### Aucune réponse ou une erreur après l'ajout ?

- Le fournisseur est-il réglé sur **Anthropic** (pas OpenAI) ?
- Avez-vous choisi Modèle personnalisé dans le menu déroulant des modèles puis saisi l'ID du modèle manuellement ?
- L'URL de requête se termine-t-elle par `/v1/messages` ?
- La clé API est-elle la clé `sk-` générée dans la console LMU AI ?

Enregistrez et redémarrez le client Trae une fois.
