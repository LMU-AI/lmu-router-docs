Se você não quer instalar o Codex CLI e só quer usar o **cliente desktop Codex App**, siga este método.

<Callout type="warn" title="Nota">

- Se você já tiver feito login com sua própria conta, primeiro **saia da conta atual** no Codex App e depois reconfigure.
- Depois de trocar a API, seu histórico de conversas desaparecerá (o histórico de conversas do tipo conta fica armazenado no espaço da sua conta GPT, não localmente).
- **Após trocar para o login via API, todo o histórico de conversas a partir de então será salvo localmente e não será perdido!**

</Callout>

---

## Passo 1 — Crie os arquivos de configuração

Local dos arquivos de configuração:
- **Mac/Linux**: a pasta `.codex` no seu diretório pessoal (`~`)
- **Windows**: `C:\users\seu-nome-de-usuario\.codex\`

Se a pasta já existir, o melhor é excluir os arquivos `auth.json` e `config.toml` dentro dela e recriá-los, para evitar interferência de configurações antigas.

**Crie a pasta com um comando no terminal:**

```bash
# Mac/Linux
rm -rf ~/.codex && mkdir ~/.codex
```

Crie dois arquivos na pasta `.codex`:

### auth.json

Guarda sua chave de API:

```json
{
  "OPENAI_API_KEY": "your sk- key generated in the console"
}
```

### config.toml

Configura o provedor de serviço:

```toml
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
sandbox_mode = "danger-full-access"
windows_wsl_setup_acknowledged = true
approval_policy = "never"
file_opener = "vscode"
model_provider = "codex"
web_search = "cached"
suppress_unstable_features_warning = true

[history]
persistence = "save-all"

[tui]
notifications = true

[shell_environment_policy]
inherit = "all"
ignore_default_excludes = false

[sandbox_workspace_write]
network_access = true

[features]
plan_tool = true
apply_patch_freeform = true
view_image_tool = true
unified_exec = false
streamable_shell = false
rmcp_client = true
elevated_windows_sandbox = true

[profiles.auto-max]
approval_policy = "never"
sandbox_mode = "workspace-write"

[profiles.review]
approval_policy = "on-request"
sandbox_mode = "workspace-write"

[notice]
hide_gpt5_1_migration_prompt = true

[model_providers.codex]
name = "codex"
base_url = "https://api.lmuai.com"
wire_api = "responses"
requires_openai_auth = true
```

<Callout type="info">

Normalmente fica dentro da pasta `.codex` no seu diretório pessoal. Se não encontrar a pasta `.codex` lá, você pode criar a pasta manualmente, junto com os arquivos `config.toml` e `auth.json`.

O conteúdo dos arquivos de configuração é idêntico ao do [guia de configuração do Codex CLI para Mac/Linux](/pt/docs/tools/codex-cli-mac) — você pode seguir aquele guia para criá-los no terminal, e eles passam a valer da mesma forma após reiniciar o Codex App.

</Callout>

---

## Passo 2 — Reabra o Codex App

Depois de salvar os arquivos de configuração, reabra o Codex App e ele fará login e estará pronto para uso automaticamente.

---

## Habilitando o contexto de 1M (opcional)

O `gpt-5.4` suporta um contexto longo de 1M tokens, mas ele vem desativado por padrão. Adicione duas linhas no **nível superior** do `config.toml` acima (antes de qualquer `[section]`) e depois reinicie o Codex App:

```toml
model_context_window = 1000000
model_auto_compact_token_limit = 900000
```

Para o significado dos campos, como verificar e ressalvas, veja [Habilitando o contexto de 1M no Codex](/pt/docs/tools/codex-cli-mac#enabling-the-1m-context-in-codex-optional).

---

## Erros comuns

**Erro 401, chave incorreta:**

Causa: a requisição ainda está indo para o endpoint oficial da OpenAI em vez do nosso relay de API, ou você não reiniciou a ferramenta para recarregar o arquivo de configuração.

Solução: siga o guia novamente para criar ou substituir os arquivos `config.toml` e `auth.json` e depois reabra o app.
