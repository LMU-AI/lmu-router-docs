يمكن لـ Cursor توجيه طلبات لوحة Chat / Plan إلى واجهة برمجة تطبيقات وسيط خارجي عبر **Override OpenAI Base URL**. تشرح هذه الصفحة كيفية استخدام هذه الطريقة الأصلية للاتصال بـ LMU AI.

<Callout type="warn" title="القيد الأساسي: لوحة Chat / Plan فقط هي المتأثرة">

Override OpenAI Base URL في Cursor **يؤثر فقط على لوحة Chat / Plan** (المحادثة التي تُفتح بـ Cmd/Ctrl + L). أما ميزات الوكيل الأساسية في Cursor — **Composer وTab autocomplete وApply وInline Edit** — فكلها مقيّدة بالخادم الرسمي لـ Cursor ولا يمكن الاستيلاء عليها بواسطة وسيط خارجي.

إذا كنت بحاجة إلى تجربة وكيل "بكامل القدرات" في Cursor (بما في ذلك ميزات من نوع Composer)، ثبّت بدلًا من ذلك (Cursor متوافق مع سوق إضافات VS Code):

- [إضافة Codex الرسمية](/ar/docs/tools/vscode-plugin) — وكيل Codex عبر بروتوكول OpenAI الخاص بـ LMU AI
- [إضافة Claude Code for VS Code](/ar/docs/tools/claude-code-vscode) — وكيل Claude Code عبر بروتوكول Anthropic الخاص بـ LMU AI

</Callout>

## خطوات التهيئة

### الخطوة 1 — افتح إعدادات Cursor

اضغط **Cmd + Shift + J** (macOS) أو **Ctrl + Shift + J** (Windows / Linux) لفتح Settings، وانقر **Models** في الشريط الجانبي الأيسر.

### الخطوة 2 — أوقف النماذج الافتراضية (موصى به)

يأتي Cursor مع العديد من النماذج الافتراضية (GPT-4 / Claude-3.5، إلخ)؛ إبقاؤها مفعّلة يتعارض مع التوجيه المخصص. في قائمة النماذج بصفحة Models، أوقفها **جميعًا** (المفتاح مطفأ على اليسار).

### الخطوة 3 — أضف نماذج مخصصة

انقر **Add Model** وأدخل معرّفات نماذج LMU AI التي تريدها، على سبيل المثال:

- `claude-opus-5`
- `claude-sonnet-5`
- `gpt-5.6-sol`
- `glm-5.2`
- `qwen3.8-max-preview`
- `deepseek-v4-pro`
- `kimi-k3`

**أضف كل نموذج مرة واحدة.** للاطلاع على القائمة الكاملة للنماذج المتاحة، راجع [معرض النماذج](/ar/docs/guide/models).

### الخطوة 4 — فعّل Override OpenAI Base URL

مرّر إلى منطقة **OpenAI API Key** في صفحة Models:

1. فعّل مفتاح **OpenAI API Key**
2. الصق مفتاح وحدة تحكم LMU AI (يبدأ بـ `sk-`) في مربع API Key
3. فعّل مفتاح **Override OpenAI Base URL**
4. اضبط Base URL على:
   ```
   https://api.lmuai.com/v1
   ```
5. انقر **Verify** للتحقق من الاتصال

<Callout type="info" title="فشل Verify لا يعني أن التهيئة خاطئة">

يتحقق Verify في Cursor باستخدام **اسم النموذج** الذي أدخلته، والأسماء غير الرسمية من OpenAI (`claude-opus-5` و`glm-5.2`، إلخ) لن تجتازه. الحل: **أضف `gpt-4` أولًا لتجاوز Verify** (للتأكد من اتصال Base URL + المفتاح)، ثم أضف معرّفات النماذج المخصصة التي تريدها بشكل منفصل؛ يحذّر Verify لكنه يعمل بشكل جيد عمليًا.

</Callout>

### الخطوة 5 — بدّل النموذج واستخدمه

اضغط **Cmd/Ctrl + L** لفتح لوحة Chat ← اختر النموذج المخصص الذي أضفته في الخطوة 3 من قائمة النماذج المنسدلة في الأعلى ← ابدأ الدردشة، وستمر الطلبات عبر LMU AI.

## المشكلات الشائعة

### تريد أن يستخدم Composer / Tab autocomplete أيضًا LMU AI؟

لا يمكن لـ Override OpenAI Base URL الأصلي فعل ذلك — فهذه الميزات الأساسية في Cursor مقيّدة بالخادم الرسمي. لتوجيه كل شيء عبر LMU AI، استخدم:

- [إضافة Codex الرسمية](/ar/docs/tools/vscode-plugin) — وكيل ببروتوكول OpenAI
- [إضافة Claude Code for VS Code](/ar/docs/tools/claude-code-vscode) — وكيل ببروتوكول Anthropic

Cursor متوافق مع سوق إضافات VS Code، لذا تُثبَّت كلتا الإضافتين مباشرةً في Cursor.

### هل يحتاج Base URL إلى `/v1`؟

**نعم.** أدخل `https://api.lmuai.com/v1`. يلحق Cursor `/chat/completions` ليصبح الطلب النهائي `https://api.lmuai.com/v1/chat/completions`. حذف `/v1` يعطي خطأ 404.

### يخطئ Claude 3.5 المدمج بعد تفعيل Override؟

هذا تعارض توجيه معروف في Cursor — تفعيل تجاوز OpenAI Base URL يقطع فرع Anthropic. للاستمرار في استخدام Claude في لوحة Chat، أضف معرّف نموذج Claude (مثل `claude-opus-5`) كنموذج مخصص، ويقوم خادم LMU AI بترجمة البروتوكول بين OpenAI ↔ Anthropic.

### أخطاء 401 / 403؟

تحقق بالترتيب:

1. هل **API Key** هو مفتاح `sk-` المُولّد في وحدة تحكم LMU AI (وليس مفتاح OpenAI رسمي)؟
2. هل **Base URL** هو `https://api.lmuai.com/v1` (**يجب أن يتضمن `/v1`**)؟
3. هل **معرّف النموذج** أحد المعرّفات التي يدعمها LMU AI (راجع [معرض النماذج](/ar/docs/guide/models))؟
4. هل تتضمن خطتك / مجموعة الفوترة الحالية النموذج الذي تستدعيه؟

### هل يؤثر BYOK على اشتراك Cursor الخاص بي؟

- استخدام BYOK **لا يستهلك** حصة الطلبات السريعة الشهرية لـ Cursor
- الميزات الأساسية مثل Composer / Tab autocomplete **ما زالت تستهلك** حصة اشتراك Cursor (لأنها لا تستخدم BYOK)
- لإسقاط اشتراك Cursor بالكامل، راجع نهج إضافة Codex / Claude Code أعلاه
