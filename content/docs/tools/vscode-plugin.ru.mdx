Если вы хотите использовать **Claude или китайские модели (GLM / Qwen и т. д.)**, в Trae есть более простой встроенный способ (без расширения, всего несколько клików в интерфейсе) — см. [Настройка моделей в Trae](/ru/docs/tools/trae).

## Частые ошибки

**Ошибка: после настройки возвращается 401 с сообщением о неверном ключе**

Причина: запрос по-прежнему уходит на официальный бэкенд OpenAI, а не на наш API-релей, либо вы не перезапустили инструмент, чтобы он перечитал файл конфигурации.

Решение: пройдите инструкцию заново и **создайте или замените** `config.toml`, затем перезапустите IDE.

<Callout type="info" title="Если возникла ошибка">

Сделайте скриншот сообщения об ошибке и переведите его — вы сами сможете понять причину!

</Callout>

## Настройка

### Шаг 1 — Создайте / перезапишите файлы конфигурации

Расположение файла конфигурации:
- **Mac/Linux**: каталог `~/.codex/`
- **Windows**: каталог `C:\users\YourUsername\.codex\`

<Callout type="warn" title="Примечание для Windows">

Если вы ранее входили через официальный аккаунт или другую платформу, сначала выйдите из него, а затем выполняйте настройку!

</Callout>

Если папки `.codex` нет, создайте её командой в терминале:

```bash
# Mac/Linux
rm -rf ~/.codex && mkdir ~/.codex
```

```powershell
# Windows (run in the terminal)
rm -rf C:\users\YourUsername\.codex
mkdir C:\users\YourUsername\.codex
```

### Шаг 2 — Запишите config.toml

В каталоге `.codex` создайте или перезапишите `config.toml`:

```toml
model_provider = "OpenAI"
model = "gpt-5.4"
review_model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
network_access = "enabled"
windows_wsl_setup_acknowledged = true
model_context_window = 1000000
model_auto_compact_token_limit = 900000

[model_providers.OpenAI]
name = "OpenAI"
base_url = "https://api.lmuai.com"
wire_api = "responses"

[model_providers.OpenAI.http_headers]
Authorization = "Bearer your sk- key generated in the console"
```

Замените последнюю строку своим ключом `sk-`, оставив один пробел между `Bearer` и ключом, и поместите секцию `http_headers` в самый конец файла. Новым версиям Codex больше не нужен `auth.json`; оставшийся старый файл не помешает.

После настройки откройте VS Code, Cursor или Trae — расширение Codex внутри выполнит вход автоматически.

## Установка расширения для Visual Studio Code

### Установка расширения

1. Откройте VS Code и сначала откройте любую папку проекта как рабочее пространство (**иначе появится всплывающее окно с просьбой открыть папку проекта!**)
2. Нажмите на панель расширений слева (иконка Extensions)
3. Найдите **Codex**, выберите официальное расширение OpenAI «Codex – OpenAI's coding agent» и нажмите «Установить»
4. После установки в левой боковой панели появится пункт Codex (если его нет, посмотрите в правом верхнем углу интерфейса)

### Выход из старого аккаунта

<Callout type="warn" title="Важно">

Если вы ранее входили через официальный аккаунт или другую платформу, сначала выйдите из него, а затем выполняйте настройку!

</Callout>

1. Нажмите на иконку настроек в правом верхнем углу панели Codex
2. Нажмите **Log out**, чтобы выйти

### Завершение настройки

После настройки `config.toml` снова откройте расширение Codex и нажмите **Continue**, чтобы завершить процесс входа.

<Callout type="info" title="Об отображении моделей">

Модель GPT-5.3 не отображается в выпадающем списке; наведите курсор на «Custom», чтобы увидеть используемую в данный момент модель.

Фактически запрошенную модель также можно посмотреть в консоли в разделе «Записи использования».

</Callout>

## Хотите использовать Claude или китайские модели?

Если вы используете только Trae и вам нужны модели вроде **Claude / GLM / Qwen**, расширение Codex не требуется — [настройка моделей в Trae](/ru/docs/tools/trae) (протокол Anthropic, достаточно заполнить несколько полей в интерфейсе) проще.
