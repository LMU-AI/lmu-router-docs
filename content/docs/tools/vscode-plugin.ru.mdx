Если вы хотите использовать **Claude или китайские модели (GLM / Qwen и т. д.)**, у Trae есть более простой встроенный способ (без расширения, всего несколько кликов в графическом интерфейсе) — см. [Встроенная настройка моделей Trae](/ru/docs/tools/trae).

</Callout>

## Частые ошибки

**Ошибка: после настройки вы получаете 401 с сообщением о неверном ключе**

Причина: запрос всё ещё идёт на официальный бэкенд OpenAI, а не на наш API-релей, или вы не перезапустили инструмент, чтобы перезагрузить файл конфигурации.

Решение: снова следуйте руководству, чтобы **создать или заменить** два файла `config.toml` и `auth.json`, затем перезапустите инструмент IDE.

<Callout type="info" title="Когда вы сталкиваетесь с ошибкой">

Сделайте скриншот сообщения об ошибке и переведите его — вы сами сможете понять, что вызвало ошибку!

</Callout>

## Настройка

### Шаг 1 — Создайте / перезапишите файлы конфигурации

Расположение файлов конфигурации:
- **Mac/Linux**: каталог `~/.codex/`
- **Windows**: каталог `C:\users\YourUsername\.codex\`

<Callout type="warn" title="Примечание для Windows">

Если вы ранее входили под официальным аккаунтом или с другой платформы, сначала выйдите из аккаунта, а затем настраивайте!

</Callout>

Если у вас нет папки `.codex`, создайте её командой в терминале:

```bash
# Mac/Linux
rm -rf ~/.codex && mkdir ~/.codex
```

```powershell
# Windows (run in the terminal)
rm -rf C:\users\YourUsername\.codex
mkdir C:\users\YourUsername\.codex
```

### Шаг 2 — Запишите config.toml

В каталоге `.codex` создайте или перезапишите `config.toml`:

```toml
model_provider = "OpenAI"
model = "gpt-5.4"
review_model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
network_access = "enabled"
windows_wsl_setup_acknowledged = true
model_context_window = 1000000
model_auto_compact_token_limit = 900000

[model_providers.OpenAI]
name = "OpenAI"
base_url = "https://api.lmuai.com"
wire_api = "responses"
requires_openai_auth = true
```

### Шаг 3 — Запишите auth.json

В каталоге `.codex` создайте или перезапишите `auth.json`:

```json
{
  "OPENAI_API_KEY": "your sk- key generated in the console"
}
```

После настройки откройте VS Code, Cursor или Trae, и расширение Codex внутри войдёт в аккаунт автоматически.

## Установка расширения Visual Studio Code

### Установите расширение

1. Откройте VS Code и сначала откройте любую папку проекта как рабочее пространство (**иначе появится всплывающее окно с просьбой открыть папку проекта!**)
2. Нажмите на панель расширений слева (иконка Extensions)
3. Найдите **Codex**, найдите официальное расширение OpenAI «Codex – OpenAI's coding agent» и нажмите Install
4. После установки в левой боковой панели появится запись Codex (если её нет, посмотрите в правом верхнем углу интерфейса)

### Выйдите из старого аккаунта

<Callout type="warn" title="Важно">

Если вы ранее входили под официальным аккаунтом или с другой платформы, сначала выйдите из аккаунта, а затем настраивайте!

</Callout>

1. Нажмите иконку настроек в правом верхнем углу панели Codex
2. Нажмите **Log out**, чтобы выйти из аккаунта

### Завершите настройку

После настройки `config.toml` и `auth.json` снова откройте расширение Codex и нажмите **Continue**, чтобы завершить процесс входа.

<Callout type="info" title="О отображении модели">

Модель GPT-5.3 не появляется в выпадающем списке; наведите курсор на «Custom», чтобы увидеть используемую в данный момент модель.

Вы также можете проверить фактически запрашиваемую модель в консоли в разделе «Записи использования».

</Callout>

## Хотите использовать Claude или китайские модели?

Если вы используете только Trae и ваша цель — модели вроде **Claude / GLM / Qwen**, вам не нужно расширение Codex — [Встроенная настройка моделей Trae](/ru/docs/tools/trae) (протокол Anthropic, достаточно заполнить несколько полей в графическом интерфейсе) проще.
