## Pré-requisitos

Antes de começar, certifique-se de que você tenha:

1. Registrado e adicionado créditos a uma conta da LMU AI ([Início rápido](/pt/docs/guide/getting-started))
2. Uma chave de API que começa com `sk-`
3. Instalado o Hermes Agent ([GitHub](https://github.com/nousresearch/hermes-agent))

## Configurar modelos da LMU AI

### Método 1 — Criar a configuração com um único comando

Abra um terminal e execute o seguinte comando:

```bash
mkdir -p ~/.hermes
cat > ~/.hermes/config.yaml << 'EOF'
providers:
  lumai:
    name: lumai
    base_url: https://api.lmuai.com/v1
    api_key: YOUR_API_KEY
    model: glm-5.2

model:
  provider: lumai
  model: glm-5.2
EOF
```

<Callout type="warn" title="Nota">

Substitua `YOUR_API_KEY` pela chave `sk-` real que você criou no console da LMU AI.

</Callout>

### Método 2 — Editar o arquivo de configuração manualmente

Se `~/.hermes/config.yaml` já existir, abra-o em um editor:

```bash
hermes config edit
```

Adicione ou modifique o seguinte no arquivo:

```yaml
providers:
  lumai:
    name: lumai
    base_url: https://api.lmuai.com/v1
    api_key: sk-your-actual-key
    model: glm-5.2

model:
  provider: lumai
  model: glm-5.2
```

Salve e saia.

## Modelos disponíveis

No campo `model`, você pode substituir por qualquer nome de modelo que a LMU AI suporte. Para a lista completa de modelos, consulte a [Galeria de Modelos](/pt/docs/guide/models).

## Verificar a configuração

Execute o seguinte comando para testar se a configuração funciona:

```bash
hermes chat -q 'Hello, please reply in one sentence' -Q
```

Se você receber uma resposta da AI, a configuração está funcionando.

## Problemas comuns

### Erro 401 Unauthorized

A chave de API está incorreta ou expirou. Verifique o status da chave no console da LMU AI.

### Erro 404 Not Found

A `base_url` está incorreta. O Hermes usa o protocolo OpenAI, então o endereço deve incluir o sufixo `/v1`:

```
https://api.lmuai.com/v1    ✅ Correct
https://api.lmuai.com       ❌ Wrong
```
