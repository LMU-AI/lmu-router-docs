## البروتوكولان

يدعم LMU AI بروتوكولَي اتصال؛ اختر واحدًا بناءً على نوع النموذج:

| البروتوكول | النماذج | API Host | API Path |
|------|----------|----------|----------|
| **Claude API (Anthropic Compatible)** | نماذج Claude، النماذج الصينية (DeepSeek، Qwen، GLM، Kimi، إلخ) | `https://api.lmuai.com` | الافتراضي جيد |
| **OpenAI Responses API Compatible** | نماذج OpenAI (GPT-5.6 / GPT-5.5، إلخ) | `https://api.lmuai.com` | `/responses` |

<Callout type="info" title="الـ API Host لا يتضمن /v1 أبدًا">

يضيف Chatbox المسار تلقائيًا عند إرسال طلب، لذا **أدخل دائمًا الـ API Host حتى النطاق فقط — لا تضمّن `/v1`**. على سبيل المثال، ينتهي بروتوكول OpenAI Responses إلى `https://api.lmuai.com/v1/responses`.

</Callout>

## الطريقة 1: بروتوكول Anthropic (Claude والنماذج الصينية)

### الخطوة 1 — إنشاء مزود

بعد فتح نافذة المزود الجديد من نقطة الدخول أعلاه:

1. **API Mode**: اختر **`Claude API (Anthropic Compatible)`**
2. **Name**: أي اسم تريده (مثل `LMU AI`)

### الخطوة 2 — إدخال تفاصيل API

- **API Host**: أدخل عنوان LMU AI API (**بدون** `/v1`)

  ```
  https://api.lmuai.com
  ```

- **API Key**: أدخل مفتاح `sk-` الذي أُنشئ في وحدة التحكم

### الخطوة 3 — إضافة النماذج

قد لا تتضمن قائمة Chatbox الافتراضية أحدث النماذج، لذا عليك إضافتها يدويًا. في صفحة إعدادات المزود، ابحث عن قسم Model → انقر New / Add Model وأدخل معرّف النموذج، على سبيل المثال:

- `claude-opus-5`
- `claude-sonnet-5`
- `claude-haiku-4-5`
- `deepseek-v4-pro`
- `qwen3.8-max-preview`
- `glm-5.2`
- `kimi-k3`

للحصول على القائمة الكاملة للنماذج المتاحة، راجع [معرض النماذج](/ar/docs/guide/models).

## الطريقة 2: بروتوكول OpenAI (نماذج GPT)

<Callout type="warn" title="المتطلبات">

عليك تلبية أحد هذين الشرطين:

- أن تكون مشتركًا في **خطة GPT**
- أن تستخدم الفوترة حسب الاستخدام وقد اخترت **مجموعة GPT** في وحدة تحكم LMU AI

</Callout>

### الخطوة 1 — إنشاء مزود

بعد فتح نافذة المزود الجديد من نقطة الدخول أعلاه:

1. **API Mode**: اختر **`OpenAI Responses API Compatible`** (وليس `OpenAI API Compatible`)
2. **Name**: أي اسم تريده (مثل `LMUAI-GPT`)

### الخطوة 2 — إدخال تفاصيل API

| الحقل | القيمة |
|------|------|
| API Key | مفتاح `sk-` الذي أُنشئ في وحدة التحكم |
| API Host | `https://api.lmuai.com` |
| API Path | `/responses` |

يجمع Chatbox تلقائيًا الـ Host و `/v1` والـ Path في عنوان الطلب الكامل `https://api.lmuai.com/v1/responses`، ويُعرض العنوان الكامل المُجمّع مباشرة أسفل الحقول.

بمجرد ملئها كما هو أعلاه، تبدو الشاشة هكذا:

![مثال على إعداد مزود GPT في Chatbox لسطح المكتب](/images/tools/chatbox-max/chatbox-mac-gpt.png)

### الخطوة 3 — إضافة النماذج

في قسم Model، انقر New وأدخل معرّف النموذج:

- `gpt-5.6-sol`
- `gpt-5.6-terra`
- `gpt-5.6-luna`
- `gpt-5.5`
- `gpt-5.4`
- `gpt-5.2`

## المشكلات الشائعة

### هل يحتاج الـ API Host إلى `/v1`؟

**لا.** أدخل دائمًا في حقل Chatbox API Host النطاق فقط: `https://api.lmuai.com`.

يضيف Chatbox `/v1` بنفسه:

- بروتوكول Anthropic: يصبح `https://api.lmuai.com/v1/messages`
- بروتوكول OpenAI Responses: عيّن الـ Path إلى `/responses`، فيصبح `https://api.lmuai.com/v1/responses`

إذا أضفت `/v1` إضافيًا في الـ Host، فستحصل على مسار 404 معطوب مثل `…/v1/v1/...`.

### لماذا نختار OpenAI Responses بدلاً من OpenAI API Compatible العادي؟

يستخدم OpenAI API Compatible في Chatbox نقطة النهاية الأقدم `/chat/completions`؛ بينما يستخدم بروتوكول OpenAI في LMU AI واجهة **Responses** الأحدث (`/v1/responses`)، لذا يجب أن تختار هنا **OpenAI Responses API Compatible** وتعيّن API Path إلى `/responses`.

### قائمة نماذج Chatbox لا تحتوي على Claude Opus 5 / GPT-5.6؟

تتحدث قائمة النماذج المُعدّة مسبقًا في Chatbox بتأخير، لذا يجب إضافة النماذج الجديدة يدويًا عبر Add Model في إعدادات المزود — فقط أدخل معرّف النموذج المقابل. للنماذج المتاحة، راجع [معرض النماذج](/ar/docs/guide/models).

### التغييرات لا تُطبَّق؟

بعد الحفظ، نوصي بـ **إعادة تشغيل عميل Chatbox مرة واحدة**، أو إعادة اختيار النموذج في شاشة المحادثة.

### أخطاء 401 / 403؟

تحقق بالترتيب:

1. هل مفتاح API هو مفتاح `sk-` الذي أُنشئ في وحدة تحكم LMU AI (وليس مفتاح Anthropic / OpenAI رسميًا)؟
2. هل الـ API Host خاطئ (يستخدم كلا البروتوكولين `https://api.lmuai.com`، **ولا أحدهما مع** `/v1`؛ بالنسبة لبروتوكول OpenAI، تحقق أيضًا من أن API Mode هو `OpenAI Responses API Compatible` وأن API Path هو `/responses`)؟
3. هل تتضمن خطتك / مجموعة الفوترة الحالية النموذج الذي تستدعيه؟
