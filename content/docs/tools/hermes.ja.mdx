## 前提条件

始める前に、以下を用意してください:

1. LMU AI アカウントを登録し、チャージ済みであること（[クイックスタート](/ja/docs/guide/getting-started)）
2. `sk-` で始まる API キー
3. Hermes Agent がインストール済みであること（[GitHub](https://github.com/nousresearch/hermes-agent)）

## LMU AI モデルを設定する

### 方法 1 — コマンド一つで設定を作成する

ターミナルを開いて、次のコマンドを実行します:

```bash
mkdir -p ~/.hermes
cat > ~/.hermes/config.yaml << 'EOF'
providers:
  lumai:
    name: lumai
    base_url: https://api.lmuai.com/v1
    api_key: YOUR_API_KEY
    model: glm-5.2

model:
  provider: lumai
  model: glm-5.2
EOF
```

<Callout type="warn" title="注意">

`YOUR_API_KEY` を、LMU AI コンソールで作成した実際の `sk-` キーに置き換えてください。

</Callout>

### 方法 2 — 設定ファイルを手動で編集する

`~/.hermes/config.yaml` が既に存在する場合は、エディタで開きます:

```bash
hermes config edit
```

ファイルに次の内容を追加または変更します:

```yaml
providers:
  lumai:
    name: lumai
    base_url: https://api.lmuai.com/v1
    api_key: sk-your-actual-key
    model: glm-5.2

model:
  provider: lumai
  model: glm-5.2
```

保存して終了します。

## 利用可能なモデル

`model` フィールドには、LMU AI がサポートする任意のモデル名を代入できます。モデルの全リストについては、[モデルギャラリー](/ja/docs/guide/models)を参照してください。

## 設定を確認する

次のコマンドを実行して、設定が機能するかどうかをテストします:

```bash
hermes chat -q 'Hello, please reply in one sentence' -Q
```

AI から返信があれば、設定は正常に機能しています。

## よくある問題

### 401 Unauthorized エラー

API キーが誤っているか期限切れです。LMU AI コンソールでキーのステータスを確認してください。

### 404 Not Found エラー

`base_url` が誤っています。Hermes は OpenAI プロトコルを使用するため、アドレスには `/v1` サフィックスを含める必要があります:

```
https://api.lmuai.com/v1    ✅ Correct
https://api.lmuai.com       ❌ Wrong
```
