إذا كنت لا ترغب في تثبيت Codex CLI وتريد فقط استخدام **عميل Codex App لسطح المكتب**، فاتبع هذه الطريقة.

<Callout type="warn" title="ملاحظة">

- إذا سبق أن سجّلت الدخول بحسابك الخاص، فقم أولًا بـ **تسجيل الخروج من الحساب الحالي** في Codex App، ثم أعد الضبط.
- بعد أن تبدّل واجهة API، سيختفي سجل محادثاتك (سجل المحادثات من نوع الحساب يُخزَّن في مساحة حساب GPT الخاص بك، وليس محليًا).
- **بعد أن تبدّل إلى تسجيل الدخول عبر API، يُحفَظ كل سجل المحادثات من ذلك الحين فصاعدًا محليًا ولن يُفقَد!**

</Callout>

## الخطوة 1 — إنشاء ملفات الضبط

موقع ملف الضبط:
- **Mac/Linux**: مجلد `.codex` في مجلدك الرئيسي (`~`)
- **Windows**: `C:\users\your-username\.codex\`

إذا كان المجلد موجودًا بالفعل، فمن الأفضل حذف `auth.json` و`config.toml` بداخله وإعادة إنشائهما، لتجنّب تداخل الضبط القديم.

**أنشئ المجلد باستخدام أمر طرفية:**

```bash
# Mac/Linux
rm -rf ~/.codex && mkdir ~/.codex
```

أنشئ ملفين في مجلد `.codex`:

### auth.json

يحمل مفتاح API الخاص بك:

```json
{
  "OPENAI_API_KEY": "your sk- key generated in the console"
}
```

### config.toml

اضبط مزوّد الخدمة:

```toml
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
sandbox_mode = "danger-full-access"
windows_wsl_setup_acknowledged = true
approval_policy = "never"
file_opener = "vscode"
model_provider = "codex"
web_search = "cached"
suppress_unstable_features_warning = true

[history]
persistence = "save-all"

[tui]
notifications = true

[shell_environment_policy]
inherit = "all"
ignore_default_excludes = false

[sandbox_workspace_write]
network_access = true

[features]
plan_tool = true
apply_patch_freeform = true
view_image_tool = true
unified_exec = false
streamable_shell = false
rmcp_client = true
elevated_windows_sandbox = true

[profiles.auto-max]
approval_policy = "never"
sandbox_mode = "workspace-write"

[profiles.review]
approval_policy = "on-request"
sandbox_mode = "workspace-write"

[notice]
hide_gpt5_1_migration_prompt = true

[model_providers.codex]
name = "codex"
base_url = "https://api.lmuai.com"
wire_api = "responses"
requires_openai_auth = true
```

<Callout type="info">

عادةً ما يكون داخل مجلد `.codex` في مجلدك الرئيسي. إذا لم تتمكن من العثور على مجلد `.codex` هناك، يمكنك إنشاء المجلد يدويًا، إلى جانب `config.toml` و`auth.json`.

محتويات ملف الضبط مطابقة لـ [دليل إعداد Codex CLI على Mac/Linux](/ar/docs/tools/codex-cli-mac) — يمكنك اتباع ذلك الدليل لإنشائها في الطرفية، وتُطبَّق بعد إعادة تشغيل Codex App بالطريقة نفسها.

</Callout>

## الخطوة 2 — أعد فتح Codex App

بعد حفظ ملفات الضبط، أعد فتح Codex App وسيسجّل الدخول ويصبح جاهزًا للاستخدام تلقائيًا.

---

## تفعيل سياق المليون توكن (اختياري)

يدعم `gpt-5.4` سياقًا طويلًا بحجم مليون توكن، لكنه معطّل افتراضيًا. أضف سطرين في **المستوى الأعلى** من ملف `config.toml` أعلاه (قبل أي `[section]`)، ثم أعد تشغيل Codex App:

```toml
model_context_window = 1000000
model_auto_compact_token_limit = 900000
```

لمعاني الحقول، وكيفية التحقق، والتحذيرات، راجع [تفعيل سياق المليون توكن في Codex](/ar/docs/tools/codex-cli-mac#enabling-the-1m-context-in-codex-optional).

## الأخطاء الشائعة

**الخطأ 401، مفتاح غير صحيح:**

السبب: لا يزال الطلب يذهب إلى نقطة نهاية OpenAI الرسمية بدلًا من مُرحّل API الخاص بنا، أو أنك لم تُعِد تشغيل الأداة لإعادة تحميل ملف الضبط.

الحل: اتبع الدليل مرة أخرى لإنشاء أو استبدال ملفي `config.toml` و`auth.json`، ثم أعد فتح التطبيق.
