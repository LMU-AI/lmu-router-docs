إذا لم ترغب في تثبيت Codex CLI وتريد فقط استخدام **عميل سطح المكتب Codex App**، فاتبع هذه الطريقة.

<Callout type="warn" title="ملاحظة">

- إذا كنت قد سجّلت الدخول سابقًا بحسابك الخاص، فعليك أولًا **تسجيل الخروج من الحساب الحالي** في Codex App، ثم إعادة الضبط.
- بعد تبديل الـ API، سيختفي سجل محادثاتك (سجل محادثات نوع الحساب يُخزَّن في مساحة حساب GPT الخاص بك، وليس محليًا).
- **بعد التبديل إلى تسجيل الدخول عبر API، يُحفَظ كل سجل المحادثات من تلك اللحظة محليًا ولن يُفقد!**

</Callout>

## الخطوة 1 — إنشاء ملفات الإعداد

موقع ملف الإعداد:
- **Mac/Linux**: مجلد `.codex` في مجلد المنزل الخاص بك (`~`)
- **Windows**: `C:\users\your-username\.codex\`

إذا كان المجلد موجودًا بالفعل، فالأفضل حذف ملف `config.toml` الموجود داخله (وأي ملف `auth.json` متبقٍّ من الدليل القديم) وإعادة إنشائه، لتجنّب تداخل الإعدادات القديمة.

**أنشئ المجلد بأمر في الطرفية:**

```bash
# Mac/Linux
rm -rf ~/.codex && mkdir ~/.codex
```

أنشئ ملف `config.toml` داخل مجلد `.codex`.

### config.toml

اضبط مزوّد الخدمة؛ ويوضع مفتاح API في ترويسة طلب في آخر الملف تمامًا:

```toml
model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
sandbox_mode = "danger-full-access"
windows_wsl_setup_acknowledged = true
approval_policy = "never"
file_opener = "vscode"
model_provider = "codex"
web_search = "cached"
suppress_unstable_features_warning = true

[history]
persistence = "save-all"

[tui]
notifications = true

[shell_environment_policy]
inherit = "all"
ignore_default_excludes = false

[sandbox_workspace_write]
network_access = true

[features]
plan_tool = true
apply_patch_freeform = true
view_image_tool = true
unified_exec = false
streamable_shell = false
rmcp_client = true
elevated_windows_sandbox = true

[profiles.auto-max]
approval_policy = "never"
sandbox_mode = "workspace-write"

[profiles.review]
approval_policy = "on-request"
sandbox_mode = "workspace-write"

[notice]
hide_gpt5_1_migration_prompt = true

[model_providers.codex]
name = "codex"
base_url = "https://api.lmuai.com"
wire_api = "responses"

[model_providers.codex.http_headers]
Authorization = "Bearer your sk- key generated in the console"
```

استبدل السطر الأخير بمفتاحك الذي يبدأ بـ `sk-`، مع الإبقاء على مسافة واحدة بين `Bearer` والمفتاح. ضع قسم `[model_providers.codex.http_headers]` في آخر الملف تمامًا، دون أي إعدادات أخرى بعده.

<Callout type="info">

عادةً ما يكون داخل مجلد `.codex` في مجلد المنزل الخاص بك. إذا لم تجد مجلد `.codex` هناك، يمكنك إنشاء المجلد يدويًا، ثم إنشاء `config.toml` داخله.

محتويات ملف الإعداد مماثلة تمامًا لما في [دليل إعداد Codex CLI على Mac/Linux](/ar/docs/tools/codex-cli-mac) — يمكنك اتباع ذلك الدليل لإنشائها في الطرفية، وتصبح فعّالة بعد إعادة تشغيل Codex App بالطريقة نفسها.

</Callout>

## الخطوة 2 — إعادة فتح Codex App

بعد حفظ ملفات الإعداد، أعد فتح Codex App وسيقوم بتسجيل الدخول تلقائيًا ويصبح جاهزًا للاستخدام.

---

## تمكين سياق المليون رمز (اختياري)

يدعم `gpt-5.4` سياقًا طويلًا بحجم مليون Token، لكنه معطّل افتراضيًا. أضف سطرين في **المستوى الأعلى** من ملف `config.toml` أعلاه (قبل أي `[section]`)، ثم أعد تشغيل Codex App:

```toml
model_context_window = 1000000
model_auto_compact_token_limit = 900000
```

لمعاني الحقول، وكيفية التحقق، والتحذيرات، راجع [تمكين سياق المليون رمز في Codex](/ar/docs/tools/codex-cli-mac#enabling-the-1m-context-in-codex-optional).

## الأخطاء الشائعة

**خطأ 401، المفتاح غير صحيح:**

السبب: لا يزال الطلب يتجه إلى نقطة النهاية الرسمية لـ OpenAI بدلًا من وسيط API الخاص بنا، أو أنك لم تعد تشغيل الأداة لإعادة تحميل ملف الإعداد.

الحل: اتبع الدليل مرة أخرى لإنشاء `config.toml` أو استبداله، ثم أعد فتح التطبيق.

**خطأ 401 API_KEY_REQUIRED:**

السبب: قد لا تقرأ الإصدارات الأحدث من Codex المفتاح من `auth.json`، لذا يُرسل الطلب دون مفتاح.

الحل: أضف قسم `[model_providers.codex.http_headers]` في نهاية ملف `config.toml` كما هو موضّح أعلاه؛ راجع [الأسئلة الشائعة · المشكلة 10](/ar/docs/guide/faq#issue-10).
