ZCode는 장기 과제를 위해 설계된 에이전틱 개발 환경(Agentic Development Environment, ADE) 데스크톱 앱입니다. Anthropic 또는 OpenAI 프로토콜을 사용하는 모든 모델 서비스에 대해 사용자 지정 제공자를 지원합니다 — 이 페이지에서는 LMU AI에 연결하는 방법을 다룹니다.

공식 사이트에서 운영 체제에 맞는 빌드를 다운로드해 설치하세요:

- 웹사이트: [https://zcode.z.ai](https://zcode.z.ai)

## LMU AI를 제공자로 추가

**설정 → 모델 제공자**를 열고 왼쪽 제공자 목록 **하단**의 "**제공자 추가**"를 클릭한 다음 아래를 입력합니다:

| 필드 | 값 |
|------|------|
| **이름** | 원하는 대로, 예: `LMU AI` |
| **Anthropic 엔드포인트** | `https://api.lmuai.com` |
| **OpenAI 엔드포인트** | `https://api.lmuai.com/v1` |
| **API Key** | LMU AI 콘솔에서 생성한 `sk-` 키 |

<Callout type="warn" title="두 엔드포인트는 서로 다른 /v1 형식을 취합니다">

- **Anthropic 엔드포인트**: `https://api.lmuai.com` — `/v1` **없음**; 클라이언트가 스스로 `/v1/messages`를 덧붙입니다
- **OpenAI 엔드포인트**: `https://api.lmuai.com/v1` — `/v1`을 **반드시** 포함해야 합니다

이 둘을 혼동하면 401 또는 404가 발생합니다. 두 주소는 같은 제공자 항목 안에 함께 있을 수 있습니다 — ZCode는 선택한 모델에 맞는 프로토콜을 사용합니다.

</Callout>

## 모델 추가

사용자 지정 제공자는 **모델 목록을 자동으로 가져오지 않으므로** 손으로 추가하세요:

1. 제공자 구성을 저장합니다
2. "**모델 추가**"를 클릭합니다
3. 모델 ID를 수동으로 입력합니다, 예: `claude-opus-5`
4. **활성화 토글**을 켭니다

원하는 각 모델에 대해 반복하세요. 일반적인 모델 ID:

| 모델 ID | 참고 |
|------|------|
| `claude-opus-5` | Claude Opus 5 (플래그십, 권장) |
| `claude-sonnet-5` | Claude Sonnet 5 (균형형) |
| `claude-haiku-4-5` | Claude Haiku 4.5 (빠름) |
| `gpt-5.6-sol` | GPT-5.6 Sol |
| `glm-5.2` | GLM-5.2 |
| `qwen3.8-max-preview` | Qwen 3.8 Max Preview |
| `deepseek-v4-pro` | DeepSeek V4 Pro |
| `kimi-k3` | Kimi K3 |

어떤 모델을 입력할지 모르겠나요? [모델 갤러리](/ko/docs/guide/models)로 이동해 사용 가능한 모든 모델 ID를 확인하고 원클릭으로 복사하세요.

## 1M 컨텍스트 창 활성화

`claude-opus-5`, `claude-sonnet-5` 같은 메인라인 모델은 1M 토큰 컨텍스트 창을 지원합니다 — 모델 ID에 `[1M]` 접미사를 추가해 활성화하세요:

```
claude-opus-5[1M]
```

위의 "모델 추가" 단계를 사용해 접미사가 포함된 전체 ID를 입력하세요.

<Callout type="info" title="컨텍스트 창은 모델별로 조정할 수 있습니다">

**설정 → 모델 제공자**에서 모델을 열고 "**고급**"을 펼쳐 해당 개별 모델의 **컨텍스트 창**과 **최대 출력 토큰**을 설정하세요. 두 값 모두 사용자 지정 제공자의 모델에 대해 편집할 수 있습니다.

최대 출력 토큰은 비워 두는 것을 권장합니다(그러면 모델 자체의 한도를 따릅니다). 출력 공간은 대화 기록과 동일한 컨텍스트를 공유하므로, 높게 설정할수록 담을 수 있는 기록이 줄어들고 자동 압축이 더 빨리 시작된다는 점에 유의하세요.

</Callout>

## 설정 확인

구성이 끝나면 **ZCode를 재시작**하고, 채팅 상자의 모델 선택기에서 새로 추가한 모델을 선택한 뒤 간단한 지시를 보내 테스트하세요. 정상적인 응답이 오면 설정이 완료된 것입니다.

<Callout type="info" title="연결이 안 되나요? 먼저 프록시를 확인하세요">

ZCode 설정의 HTTP 프록시는 전역 프록시는 아니지만, **모델 요청은 그 프록시를 거칩니다**. 프록시가 연결을 방해한다면 끄고 다시 시도하세요. `HTTP_PROXY` / `HTTPS_PROXY` 환경 변수도 적용되며, 변경 후에는 ZCode를 재시작해야 합니다.

</Callout>

## 참고

- LMU AI는 서드파티 / 사용자 지정 제공자이므로 목록 하단의 "**제공자 추가**"로 생성하세요 — 내장 공급자 항목을 수정하지 마세요
- **Anthropic 엔드포인트**는 `https://api.lmuai.com`을 사용하고(`/v1` 없음), **OpenAI 엔드포인트**는 `https://api.lmuai.com/v1`을 사용합니다(`/v1` 포함)
- API Key에는 LMU AI 콘솔에서 생성한 `sk-` 키를 입력하세요
- 사용자 지정 제공자는 각 모델을 손으로 추가하고 선택기에 표시되기 전에 활성화 토글을 켜야 합니다
- 같은 이름의 모델을 서드파티로 배포한 경우 공식 엔드포인트와 다른 **사고 강도 레벨**을 제공할 수 있습니다; 사용자 지정 모델은 보통 켜기/끄기 한 쌍만 노출하거나 아예 노출하지 않습니다
- 사용자 지정 모델에서 이미지 관련 오류가 발생하면, 해당 모델이 이미지 입력을 지원하는지 확인하고 모델 구성에서 이미지 지원 기능을 선언하세요
