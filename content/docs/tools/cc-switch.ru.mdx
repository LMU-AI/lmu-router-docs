**CC Switch** — это кроссплатформенный настольный инструмент с открытым исходным кодом для управления и переключения одним кликом конфигураций провайдеров API в инструментах для ИИ-кодинга, таких как Claude Code, Codex, OpenCode и Gemini CLI.

В сочетании с кнопкой «**Import to CCS**» в консоли LMU AI он подключает Claude Code к API одним кликом, **без необходимости создавать или редактировать `settings.json` вручную**.

---

## Шаг 1 — Установите CC Switch

Скачайте установщик для вашей платформы со страницы Releases официального репозитория:

- **GitHub Releases**: [https://github.com/farion1231/cc-switch/releases](https://github.com/farion1231/cc-switch/releases)

Поддерживаются Windows / macOS / Linux. После установки запустите CC Switch хотя бы один раз, чтобы система зарегистрировала его пользовательскую URL-схему.

<Callout type="info">

После первого запуска держите CC Switch запущенным (или пусть он остаётся в фоне), чтобы нажатие «Import to CCS» могло корректно его вызвать.

</Callout>

---

## Шаг 2 — Создайте ключ API в консоли LMU AI

См. [Начало работы — Создание ключа API](/ru/docs/guide/getting-started#create-key):

1. Откройте «**API Keys**» в левом меню
2. Нажмите «**Create key**» и задайте любое имя
3. Выберите **группу** для активированного вами плана и завершите создание

---

## Шаг 3 — Импорт в CC Switch одним кликом

В списке ключей API найдите только что созданный ключ и нажмите кнопку «**Import to CCS**» в столбце «**Actions**» справа в его строке:

![Расположение кнопки «Import to CCS» в списке ключей API консоли LMU AI](/images/tools/cc-switch/ccs.avif)


- Браузер покажет запрос «Разрешить этому сайту открыть CC Switch?» — нажмите «**Разрешить / Открыть**»
- CC Switch автоматически определит и заполнит `Base URL` LMU AI и ваш ключ API
- Установите эту конфигурацию как активный элемент в CC Switch

<Callout type="info" title="Запрос при первом использовании">

Разные браузеры (Chrome / Edge / Safari) формулируют подтверждение немного по-разному, но все они спрашивают, запускать ли внешнее приложение CC Switch. Отметьте «запомнить мой выбор», чтобы вас не спрашивали снова.

</Callout>

---

## Шаг 4 — Примените изменения в Claude Code

CC Switch записывает выбранную конфигурацию в `settings.json` Claude Code (или внедряет переменные окружения при запуске), поэтому:

- Если Claude Code **уже открыт**, перезапустите его один раз, чтобы новая конфигурация вступила в силу
- После этого просто запустите `claude` — не нужно редактировать никакие файлы конфигурации вручную

Проверьте, что Base URL равен `https://api.lmuai.com`, командой `/status`.

## Частые проблемы

### Кнопка «Import to CCS» ничего не делает

**Причина:** система не зарегистрировала URL-схему CC Switch.

**Решение:**
1. Убедитесь, что вы полностью установили CC Switch (а не запустили распакованную портативную сборку напрямую)
2. Запустите CC Switch один раз, полностью закройте его, затем снова нажмите «Import to CCS»
3. Если на Windows по-прежнему не работает, найдите в настройках CC Switch опцию «зарегистрировать протокол / связать ссылки»

### Браузер заблокировал переход по протоколу

Некоторые браузеры по умолчанию блокируют неизвестные протоколы. В диалоговом окне выберите «**всегда разрешать** домену документации / консоли открывать такие ссылки».

### Вы хотите добавить конфигурацию вручную

CC Switch также поддерживает добавление пользовательского провайдера вручную:

- **Имя**: любое (например, `LMU AI`)
- **Base URL**: `https://api.lmuai.com`
- **API Key**: ключ `sk-`, сгенерированный в консоли

Сохраните его и установите как активный элемент на главном экране.

## Рекомендации

- CC Switch может хранить ключи для нескольких групп / планов и переключаться одним кликом, что делает его **лучше редактирования `settings.json` для пользователей с несколькими планами**
- В режиме работы в трее он потребляет очень мало ресурсов, поэтому рекомендуется настроить автозапуск при загрузке
- Если вы в основном пользуетесь командной строкой и не против редактировать файл конфигурации, продолжайте настраивать вручную согласно [руководству по Claude Code](/ru/docs/tools/claude-code) — оба способа дают одинаковый эффект
