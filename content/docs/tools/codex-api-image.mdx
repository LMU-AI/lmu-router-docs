[api-image](https://github.com/yc-duan/api-image) 是个社区 Skill（MIT 协议）：API 模式下的 Codex App 没有内置 imagegen，装上它就能出图，走你自己配置的 OpenAI 兼容图片接口。接灵眸**零配置**——它直接复用你 `~/.codex` 里已有的密钥和接口地址，对话里说一句话就能出图。

<Callout type="warn" title="第三方社区 Skill">

它会在你本机运行、读取 `~/.codex/auth.json` 里的密钥，并把提示词与参考图发给 provider，装之前请自行确认可以接受。作者也说明不同 provider 兼容程度不同，遇到参数问题以实际报错为准。

</Callout>

---

## 安装：对 Codex 说一句话

打开 Codex App，直接说：

> 安装 https://github.com/yc-duan/api-image 这个 skill，我要用 OpenAI image 2 标准 API 做图，参考使用说明 https://github.com/yc-duan/api-image

Codex 会自己把仓库装进 `~/.codex/skills/api-image`（Windows 是 `%USERPROFILE%\.codex\skills\api-image`），装完**重开 Codex App** 生效。

想手动装也行：

```bash
git clone https://github.com/yc-duan/api-image.git ~/.codex/skills/api-image
```

## 用法：还是说一句话

| 你想要 | 就这样说 |
|------|------|
| 文生图 | 用 api-image 生成一张 2048x1152 的电影感照片：雨夜东京街头，霓虹反光，真实摄影风格 |
| 图生图 | 参考这张图的构图和人物姿势，生成一张暖色插画，保持主体姿态，不要照抄原图 |
| 局部编辑 | 把这张图里的红杯子改成绿色，保留原来的形状、构图和光线 |
| 指定参数 | 用 api-image 生成一张 1024x1024 的扁平插画，画质 low，出 2 张，保存到 ./public/cover.png |

默认就是 `gpt-image-2`、`2048x1152`、画质 high、一次 1 张；尺寸、画质、张数、输出路径都直接在对话里改。生成结果默认落在当前工作目录（`provider-image-<时间戳>.png`）。

---

## 注意

- **接灵眸无需改任何配置**：Skill 读的就是你接灵眸时配好的 `auth.json`（密钥）与 `config.toml`（接口地址），对应完整端点 `https://api.lmuai.com/v1/images/generations` 与 `/v1/images/edits`
- 报 `model_not_found` / 403：你的分组没开图片模型，去后台「可用模型」确认或换分组
- `gpt-image-2` 不支持透明背景；请求的尺寸上游可能归一化，以实际输出为准
