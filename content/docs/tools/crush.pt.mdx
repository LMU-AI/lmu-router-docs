Crush é uma ferramenta de codificação de IA de terminal da [Charm](https://charm.land), oferecendo tanto uma CLI quanto uma TUI para geração de código, depuração, conversação, operações de arquivos e multitarefa a partir da linha de comando. Ela suporta provedores personalizados — esta página cobre como conectá-la ao LMU AI.

## Configurar o LMU AI

O Crush é configurado com um **script Bash**. Edite o arquivo de configuração global:

- **macOS / Linux**: `~/.config/crush/crushrc`
- **Windows**: `%USERPROFILE%\.config\crush\crushrc`

Há duas etapas: adicionar o LMU AI como provedor com `provider add`, depois registrar os modelos que você deseja com `model add`. Escolha o protocolo que corresponde aos modelos que você planeja usar:

<Tabs items={['GPT / geral (openai-compat)', 'Claude / modelos chineses (anthropic)']}>
<Tab value="GPT / geral (openai-compat)">

Funciona para modelos OpenAI como `gpt-5.6-sol` e `gpt-5.5`. Claude e modelos chineses também podem passar por este protocolo (o backend do LMU AI lida com a conversão de protocolo).

```bash
# Add LMU AI as a provider (OpenAI-compatible protocol)
provider add lmuai \
  --type openai-compat \
  --base-url "https://api.lmuai.com/v1" \
  --api-key "sk-your-lmu-ai-api-key"

# Register the models you want
model add lmuai/gpt-5.6-sol --name "GPT-5.6 Sol" --context-window 400000
model add lmuai/claude-opus-5 --name "Claude Opus 5" --context-window 200000

# Set it as the default large-model slot
model large lmuai/claude-opus-5
```

<Callout type="warn" title="O tipo é openai-compat, não openai">

O Crush tem dois tipos OpenAI. De acordo com a documentação oficial, `openai` é para fazer proxy ou rotear solicitações **através do próprio OpenAI**, enquanto `openai-compat` é para **provedores não-OpenAI que oferecem APIs compatíveis com OpenAI**. O LMU AI é o último caso, então use `openai-compat`.

</Callout>

</Tab>
<Tab value="Claude / modelos chineses (anthropic)">

Funciona para modelos servidos pelo protocolo Anthropic, como `claude-opus-5`, `claude-sonnet-5`, `qwen3.8-max-preview`, `deepseek-v4-pro`, `glm-5.2` e `kimi-k3`.

```bash
# Add LMU AI as a provider (Anthropic protocol)
provider add lmuai-anthropic \
  --type anthropic \
  --base-url "https://api.lmuai.com" \
  --api-key "sk-your-lmu-ai-api-key" \
  --extra-header anthropic-version 2023-06-01

# Register the models you want
model add lmuai-anthropic/claude-opus-5 \
  --name "Claude Opus 5" \
  --context-window 200000 \
  --can-reason true \
  --supports-images true

model add lmuai-anthropic/glm-5.2 --name "GLM-5.2" --context-window 200000

# Set it as the default large-model slot
model large lmuai-anthropic/claude-opus-5
```

<Callout type="warn" title="Não adicione /v1 à URL base da Anthropic">

Defina `--base-url` como `https://api.lmuai.com` — **não** `https://api.lmuai.com/v1`. O Crush anexa `/v1/messages` por conta própria, então o segmento extra faz com que ele solicite `/v1/v1/messages`, o que falha com:

```
not found: POST "https://api.lmuai.com/v1/v1/messages": 404 Not Found
```

Isso é o oposto de `openai-compat` (que precisa de `/v1`) — não confunda os dois.

</Callout>

</Tab>
</Tabs>

<Callout type="warn" title="Arquivos de configuração são código confiável">

Um aviso oficial: `crushrc` roda com os privilégios do seu shell antes de a UI aparecer, e qualquer `$(...)` no `crush.json` roda no momento do carregamento. **Não inicie o Crush em um diretório cuja configuração você não tenha revisado**, e não faça `source` de arquivos de configuração de origem desconhecida.

</Callout>

## Começar a usar

Reinicie o Crush uma vez configurado:

```bash
crush
```

Alterne modelos dentro de uma sessão com:

```
/models
```

<Callout type="info" title="Modelos do LMU AI faltando em /models?">

A lista de modelos integrada do Crush vem do banco de dados [Catwalk](https://github.com/charmbracelet/catwalk), que não inclui os IDs de modelo do LMU AI. Você deve registrá-los com `model add <provider>/<model-id>` primeiro — eles aparecerão na lista `/models` após uma reinicialização.

</Callout>

## Configuração JSON legada

<Callout type="warn" title="crush.json está oficialmente descontinuado">

O Crush originalmente usava `crush.json`, que agora está **descontinuado** — os mantenedores disseram que continuarão a suportá-lo, mas novas opções de configuração serão adicionadas apenas à configuração Bash (`crushrc`). Muitos tutoriais ainda ensinam o formato JSON, mas **novas configurações devem usar o `crushrc` como mostrado acima**.

Já tem uma configuração JSON e quer migrar? Inicie o Crush e simplesmente peça a ele em linguagem natural para convertê-la para você.

</Callout>

Se você realmente quiser usar JSON, o formato se parece com isto (em um `crush.json` no diretório do seu projeto ou sob `~/.config/crush/`):

```json
{
  "$schema": "https://charm.land/crush.json",
  "providers": {
    "lmuai": {
      "id": "lmuai",
      "name": "LMU AI",
      "type": "openai-compat",
      "base_url": "https://api.lmuai.com/v1",
      "api_key": "sk-your-lmu-ai-api-key",
      "models": [
        {
          "id": "claude-opus-5",
          "name": "Claude Opus 5",
          "context_window": 200000,
          "default_max_tokens": 32000
        }
      ]
    }
  }
}
```

<Callout type="warn" title="Não omita type e models no JSON">

Apenas `id` / `name` / `base_url` / `api_key` não funcionará: `type` decide qual protocolo é usado (omiti-lo recorre a uma suposição padrão), e `models` decide o que você pode escolher em `/models`. Este é o motivo mais comum de um exemplo mínimo copiado e colado falhar.

</Callout>

## Notas

- O arquivo de configuração é `~/.config/crush/crushrc` (`%USERPROFILE%\.config\crush\crushrc` no Windows); `~/.local/share/crush/crush.json` é um estado gerenciado pela máquina — **não o edite**
- Use `--type openai-compat` para o endpoint compatível com OpenAI do LMU AI (**não** `openai`), e `--type anthropic` para o protocolo Anthropic
- **Os dois tipos assumem formas opostas de `--base-url`**: `anthropic` assume `https://api.lmuai.com` (sem `/v1`), enquanto `openai-compat` assume `https://api.lmuai.com/v1` (com `/v1`). Adicionar `/v1` no lado Anthropic produz `/v1/v1/messages` e um 404
- Para a chave da API, basta inserir a chave `sk-` gerada no console do LMU AI
- Os modelos do LMU AI não estão na lista integrada do Crush, então devem ser registrados com `model add` antes de aparecerem em `/models`
