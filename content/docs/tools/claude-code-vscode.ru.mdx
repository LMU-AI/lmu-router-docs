Официальное расширение VS Code **Claude Code for VS Code** позволяет использовать Claude Code прямо в боковой панели редактора, без переключения на терминал. Оно **использует один общий файл конфигурации** с CLI Claude Code, поэтому ключ / Base URL, которые вы настроили в CLI, работают в расширении напрямую — их не нужно настраивать заново.

<Callout type="info" title="Также работает с Cursor / Trae / Antigravity и другими редакторами">

Любой редактор, построенный на ядре VS Code (**Cursor, Trae, Antigravity** и др.), может **найти в своём встроенном магазине расширений то же расширение `Claude Code for VS Code`**, чтобы установить и настроить его — шаги точно такие же, как в VS Code.

Все скриншоты и команды на этой странице используют VS Code в качестве примера; пользователи Cursor / Trae / Antigravity могут следовать им как есть.

</Callout>

## Скачивание и установка VS Code

<Callout type="info" title="Используете Cursor / Trae / Antigravity?">

Это самостоятельные редакторы — скачайте правильный установщик с официального сайта каждого из них (а не VS Code), и после установки сразу переходите к следующему разделу — [Установка расширения](#install-the-extension) — магазин расширений и шаги установки те же, что и в VS Code.

</Callout>

Перейдите на [code.visualstudio.com](https://code.visualstudio.com/) и нажмите кнопку **Download**; сайт автоматически определит вашу ОС. Также можно использовать официальные прямые ссылки ниже (без номера версии, всегда указывают на последний стабильный релиз, посещать сайт заранее не нужно):

<Tabs items={['Windows', 'macOS', 'Linux']}>
<Tab value="Windows">

**Скачать**: [Windows User Installer (x64)](https://update.code.visualstudio.com/latest/win32-x64-user/stable) — не требует прав администратора, устанавливается в каталог текущего пользователя и является официальной рекомендацией. Для устройств ARM используйте [сборку ARM64](https://update.code.visualstudio.com/latest/win32-arm64-user/stable).

**Установка**:

1. Дважды щёлкните скачанный `VSCodeUserSetup-*.exe`
2. Нажимайте «Next» на шагах, а на этапе «Select Additional Tasks» **отметьте**:
   - «Add to PATH» (отмечено по умолчанию, оставьте) — позволяет терминалу использовать команду `code`
   - «Register Code as an editor for supported file types»
   - «Add 'Open with Code' action to the Windows Explorer context menu» (необязательно, но удобно)
3. По завершении запустите VS Code

</Tab>
<Tab value="macOS">

**Скачать**: [универсальная сборка для macOS](https://update.code.visualstudio.com/latest/darwin-universal/stable) — один пакет, поддерживающий чипы как Apple Silicon, так и Intel.

**Установка**:

1. Вы получите `VSCode-darwin-universal.zip`; дважды щёлкните, чтобы распаковать
2. Перетащите извлечённое **Visual Studio Code.app** в папку **Applications** в Finder
3. Откройте VS Code из Launchpad
4. (Рекомендуется) Нажмите `Cmd+Shift+P`, чтобы открыть палитру команд, и выполните **Shell Command: Install 'code' command in PATH**; после этого вы сможете открывать текущий каталог в терминале командой `code .`

</Tab>
<Tab value="Linux">

Выбирайте по дистрибутиву:

- **Debian / Ubuntu**: скачайте [пакет .deb](https://update.code.visualstudio.com/latest/linux-deb-x64/stable), затем `sudo apt install ./code_*.deb`
- **RHEL / Fedora / openSUSE**: скачайте [пакет .rpm](https://update.code.visualstudio.com/latest/linux-rpm-x64/stable), затем `sudo rpm -i code-*.rpm` (или `sudo dnf install code-*.rpm`)

Установка `.deb` / `.rpm` автоматически добавляет `code` в PATH и подключается к системным обновлениям ПО. После установки выполните `code` в терминале или запустите из меню приложений.

</Tab>
</Tabs>

<Callout type="info" title="Официальный сайт или скачивание медленное?">

Установщик весит 100–200 МБ, и однопоточные загрузки в браузере иногда бывают медленными в Китае. Скопировать **официальные прямые ссылки** выше в загрузчик с поддержкой многопоточности обычно намного быстрее — эти прямые ссылки не содержат номера версии и всегда указывают на последний стабильный релиз.

</Callout>

## Установка расширения

1. Откройте VS Code (или Cursor / Trae / Antigravity) и перейдите на панель расширений (сочетание `Cmd+Shift+X` / `Ctrl+Shift+X`)
2. Найдите **`Claude Code for VS Code`** и убедитесь, что это официальный релиз Anthropic
3. Нажмите **Install**; после установки в боковой панели появится значок Claude

<Callout type="warn" title="Примечание для Cursor / Trae / Antigravity">

Некоторые редакторы на основе VS Code используют приватный магазин расширений (например, Open VSX). Если вы не можете найти `Claude Code for VS Code`:

1. Перейдите на страницу официального магазина расширений VS Code и скачайте пакет `.vsix`
2. В меню `…` в правом верхнем углу панели расширений редактора выберите **Install from VSIX**

</Callout>

## Настройка LMU AI API

<Callout type="info" title="Если вы уже настроили CLI Claude Code, можете пропустить этот раздел">

Расширение читает `~/.claude/settings.json` точно так же, как CLI. **Ключ и Base URL, которые вы настроили в [конфигурации CLI Claude Code](/ru/docs/tools/claude-code), автоматически повторно используются расширением — никаких дополнительных шагов не требуется.**

Это также означает, что **VS Code, Cursor, Trae и Antigravity используют один и тот же конфиг** — измените его один раз в любом редакторе, и это применится к другим редакторам и к CLI.

</Callout>

Если вы настраиваете это впервые, создайте файл конфигурации следующим образом:

<Tabs items={['Mac/Linux', 'Windows']}>
<Tab value="Mac/Linux">

```bash
mkdir -p ~/.claude && touch ~/.claude/settings.json
```

</Tab>
<Tab value="Windows">

```powershell
mkdir "$env:USERPROFILE\.claude" -Force
New-Item "$env:USERPROFILE\.claude\settings.json" -Force
```

</Tab>
</Tabs>

Добавьте следующее (замените ключ на свой):

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.lmuai.com",
    "ANTHROPIC_AUTH_TOKEN": "sk-your-lmu-ai-api-key",
    "API_TIMEOUT_MS": "3000000",
    "CLAUDE_CODE_ATTRIBUTION_HEADER": "0"
  }
}
```

Подробности (включая настройки китайской модели по умолчанию, настройку `effortLevel` и другое) см. в [конфигурации CLI Claude Code](/ru/docs/tools/claude-code); **применимы все параметры конфигурации**.

## Запуск расширения

1. В редакторе нажмите `Cmd+Shift+P` / `Ctrl+Shift+P`, чтобы открыть палитру команд
2. Введите **`Claude Code: Open`** или просто щёлкните значок Claude в боковой панели
3. В открывшейся панели чата вы можете общаться с Claude Code, генерировать код и позволять ему автоматически редактировать файлы

<Callout type="info" title="Один конфиг, работает везде">

- Выполните `claude` в терминале → используйте CLI Claude Code
- Щёлкните значок Claude в боковой панели **VS Code / Cursor / Trae / Antigravity** → используйте расширение

**Они читают один и тот же `~/.claude/settings.json`**, поэтому ключ, Base URL, модель и настройки таймаута действуют везде при изменении в одном месте.

</Callout>

## Частые проблемы

### 401 / Unauthorized в расширении

Тот же подход, что и с CLI — обычно переменные окружения оболочки `ANTHROPIC_BASE_URL` / `ANTHROPIC_API_KEY` переопределяют `settings.json`. См. [Конфигурация CLI Claude Code → Частые проблемы](/ru/docs/tools/claude-code#common-issues) для устранения.

### Использование китайской модели / смена модели по умолчанию

Добавьте `"model": "qwen3.8-max-preview"` в `settings.json`, и CLI, а также все редакторы семейства VS Code будут автоматически использовать эту модель. Список доступных моделей см. в [Галерее моделей](/ru/docs/guide/models).

### Не удаётся найти расширение в Cursor / Trae / Antigravity

Следуйте изложенному ранее «Примечанию для Cursor / Trae / Antigravity» и установите офлайн через VSIX.

### Расширение или CLI — что выбрать?

- Предпочитаете писать код прямо в редакторе → используйте расширение, где весь контекст остаётся в редакторе
- Работа между редакторами, написание скриптов, пакетные задачи → используйте CLI, он более гибкий

**Ни одно из них функционально не превосходит другое** — выбирайте то, что вам подходит.
