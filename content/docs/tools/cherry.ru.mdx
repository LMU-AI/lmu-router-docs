Cherry Studio — это настольный ИИ-клиент для нескольких моделей.

---

## Загрузка и установка

- **Официальный сайт для настольных систем**: [https://www.cherry-ai.com/](https://www.cherry-ai.com/)
- **Мобильная версия (Android и iOS)**: [https://github.com/CherryHQ/cherry-studio-app/releases](https://github.com/CherryHQ/cherry-studio-app/releases)
  - Android: скачайте файл `.apk`
  - iOS: скачайте файл `.ipa`

Процесс установки на мобильном устройстве во многом похож на настольный — присмотритесь, и вы разберётесь.

---

## Два протокола

LMU AI поддерживает два протокола подключения; выберите один в зависимости от типа модели:

| Протокол | Модели |
|------|----------|
| **Anthropic** | Модели Claude, китайские модели (DeepSeek, Qwen и т. д.) |
| **OpenAI-Response** | Модели OpenAI (GPT-4, GPT-5 и т. д.) |

---

## Способ 1: протокол Anthropic (Claude и китайские модели)

### Шаг 1 — добавьте провайдера

Перейдите в Настройки Cherry Studio → нажмите «Добавить провайдера»:

1. **Имя провайдера**: любое на ваш выбор (например, `LMU AI`)
2. **Тип провайдера**: выберите **`Anthropic`** из выпадающего списка

![Добавление провайдера Anthropic](/images/tools/cherry-studio/c-studio-1.png)

### Шаг 2 — введите данные API

- **API Key**: введите ключ `sk-`, сгенерированный в консоли
- **API Host**: введите адрес запроса ретрансляции API

```
https://api.lmuai.com
```

Нажмите «Получить список моделей», чтобы получить доступные модели; серия Claude и китайские модели загрузятся автоматически.

![Настройка Anthropic завершена](/images/tools/cherry-studio/c-studio-2.png)

## Способ 2: протокол OpenAI-Response (модели OpenAI)

### Шаг 1 — добавьте провайдера

Перейдите в Настройки Cherry Studio → нажмите «Добавить провайдера»:

1. **Имя провайдера**: любое на ваш выбор (например, `LMU AI`)
2. **Тип провайдера**: выберите **`OpenAI-Response`** из выпадающего списка (второй вариант, а не первый OpenAI)

### Шаг 2 — введите данные API

- **API Key**: введите ключ `sk-`, сгенерированный в консоли
- **API Host**: введите адрес запроса ретрансляции API

```
https://api.lmuai.com
```

Нажмите «Получить список моделей», чтобы получить доступные модели; серия GPT загрузится автоматически.

![Настройка OpenAI-Response завершена](/images/tools/cherry-studio/c-studio-3.png)

После настройки вы можете выбрать и использовать модель на экране чата:

![Экран чата](/images/tools/cherry-studio/c-studio-4.png)

---

## Примечания

- Один и тот же API Key и API Host работают для обоих протоколов; просто добавьте двух провайдеров при необходимости
- Для типа OpenAI-Response обязательно выберите второй вариант, а не первый OpenAI
- Введите адрес ретрансляции API в качестве адреса API; не вводите официальный адрес OpenAI или Anthropic
