面向已经把 AI 调用接入到产品或内部流程的团队，我们提供独立于个人套餐的企业方案，覆盖 **Anthropic（Claude）** 与 **OpenAI（GPT）** 两大平台，共 **企业标准版 / 企业旗舰版** 两档、6 个 SKU。

## 我们解决的问题

如果你的团队遇到过以下任何一种情况，企业方案通常比个人套餐更合适：

- **波动影响生产**：模型调用偶发失败，需要自己在代码里写 fallback、重试、监控
- **额度结构不灵活**：日卡 / 周卡难以支撑团队多人多场景的并发需求
- **支持响应慢**：出问题时联系客服等好几个小时，业务停摆
- **缺合规材料**：财务要发票、法务要合同
- **没有可见性**：不知道每个项目花了多少 token、谁在跑什么、成本怎么分摊

## 企业档共有的能力

无论选哪一档，所有企业套餐都包含：

| 能力 | 说明 |
|------|------|
| **多源路由 + 自动故障转移** | 详见 [稳定性架构](/docs/guide/reliability) |
| **99.5% 可用性目标 + 月度报告** | 企业档承诺 99.5% 可用性目标并提供月度可用性报告，详见 [SLA 章节](/docs/guide/reliability#服务等级sla) |
| **使用明细 API** | 通过 [/api/v1/usage 接口](/docs/api/usage-export) 自动化拉取调用明细、token 消耗与费用 |
| **零内容留存** | 不持久化 prompt 与响应内容，详见 [数据与隐私](/docs/guide/privacy) |
| **合同与发票** | 支持签订采购合同、开具增值税发票 |
| **一把 Key 通调多平台** | 可调用的模型由 API Key 所属分组决定，与协议无关，详见 [接入协议](/docs/guide/api-protocols) |

> 更高的 SLA 与赔付条款可与商务约定，具体以合同为准。

## 我们不卖什么

为了不浪费你的时间，以下需求**不在我们当前的服务范围内**：

- 用于训练自有大模型的批量数据请求（请直接联系模型提供方）
- 涉政、涉黄、涉赌、涉诈骗内容的 API 调用
- 任何要求规避模型提供方使用条款的方案

## 常见问题

<Callout type="info" title="企业档和个人套餐能并存吗？">

可以。同一账号下可同时持有多个套餐，调用时按 API Key 所属分组路由，详见 [API 协议 · 协议和可用模型是两件事](/docs/guide/api-protocols#协议和可用模型是两件事)。

</Callout>

<Callout type="info" title="可以混用 Claude 和 GPT 吗？">

一把 API Key 能调哪些模型由所属分组决定：如果你订购了 Anthropic 平台的 SKU，就能调用 Claude 系模型；订购了 OpenAI 平台的 SKU，就能调用 GPT 系模型。两个平台同时需要时可分别订购对应 SKU。

</Callout>

<Callout type="info" title="更高的 SLA 或赔付条款怎么谈？">

企业档默认的 99.5% 可用性目标之上，如需更高 SLA 或明确赔付条款，请通过商务对接约定，具体以合同为准。

</Callout>
